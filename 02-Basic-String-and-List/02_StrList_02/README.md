## ลิสต์และดัชนี

ลิสต์ (`list`) ใช้เก็บข้อมูลหลายค่าโดยเรียงตามลำดับ
โจทย์ข้อนี้สร้างลิสต์ `NUMBERS` ซึ่งเก็บคำอ่านภาษาอังกฤษตั้งแต่ `"zero"`
ถึง `"nine"` ตามลำดับ

ดัชนีของลิสต์ใน Python เริ่มจาก `0` ตำแหน่งของคำอ่านจึงตรงกับตัวเลขพอดี

| ตัวเลข | ดัชนี | ค่าที่ตำแหน่งนั้น |
| :----: | :---: | :---------------: |
| `0` | `0` | `"zero"` |
| `1` | `1` | `"one"` |
| `2` | `2` | `"two"` |
| `3` | `3` | `"three"` |
| `4` | `4` | `"four"` |
| `5` | `5` | `"five"` |
| `6` | `6` | `"six"` |
| `7` | `7` | `"seven"` |
| `8` | `8` | `"eight"` |
| `9` | `9` | `"nine"` |

---

## การจับคู่ตัวเลขกับคำอ่าน

`input()` คืนค่าเป็นข้อความ แต่ดัชนีของลิสต์ต้องเป็นจำนวนเต็ม
โปรแกรมจึงแปลงข้อมูลด้วย `int()` ก่อน

```python
num = int(input())
```

เมื่อข้อมูลนำเข้าอยู่ในช่วง `0` ถึง `9` เราสามารถใช้ `num`
เป็นดัชนีเพื่อเลือกคำอ่านได้โดยตรง

```python
NUMBERS[num]
```

ตัวอย่างเช่น ถ้า `num` เท่ากับ `5` นิพจน์ `NUMBERS[5]`
จะได้ข้อความ `"five"`

---

## การจัดรูปแบบผลลัพธ์

โจทย์ตัวอย่างกำหนดให้ผลลัพธ์มีทั้งตัวเลข เครื่องหมายลูกศร และคำอ่าน
โปรแกรมใช้ f-string เพื่อนำค่าทั้งหมดมาต่อกันในรูปแบบเดียวกัน

```python
f"{num} --> {NUMBERS[num]}"
```

ต้องมีช่องว่างหนึ่งช่องทั้งก่อนและหลัง `-->` เช่น เมื่อรับ `5` โปรแกรมจะแสดง

```text
5 --> five
```

แม้คำอธิบายข้อมูลส่งออกในโจทย์จะกล่าวถึงคำอ่านภาษาอังกฤษ
แต่ตัวอย่างของโจทย์ระบุรูปแบบเต็มดังกล่าว และโค้ดจึงแสดงผลตามตัวอย่างนี้

# Solution

```python
# --------------------------------------------------
# File Name : 02_StrList_02.py
# Problem   : Arabic Numerals
# Author    : Worralop Srichainont
# Date      : 2025-06-10
# --------------------------------------------------

# List of string representations of numbers from 0 to 9
NUMBERS = [
    "zero",
    "one",
    "two",
    "three",
    "four",
    "five",
    "six",
    "seven",
    "eight",
    "nine",
]

# Input a number (0-9)
num = int(input())

# Output the number and its string representation
print(f"{num} --> {NUMBERS[num]}")
```
