## ลิสต์และดัชนี

ลิสต์ช่วยเก็บข้อมูลหลายค่าไว้ในตัวแปรเดียว และเรียงค่าเหล่านั้นตามลำดับ
โจทย์ข้อนี้สร้างลิสต์ `NUMBERS` เพื่อเก็บคำอ่านภาษาอังกฤษของเลข `0` ถึง `9`

```python
NUMBERS = [
    "zero", "one", "two", "three", "four",
    "five", "six", "seven", "eight", "nine",
]
```

ดัชนีของลิสต์ใน Python เริ่มจาก `0` จึงทำให้ตำแหน่งของคำอ่านตรงกับค่าของตัวเลขพอดี
ตัวอย่างเช่น

-   `NUMBERS[0]` มีค่าเป็น `"zero"`
-   `NUMBERS[5]` มีค่าเป็น `"five"`
-   `NUMBERS[9]` มีค่าเป็น `"nine"`

ดังนั้นเมื่อทราบตัวเลขแล้ว เราสามารถใช้ตัวเลขนั้นเป็นดัชนีเพื่อเลือกคำอ่านได้ทันที

---

## การแปลงค่าให้เป็นดัชนี

ฟังก์ชันใช้คำสั่ง `int(num)` เพื่อแปลงค่าที่ได้รับให้เป็นจำนวนเต็มก่อนนำไปเป็นดัชนี
ภายใต้ข้อมูลที่โจทย์กำหนด ค่า `"5"`, `5` และ `5.0` จึงเลือกสมาชิกตำแหน่งเดียวกัน

| ค่า `num` | ค่า `int(num)` | สมาชิกที่เลือก | ค่าที่ส่งกลับ |
|---|---:|---|---|
| `"5"` | `5` | `NUMBERS[5]` | `"five"` |
| `5` | `5` | `NUMBERS[5]` | `"five"` |
| `5.0` | `5` | `NUMBERS[5]` | `"five"` |

นิพจน์ทั้งขั้นตอนจึงเขียนสั้น ๆ ได้เป็น

```python
NUMBERS[int(num)]
```

เมื่อ `num` เป็น `0` จะเลือกคำแรกคือ `"zero"` และเมื่อ `num` เป็น `9`
จะเลือกคำสุดท้ายคือ `"nine"`

---

## ขั้นตอนการทำงานของฟังก์ชัน

ฟังก์ชัน `number_name(num)` ทำงานตามลำดับดังนี้

1. รับค่าตัวเลข `0` ถึง `9` ผ่านพารามิเตอร์ `num`
2. ใช้ `int(num)` แปลงค่าให้พร้อมใช้เป็นดัชนี
3. เข้าถึงคำอ่านที่ตำแหน่ง `NUMBERS[int(num)]`
4. ส่งคำอ่านนั้นกลับด้วย `return`

ฟังก์ชันนี้ส่งกลับค่าเป็น `str` และไม่ได้เรียก `print()` ภายในฟังก์ชัน
เช่น `number_name(9.0)` ส่งกลับ `"nine"` ผู้เรียกฟังก์ชันจะเป็นผู้ตัดสินใจเองว่า
จะเก็บคำอ่านไว้ใช้งานต่อหรือแสดงผลออกทางหน้าจอ

---

## การรับคำสั่งจาก Grader

หลังประกาศลิสต์และฟังก์ชันเรียบร้อยแล้ว โปรแกรมใช้ `exec(input())`
เพื่อรับคำสั่ง Python จาก Grader เช่น `print(number_name("5"))`
คำสั่งนี้เรียก `number_name()` แล้วแสดงผล `five`

การให้ Grader เป็นผู้ส่งคำสั่งเข้ามาช่วยให้ทดสอบฟังก์ชันด้วยชนิดข้อมูลตามที่โจทย์กำหนดได้
หลายกรณี โดยไม่ต้องเขียนคำสั่งเรียกฟังก์ชันตายตัวไว้ในโปรแกรม

> [!WARNING]
>
> ใช้ `exec()` ในข้อนี้ได้เพราะคำสั่งมาจาก Grader ที่เชื่อถือได้เท่านั้น
> ไม่ควรใช้ `exec()` กับข้อความจากผู้ใช้หรือแหล่งที่ไม่น่าเชื่อถือ
> เพราะข้อความนั้นอาจสั่งให้ Python รันโค้ดที่เป็นอันตรายได้

# Solution

```python
# --------------------------------------------------
# File Name : 02_StrList_F02.py
# Problem   : Arabic Numerals (Function)
# Author    : Worralop Srichainont
# Date      : 2025-06-10
# --------------------------------------------------

# List of string representations of numbers from 0 to 9
NUMBERS = [
    "zero",
    "one",
    "two",
    "three",
    "four",
    "five",
    "six",
    "seven",
    "eight",
    "nine",
]


# Function to convert a number to its string representation
def number_name(num):
    return NUMBERS[int(num)]


# Execute the input string as code
exec(input())
```
