## การบวกเวกเตอร์ทีละองค์ประกอบ

การบวกเวกเตอร์สามมิติต้องนำสมาชิกที่อยู่ในตำแหน่งเดียวกันมาบวกกัน
กำหนดให้

$$
\mathbf{u} = [u_1,u_2,u_3]
\qquad\text{และ}\qquad
\mathbf{v} = [v_1,v_2,v_3]
$$

ผลบวกของเวกเตอร์ทั้งสองคือ

$$
\mathbf{u} + \mathbf{v}
= [u_1+v_1,\;u_2+v_2,\;u_3+v_3]
$$

แนวคิดนี้ตรงกับการบวกค่าใน Python ตามดัชนี

| องค์ประกอบของผลลัพธ์ | นิพจน์ใน Python |
|---|---|
| ตำแหน่งที่ 1 | `float(u[0]) + float(v[0])` |
| ตำแหน่งที่ 2 | `float(u[1]) + float(v[1])` |
| ตำแหน่งที่ 3 | `float(u[2]) + float(v[2])` |

---

## การแทนเวกเตอร์ด้วยลิสต์

ฟังก์ชันรับเวกเตอร์ `u` และ `v` ในรูปลิสต์ที่มีสมาชิกอย่างละ 3 ค่า
สมาชิกตำแหน่งแรกใช้ดัชนี `0` ตำแหน่งถัดไปใช้ดัชนี `1` และตำแหน่งสุดท้ายใช้ดัชนี
`2`

โปรแกรมสร้างลิสต์ใหม่ชื่อ `total` สำหรับเก็บคำตอบ

```python
total = [0.0, 0.0, 0.0]
```

จากนั้นจึงแทนค่าทั้งสามตำแหน่งด้วยผลบวกที่คำนวณได้ การสร้างลิสต์ผลลัพธ์แยกต่างหาก
ทำให้ฟังก์ชันไม่แก้สมาชิกเดิมภายใน `u` หรือ `v`

การเขียน `u + v` โดยตรงไม่ใช่การบวกเวกเตอร์ เพราะเครื่องหมาย `+` ระหว่างลิสต์
หมายถึงการนำลิสต์มาต่อกัน เช่น `[1, 2, 3] + [4, 5, 6]` จะได้ลิสต์ที่มี 6
สมาชิก ฟังก์ชันจึงต้องบวกสมาชิกทีละตำแหน่ง

---

## ขั้นตอนการทำงานของฟังก์ชัน

ฟังก์ชัน `add_vector(u, v)` ทำงานตามลำดับดังนี้

1. สร้าง `total = [0.0, 0.0, 0.0]` เพื่อเตรียมพื้นที่สำหรับคำตอบสามตำแหน่ง
2. แปลง `u[0]` และ `v[0]` เป็น `float` บวกกัน แล้วเก็บใน `total[0]`
3. ทำแบบเดียวกันกับสมาชิกดัชนี `1` และ `2`
4. ส่งลิสต์ `total` กลับด้วย `return`

ตัวอย่างเช่น

```python
add_vector([1, -2, 0.5], [3, 2, -0.5])
```

ฟังก์ชันจะส่งกลับ `[4.0, 0.0, 0.0]` โดยสมาชิกตำแหน่งที่ 2 และ 3
แสดงกรณีที่จำนวนบวกกับจำนวนลบแล้วหักล้างกันพอดี

---

## ชนิดข้อมูลและเลขทศนิยม

ก่อนบวกแต่ละองค์ประกอบ โปรแกรมเรียก `float()` กับค่าจากทั้งสองเวกเตอร์
ผลบวกทุกตำแหน่งจึงเป็นเลขชนิด `float` แม้ค่าตั้งต้นจะเป็นจำนวนเต็ม เช่น `1 + 3`
ในฟังก์ชันนี้จะได้ `4.0`

โค้ดไม่มีการเรียก `round()` และไม่มีการกำหนดจำนวนตำแหน่งทศนิยม
ค่าที่ส่งกลับจึงเป็นค่าของ `float` ตามปกติของ Python ตัวอย่างเช่น
`0.1 + 0.2` อาจปรากฏเป็น `0.30000000000000004` เนื่องจากคอมพิวเตอร์เก็บเลขทศนิยม
บางค่าในระบบฐานสองได้ไม่พอดี ฟังก์ชันจะเก็บและส่งค่านั้นกลับโดยไม่ตัดหรือปัดเศษ

## การรับคำสั่งจาก Grader

บรรทัด `exec(input())` รับคำสั่ง Python จาก Grader แล้วประมวลผลคำสั่งนั้น
เช่น `print(add_vector([1, 2, 3], [4, 5, 6]))` จะเรียกฟังก์ชันและแสดงผล
`[5.0, 7.0, 9.0]`

ฟังก์ชันมีหน้าที่ส่งลิสต์คำตอบกลับด้วย `return` ส่วนคำสั่งจาก Grader
เป็นผู้กำหนดว่าจะนำผลลัพธ์ไปแสดงหรือใช้งานอย่างไร

> [!WARNING]
>
> ใช้ `exec()` ในข้อนี้ได้เพราะคำสั่งมาจาก Grader ที่เชื่อถือได้เท่านั้น
> ไม่ควรใช้ `exec()` กับข้อความจากผู้ใช้หรือแหล่งที่ไม่น่าเชื่อถือ
> เพราะข้อความนั้นอาจสั่งให้ Python รันโค้ดที่เป็นอันตรายได้

# Solution

```python
# --------------------------------------------------
# File Name : 02_StrList_F06.py
# Problem   : Add Vector (Function)
# Author    : Worralop Srichainont
# Date      : 2025-06-10
# --------------------------------------------------


# Create a function to add two vectors
def add_vector(u, v):
    total = [0.0, 0.0, 0.0]
    total[0] = float(u[0]) + float(v[0])
    total[1] = float(u[1]) + float(v[1])
    total[2] = float(u[2]) + float(v[2])
    return total


# Execute the input string as code
exec(input())
```
