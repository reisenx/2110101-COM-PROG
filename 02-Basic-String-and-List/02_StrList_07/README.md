## ตำแหน่งในโจทย์กับดัชนีของ Python

โจทย์เรียกตัวเลขซ้ายสุดว่า **หลักที่ 1** แต่ดัชนีของข้อความใน Python
เริ่มจาก `0` จึงต้องลบตำแหน่งในโจทย์ออก `1` ก่อนนำมาใช้เป็นดัชนี

| ตำแหน่งตามโจทย์ | ดัชนีใน Python |
|---|---|
| `4, 11, 18, 25, 32` | `3, 10, 17, 24, 31` |
| `8, 13, 18, 23, 28` | `7, 12, 17, 22, 27` |

โปรแกรมเก็บข้อมูล 32 หลักเป็น `str` แทนการแปลงทั้งก้อนเป็นจำนวนเต็ม
จึงเลือกตัวเลขตามตำแหน่งได้โดยตรง และเลข `0` ที่อยู่ด้านหน้าก็ไม่หายไป

## การเลือกตัวเลขด้วย Slicing

รูปแบบการตัดข้อความคือ `ข้อความ[start:stop:step]` โดย `start` คือดัชนีเริ่มต้น
และ `step` คือระยะที่เลื่อนไปในแต่ละครั้ง ถ้าเว้น `stop` ไว้ Python
จะเลือกต่อไปจนถึงท้ายข้อความ

-   `num[3::7]` เริ่มที่ดัชนี `3` แล้วเลื่อนไปครั้งละ `7`
    จึงได้ดัชนี `3, 10, 17, 24, 31`
-   `num[7::5]` เริ่มที่ดัชนี `7` แล้วเลื่อนไปครั้งละ `5`
    จึงได้ดัชนี `7, 12, 17, 22, 27`

ตัวเลขที่เลือกได้ยังเป็นข้อความและถูกเขียนติดกันอยู่ จากนั้น `int()`
จึงแปลงข้อความแต่ละชุดให้เป็นจำนวนเต็มสำหรับนำไปบวก

อีกส่วนหนึ่งของโปรแกรมใช้ `step3[-4:-1]` ดัชนีติดลบนับจากด้านขวา
โดย `-1` หมายถึงหลักหน่วย และตำแหน่ง `stop` จะไม่ถูกรวมอยู่ในผลลัพธ์
slice นี้จึงเลือกหลักพัน หลักร้อย และหลักสิบ โดยไม่เลือกหลักหน่วย

คำว่า “สามหลักตรงกลาง” ในขั้นตอนนี้จึงหมายถึงสามหลักดังกล่าวเมื่อมองจาก
ด้านขวาของผลรวม แม้ผลรวมจะมี 6 หลัก `[-4:-1]` ก็ยังเลือกหลักพัน
หลักร้อย และหลักสิบได้ถูกต้อง

## ขั้นตอนการถอดรหัส

ลองติดตามข้อมูลตัวอย่าง
`92813912398100282033745980018127` ทีละขั้นตอน

1. `num[3::7]` ได้ข้อความ `18087` แล้วแปลงเป็นจำนวนเต็ม `18087`
2. `num[7::5]` ได้ข้อความ `20051` แล้วแปลงเป็นจำนวนเต็ม `20051`
3. นำสองจำนวนมาบวกกันและบวก `10000` ได้
   $18087 + 20051 + 10000 = 48138$ จากนั้นเก็บเป็นข้อความ `"48138"`
4. `step3[-4:-1]` เลือกหลักพัน หลักร้อย และหลักสิบ ได้ `"813"`
5. บวกตัวเลขทั้งสามได้ $8 + 1 + 3 = 12$ แล้วคำนวณ
   `(12 % 10) + 1` ได้ `3` เครื่องหมาย `% 10` เลือกหลักหน่วยก่อนบวก `1`
6. ค่า `3` ต้องแทนด้วยตัวอักษรลำดับที่ 3 คือ `C` เนื่องจากดัชนีเริ่มที่ `0`
   โปรแกรมจึงใช้ `ALPHABET[step5 - 1]` หรือ `ALPHABET[2]`
7. f-string เชื่อม `"813"` กับ `"C"` และแสดงผลเป็น `813C`

หลังใช้ `% 10` แล้วบวก `1` ค่าในขั้นตอนที่ 5 จะอยู่ระหว่าง `1` ถึง `10`
พอดีกับตัวอักษร `A` ถึง `J` ทั้งสิบตัว ส่วนกรณีที่สามหลักจากขั้นตอนที่ 4
มีเลขศูนย์นำหน้า เลขศูนย์นั้นยังคงอยู่ เพราะ `step4` เป็นข้อความ เช่น
ผลจาก `10000` จะเลือกได้ `"000"` ไม่ใช่จำนวนเต็ม `0`

# Solution

```python
# --------------------------------------------------
# File Name : 02_StrList_07.py
# Problem   : Decryption
# Author    : Worralop Srichainont
# Date      : 2025-06-10
# --------------------------------------------------

# Input a string of numbers
num = input().strip()

# Step 1: Concatenate the numbers at indices 3, 10, 17, 24, and 31
#         and convert them to an integer.
step1 = int(num[3::7])

# Step 2: Concatenate the numbers at indices 7, 12, 17, 22, and 27
#         and convert them to an integer.
step2 = int(num[7::5])

# Step 3: Add the results from Step 1 and Step 2, then add 10000
#         and convert the result to a string.
step3 = str(step1 + step2 + 10000)

# Step 4: Take the middle three digits from the result of Step 3
step4 = step3[-4:-1]

# Step 5: Calculate the sum of the digits in Step 4,
#         choose the last digit, and add 1.
step5 = int(step4[0]) + int(step4[1]) + int(step4[2])
step5 = (step5 % 10) + 1

# Step 6: Use the result from Step 5 to select a letter from the alphabet
ALPHABET = "ABCDEFGHIJ"
step6 = ALPHABET[step5 - 1]

# Step 7: Output the final result by concatenating Step 4 and Step 6
print(f"{step4}{step6}")
```
