## การเข้าถึงตัวเลขในสตริง

ฟังก์ชัน `check_digit(citizen_id)` รับเลขประจำตัว 12 หลักแรกมาเป็น `str`
การเก็บข้อมูลนี้เป็นข้อความสำคัญ เพราะเลขประจำตัวเป็นรหัส ไม่ใช่จำนวนที่นำไปคำนวณทั้งก้อน
และอาจขึ้นต้นด้วยเลขศูนย์ได้ เช่น `"012345678901"` หากเก็บเป็น `int`
เลขศูนย์ด้านหน้าจะหายไปทันที

เราสามารถเข้าถึงตัวอักษรแต่ละตัวในสตริงด้วยดัชนี โดยดัชนีของ Python เริ่มจาก `0`
ดังนั้นหลักที่ 1 ถึงหลักที่ 12 ในโจทย์ จึงตรงกับ `citizen_id[0]` ถึง
`citizen_id[11]` ตามลำดับ

ค่าที่หยิบออกมาจากสตริงยังเป็นข้อความ เช่น `citizen_id[0]` อาจมีค่าเป็น `"1"`
โปรแกรมจึงใช้ `int(citizen_id[0])` เพื่อแปลงเป็นจำนวนเต็มก่อนนำไปคูณ

## การคำนวณ Check Digit

กำหนดให้เลขประจำตัว 12 หลักแรกเป็น $d_1, d_2, \ldots, d_{12}$
ขั้นแรกต้องหาผลรวมแบบถ่วงน้ำหนัก

$$
S = 13d_1 + 12d_2 + 11d_3 + \cdots + 3d_{11} + 2d_{12}
$$

น้ำหนักเริ่มจาก `13` แล้วลดลงทีละ `1` จนถึง `2` ซึ่งตรงกับนิพจน์ใน Python
ตั้งแต่ `13 * int(citizen_id[0])` ไปจนถึง
`2 * int(citizen_id[11])` ผลรวมทั้งหมดถูกเก็บไว้ในตัวแปร `val`

จากนั้นคำนวณเลขหลักตรวจสอบด้วยสูตร

$$
\text{check digit} = (11 - (S \bmod 11)) \bmod 10
$$

ซึ่งเขียนใน Python ได้ตรงตัวเป็น

```python
last_digit = (11 - (val % 11)) % 10
```

เครื่องหมาย `%` ใช้หาเศษจากการหาร โดย `% 11` ตัวแรกหาเศษของผลรวมเมื่อหารด้วย
`11` ส่วน `% 10` ตัวสุดท้ายทำให้คำตอบเหลือเพียงหนึ่งหลักตั้งแต่ `0` ถึง `9`

ตัวอย่างเช่น สำหรับ `citizen_id = "123456789012"` จะคำนวณได้ `val = 352`
ดังนั้น `352 % 11` เท่ากับ `0` และเลขหลักตรวจสอบคือ `(11 - 0) % 10`
ซึ่งเท่ากับ `1`

## ขั้นตอนการทำงานของฟังก์ชัน

การทำงานของ `check_digit()` สรุปได้ดังนี้

1. รับสตริงเลขประจำตัว 12 หลักผ่านพารามิเตอร์ `citizen_id`
2. แปลงตัวเลขแต่ละหลักเป็น `int` คูณด้วยน้ำหนักประจำหลัก แล้วรวมไว้ใน `val`
3. นำ `val` ไปเข้าสูตรและเก็บผลไว้ใน `last_digit`
4. ส่งเลขหลักตรวจสอบกลับด้วย `return last_digit`

`return` ต่างจาก `print()` ตรงที่ `return` ส่งค่ากลับไปยังจุดที่เรียกฟังก์ชัน
โดยไม่ได้แสดงผลเอง ค่าที่ฟังก์ชันนี้ส่งกลับเป็น `int` เช่น
`check_digit("123456789012")` ส่งกลับค่า `1` ผู้เรียกจึงสามารถนำค่านี้ไปเก็บในตัวแปร
คำนวณต่อ หรือส่งให้ `print()` แสดงผลได้

## การรับคำสั่งจาก Grader

บรรทัด `exec(input())` อ่านคำสั่ง Python หนึ่งบรรทัดที่ Grader ส่งเข้ามา
แล้วสั่งให้ Python ประมวลผลคำสั่งนั้น เช่น หากได้รับ
`print(check_digit("123456789012"))` โปรแกรมจะเรียกฟังก์ชันและแสดงผล `1`

รูปแบบนี้ช่วยให้ Grader เรียกฟังก์ชันด้วยชุดทดสอบหลายแบบได้ โดยโค้ดของเรามีหน้าที่ประกาศ
`check_digit()` ให้พร้อมใช้งานก่อนถึงบรรทัดดังกล่าว

> [!WARNING]
>
> ใช้ `exec()` ในข้อนี้ได้เพราะคำสั่งมาจาก Grader ที่เชื่อถือได้เท่านั้น
> ไม่ควรใช้ `exec()` กับข้อความจากผู้ใช้หรือแหล่งที่ไม่น่าเชื่อถือ
> เพราะข้อความนั้นอาจสั่งให้ Python รันโค้ดที่เป็นอันตรายได้

# Solution

```python
# --------------------------------------------------
# File Name : 02_StrList_F01.py
# Problem   : Citizen ID (Function)
# Author    : Worralop Srichainont
# Date      : 2025-06-10
# --------------------------------------------------


# Create a function to calculate the last digit of a citizen ID
def check_digit(citizen_id):
    val = (
        13 * int(citizen_id[0])
        + 12 * int(citizen_id[1])
        + 11 * int(citizen_id[2])
        + 10 * int(citizen_id[3])
        + 9 * int(citizen_id[4])
        + 8 * int(citizen_id[5])
        + 7 * int(citizen_id[6])
        + 6 * int(citizen_id[7])
        + 5 * int(citizen_id[8])
        + 4 * int(citizen_id[9])
        + 3 * int(citizen_id[10])
        + 2 * int(citizen_id[11])
    )
    last_digit = (11 - (val % 11)) % 10
    return last_digit


# Execute the input string as code
exec(input())
```
