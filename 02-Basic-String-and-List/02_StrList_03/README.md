## การแยกข้อมูลวันที่

ข้อมูลนำเข้าอยู่ในรูป `เลขวัน/เลขเดือน/เลขปี` เช่น `12/1/2019`
โปรแกรมรับข้อมูลเป็นข้อความและใช้ `.strip()` ตัดช่องว่างที่อาจอยู่บริเวณหัวหรือท้าย

```python
date = input().strip()
```

เมธอด `.split("/")` แบ่งข้อความทุกตำแหน่งที่พบเครื่องหมาย `/`
สำหรับข้อมูลตัวอย่างจะได้ลิสต์ดังนี้

```python
"12/1/2019".split("/")  # ได้ ["12", "1", "2019"]
```

จากนั้น Python กระจายสมาชิกทั้งสามค่าไปยังตัวแปรตามลำดับ

```python
d, m, y = date.split("/")
```

จึงได้ `d = "12"`, `m = "1"` และ `y = "2019"`
ค่าทั้งสามยังเป็น `str` เพราะการแยกข้อความไม่ได้แปลงชนิดข้อมูล

## การแปลงเลขเดือนเป็นชื่อเดือน

ลิสต์ `MONTH` เก็บชื่อเดือนภาษาอังกฤษเรียงจาก `"January"` ถึง
`"December"` แต่เลขเดือนเริ่มจาก `1` ขณะที่ดัชนีของลิสต์เริ่มจาก `0`
จึงต้องลบ `1` ก่อนนำไปเป็นดัชนี

```python
MONTH[int(m) - 1]
```

ตัวอย่างเช่น เดือน `1` ถูกแปลงเป็นดัชนี `0` จึงเลือก `"January"`
ส่วนเดือน `12` ถูกแปลงเป็นดัชนี `11` จึงเลือก `"December"`
มีเพียง `m` ที่ต้องแปลงเป็น `int` เพื่อใช้เป็นดัชนี

## การจัดรูปแบบผลลัพธ์

ผลลัพธ์ต้องเรียงเป็น `ชื่อเดือน เลขวัน, เลขปี` โปรแกรมจึงใช้ f-string
วางชื่อเดือนก่อน ตามด้วยช่องว่าง วัน เครื่องหมายจุลภาค ช่องว่าง และปี

```python
f"{MONTH[int(m) - 1]} {d}, {y}"
```

เมื่อรับ `12/1/2019` จึงได้

```text
January 12, 2019
```

> [!NOTE]
>
> ความเห็นในโค้ดเขียนรูปแบบย่อว่า `DD/MM/YYYY` แต่โจทย์และตัวอย่าง
> ไม่ได้กำหนดว่าทุกส่วนต้องมีความกว้างคงที่ โค้ดเก็บ `d` และ `y`
> เป็นข้อความ จึงแสดงเลขวันและเลขปีตามที่รับมาโดยไม่เติมหรือตัดเลข `0`

# Solution

```python
# --------------------------------------------------
# File Name : 02_StrList_03.py
# Problem   : US Date
# Author    : Worralop Srichainont
# Date      : 2025-06-10
# --------------------------------------------------

# List of month names in English
MONTH = [
    "January",
    "February",
    "March",
    "April",
    "May",
    "June",
    "July",
    "August",
    "September",
    "October",
    "November",
    "December",
]

# Input a date in the format DD/MM/YYYY
date = input().strip()

# Split the input date into day, month, and year
d, m, y = date.split("/")

# Output the date in the format "Month Day, Year"
print(f"{MONTH[int(m) - 1]} {d}, {y}")
```
