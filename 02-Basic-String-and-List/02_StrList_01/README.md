## การเก็บเลขประจำตัวเป็นข้อความ

ข้อมูลนำเข้าเป็นเลขประจำตัว 12 หลักแรก แต่โปรแกรมเก็บข้อมูลนี้เป็น `str`
แทนที่จะเป็น `int` เพราะเราไม่ได้ต้องการนำเลขทั้งชุดไปคำนวณพร้อมกัน
เราต้องการเข้าถึงตัวเลขแต่ละหลักตามตำแหน่ง และต้องรักษาเลข `0`
ที่อาจอยู่ด้านหน้าเอาไว้ด้วย

```python
citizen_id = input().strip()
```

`input()` รับข้อมูลเป็นข้อความอยู่แล้ว ส่วน `.strip()` ตัดช่องว่างและอักขระขึ้นบรรทัดใหม่
ที่อาจติดอยู่บริเวณหัวหรือท้ายข้อมูลออก

ดัชนีของข้อความใน Python เริ่มนับจาก `0` ดังนั้น
`citizen_id[0]` คือหลักแรก และ `citizen_id[11]` คือหลักที่ 12
ค่าที่ได้จากการใช้ดัชนียังคงเป็นข้อความหนึ่งตัวอักษร เช่น `"3"`
จึงต้องแปลงด้วย `int()` ก่อนนำไปคูณในสูตร

## การคำนวณ Check Digit

ให้ตัวเลข 12 หลักแรกจากซ้ายไปขวาเป็น
$n_0, n_1, \ldots, n_{11}$ ขั้นแรกคำนวณผลรวมถ่วงน้ำหนัก

$$
S = 13n_0 + 12n_1 + 11n_2 + \cdots + 3n_{10} + 2n_{11}
$$

น้ำหนักจึงลดลงจาก `13` ถึง `2` ตามลำดับ โค้ดแปลงตัวอักษรแต่ละหลักเป็น
`int` แล้วคูณด้วยน้ำหนักของตำแหน่งนั้น เช่น
`13 * int(citizen_id[0])` และ `2 * int(citizen_id[11])`

จากนั้นหา check digit ด้วยสูตร

$$
n_{12} = \bigl(11 - (S \bmod 11)\bigr) \bmod 10
$$

ซึ่งตรงกับนิพจน์ Python ดังนี้

```python
(11 - (last_digit % 11)) % 10
```

ตัวดำเนินการ `%` ใช้หาเศษจากการหาร ในการกำหนดค่าให้ `last_digit`
ครั้งแรก ตัวแปรนี้ยังเก็บผลรวม $S$ อยู่ ยังไม่ใช่ check digit
เมื่อบรรทัดถัดไปทำงานจึงคำนวณตามสูตรและเขียนทับด้วย check digit จริง

ตัวอย่างข้อมูล `123456789012` จะได้ผลรวมถ่วงน้ำหนัก
$S = 352$ และ $352 \bmod 11 = 0$ ดังนั้น

$$
n_{12} = (11 - 0) \bmod 10 = 1
$$

## การจัดรูปแบบผลลัพธ์

รูปแบบมาตรฐานแบ่งเลขออกเป็นกลุ่มขนาด `1`, `4`, `5`, `2` และ `1` หลัก
โดยกลุ่มสุดท้ายคือ check digit ที่เพิ่งคำนวณได้ การตัดข้อความด้วย
`citizen_id[start:stop]` จะเลือกตั้งแต่ดัชนี `start` ไปจนถึงก่อนดัชนี
`stop`

-   `citizen_id[0]` เลือกหลักแรก
-   `citizen_id[1:5]` เลือก 4 หลักถัดมา
-   `citizen_id[5:10]` เลือก 5 หลักถัดมา
-   `citizen_id[10:12]` เลือก 2 หลักสุดท้ายของข้อมูลนำเข้า

เมื่อส่งทั้งห้าค่าให้ `print()` คั่นด้วยเครื่องหมายจุลภาค Python
จะเติมช่องว่างระหว่างค่าให้อัตโนมัติ ตัวอย่างข้างต้นจึงแสดงผลเป็น

```text
1 2345 67890 12 1
```

การตัดจากข้อความยังทำให้เลข `0` ภายในแต่ละกลุ่มไม่สูญหาย

# Solution

```python
# --------------------------------------------------
# File Name : 02_StrList_01.py
# Problem   : Citizen ID
# Author    : Worralop Srichainont
# Date      : 2025-08-09
# --------------------------------------------------

# Input citizen ID
citizen_id = input().strip()

# Calculate the last digit based on the first 12 digits
last_digit = (
    13 * int(citizen_id[0])
    + 12 * int(citizen_id[1])
    + 11 * int(citizen_id[2])
    + 10 * int(citizen_id[3])
    + 9 * int(citizen_id[4])
    + 8 * int(citizen_id[5])
    + 7 * int(citizen_id[6])
    + 6 * int(citizen_id[7])
    + 5 * int(citizen_id[8])
    + 4 * int(citizen_id[9])
    + 3 * int(citizen_id[10])
    + 2 * int(citizen_id[11])
)
last_digit = (11 - (last_digit % 11)) % 10

# Output the formatted ID
print(citizen_id[0], citizen_id[1:5], citizen_id[5:10], citizen_id[10:12], last_digit)
```
