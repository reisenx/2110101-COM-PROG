## การแยกข้อมูลยอดขาย

ข้อมูลนำเข้าเป็นยอดขายของทั้ง 7 วันในหนึ่งสัปดาห์ เขียนอยู่ในบรรทัดเดียวและ
คั่นแต่ละจำนวนด้วยช่องว่าง เมื่อใช้คำสั่ง

```python
sales = input().strip().split()
```

Python จะทำงานตามลำดับดังนี้

1. `input()` รับข้อมูลทั้งบรรทัดมาเป็นข้อความ (`str`)
2. `strip()` ตัดช่องว่างที่อยู่หน้าสุดและท้ายสุดของบรรทัด
3. `split()` แยกข้อความตรงช่องว่าง แล้วเก็บแต่ละส่วนไว้ในลิสต์

ตัวอย่างเช่น ข้อมูล `10 20 30 40 50 60 70` จะทำให้ `sales` มีค่าเป็น

```python
["10", "20", "30", "40", "50", "60", "70"]
```

สมาชิกของลิสต์ยังเป็นข้อความอยู่ และลิสต์ของ Python เริ่มนับดัชนีจาก `0`
ดังนั้น `sales[0]` คือยอดขายวันแรก ส่วน `sales[6]` คือยอดขายวันที่เจ็ด

การเรียก `split()` โดยไม่ระบุตัวคั่นยังรองรับช่องว่างติดกันหลายตัวได้
เพราะ Python จะมองช่องว่างเหล่านั้นเป็นบริเวณแบ่งข้อมูลเดียวกัน

## การหายอดขายรวม

ก่อนบวกยอดขาย ต้องแปลงสมาชิกแต่ละตัวจากข้อความเป็นจำนวนเต็มด้วย `int()`
จากนั้นจึงนำยอดขายทั้ง 7 วันมาบวกกัน

ถ้าให้ยอดขายแต่ละวันเป็น $s_0, s_1, \ldots, s_6$ ยอดขายรวมคือ

$$
S = s_0 + s_1 + s_2 + s_3 + s_4 + s_5 + s_6
$$

ในโปรแกรมจึงเขียนเป็นการบวก `int(sales[0])` ไปจนถึง
`int(sales[6])` อย่างชัดเจน เช่น จากตัวอย่างข้างต้นจะได้
$10 + 20 + 30 + 40 + 50 + 60 + 70 = 280$

คำสั่ง `print()` แสดงเฉพาะยอดรวมที่เป็นจำนวนเต็มหนึ่งค่า ไม่มีข้อความกำกับ
และไม่มีการหารหรือจัดรูปแบบเลขทศนิยม จึงไม่ต้องปัดเศษผลลัพธ์

# Solution

```python
# --------------------------------------------------
# File Name : 02_StrList_05.py
# Problem   : Weekly Sales
# Author    : Worralop Srichainont
# Date      : 2025-06-10
# --------------------------------------------------

# Input weekly sales data
sales = input().strip().split()

# Output the total sales for the week
print(
    int(sales[0])
    + int(sales[1])
    + int(sales[2])
    + int(sales[3])
    + int(sales[4])
    + int(sales[5])
    + int(sales[6])
)
```
