## รูปแบบการแยกตัวประกอบเฉพาะ

โจทย์ให้เขียนฟังก์ชัน `factor(N)` สำหรับจำนวนเต็มบวก $N > 1$
เพื่อแยก $N$ ให้อยู่ในรูปผลคูณของจำนวนเฉพาะ ดังนี้

$$
N = \prod_{i=1}^{k} p_i^{n_i}
$$

โดย $p_i$ คือจำนวนเฉพาะแต่ละตัว และ $n_i$ คือเลขชี้กำลัง
ฟังก์ชันต้องคืนลิสต์ที่เก็บแต่ละคู่ในรูป `[p_i, n_i]`

ตัวอย่างเช่น

$$
200 = 2^3 \times 5^2
$$

จึงเขียนเป็นลิสต์ใน Python ได้ว่า

```python
[[2, 3], [5, 2]]
```

คู่ตัวประกอบต้องเรียงจากค่าน้อยไปมาก ซึ่งเกิดขึ้นได้โดยทดลองค่า `k`
ตามลำดับ `2`, `3`, `4`, ... และเพิ่ม `[k, n]` ลงใน `factors`
เมื่อพบว่า `k` หารจำนวนที่เหลือลงตัว

## การทดลองหารและนับเลขชี้กำลัง

ภายในฟังก์ชัน ตัวแปร `number` คือจำนวนที่ยังเหลือให้แยกตัวประกอบ
ส่วน `k` คือตัวหารที่กำลังทดลอง โดยเริ่มจาก `2`

```python
factors = []
k = 2
```

เงื่อนไข `number % k == 0` ตรวจว่า `number` หารด้วย `k` ลงตัวหรือไม่
เพราะเศษจากการหาร (`%`) จะเท่ากับ `0` เมื่อหารลงตัว

เมื่อลงตัว ลูป `while` ด้านในจะทำซ้ำเพื่อหาว่า `k`
หารได้สำเร็จกี่ครั้ง แต่ละครั้งจะเพิ่ม `n` และลดค่าของ `number`

```python
while number % k == 0:
    n += 1
    number //= k
```

คำสั่ง `number //= k` มีความหมายเดียวกับ
`number = number // k` และยังคงผลลัพธ์เป็นจำนวนเต็ม
เมื่อหารต่อไม่ได้แล้ว ถ้า `n > 0` โปรแกรมจึงเพิ่ม `[k, n]` ลงในคำตอบ

```python
if n > 0:
    factors.append([k, n])
```

แม้โปรแกรมไม่ได้ตรวจโดยตรงว่า `k` เป็นจำนวนเฉพาะ
แต่ตัวประกอบที่เล็กกว่าจะถูกหารออกจนหมดก่อนเสมอ
ดังนั้นจำนวนประกอบ เช่น `4` จะไม่สามารถหาร `number` ที่เหลือลงตัวได้
ค่าที่ถูกเพิ่มลงใน `factors` จึงเป็นจำนวนเฉพาะ

วิธีนี้เป็นการทดลองหารแบบตรงไปตรงมา หรือแบบ naïve
เพราะเพิ่ม `k` ทีละ `1` และลองทุกจำนวน รวมถึงค่าที่หารไม่ลงตัวด้วย
ถ้า $N$ เป็นจำนวนเฉพาะขนาดใหญ่ โปรแกรมจึงต้องทดลองหลายครั้ง

## ลำดับการทำงานของฟังก์ชัน

พิจารณาการเรียก `factor(200)`

| `k` | การหารที่สำเร็จ | `n` | สิ่งที่เพิ่มลงใน `factors` |
|---:|:---|---:|:---|
| `2` | `200 → 100 → 50 → 25` | `3` | `[2, 3]` |
| `3`, `4` | หาร `25` ไม่ลงตัว | `0` | ไม่เพิ่มข้อมูล |
| `5` | `25 → 5 → 1` | `2` | `[5, 2]` |

สำหรับ `k = 2` มีการหารที่สำเร็จทั้งหมด `3` ครั้ง
ส่วนการตรวจ `25 % 2` เป็นครั้งถัดไปที่หารไม่ลงตัว จึงไม่นับเพิ่มใน `n`

เมื่อ `number` ลดเหลือ `1` เงื่อนไขลูปด้านนอก `k <= number`
จะเป็นเท็จ ฟังก์ชันจึงคืนผลลัพธ์ตามลำดับที่ค้นพบ

```python
[[2, 3], [5, 2]]
```

กรณี $N$ เป็นจำนวนเฉพาะ เช่น `97` โปรแกรมจะทดลองตัวหารตามลำดับ
จนถึง `k = 97` แล้วได้ `[[97, 1]]` ส่วนค่าที่ไม่เป็นไปตามเงื่อนไข
$N > 1$ อยู่นอกขอบเขตของโจทย์ และฟังก์ชันนี้ไม่ได้ตรวจสอบข้อมูลกรณีดังกล่าว

## การรับคำสั่งทดสอบด้วย exec

ฟังก์ชัน `factor()` ทำหน้าที่ `return` ลิสต์ แต่ไม่ได้แสดงผลด้วย `print()` เอง
ข้อมูลเข้าของโปรแกรมจึงเป็นคำสั่ง Python สำหรับทดสอบฟังก์ชัน เช่น

```python
print(factor(200))
```

บรรทัดสุดท้ายอ่านคำสั่งดังกล่าว ตัด whitespace ที่หัวและท้ายด้วย `.strip()`
แล้วให้ `exec()` รันคำสั่ง จึงเกิดการเรียก `factor(200)` และแสดงลิสต์ออกมา
ด้วยรูปแบบมาตรฐานของ Python

```python
exec(input().strip())
```

บรรทัดนี้จำเป็นสำหรับ Grader ของโจทย์ เพื่อให้ Grader ส่งคำสั่งทดสอบฟังก์ชันได้

> [!WARNING]
>
> `exec()` สามารถรันคำสั่ง Python ใด ๆ ที่ได้รับได้
> ในโจทย์นี้จึงควรใช้เฉพาะกับคำสั่งจาก Grader ที่เชื่อถือได้เท่านั้น
> ไม่ควรใช้ `exec()` กับข้อมูลจากผู้ใช้หรือแหล่งที่ไม่เชื่อถือ

# Solution

```python
# --------------------------------------------------
# File Name : 09_Nested_21.py
# Problem   : Factorization
# Author    : Worralop Srichainont
# Date      : 2025-08-09
# --------------------------------------------------


# Return the prime factorization of a number as a list.
def factor(number):
    factors = []
    # Find divisors starting from 2
    k = 2
    while k <= number:
        n = 0
        # Find how many times N divisible by k
        while number % k == 0:
            n += 1
            number //= k
        # If k is a factor, append it to the list
        if n > 0:
            factors.append([k, n])
        k += 1
    return factors


# Execute the input string as code
exec(input().strip())
```
