## รูปแบบข้อมูลและเป้าหมาย

โจทย์กำหนดให้บรรทัดแรกเป็นจำนวนเต็ม `n` ซึ่งบอกจำนวนบรรทัดของโค้ด Python
ที่จะตามมาอีก `n` บรรทัด โดยใช้เครื่องหมายจุด (`.`) ที่อยู่ติดกันทางซ้าย
แทนระยะเยื้องของโค้ด เพื่อให้เรามองเห็นและนับได้ชัดเจน

หน้าที่ของโปรแกรมคือแสดงโค้ดออกมาให้ครบ `n` บรรทัดตามลำดับเดิม
แต่ลดจำนวนจุดที่ติดกันทางซ้ายของแต่ละบรรทัดลงครึ่งหนึ่ง
โจทย์รับประกันว่าจำนวนจุดทางซ้ายเป็นจำนวนคู่เสมอ

โปรแกรมอ่านและเก็บทุกบรรทัดไว้ในลิสต์ `code` ก่อน

```python
n = int(input())
code = []
for _ in range(n):
    code.append(input().strip())
```

คำสั่ง `input().strip()` จะตัด whitespace เช่น ช่องว่างหรือ tab
ที่อยู่หน้าสุดและท้ายสุดของบรรทัดออก แต่ไม่ตัดเครื่องหมาย `.`
ดังนั้นจุดที่โจทย์ใช้แทนระยะเยื้องยังอยู่ครบ ส่วนช่องว่างที่อยู่กลางบรรทัดก็ไม่เปลี่ยนแปลง

## การนับจุดที่อยู่ชิดซ้าย

สำหรับแต่ละ `line` เราเริ่มตัวนับ `leading_dots` ที่ `0`
แล้วตรวจตัวอักษรจากซ้ายไปขวา ถ้าเป็น `.` ก็เพิ่มตัวนับขึ้น `1`
แต่เมื่อเจอตัวอักษรอื่นจะใช้ `break` หยุดนับทันที

```python
leading_dots = 0
for char in line:
    if char == ".":
        leading_dots += 1
    else:
        break
```

วิธีนี้จึงนับเฉพาะกลุ่มจุดที่เริ่มตั้งแต่ตัวแรกของบรรทัดเท่านั้น

> [!NOTE]
>
> `break` ออกจากลูป `for char in line` ที่กำลังนับตัวอักษรเท่านั้น
> โปรแกรมยังทำบรรทัดถัดไปต่อ และจุดที่อยู่ภายหลังตัวอักษรอื่น เช่น `..` ใน
> `print("composite..")` จะไม่ถูกนับเป็นระยะเยื้อง

## การตัดจุดออกครึ่งหนึ่ง

ให้ $d$ เป็นจำนวนจุดที่อยู่ชิดซ้าย และให้ $r$ เป็นจำนวนจุดที่ต้องตัดออก
เมื่อโจทย์ต้องการลดจุดลงครึ่งหนึ่ง จะได้ว่า

$$
r = \frac{d}{2}
$$

จึงเหลือจุดทางซ้ายจำนวน

$$
d-r = d-\frac{d}{2} = \frac{d}{2}
$$

ใน Python คำนวณ $r$ ด้วย `leading_dots // 2`
เครื่องหมาย `//` เป็นการหารแบบได้ผลลัพธ์เป็นจำนวนเต็ม
และเพราะโจทย์รับประกันว่า $d$ เป็นจำนวนคู่ ผลลัพธ์จึงเท่ากับครึ่งหนึ่งพอดี

จากนั้นใช้การ slice `line[start:]` เพื่อเลือกข้อความตั้งแต่ตำแหน่ง `start`
ไปจนจบบรรทัด

```python
dedented_line = line[leading_dots // 2 :]
```

ตัวอย่างเช่น เมื่อบรรทัดเป็น

```text
........print("composite..")
```

-   นับได้ `leading_dots = 8`
-   ตัดด้านซ้ายออก `8 // 2 = 4` ตัว
-   slice จากตำแหน่งที่ `4`
-   ได้ `....print("composite..")`

จะเห็นว่าจุด `..` ภายในข้อความ `"composite.."` ยังคงอยู่เหมือนเดิม
เพราะโปรแกรมตัดเฉพาะอักขระจากด้านซ้ายตามจำนวนที่คำนวณไว้

## ลำดับการทำงานของโปรแกรม

โปรแกรมทำงานตามลำดับดังนี้

1. อ่านจำนวนบรรทัด `n`
2. อ่านสตริงอีก `n` บรรทัดและเก็บไว้ใน `code`
3. วนพิจารณาแต่ละ `line` ตามลำดับเดิม
4. นับจำนวนจุดที่ติดกันทางซ้ายไว้ใน `leading_dots`
5. ตัดจุดออก `leading_dots // 2` ตัว แล้วแสดง `dedented_line`

ถ้าบรรทัดใดไม่ได้ขึ้นต้นด้วยจุด จะได้ `leading_dots = 0`
และ `line[0:]` ก็คือข้อความเดิมทั้งบรรทัด จึงไม่ต้องแยกกรณีพิเศษเพิ่มเติม

# Solution

```python
# --------------------------------------------------
# File Name : 09_Nested_11.py
# Problem   : Dedent
# Author    : Worralop Srichainont
# Date      : 2025-06-12
# --------------------------------------------------

# Input python code as a string
n = int(input())
code = []
for _ in range(n):
    code.append(input().strip())

# Output the dedented code
for line in code:
    # Count amount of leading dot
    leading_dots = 0
    for char in line:
        if char == ".":
            leading_dots += 1
        else:
            break
    # Remove half of leading dots
    dedented_line = line[leading_dots // 2 :]
    # Print the dedented line
    print(dedented_line)
```
