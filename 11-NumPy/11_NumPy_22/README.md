# แนวคิดสำคัญ

## ตารางสูตรคูณในรูปอาเรย์

ฟังก์ชัน `mult_table(rows, cols)` ต้องคืนอาเรย์สองมิติขนาด
`rows` แถวและ `cols` คอลัมน์ โดยสมาชิกแต่ละช่องเป็นผลคูณของหมายเลขแถว
กับหมายเลขคอลัมน์ เริ่มนับหมายเลขเหล่านี้จาก `1`

ถ้าใช้อินเด็กซ์ของ NumPy ซึ่งเริ่มจาก `0` ค่าที่ตำแหน่งแถว `i`
และคอลัมน์ `j` คือ

$$
\text{table}[i,j] = (i+1)(j+1)
$$

ใน Python ความสัมพันธ์นี้เกิดขึ้นจากนิพจน์ `row * col`
หลังจัดรูปร่างของอาเรย์ให้เหมาะกับการทำ Broadcasting

## เตรียมอาเรย์แถวและคอลัมน์

เริ่มจากสร้างจำนวนเต็มตั้งแต่ `1` ถึงจำนวนแถวและจำนวนคอลัมน์ด้วย
`np.arange`

```python
row = np.arange(1, rows + 1).reshape(-1, 1)
col = np.arange(1, cols + 1)
```

อาเรย์ทั้งสองมีรูปร่างต่างกันดังนี้

| ตัวแปร | ตัวอย่างเมื่อ `rows = 3`, `cols = 4` | `shape` |
|---|---|---|
| `row` | `[[1], [2], [3]]` | `(3, 1)` |
| `col` | `[1, 2, 3, 4]` | `(4,)` |

`reshape(-1, 1)` เปลี่ยน `row` ให้เป็นอาเรย์สองมิติที่มีหนึ่งคอลัมน์
ส่วน `-1` หมายถึงให้ NumPy คำนวณจำนวนแถวที่เหมาะสมให้เอง

## Broadcasting กับ Outer Product

เมื่อคูณอาเรย์รูปร่าง `(rows, 1)` กับอาเรย์รูปร่าง `(cols,)` NumPy จะ
Broadcast ค่าใน `row` ไปตามแนวคอลัมน์ และ Broadcast ค่าใน `col`
ไปตามแนวแถว ผลลัพธ์จึงมีรูปร่าง `(rows, cols)`

ในทางคณิตศาสตร์ การคำนวณนี้คือ Outer Product

$$
\begin{bmatrix}
1\\2\\\vdots\\\text{rows}
\end{bmatrix}
\begin{bmatrix}
1 & 2 & \cdots & \text{cols}
\end{bmatrix}
$$

โค้ดไม่จำเป็นต้องเรียก `np.outer` โดยตรง เพราะ `row * col`
ให้ผลเดียวกันผ่าน Broadcasting

# ลำดับการทำงาน

1. `np.arange(1, rows + 1)` สร้างหมายเลขแถว แล้ว `reshape(-1, 1)`
   จัดให้เป็นอาเรย์คอลัมน์
2. `np.arange(1, cols + 1)` สร้างหมายเลขคอลัมน์เป็นอาเรย์หนึ่งมิติ
3. `row * col` คูณทุกคู่ด้วย Broadcasting และคืนอาเรย์ตารางสูตรคูณ

ฟังก์ชันนี้ใช้ `return` จึงยังไม่แสดงอะไรทางจอภาพ ผู้เรียกต้องใช้คำสั่งอย่าง
`print(mult_table(3, 4))` หากต้องการเห็นผลลัพธ์

# ตัวอย่างการทำงาน

เมื่อเรียก `mult_table(3, 4)` จะได้

```text
[[ 1  2  3  4]
 [ 2  4  6  8]
 [ 3  6  9 12]]
```

ตัวอย่างเช่น สมาชิกแถวที่ `3` คอลัมน์ที่ `4` มีค่า $3\times4=12$
ซึ่งใน Python อยู่ที่อินเด็กซ์ `[2, 3]` เพราะอินเด็กซ์เริ่มจาก `0`

# รูปแบบข้อมูลและข้อควรระวัง

- โจทย์ส่งคำสั่ง Python สำหรับทดสอบมาเป็นบรรทัดแรก เช่น
  `print(mult_table(2, 2))` และไม่มีข้อมูลตัวเลขบรรทัดถัดไปที่ฟังก์ชันต้องอ่าน
- ตัวอย่างของโจทย์ใช้ `rows` และ `cols` เป็นจำนวนเต็มบวก โค้ดไม่ได้ตรวจสอบ
  ความถูกต้องของอาร์กิวเมนต์เพิ่มเติม หากมิติใดเป็น `0` จะได้อาเรย์ที่มีแกนนั้นว่าง
- `np.arange` ในโค้ดนี้สร้างจำนวนเต็ม จึงไม่มีการปัดเศษ ผลลัพธ์ที่เห็นเป็น
  รูปแบบการแสดงอาเรย์มาตรฐานของ NumPy

# Solution

```python
# --------------------------------------------------
# File Name : 11_Numpy_22.py
# Problem   : Outer Product
# Author    : Worralop Srichainont
# Date      : 2025-06-16
# --------------------------------------------------

import numpy as np


# Calculate the multiplication table of size rows x cols
def mult_table(rows, cols):
    row = np.arange(1, rows + 1).reshape(-1, 1)
    col = np.arange(1, cols + 1)
    return row * col


# Execute an input string as code
exec(input().strip())
```
