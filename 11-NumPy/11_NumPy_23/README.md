# โครงสร้างข้อมูล

โจทย์แบ่งงานเป็นสองฟังก์ชัน ได้แก่ `read_data()` สำหรับอ่านข้อมูลและคืนอาเรย์
สองตัว และ `report_lower_than_mean(weight, data)` สำหรับคำนวณแล้วแสดง
เลขประจำตัวของผู้ที่ได้คะแนนรวมต่ำกว่าคะแนนเฉลี่ย

## ลำดับข้อมูลเข้า

เมื่อนำโปรแกรมทั้งไฟล์ไปรัน ข้อมูลจะเข้าตามลำดับนี้

1. คำสั่ง Python ที่ Grader ใช้ทดสอบ เช่น
   `w,d = read_data(); report_lower_than_mean(w,d)`
2. น้ำหนักคะแนนสามค่าในบรรทัดเดียว เรียงเป็น กลางภาค ปลายภาค และโครงงาน
3. จำนวนผู้เรียน `n`
4. ข้อมูลผู้เรียนอีก `n` บรรทัด แต่ละบรรทัดเรียงเป็น
   เลขประจำตัว คะแนนกลางภาค คะแนนปลายภาค และคะแนนโครงงาน

คำสั่งในข้อ 1 เรียก `read_data()` จึงทำให้ฟังก์ชันอ่านบรรทัดที่เหลือต่อทันที

## อาเรย์น้ำหนักและข้อมูลนักเรียน

`read_data()` แปลงข้อมูลเป็นอาเรย์ดังนี้

| ตัวแปร | ชนิดข้อมูล | `shape` | ความหมาย |
|---|---|---|---|
| `weight` | `float` | `(3,)` | น้ำหนักกลางภาค ปลายภาค และโครงงาน |
| `data` | `int` | `(n, 4)` | เลขประจำตัวและคะแนนสามส่วนของผู้เรียนแต่ละคน |

ดังนั้น `data[:, 0]` คือเลขประจำตัวทุกคน ส่วน `data[:, 1:4]`
คือคะแนนสามส่วน โดยยังเรียงแถวตามลำดับเดิมจากข้อมูลเข้า

# แนวคิดการคำนวณ

## คะแนนรวมแบบถ่วงน้ำหนัก

ถ้าผู้เรียนคนที่ `i` มีคะแนนกลางภาค ปลายภาค และโครงงานเป็น
$s_{i,m}$, $s_{i,f}$ และ $s_{i,p}$ คะแนนรวมของคนนั้นคือ

$$
T_i = s_{i,m}w_m + s_{i,f}w_f + s_{i,p}w_p
$$

โค้ดคำนวณคะแนนรวมของทุกคนพร้อมกันด้วย

```python
total_score = np.dot(data[:, 1:4], weight)
```

นี่คือ Dot Product ระหว่างเมทริกซ์คะแนนรูปร่าง `(n, 3)` กับเวกเตอร์น้ำหนัก
รูปร่าง `(3,)` จึงได้ `total_score` รูปร่าง `(n,)` ซึ่งมีคะแนนรวมหนึ่งค่าต่อคน

> [!NOTE]
> ข้อแนะนำท้าย PDF ที่กล่าวถึง Outer Product ไม่ตรงกับการคำนวณของข้อนี้
> โค้ดเฉลยใช้ `np.dot` เพื่อหาผลรวมแบบถ่วงน้ำหนักตามข้อกำหนดของโจทย์

## คะแนนเฉลี่ยและ Boolean Mask

คะแนนเฉลี่ยของผู้เรียนทั้งหมดคือ

$$
\overline{T} = \frac{1}{n}\sum_{i=1}^{n}T_i
$$

ซึ่งตรงกับ `mean_score = np.mean(total_score)` จากนั้นเปรียบเทียบทุกคนด้วย
`total_score < mean_score` เพื่อสร้าง Boolean Mask

เครื่องหมาย `<` สำคัญมาก เพราะโจทย์ต้องการเฉพาะผู้ที่ได้คะแนน **ต่ำกว่า**
ค่าเฉลี่ย ผู้ที่ได้คะแนนเท่ากับค่าเฉลี่ยจึงไม่ถูกเลือก เมื่อใช้ Mask นี้กับ
`student_ids` ลำดับเลขประจำตัวยังคงเหมือนลำดับแถวใน `data`

# ลำดับการทำงาน

1. `read_data()` อ่านน้ำหนักเป็น `float` อ่านจำนวนผู้เรียน แล้วอ่านข้อมูล
   แต่ละแถวเป็น `int`
2. `data[:, 0]` แยกเลขประจำตัว และ `data[:, 1:4]` แยกคะแนนสามส่วน
3. `np.dot(data[:, 1:4], weight)` คำนวณคะแนนรวมทุกคน
4. `np.mean(total_score)` หาคะแนนเฉลี่ย
5. `student_ids[total_score < mean_score]` เลือกเฉพาะเลขประจำตัวที่ตรงเงื่อนไข
6. แปลงเลขประจำตัวเป็นข้อความ แล้วพิมพ์โดยคั่นด้วย `", "` หรือพิมพ์
   `None` เมื่อไม่มีผู้ผ่านเงื่อนไข

# ตัวอย่างการคำนวณ

สำหรับน้ำหนัก `0.3 0.5 0.2` และข้อมูลตัวอย่างแรก จะได้

| เลขประจำตัว | การคำนวณ | คะแนนรวม | ต่ำกว่า `74.02` หรือไม่ |
|---|---|---:|:---:|
| `610111` | $80(0.3)+90(0.5)+70(0.2)$ | `83.0` | ไม่ |
| `610222` | $50(0.3)+80(0.5)+68(0.2)$ | `68.6` | ใช่ |
| `610333` | $70(0.3)+85(0.5)+80(0.2)$ | `79.5` | ไม่ |
| `610444` | $60(0.3)+50(0.5)+90(0.2)$ | `61.0` | ใช่ |
| `610555` | $90(0.3)+74(0.5)+70(0.2)$ | `78.0` | ไม่ |

คะแนนเฉลี่ยคือ

$$
\frac{83.0+68.6+79.5+61.0+78.0}{5}=74.02
$$

จึงแสดงผลตามลำดับเดิมเป็น

```text
610222, 610444
```

ในตัวอย่างที่สอง ผู้เรียนทั้งสองคนได้คะแนนรวม `85.0` ซึ่งเท่ากับค่าเฉลี่ย
จึงไม่มีใครได้ต่ำกว่าค่าเฉลี่ยและโปรแกรมพิมพ์ `None`

# รูปแบบผลลัพธ์และข้อควรระวัง

- โปรแกรมไม่แสดงคะแนนรวมหรือคะแนนเฉลี่ย จึงไม่มีการปัดเศษเพื่อแสดงผล
  ค่าชนิด `float` ถูกนำไปเปรียบเทียบโดยตรง
- เมื่อพบหลายคน ต้องแสดงเลขประจำตัวในบรรทัดเดียว คั่นด้วยจุลภาคและช่องว่าง
  หนึ่งช่อง และรักษาลำดับที่ปรากฏใน `data`
- `print(None)` แสดงข้อความ `None` โดยไม่มีเครื่องหมายอัญประกาศ ตรงตามโจทย์
- โค้ดคาดว่ามีน้ำหนักครบสามค่า ข้อมูลแต่ละคนครบสี่จำนวน และ `n` อย่างน้อย
  `1` หาก `n = 0` อาเรย์ `data` ที่สร้างจากรายการว่างจะไม่มีสองมิติให้เลือก
  ด้วย `data[:, 0]`

> [!NOTE]
> โครงร่างใน PDF สร้างอาเรย์ขนาด `(n, 4)` ก่อนแล้วเติมข้อมูลทีละแถว
> ส่วนโค้ดเฉลยสร้างอาเรย์จาก List Comprehension โดยตรง สำหรับ `n` ที่เป็นบวก

# Solution

```python
# --------------------------------------------------
# File Name : 11_Numpy_23.py
# Problem   : Lower than Mean
# Author    : Worralop Srichainont
# Date      : 2025-06-16
# --------------------------------------------------

import numpy as np


# Read data from input
def read_data():
    # Read score weight as a float array
    weight = np.array(input().split(), float)
    # Read student data as an integer array
    n = int(input())
    data = np.array([input().split() for _ in range(n)], int)
    # Return the weight and data
    return weight, data


# Report students with total score lower than the mean score
def report_lower_than_mean(weight, data):
    # Get the student IDs
    student_ids = data[:, 0]
    # Calculate the total score for each student
    total_score = np.dot(data[:, 1:4], weight)
    # Calculate the mean score
    mean_score = np.mean(total_score)
    # Select students with total score lower than the mean score
    # Convert student IDs to string for output
    lower_than_mean = np.array(student_ids[total_score < mean_score], str)

    # Output the result
    if len(lower_than_mean) > 0:
        print(", ".join(lower_than_mean))
    else:
        print(None)


# Execute an input string as code
exec(input().strip())
```
