# ความหมายของยอด

ให้ `numbers` เป็นอาเรย์หนึ่งมิติ ตำแหน่ง `i` จะเป็น **ยอด** เมื่อค่าที่ตำแหน่งนี้
มากกว่าค่าที่อยู่ติดกันทั้งด้านซ้ายและด้านขวาอย่างเคร่งครัด

$$
i\text{ เป็นยอด}
\iff
\text{numbers}[i] > \text{numbers}[i-1]
\quad\text{และ}\quad
\text{numbers}[i] > \text{numbers}[i+1]
$$

ตำแหน่งที่ตรวจได้จึงมีเฉพาะ

$$
1 \leq i \leq \operatorname{len}(\text{numbers})-2
$$

เพราะสมาชิกตัวแรกไม่มีเพื่อนบ้านด้านซ้าย และสมาชิกตัวสุดท้ายไม่มีเพื่อนบ้าน
ด้านขวา ตำแหน่งที่คืนเป็นอินเด็กซ์แบบ Python ซึ่งเริ่มนับจาก `0`

# การเปรียบเทียบด้วย Slicing

แทนที่จะวนลูปตรวจทีละตำแหน่ง เราสร้างอาเรย์สามชุดที่เยื้องกันหนึ่งตำแหน่ง

```python
left = numbers[:-2]
center = numbers[1:-1]
right = numbers[2:]
```

ถ้า `numbers` คือ `[1, 9, 1, 9, 1]` จะจัดตำแหน่งเพื่อเปรียบเทียบได้ดังนี้

| หน้าที่ | Slice | ค่า |
|---|---|---|
| ด้านซ้าย | `numbers[:-2]` | `[1, 9, 1]` |
| ตรงกลาง | `numbers[1:-1]` | `[9, 1, 9]` |
| ด้านขวา | `numbers[2:]` | `[1, 9, 1]` |

สมาชิกทั้งสามอาเรย์ที่อินเด็กซ์เดียวกันจึงเป็นค่าซ้าย ค่ากลาง และค่าขวา
ของตำแหน่งที่กำลังตรวจพอดี

# Boolean Mask และตำแหน่งจริง

เปรียบเทียบทั้งอาเรย์พร้อมกันด้วย

```python
is_peak = (center > left) & (center > right)
```

นิพจน์นี้ตรงกับเงื่อนไขทางคณิตศาสตร์ โดย `&` ทำ AND แบบสมาชิกต่อสมาชิก
สำหรับตัวอย่างข้างต้นจะได้ Mask `[True, False, True]`

> [!WARNING]
> ต้องใส่วงเล็บรอบ `center > left` และ `center > right` แล้วเชื่อมด้วย `&`
> การใช้ `and` ของ Python กับอาเรย์จะไม่เปรียบเทียบสมาชิกทีละคู่และทำให้เกิด
> ข้อผิดพลาดเกี่ยวกับค่าความจริงของอาเรย์

Mask มีเพียง `len(numbers) - 2` ช่อง จึงสร้างอินเด็กซ์ของสมาชิกตรงกลางให้ตรงกัน

```python
np.arange(1, len(numbers) - 1)
```

สำหรับตัวอย่าง อาเรย์อินเด็กซ์คือ `[1, 2, 3]` เมื่อนำ Mask มากรองจึงเหลือ
`[1, 3]` ซึ่งเป็นตำแหน่งจริงใน `numbers`

# ลำดับการทำงาน

1. ถ้าอาเรย์มีสมาชิกน้อยกว่า `3` ให้คืน `[]` ทันที เพราะไม่มีตำแหน่งที่มี
   เพื่อนบ้านครบสองด้าน
2. สร้าง `left`, `center` และ `right` ด้วย Slicing
3. เปรียบเทียบค่ากลางกับเพื่อนบ้านทั้งสองด้านเพื่อสร้าง `is_peak`
4. สร้างอินเด็กซ์ตั้งแต่ `1` ถึง `len(numbers) - 2` แล้วเลือกด้วย Mask
5. `main()` แสดงอินเด็กซ์ที่พบโดยคั่นด้วย `", "` หรือแสดง `No peaks`
   ถ้าไม่พบยอด

ทุกขั้นตอนค้นหายอดใช้การทำงานกับอาเรย์ของ NumPy จึงไม่ต้องใช้ลูปตามที่โจทย์
กำหนด

# ตัวอย่างการทำงาน

เมื่อข้อมูลคือ

```text
1 9 1 9 1 9 1 9 1 9 1
```

ค่าที่อินเด็กซ์ `1`, `3`, `5`, `7` และ `9` เป็น `9` และมีค่า `1`
ขนาบอยู่ทั้งสองด้าน จึงได้ผลลัพธ์

```text
1, 3, 5, 7, 9
```

ในทางกลับกัน `[1, 2, 3, 4]` เพิ่มขึ้นตลอด ไม่มีค่าตรงกลางใดมากกว่าเพื่อนบ้าน
ทั้งสองด้าน `peak_indexes` จึงคืนอาเรย์ว่าง และ `main()` แสดง `No peaks`

# กรณีพิเศษและรูปแบบผลลัพธ์

- จุดปลายทั้งสองไม่เป็นยอด แม้ค่าจะมากกว่าสมาชิกที่อยู่ติดกันเพียงด้านเดียว
- ถ้าค่าตรงกลางเท่ากับเพื่อนบ้านอย่างน้อยหนึ่งด้าน ตำแหน่งนั้นไม่เป็นยอด
  เพราะโค้ดใช้ `>` ไม่ใช่ `>=` ดังนั้นบริเวณที่ราบหรือ Plateau ไม่ถูกนับ
- ข้อมูลใน `main()` ถูกอ่านเป็น `float` แต่ผลลัพธ์เป็นอินเด็กซ์จำนวนเต็ม
  จึงไม่มีการปัดเศษค่าอินพุตเพื่อแสดงผล
- เมื่อนำทั้งไฟล์ไปรัน บรรทัดแรกเป็นคำสั่งทดสอบ หากเป็น `main()` โปรแกรมจึง
  อ่านรายการจำนวนจริงจากบรรทัดถัดไป แต่ถ้าเป็นคำสั่งโดยตรง เช่น
  `print(peak_indexes(np.array([1, 2, 3, 4])))` ก็ไม่ต้องมีข้อมูลบรรทัดถัดไป

> น้อยกว่า `3` และคืน NumPy array เมื่อมีสมาชิกตั้งแต่ `3` ขึ้นไป `main()`
> รองรับทั้งสองชนิดเพราะตรวจด้วย `len` และนำสมาชิกไปแปลงเป็นข้อความเท่านั้น

# Solution

```python
# --------------------------------------------------
# File Name : 11_Numpy_24.py
# Problem   : Peak Indexes
# Author    : Worralop Srichainont
# Date      : 2025-06-16
# --------------------------------------------------

import numpy as np


# Find the indexes of peaks in a 1D NumPy array
def peak_indexes(numbers):
    # Check if the input array has at least 3 elements
    if len(numbers) < 3:
        return []
    # Create slices for left, center, and right elements
    left = numbers[:-2]
    center = numbers[1:-1]
    right = numbers[2:]
    # Identify peaks where the center element is greater than adjacent elements
    is_peak = (center > left) & (center > right)
    peak_indices = np.arange(1, len(numbers) - 1)[is_peak]
    return peak_indices


# Main function to read input and output peak indexes
def main():
    numbers = np.array(input().split(), float)
    peak_indices = peak_indexes(numbers)
    # Output
    if len(peak_indices) > 0:
        print(", ".join(np.array(peak_indices, str)))
    else:
        print("No peaks")


# Execute an input string as code
exec(input().strip())
```
