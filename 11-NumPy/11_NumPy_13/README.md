# โจทย์ต้องการอะไร

ฟังก์ชัน `p(x)` รับอาเรย์ NumPy สองมิติขนาด $n \times 2$ ซึ่งแต่ละแถวแทนนักเรียนหนึ่งคน ข้อมูลในแต่ละคอลัมน์มีความหมายดังนี้

| คอลัมน์ | ความหมาย | วิธีเลือกด้วย NumPy |
|:---:|---|---|
| `0` | จำนวนโจทย์ที่นักเรียนทำได้ $(x_0)$ | `x[:, 0]` |
| `1` | เกรดเฉลี่ยของนักเรียน $(x_1)$ | `x[:, 1]` |

ฟังก์ชันต้องคืนอาเรย์หนึ่งมิติขนาด `n` ซึ่งเก็บความน่าจะเป็นที่นักเรียนแต่ละคนจะเรียนผ่าน ผลลัพธ์ตำแหน่งที่ `i` จึงเป็นของนักเรียนในแถวที่ `i` และเรียงลำดับเหมือนข้อมูลนำเข้าเสมอ

# แนวคิดที่ใช้

## การเลือกข้อมูลแต่ละคอลัมน์

คำสั่ง `x[:, 0]` อ่านว่า “เลือกทุกแถวของคอลัมน์ที่ `0`” โดย `:` หมายถึงทุกแถว ส่วน `x[:, 1]` เลือกทุกแถวของคอลัมน์ที่ `1` ผลลัพธ์ของทั้งสองคำสั่งเป็นอาเรย์หนึ่งมิติขนาด `n`

เมื่อคูณหรือบวกอาเรย์เหล่านี้กับตัวเลข NumPy จะคำนวณให้ทุกสมาชิกแบบ **element-wise** จึงหาค่าให้กับนักเรียนทุกคนพร้อมกันได้โดยไม่ต้องเขียนวงวน กระบวนการนี้เรียกว่า **vectorization**

## Logistic Regression และฟังก์ชัน Sigmoid

โจทย์กำหนดค่าคะแนนดิบหรือ `logit` ของนักเรียนแต่ละคนไว้ว่า

$$
\operatorname{logit}(x) = -3.98 + 0.1x_0 + 0.5x_1
$$

เมื่อนำสัญลักษณ์ทางคณิตศาสตร์มาเขียนเป็น Python จะได้

```python
logit = -3.98 + (0.1 * x[:, 0]) + (0.5 * x[:, 1])
```

ขณะนี้ `logit` เป็นอาเรย์หนึ่งมิติขนาด `n` จากนั้นแปลงคะแนนแต่ละค่าให้เป็นความน่าจะเป็นด้วยฟังก์ชัน **Sigmoid**

$$
p(x) = \frac{1}{1 + e^{-\operatorname{logit}(x)}}
$$

เลขยกกำลัง $e^a$ เขียนด้วย NumPy เป็น `np.exp(a)` ดังนั้นสูตรข้างบนตรงกับ

```python
1 / (1 + np.exp(-logit))
```

`np.exp()` คำนวณเลขยกกำลังให้ทุกสมาชิกของ `logit` ผลลัพธ์จึงยังมีขนาด `n` และตามหลักคณิตศาสตร์จะอยู่ระหว่าง `0` กับ `1`

# ขั้นตอนการทำงาน

1. เลือกจำนวนโจทย์ของนักเรียนทุกคนด้วย `x[:, 0]` และเลือกเกรดเฉลี่ยด้วย `x[:, 1]`
2. แทนค่าทั้งสองคอลัมน์ในสูตร `logit` แบบ element-wise ได้อาเรย์ขนาด `n`
3. ส่ง `logit` ทุกค่าเข้าสูตร Sigmoid ด้วย `np.exp(-logit)` แล้วคืนอาเรย์ความน่าจะเป็นตามลำดับแถวเดิม

# ตัวอย่างการคำนวณ

สำหรับนักเรียนที่ทำโจทย์ได้ `100` ข้อและมีเกรดเฉลี่ย `4.00` จะได้

$$
\begin{aligned}
\operatorname{logit}(x)
  &= -3.98 + (0.1 \times 100) + (0.5 \times 4.00) \\
  &= 8.02 \\
p(x)
  &= \frac{1}{1 + e^{-8.02}} \\
  &\approx 0.99967129
\end{aligned}
$$

จึงตรงกับผลลัพธ์ของตัวอย่างแรก

```python
print(p(np.array([[100, 4.00]])))
# [0.99967129]
```

เมื่อมีนักเรียนสองคน NumPy จะคำนวณทั้งสองแถวพร้อมกัน

| แถว | $(x_0, x_1)$ | `logit` | ความน่าจะเป็น |
|:---:|:---:|---:|---:|
| `0` | `(80, 2.50)` | `5.27` | `0.99488271` |
| `1` | `(1, 4.00)` | `-1.88` | `0.13238887` |

ดังนั้นผลลัพธ์ยังเรียงตามแถว `0` แล้วจึงเป็นแถว `1`

```python
print(p(np.array([[80, 2.50], [1, 4.00]])))
# [0.99488271 0.13238887]
```

# ข้อควรระวัง

- แม้มีนักเรียนเพียงคนเดียว ข้อมูลยังต้องเป็นอาเรย์ **สองมิติ** เช่น `np.array([[100, 4.00]])` ซึ่งมีรูปร่าง `(1, 2)` หากเขียนเป็น `np.array([100, 4.00])` จะใช้ `x[:, 0]` ไม่ได้
- โจทย์ไม่ได้กำหนดให้ปัดเศษ ฟังก์ชันจึงคืนค่าทศนิยมจาก NumPy โดยตรง การแสดงผลอาจมีรายละเอียดเล็กน้อยตามการคำนวณแบบ floating-point
- ถ้า `logit` มีขนาดสุดขั้วมาก `np.exp(-logit)` อาจเกิดการล้นของเลขทศนิยมและได้ค่าที่ขอบเขต `0` หรือ `1` โค้ดคำตอบใช้สูตรตามโจทย์โดยไม่ได้ปรับค่าหรือปัดเศษเพิ่มเติม
- เอกสารโจทย์เขียนชื่อพารามิเตอร์เป็น `X` แต่ไฟล์คำตอบใช้ `x` ความแตกต่างนี้ไม่มีผลต่อการทำงาน ส่วนคอมเมนต์หัวไฟล์สะกด `11_Numpy_13.py` ต่างจากชื่อไฟล์จริง `11_NumPy_13.py` เล็กน้อย จึงคงคอมเมนต์เดิมไว้ใน Solution ให้ตรงกับไฟล์คำตอบ

# Solution

```python
# --------------------------------------------------
# File Name : 11_Numpy_13.py
# Problem   : Logistic Regression
# Author    : Worralop Srichainont
# Date      : 2025-06-16
# --------------------------------------------------

import numpy as np


# Calculate the probability of a binary outcome using logistic regression
def p(x):
    logit = -3.98 + (0.1 * x[:, 0]) + (0.5 * x[:, 1])
    return 1 / (1 + np.exp(-logit))


# Execute an input string as code
exec(input().strip())
```
