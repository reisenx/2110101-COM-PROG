# แนวคิดสำคัญ

โจทย์ข้อนี้ใช้ NumPy คำนวณข้อมูลหลายค่าพร้อมกัน แทนการวนลูปทีละสมาชิก
เมื่อคำนวณอาเรย์กับค่าสเกลาร์ NumPy จะนำค่าสเกลาร์ไปใช้กับสมาชิกทุกตัว
เรียกว่า **broadcasting** เช่น

```python
fahrenheit = np.array([32, 212])
fahrenheit - 32
```

ผลลัพธ์คือ `[0, 180]` เพราะ `32` ถูกลบออกจากสมาชิกทั้งสองตำแหน่ง
การบวก ลบ คูณ หาร และยกกำลังระหว่างอาเรย์ที่มีรูปร่างเหมาะสม
ก็ทำงานแบบสมาชิกต่อสมาชิกเช่นเดียวกัน

สำหรับอาเรย์สองมิติ เครื่องหมาย `:` หมายถึงเลือกทุกแถว เช่น

```python
data[:, 0]  # คอลัมน์แรกของทุกแถว
data[:, 1]  # คอลัมน์ที่สองของทุกแถว
```

ดังนั้นเราสามารถแยกน้ำหนัก ความสูง หรือพิกัดของทุกจุดออกมาเป็นอาเรย์
หนึ่งมิติ แล้วใช้สูตรเดียวคำนวณทุกแถวได้ทันที

# ข้อมูลนำเข้าและข้อมูลส่งออก

แต่ละฟังก์ชันคืนอาเรย์หนึ่งมิติ โดยตำแหน่งที่ `i` ของผลลัพธ์ยังตรงกับ
ข้อมูลตำแหน่งที่ `i` ของอาเรย์นำเข้า

| ฟังก์ชัน | ข้อมูลที่รับ | อาเรย์ที่คืน |
| --- | --- | --- |
| `toCelsius(fahrenheit)` | อาเรย์หนึ่งมิติของอุณหภูมิหน่วยฟาเรนไฮต์ | อุณหภูมิเซลเซียสของแต่ละตำแหน่งตามลำดับเดิม |
| `BMI(weight_and_height)` | อาเรย์ขนาด `n x 2` แต่ละแถวเป็น `[น้ำหนักกิโลกรัม, ความสูงเซนติเมตร]` | ค่า BMI จำนวน `n` ค่า เรียงตามแถวของบุคคล |
| `distanceTo(point, all_points)` | จุดอ้างอิงขนาด `2` และอาเรย์จุดขนาด `n x 2` | ระยะจากจุดอ้างอิงไปยังแต่ละจุด เรียงตามแถวของ `all_points` |

โจทย์อธิบาย `point` ว่าเป็นอาเรย์หนึ่งมิติ แต่ตัวอย่างส่งลิสต์ `[0, 0]`
ซึ่งใช้ได้เช่นกัน เพราะโค้ดเข้าถึงเพียง `point[0]` และ `point[1]`

ผลลัพธ์ไม่มีการปัดเศษหรือกำหนดจำนวนตำแหน่งทศนิยม `print` จะแสดง
อาเรย์ทศนิยมด้วยรูปแบบปกติของ NumPy เช่น `[  0. 100.]`

# อธิบายการทำงาน

## `toCelsius`

สูตรแปลงอุณหภูมิจากฟาเรนไฮต์เป็นเซลเซียสคือ

$$
C = \frac{F - 32}{1.8}
$$

เมื่อนำสูตรมาใช้กับอาเรย์ Python เขียนได้ตรง ๆ เป็น
`(fahrenheit - 32) / 1.8` NumPy จะลบ `32` และหารด้วย `1.8`
ให้สมาชิกทุกตัว

ตัวอย่างเช่น

$$
\frac{32 - 32}{1.8} = 0
\qquad
\frac{212 - 32}{1.8} = 100
$$

จึงคืน `[  0. 100.]` การหารทำให้ผลลัพธ์เป็นเลขทศนิยม แม้ข้อมูลนำเข้า
จะเป็นจำนวนเต็ม

## `BMI`

แต่ละแถวของ `weight_and_height` เก็บน้ำหนักไว้คอลัมน์ `0`
และความสูงไว้คอลัมน์ `1` โค้ดจึงแยกข้อมูลเป็น

```python
weight = weight_and_height[:, 0]
height = weight_and_height[:, 1] / 100
```

โจทย์ให้ความสูงเป็นเซนติเมตร แต่สูตร BMI ใช้เมตร จึงต้องแปลงหน่วยก่อน

$$
h_{m} = \frac{h_{cm}}{100}
$$

Python คือ `weight_and_height[:, 1] / 100` จากนั้นใช้สูตร

$$
BMI = \frac{w}{h_{m}^{2}}
$$

ซึ่งตรงกับ `weight / (height**2)` โดย `**2` ยกกำลังสมาชิกทุกตัว

สำหรับคนแรกที่หนัก `60` กิโลกรัมและสูง `170` เซนติเมตร จะได้
`height = 1.7` เมตร และ

$$
BMI = \frac{60}{1.7^2} = 20.761245674...
$$

คนที่สองได้ `50 / 1.6**2 = 19.53125` ดังนั้นผลลัพธ์ตามลำดับแถวคือ
`[20.76124567 19.53125   ]` ช่องว่างและจำนวนหลักที่เห็นเป็นการแสดงผล
ปกติของ NumPy ไม่ใช่การปัดค่าในฟังก์ชัน

## `distanceTo`

สำหรับจุดอ้างอิง `p = (p_x, p_y)` และจุดลำดับที่ `i`
ซึ่งมีพิกัด `(x_i, y_i)` ระยะทางแบบยุคลิดคือ

$$
d_i = \sqrt{(x_i - p_x)^2 + (y_i - p_y)^2}
$$

โค้ดคำนวณผลต่างของพิกัดทุกจุดก่อน

```python
distance_x = all_points[:, 0] - point[0]
distance_y = all_points[:, 1] - point[1]
```

จากนั้น `((distance_x**2) + (distance_y**2)) ** 0.5`
ยกกำลัง `0.5` ซึ่งเท่ากับการหารากที่สองของแต่ละตำแหน่ง

เมื่อจุดอ้างอิงเป็น `[0, 0]` จะคำนวณตามลำดับแถวได้ดังนี้

| จุด | `distance_x` | `distance_y` | ระยะทาง |
| --- | ---: | ---: | ---: |
| `[3, 0]` | `3` | `0` | `3` |
| `[0, 4]` | `0` | `4` | `4` |
| `[3, 4]` | `3` | `4` | `5` |

ผลลัพธ์จึงเป็น `[3. 4. 5.]` โดยรักษาลำดับเดียวกับแถวใน
`all_points`

# ข้อควรระวัง

- ต้องหารความสูงด้วย `100` ให้เป็นเมตร **ก่อน** นำไปยกกำลังสอง
  มิฉะนั้นหน่วยและค่า BMI จะผิด
- `**2` และ `**0.5` ทำงานกับสมาชิกทุกตัวของอาเรย์ ไม่ได้ยกกำลัง
  ทั้งอาเรย์ในความหมายของการคูณเมทริกซ์
- โค้ดไม่ได้ตรวจความสูงเป็นศูนย์ หากมีค่า `0` NumPy จะเกิดการหารด้วยศูนย์
  และให้คำเตือนพร้อมค่าตามกฎของเลขทศนิยม
- จุดที่ตรงกับจุดอ้างอิงจะมีระยะทาง `0` และพิกัดติดลบคำนวณได้ตามสูตรปกติ
  หากรับอาเรย์ขนาด `0 x 2` ผลลัพธ์ก็เป็นอาเรย์ว่าง
- ค่าทศนิยมทั้งหมดถูกคืนตามที่คำนวณได้ ไม่มีการเรียก `round`
  หรือจัดรูปแบบทศนิยมภายในฟังก์ชัน

# Solution

```python
# --------------------------------------------------
# File Name : 11_Numpy_12.py
# Problem   : Scalar and Array
# Author    : Worralop Srichainont
# Date      : 2025-06-16
# --------------------------------------------------

import numpy as np


# Convert Fahrenheit to Celsius
def toCelsius(fahrenheit):
    return (fahrenheit - 32) / 1.8


# Calculate Body Mass Index (BMI)
def BMI(weight_and_height):
    weight = weight_and_height[:, 0]
    height = weight_and_height[:, 1] / 100
    return weight / (height**2)


# Calculate the distance from a point to all points in an array
def distanceTo(point, all_points):
    distance_x = all_points[:, 0] - point[0]
    distance_y = all_points[:, 1] - point[1]
    return ((distance_x**2) + (distance_y**2)) ** 0.5


# Execute an input string as code
exec(input().strip())
```
