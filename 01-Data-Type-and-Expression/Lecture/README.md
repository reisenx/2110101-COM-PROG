# Section 1: Data Types

ก่อนที่เราจะขึ้นเรื่องประเภทของข้อมูลในภาษา Python เราต้องเข้าใจก่อนว่าภาษา
Python นั้นทำงานอย่างไร

สมมติว่าเราเขียน code ในภาษา Python ขึ้นมาดังนี้

```python
x = 10
y = 20
z = x + y
print(z)
print(x)
print(y)
```

เมื่อกด run code แล้วนั้น <ins>มันจะรันคำสั่งทีละบรรทัด


ในตอนนี้ เราทราบแล้วว่า code ในภาษา Python จะถูกรันคำสั่งทีละบรรทัด

พาผู้อ่านทำความเข้าใจทีละประเด็น จนเข้าใจ code ดังกล่าวในที่สุด

## 1.2. Data Types

**Data Types (ประเภทข้อมูล)** หมายถึง ประเภทข้อมูลในภาษา Python ได้แก่

**ข้อมูลประเภท `int`** หมายถึง ข้อมูลประเภทจำนวนเต็ม

```python
x = 10
y = -99
z = 0
```

**ข้อมูลประเภท `float`** หมายถึง ข้อมูลประเภทจำนวนจริง มีการแสดงจุดทศนิยม

```python
x = 10.0
y = -3.14
z = 0.59184
```

**ข้อมูลประเภท `str`** หมายถึง ข้อมูลประเภทข้อความ มีสัญลักษณ์ `"` หรือ `'`
ที่ต้น และท้ายข้อความ

```python
x = "Hello, World!"
y = 'cheese'
z = "The Faculty of Engineering, Chulalongkorn University."
```

**ข้อมูลประเภท `bool`** หมายถึง ข้อมูลประเภทค่าความจริง ประกอบไปด้วย 2 ค่า
ได้แก่ `True` (จริง) และ `False` (เท็จ)

```python
x = True
y = False
```

**ข้อมูลประเภท `list`** หมายถึง ข้อมูลประเภทรายการข้อมูล ที่สามารถแก้ไขค่าได้

```python
p = []
q = [1, 2, 3]
r = [1, "apple", 3.14, True]
s = [[1, 2, 3], [4, 5, 6], [7, 8, 9]]
```

**ข้อมูลประเภท `tuple`** หมายถึง ข้อมูลประเภทรายการข้อมูล
ที่<ins>ไม่สามารถแก้ไขค่าได้</ins>

```python
p = ()
q = (1, 2, 3)
r = (1, "apple", 3.14, True)
s = ((1, 2, 3), (4, 5, 6), (7, 8, 9))
```

**ข้อมูลประเภท `set`** หมายถึง ข้อมูลประเภทรายการข้อมูล
ที่<ins>มีสมาชิกไม่ซ้ำกัน</ins>

```python
x = set()
y = {1, 2, 3, 4}
z = {"apple", "banana", "orange"}
```

**ข้อมูลประเภท `dict`** หมายถึง ข้อมูลประเภทรายการของคู่ข้อมูล `key` และ `value`

```python
x = {}
y = {"name": "John", "age": 20, "gender": "male"}
```

**ข้อมูลประเภท `None`** หมายถึง ข้อมูลพิเศษที่บ่งบอกว่า ไม่มีค่าใด ๆ

```python
x = None
```

## 1.3. Type Conversion

**ฟังก์ชัน `int()`** หมายถึง คำสั่งที่แปลงข้อมูลให้เป็นประเภท `int`

**ตัวอย่างที่ 1:** การแปลงค่า `5.8` เป็น `5`

```python
x = int(5.8)
```

**ตัวอย่างที่ 2:** การแปลงค่า `"125"` เป็น `125`

```python
x = int("125")
```

> [!WARNING]
>
> การใช้คำสั่งอย่าง `int("ABCD")` หรือ `int("3.14")` จะทำให้เกิด error

**ฟังก์ชัน `float()`** หมายถึง คำสั่งที่แปลงข้อมูลเป็นประเภท `float`

**ตัวอย่างที่ 1:** การแปลงค่า `5` เป็น `5.0`

```python
x = float(5)
```

**ตัวอย่างที่ 2:** การแปลงค่า `"-91"` เป็น `-91.0`

```python
x = float("-91")
```

**ตัวอย่างที่ 3:** การแปลงค่า `"3.14"` เป็น `3.14`

```python
x = float("3.14")
```

> [!WARNING]
>
> การใช้คำสั่งอย่าง `float("ABCD")` จะทำให้เกิด error

**ฟังก์ชัน `str()`** หมายถึง คำสั่งที่แปลงข้อมูลเป็นประเภท `str`

**ตัวอย่างที่ 1:** การแปลงค่า `5` เป็น `"5"`

```python
x = str(5)
```

**ตัวอย่างที่ 2:** การแปลงค่า `3.14` เป็น `"3.14"`

```python
x = str(3.14)
```

**ตัวอย่างที่ 3:** การแปลงค่า `[1, 2, 3]` เป็น `"[1, 2, 3]"`

```python
x = str([1, 2, 3])
```

# Section 2: Input/Output

ก่อนอื่น เราต้องทำเข้าใจความหมายของสองคำนี้ก่อน

- **Input** หมายถึง การรับค่าข้อมูลจากผู้ใช้งาน เข้าสู่โปรแกรม
- **Output** หมายถึง การที่โปรแกรม แสดงผลข้อมูลออกมาทางหน้าจอ

## 2.1. Input

**ฟังก์ชัน `input()`** หมายถึง คำสั่งที่ใช้รับค่าจากผู้ใช้งาน
แล้วเก็บใส่ตัวแปรเป็นข้อมูลประเภท `str`

**ตัวอย่างที่ 1:** การรับค่าจากผู้ใช้งาน แล้วเก็บใส่ตัวแปร `x` เป็นข้อมูลประเภท
`str`

```python
x = input()
```

หลังจาก run code นี้แล้ว ถ้าหากกรอกค่าดังกล่าวลงบน terminal

```
20
```

ตัวแปร `x` จะเก็บค่า `"20"` ที่เป็นข้อมูลประเภท `str`

**ตัวอย่างที่ 2:** การรับค่าจากผู้ใช้งาน แล้วเก็บใส่ตัวแปร `x` เป็นข้อมูลประเภท
`int`

```python
x = int(input())
```

หลังจาก run code นี้แล้ว ถ้าหากกรอกค่าดังกล่าวลงบน terminal

```
20
```

- โดยปกติแล้ว ฟังก์ชันจะได้รับข้อมูลจากผู้ใช้งานเป็น `"20"` ซึ่งเป็นข้อมูลประเภท
  `str`
- แต่ว่าเรามีฟังก์ชัน `int()` ครอบไว้อยู่ จึงมีการแปลง `"20"` ให้เป็น `20`
- ดังนั้น ตัวแปร `x` จะเก็บค่า `20` ที่เป็นข้อมูลประเภท `int`

> [!WARNING]
>
> ในการใช้คำสั่ง `x = int(input())` นั้น
>
> โปรแกรมจะเกิด error เมื่อผู้ใช้งานกรอกค่าที่ไม่สามารถแปลงเป็น `int` ได้ (เช่น
> `"ABCD"` หรือ `"10.5"`)

**ตัวอย่างที่ 3:** การรับค่าจากผู้ใช้งาน แล้วเก็บใส่ตัวแปร `x` เป็นข้อมูลประเภท
`float`

```python
x = float(input())
```

หลังจาก run code นี้แล้ว ถ้าหากกรอกค่าดังกล่าวลงบน terminal

```
20
```

- โดยปกติแล้ว ฟังก์ชันจะได้รับข้อมูลจากผู้ใช้งานเป็น `"20"` ซึ่งเป็นข้อมูลประเภท
  `str`
- แต่ว่าเรามีฟังก์ชัน `float()` ครอบไว้อยู่ จึงมีการแปลง `"20"` ให้เป็น `20.0`
- ดังนั้น ตัวแปร `x` จะเก็บค่า `20.0` ที่เป็นข้อมูลประเภท `float`

> [!WARNING]
>
> ในการใช้คำสั่ง `x = float(input())` นั้น
>
> โปรแกรมจะเกิด error เมื่อผู้ใช้งานกรอกค่าที่ไม่สามารถแปลงเป็น `float` ได้
> (เช่น `"ABCD"`)

นอกจากนี้ ฟังก์ชัน `input()` ยังสามารถใส่ข้อความเข้าไปข้างในฟังก์ชันได้ด้วย
เพื่อระบุว่าให้ผู้ใช้งานโปรแกรมกรอกค่าอะไรเข้าไป

**ตัวอย่างที่ 4:** การรับค่าจากผู้ใช้งาน แล้วเก็บใส่ตัวแปร `x`
โดยมีการแสดงผลข้อความว่าให้กรอกค่าอะไร

```python
name = input("Enter your name here: ")
```

เมื่อกด run code ก็จะมีข้อความแบบนี้ขึ้นมาทันที

```
Enter your name here:
```

จากนั้นเราก็พิมพ์ค่าที่เราต้องการลงบน terminal ดังตัวอย่าง

```
Enter your name here: John
```

เมื่อกด Enter ตัวแปร `name` จะเก็บค่า `"John"` ที่เป็นข้อมูลประเภท `str` ทันที

## 2.2. Output

**ฟังก์ชัน `print()`** หมายถึง คำสั่งที่แสดงผลค่าบนหน้าจอ

**ตัวอย่างที่ 1:** การแสดงข้อมูลประเภทต่าง ๆ

```python
print("Hello, World!")
print(12)
print(12.5)
print(True)
print([1, 2, 3])
print({"name": "John", "age": 20})
```

โปรแกรมจะแสดงผลดังนี้

```
Hello, World!
12
12.5
True
[1, 2, 3]
{'name': 'John', 'age': 20}
```

**ตัวอย่างที่ 2:** การแสดงผลค่าบนตัวแปร

```python
a = "Hello, World!"
b = 12
c = 12.5
d = True
e = [1, 2, 3]
f = {"name": "John", "age": 20}

print(a)
print(b)
print(c)
print(f)
print(g)
print(h)
```

โปรแกรมจะแสดงผลดังนี้

```
Hello, World!
12
12.5
True
[1, 2, 3]
{'name': 'John', 'age': 20}
```

**ตัวอย่างที่ 3:** การแสดงผลหลายค่าบน 1 บรรทัด

```python
width = 10
height = 20

print("The rectangle width is", width)
print("The rectangle height is", height)
```

โปรแกรมจะแสดงผลดังนี้

```
The rectangle width is 10
The rectangle height is 20
```

**ตัวอย่างที่ 4:** การใช้งานคำสั่ง `input()` ร่วมกับ `print()`

```python
name = input("Enter your name: ")
age = int(input("Enter your age: "))

print("Hello", name)
print("You are", age, "years old.")
```

เมื่อรันโปรแกรม บน terminal จะแสดงผลดังกล่าว

```
Enter your name:
```

ผู้ใช้งานกรอกชื่อ `John` เข้าไปบนโปรแกรม

```
Enter your name: John
```

เมื่อกด Enter แล้ว จะแสดงผลให้กรอกค่าอายุเข้าไป

```
Enter your name: John
Enter yout age:
```

ผู้ใช้งานกรอกอายุ `20` เข้าไปบนโปรแกรม

```
Enter your name: John
Enter yout age: 20
```

เมื่อกด Enter ก็จะแสดงผลดังนี้

```
Enter your name: John
Enter your age: 20
Hello John

```

## 2.3. `f-string`

`f-string` เป็นเครื่องมือที่ช่วยในการจัดรูปแบบการแสดงผลข้อความในภาษา Python

**ตัวอย่าง:** การใช้งาน `f-string`

```python
name = input("Enter your name: ")
age = int(input("Enter your age: "))

print(f"Hello {name}, you are {age} years old.")
```

เมื่อกรอกข้อมูลชื่อ `John` และอายุ `20` ปี ลงไปบนโปรแกรม จะแสดงผลดังนี้

```
Enter your name: John
Enter your age: 20
Hello John, you are 20 years old.
```

# Section 3: Arithmetic Operations

**Arithmetic Operations** จะกล่าวถึงการดำเนินการทางคณิตศาสตร์เบื้องต้น ในภาษา
Python เช่น การบวก การลบ การคูณ การหาร เป็นต้น

## 3.1. Arithmetic Operations

**การบวก (Addition)** จะใช้เครื่องหมาย `+`

```python
a = 3 + 2
b = 2 + 3.6
c = 3.25 + 0.1090
```

ซึ่งแต่ละบรรทัดจะมีผลลัพธ์ดังนี้

```python
a = 5
b = 5.6
c = 3.359
```

---

**การลบ (Subtraction)** จะใช้เครื่องหมาย `-`

```python
a = 3 - 2
b = 2 - 3.6
c = 3.25 - 0.1090
```

ซึ่งแต่ละบรรทัดจะมีผลลัพธ์ดังนี้

```python
a = 1
b = -1.6
c = 3.141
```

---

**การคูณ (Multiplication)** จะใช้เครื่องหมาย `*`

```python
a = 3 * 2
b = 2 * 3.6
c = 3.25 * 0.1090
```

ซึ่งแต่ละบรรทัดจะมีผลลัพธ์ดังนี้

```python
a = 6
b = 7.2
c = 0.35425
```

---

**การหาร (Division)** จะใช้เครื่องหมาย `/`

```python
a = 4 / 2
b = 2 / 3.6
c = 3.25 / 0.1090
```

ซึ่งแต่ละบรรทัดจะมีผลลัพธ์ดังนี้

```python
a = 2.0
b = 0.5555555555555556
c = 29.81651376146789
```

> [!IMPORTANT]
>
> การหาร (Division) จะได้ผลลัพธ์ออกมาเป็น `float` เสมอ

---

**การหารปัดเศษ (Floor Division)** หมายถึง การหารโดยปัดเศษทิ้ง
โดยจะใช้เครื่องหมาย `//`

```python
a = 5 // 2
b = 2 // 3.6
c = 3.6 // 2
d = 3.25 // 0.1090
```

ซึ่งแต่ละบรรทัดจะมีผลลัพธ์ดังนี้

```python
a = 2
b = 0.0
c = 1.0
d = 29.0
```

> [!IMPORTANT]
>
> การหารปัดเศษ (Floor Division) จะได้ผลลัพธ์ออกมาเป็น `int` หรือ `float` ก็ได้

---

**เศษจากการหาร (Modulo)** หมายถึง การหาเศษจากการหาร โดยจะใช้เครื่องหมาย `%`

```python
a = 5 % 2
b = 2 % 11
```

ซึ่งแต่ละบรรทัดจะมีผลลัพธ์ดังนี้

```python
a = 1
b = 2
```

---

**ยกกำลัง (Power)** จะใช้เครื่องหมาย `**`

```python
a = 5 ** 2
b = 2 ** 3.6
c = -3.6 ** -2
d = 3.25 ** 0.1090
```

ซึ่งแต่ละบรรทัดจะมีผลลัพธ์ดังนี้

```python
a = 25
b = 12.125732532083186
c = -0.07716049382716049
d = 1.1370911681248133
```

## 3.2. Operations Precedence

**Operations Precedence** หมายถึง ลำดับการคำนวณในภาษา Python โดยยึดตามหลักการ
PEMDAS

หลักการ PEMDAS จะเรียงลำดับความสำคัญการดำเนินการทางคณิตศาสตร์ ดังนี้

- **P**arentheses หมายถึง การคำนวณวงเล็บ `()`
- **E**xponential หมายถึง ยกกำลัง `**`
- **M**ultiply หมายถึง การคูณ `*`
- **D**ivide หมายถึง การหาร (`/` และ `//`) และ modulo `%`
- **A**dd หมายถึง การบวก `+`
- **S**ubtract หมายถึง การลบ `-`

> [!IMPORTANT]
>
> - การคูณ และ การหาร มีความสำคัญเท่ากัน
> - การบวก และ การลบ มีความสำคัญเท่ากัน
> - ถ้าหากมีความสำคัญเท่ากัน จะดำเนินการจากซ้ายไปขวา (ยกเว้นการยกกำลัง
>   จะดำเนินการจากขวาไปซ้าย)

**ตัวอย่าง:** การดำเนินการทางคณิตศาสตร์บนภาษา Python

```python
x = 2 * 3 + 8 / -(2 - 4) - 2 ** 2 ** 3
```

**ขั้นตอนที่ 1:** คำนวณในวงเล็บก่อน

```python
x = 2 * 3 + 8 / -(-2) - 2 ** 2 ** 3
```

**ขั้นตอนที่ 2:** คำนวณยกกำลังจากขวาไปซ้าย

```python
x = 2 * 3 + 8 / -(-2) - 2 ** 8
x = 2 * 3 + 8 / -(-2) - 256
```

**ขั้นตอนที่ 3:** เครื่องหมายติดลบ

```python
x = 2 * 3 + 8 / 2 - 256
```

**ขั้นตอนที่ 4:** เครื่องหมายคูณ และเครื่องหมายหาร

```python
x = 6 + 8 / 2 - 256
x = 6 + 4.0 - 256
```

**ขั้นตอนที่ 5:** เครื่องหมายบวก และเครื่องหมายลบ

```python
x = 10.0 - 256
x = -246.0
```

## 4.1. Built-in Function

**Built-in Function** หมายถึง ฟังก์ชันทางคณิตศาสตร์เบื้องต้น ที่ภาษา Python
มีมาให้อยู่แล้ว

**ฟังก์ชัน `abs(x)`** หมายถึง คำสั่งในการคำนวณค่าสัมบูรณ์ของ `x`

```python
a = abs(-5)
b = abs(-2.13)
```

ซึ่งแต่ละบรรทัดจะมีผลลัพธ์ดังนี้

```python
a = 5
b = 2.13
```

**ฟังก์ชัน `max()`** หมายถึง คำสั่งในการคำนวณค่าสูงสุดในรายการข้อมูล

```python
a = max(-99, 81.2)
b = max("apple", "banana")
c = max([8, 1, -99, 1.02, 99, 124.2])
d = max(["apple", "orange", "grape", "banana"])
```

ซึ่งแต่ละบรรทัดจะมีผลลัพธ์ดังนี้

```python
a = 81.2
b = "banana"
c = 124.2
d = "orange"
```

> [!WARNING]
>
> ถ้าหากข้อมูลภายในรายการข้อมูล ไม่สามารถนำมาเปรียบเทียบกันได้ จะเกิด error
>
> ตัวอย่าง: การใช้คำสั่ง `max(["banana", 82, -36.2, "apple"])` จะเกิด error
> เนื่องจากว่าเราไม่สามารถเปรียบเทียบ `"banana"` ที่เป็นข้อมูลประเภท `str`
> ว่ามีค่ามากกว่าหรือน้อยกว่า `82` ที่เป็นข้อมูลประเภท `int`

**ฟังก์ชัน `min()`** หมายถึง คำสั่งในการคำนวณค่าต่ำสุดในรายการข้อมูล

```python
a = min(-99, 81.2)
b = min("apple", "banana")
c = min([8, 1, -99, 1.02, 99, 124.2])
d = min(["apple", "orange", "grape", "banana"])
```

ซึ่งแต่ละบรรทัดจะมีผลลัพธ์ดังนี้

```python
a = -99
b = "apple"
c = -99
d = "apple"
```

> [!WARNING]
>
> ถ้าหากข้อมูลภายในรายการข้อมูล ไม่สามารถนำมาเปรียบเทียบกันได้ จะเกิด error
>
> ตัวอย่าง: การใช้คำสั่ง `min(["banana", 82, -36.2, "apple"])` จะเกิด error
> เนื่องจากว่าเราไม่สามารถเปรียบเทียบ `"banana"` ที่เป็นข้อมูลประเภท `str`
> ว่ามีค่ามากกว่าหรือน้อยกว่า `82` ที่เป็นข้อมูลประเภท `int`

**ฟังก์ชัน `pow(x, y)`** หมายถึง คำสั่งในการคำนวณค่ายกกำลัง (`x ** y`)

```python
a = pow(2, 3)
b = pow(-3, 2)
c = pow(0.125, 9.21)
d = pow(-1.2, -2.945)
```

ซึ่งแต่ละบรรทัดจะมีผลลัพธ์ดังนี้

```python
a = 8
b = 9
c = 4.814389462163634e-09
d = (-0.5758318213704288-0.10049874093356931j)
```

> [!TIP]
>
> ในภาษา Python จะมีประเภทข้อมูล `complex` หรือข้อมูลประเภทจำนวนเชิงซ้อนอยู่
> เช่น `x = 2 + 5j` โดยที่ `j = sqrt(-1)`

**ฟังก์ชัน `round(x, n)`** หมายถึง คำสั่งในการปัดเศษเลข `x` ให้มีจำนวนทศนิยม `n`
ตำแหน่ง

```python
a = round(3.14159265359, 2)
b = round(3.14159265359, 3)
c = round(2, 3)
d = round(3.14159265359)
```

ซึ่งแต่ละบรรทัดจะมีผลลัพธ์ดังนี้

```python
a = 3.14
b = 3.142
c = 2
d = 3
```

> [!TIP]
>
> - สำหรับฟังก์ชัน `round(x, n)` ถ้าหากตัวเลข `x`
>   ที่ป้อนเข้าไปมีจำนวนทศนิยมน้อยกว่า `n` จะได้ค่าออกมาเท่าเดิม
> - สำหรับฟังก์ชัน `round(x, n)` ถ้าหากไม่ป้อนค่า `n` เข้าไป
>   จะเป็นการปัดเลขเป็นจำนวนเต็ม

**ฟังก์ชัน `sum(nums)`** หมายถึง คำสั่งในการปัดเศษเลข `x` ให้มีจำนวนทศนิยม `n`
ตำแหน่ง

```python
a = sum([1, 2, 3])
b = sum([1.7, 2.4, 3.9])
c = sum([1.5, 2, 3.9])
```

```python
a = 6
b = 8.0
c = 7.4
```
