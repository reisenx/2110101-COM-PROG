## การรับค่าสัมประสิทธิ์เป็นจำนวนจริง

สมการกำลังสองมีรูป $ax^2 + bx + c = 0$ โดย `a`, `b` และ `c`
อาจมีส่วนทศนิยม จึงรับข้อมูลแต่ละบรรทัดด้วย `float(input())`

```python
a = float(input())
b = float(input())
c = float(input())
```

เนื่องจากเป็นสมการกำลังสองจึงมี $a \ne 0$
และค่าทั้งสามนี้จะนำไปใช้ในสูตรหารากโดยตรง

---

## ดิสคริมิแนนต์และสูตรหาราก

ส่วนที่อยู่ภายในรากที่สองเรียกว่า **ดิสคริมิแนนต์**

$$
\Delta = b^2 - 4ac
$$

เมื่อทราบ $\Delta$ แล้ว รากทั้งสองค่าคือ

$$
x_1 = \frac{-b-\sqrt{\Delta}}{2a}
\qquad
x_2 = \frac{-b+\sqrt{\Delta}}{2a}
$$

ใน Python ใช้ `**` คำนวณ $b^2$ และใช้ `math.sqrt(...)` คำนวณรากที่สอง
จึงแปลงสูตรได้ตรงตัวดังนี้

```python
x1 = (-1 * b - math.sqrt(b**2 - 4 * a * c)) / (2 * a)
x2 = (-1 * b + math.sqrt(b**2 - 4 * a * c)) / (2 * a)
```

`-1 * b` มีค่าเดียวกับ $-b$ และวงเล็บรอบตัวเศษทำให้ทั้งตัวเศษ
ถูกหารด้วย `2 * a`

> [!NOTE]
>
> โจทย์รับประกันว่าสมการมีรากจริงสองค่าที่ต่างกัน จึงมี $\Delta > 0$
> เสมอ `math.sqrt(...)` จึงไม่พบจำนวนลบ และไม่ต้องเขียนกรณีรากซ้ำ
> หรือรากเชิงซ้อนเพิ่ม

---

## ลำดับรากและการปัดเศษ

โจทย์นิยาม `x1` ด้วยเครื่องหมายลบหน้า $\sqrt{\Delta}$
และนิยาม `x2` ด้วยเครื่องหมายบวก จากนั้นต้องแสดง `x1` ก่อน `x2`

แต่ละค่าถูกปัดให้เหลือทศนิยมไม่เกิน 3 ตำแหน่งด้วย `round(..., 3)`
แล้ว `print()` จะแสดงสองค่าในบรรทัดเดียวโดยคั่นด้วยช่องว่าง

```python
print(round(x1, 3), round(x2, 3))
```

> [!NOTE]
>
> `round()` ปัดค่าของตัวเลข แต่ไม่ได้เติมเลขศูนย์ท้ายทศนิยม
> ดังนั้นผลลัพธ์อาจเป็น `2.0` แทน `2.000` ซึ่งตรงกับรูปแบบที่โจทย์กำหนด

# Solution

```python
# --------------------------------------------------
# File Name : 01_Expr_02.py
# Problem   : Quadratic Root
# Author    : Worralop Srichainont
# Date      : 2025-06-10
# --------------------------------------------------

import math

# Input a, b and c as float
a = float(input())
b = float(input())
c = float(input())

# Calculate roots of the equation ax^2 + bx + c
x1 = (-1 * b - math.sqrt(b**2 - 4 * a * c)) / (2 * a)
x2 = (-1 * b + math.sqrt(b**2 - 4 * a * c)) / (2 * a)

# Output
# Round the result to 3 decimal places
print(round(x1, 3), round(x2, 3))
```
