## การประมาณค่าแฟกทอเรียลด้วยขอบเขต

ค่าแฟกทอเรียล $n! = 1 \times 2 \times \cdots \times n$ โตเร็วมากเมื่อ `n`
มีค่ามาก สูตรของ Stirling ในโจทย์จึงไม่ได้หาค่า `n!` โดยตรง
แต่สร้างค่าที่คร่อมคำตอบไว้ระหว่าง **ขอบเขตล่าง** และ **ขอบเขตบน**

สำหรับ $n > 0$ ขอบเขตทั้งสองเป็นดังนี้

$$
L = \sqrt{2\pi}\,n^{n+\frac{1}{2}}
    e^{-n+\frac{1}{12n+1}}
$$

$$
U = \sqrt{2\pi}\,n^{n+\frac{1}{2}}
    e^{-n+\frac{1}{12n}}
$$

โดยมีความสัมพันธ์ $L < n! < U$ ดังนั้นตัวแปร `lower` ใช้เก็บ $L$
และตัวแปร `upper` ใช้เก็บ $U$

> [!NOTE]
>
> โค้ดนี้ต้องรับจำนวนเต็มบวก `n` เพราะเมื่อ `n = 0` พจน์ `1 / (12 * n)`
> ในสูตรขอบเขตบนจะเกิดการหารด้วยศูนย์

---

## การเขียนสูตรด้วย Python

โมดูล `math` มีค่าคงที่ `math.pi` สำหรับ $\pi$, `math.e` สำหรับ $e$
และฟังก์ชัน `math.sqrt(x)` สำหรับ $\sqrt{x}$ ส่วนเครื่องหมาย `**`
ใช้ยกกำลัง เช่น `n ** (n + (1 / 2))` ตรงกับ $n^{n+\frac{1}{2}}$

เมื่อนำแต่ละส่วนมาประกอบกัน ขอบเขตล่างเขียนได้ว่า

```python
lower = (
    math.sqrt(2 * math.pi) * n ** (n + (1 / 2)) * math.e ** (-n + (1 / (12 * n + 1)))
)
```

และขอบเขตบนต่างจากขอบเขตล่างเฉพาะส่วนท้ายของเลขชี้กำลัง
จาก $\frac{1}{12n+1}$ เป็น $\frac{1}{12n}$

```python
upper = math.sqrt(2 * math.pi) * n ** (n + (1 / 2)) * math.e ** (-n + (1 / (12 * n)))
```

วงเล็บช่วยให้ Python คำนวณเลขชี้กำลังแต่ละชุดตามรูปของสูตร
ก่อนนำผลจากทุกพจน์มาคูณกัน

---

## ลำดับการแสดงผล

โจทย์กำหนดให้แสดงขอบเขตล่างก่อน แล้วจึงแสดงขอบเขตบน
โดยแต่ละค่าอยู่คนละบรรทัด

```python
print(lower)
print(upper)
```

> [!WARNING]
>
> นิพจน์นี้ให้ผลเป็น `float` ซึ่งมีขอบเขตและความละเอียดจำกัด
> ค่าอย่าง `3.0414009534599554e+64` เป็นเพียงการแสดงเลขขนาดใหญ่
> ในรูปสัญกรณ์วิทยาศาสตร์ แต่ถ้า `n` ใหญ่มากกว่านั้น การคำนวณอาจล้นช่วง
> หรือสูญเสียความแม่นยำได้

# Solution

```python
# --------------------------------------------------
# File Name : 01_Expr_01.py
# Problem   : Stirling Factorial
# Author    : Worralop Srichainont
# Date      : 2025-06-10
# --------------------------------------------------

import math

# Input n
n = int(input())

# Calculate the lower bound of n!
lower = (
    math.sqrt(2 * math.pi) * n ** (n + (1 / 2)) * math.e ** (-n + (1 / (12 * n + 1)))
)
print(lower)

# Calculate the upper bound of n!
upper = math.sqrt(2 * math.pi) * n ** (n + (1 / 2)) * math.e ** (-n + (1 / (12 * n)))
print(upper)
```
