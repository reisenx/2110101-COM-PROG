## แนวคิดของฟังก์ชันทั้งสี่

โจทย์ข้อนี้แบ่งงานออกเป็นฟังก์ชันย่อย 4 ฟังก์ชัน แต่ละฟังก์ชันรับข้อมูล
และคืนผลลัพธ์ตามหน้าที่ของตนเอง

-   `make_int_list(numbers)` แปลงข้อความเป็นลิสต์จำนวนเต็ม
-   `is_odd(num)` ตรวจว่าจำนวนหนึ่งเป็นจำนวนคี่หรือไม่
-   `odd_list(numbers)` เลือกเฉพาะจำนวนคี่จากลิสต์
-   `sum_square(numbers)` หาผลรวมกำลังสองของสมาชิกทุกตัว

การกำหนดหน้าที่ให้ชัดเจนทำให้ฟังก์ชันหนึ่งเรียกใช้อีกฟังก์ชันหนึ่งได้
เช่น `odd_list` ใช้ `is_odd` ตรวจสมาชิกทีละตัว จึงไม่ต้องเขียนเงื่อนไข
ตรวจจำนวนคี่ซ้ำ

---

## การแปลงข้อความเป็นลิสต์จำนวนเต็ม

ข้อมูลของ `make_int_list` เป็นสตริงที่มีจำนวนหลายจำนวนคั่นด้วยช่องว่าง
การแปลงข้อมูลทำเป็น 2 ขั้นตอน

1. `numbers.split()` แยกสตริงเป็นคำตาม whitespace เช่น ช่องว่างหรือ tab
2. `int(num)` แปลงแต่ละคำจากสตริงให้เป็นจำนวนเต็ม

โค้ดใช้ list comprehension เพื่อทำทั้งสองขั้นตอนกับทุกคำ

```python
[int(num) for num in numbers.split()]
```

ตัวอย่างเช่น สตริง `'  12   -3 12 '` ถูกแยกเป็น
`['12', '-3', '12']` แล้วแปลงเป็น `[12, -3, 12]`
`split()` ที่ไม่ระบุตัวคั่นจะข้าม whitespace ที่ซ้ำกัน
ส่วนลำดับและค่าที่ซ้ำยังคงเหมือนข้อมูลเดิม

ถ้าสตริงว่างหรือมีแต่ whitespace จะไม่มีคำให้แปลง จึงได้ลิสต์ว่าง `[]`

## การตรวจและคัดเลือกจำนวนคี่

จำนวนคี่คือจำนวนที่หารด้วย `2` แล้วมีเศษไม่เท่ากับ `0`
ฟังก์ชัน `is_odd` จึงใช้นิพจน์

```python
num % 2 != 0
```

เครื่องหมาย `%` หาเศษจากการหาร นิพจน์นี้ให้ค่า `True` เมื่อ `num` เป็น
จำนวนคี่ และให้ค่า `False` เมื่อเป็นจำนวนคู่หรือ `0`
วิธีนี้ใช้กับจำนวนเต็มลบได้ด้วย เช่น `-3 % 2` มีค่า `1`
ดังนั้น `is_odd(-3)` จึงเป็น `True`

จากนั้น `odd_list` เดินดูสมาชิกใน `numbers` จากซ้ายไปขวา และเก็บสมาชิกไว้
เมื่อ `is_odd(num)` เป็นจริง

```python
[num for num in numbers if is_odd(num)]
```

เพราะตรวจตามลำดับเดิม ฟังก์ชันจึงไม่เรียงข้อมูลใหม่และไม่ลบค่าซ้ำ เช่น
`[4, -3, 3, 3, -2]` จะได้ `[-3, 3, 3]`
ถ้าลิสต์ว่างหรือไม่มีจำนวนคี่ จะได้ `[]`

## การหาผลรวมกำลังสอง

ถ้าลิสต์มีสมาชิก $a_1, a_2, \ldots, a_n$ ค่าที่ต้องการคือ

$$
S = a_1^2 + a_2^2 + \cdots + a_n^2
$$

โค้ดเริ่มตัวสะสม `total` ที่ `0` แล้วบวกกำลังสองของสมาชิกแต่ละตัว

```python
total += num**2
```

ตัวอย่าง `[1, 1, 2, 3]` ให้ผลลัพธ์
$1^2 + 1^2 + 2^2 + 3^2 = 15$
ค่าที่ซ้ำจะถูกนำมาคิดทุกครั้ง และจำนวนลบก็ใช้ได้เพราะกำลังสองเป็นค่าบวก
เช่น `(-3) ** 2` เท่ากับ `9`

ถ้า `numbers` เป็นลิสต์ว่าง ลูปจะไม่ทำงานและฟังก์ชันจะคืนค่าเริ่มต้น `0`

## การทดสอบฟังก์ชันด้วย exec

ข้อมูลนำเข้าของโจทย์เป็นคำสั่ง Python ที่ Grader ใช้เรียกฟังก์ชัน เช่น
`print(odd_list([1, 2, 3, 4]))` บรรทัด `exec(input().strip())`
จะอ่านคำสั่งหนึ่งบรรทัด ตัด whitespace ที่หัวและท้าย แล้วประมวลผลคำสั่งนั้น
ผลจาก `print()` จึงปรากฏบนหน้าจอ

> [!WARNING]
>
> `exec()` สามารถรันข้อความใด ๆ ในฐานะโค้ด Python ได้ วิธีนี้เหมาะกับคำสั่ง
> จาก Grader ที่เชื่อถือได้เท่านั้น ห้ามใช้กับข้อความจากผู้ใช้หรือแหล่งข้อมูล
> ที่ไม่เชื่อถือ

# Solution

```python
# --------------------------------------------------
# File Name : 06_Func_23.py
# Problem   : Four Functions
# Author    : Worralop Srichainont
# Date      : 2025-06-12
# --------------------------------------------------


# Convert a string into a list of integers
def make_int_list(numbers):
    return [int(num) for num in numbers.split()]


# Check if a number is odd
def is_odd(num):
    return num % 2 != 0


def odd_list(numbers):
    return [num for num in numbers if is_odd(num)]


# Calculate the sum of squares of a list of numbers
def sum_square(numbers):
    total = 0
    for num in numbers:
        total += num**2
    return total


# Execute a input string as code
exec(input().strip())
```
