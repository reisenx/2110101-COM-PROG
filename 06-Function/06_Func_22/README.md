## การหาระยะห่างระหว่างสองจุด

ระยะห่างระหว่างจุด $(x_1, y_1)$ และ $(x_2, y_2)$
หาได้จากทฤษฎีบทพีทาโกรัส

$$
d = \sqrt{(x_1 - x_2)^2 + (y_1 - y_2)^2}
$$

เมื่อนำสูตรนี้มาเขียนเป็น Python จะได้

```python
((x1 - x2) ** 2 + (y1 - y2) ** 2) ** 0.5
```

-   `** 2` คือการยกกำลังสอง
-   `** 0.5` คือการยกกำลัง $\frac{1}{2}$ ซึ่งเท่ากับการหารากที่สอง

ฟังก์ชัน `distance1(x1, y1, x2, y2)` จึงคืนค่าจากสูตรนี้ได้โดยตรง เช่น
จุด `(0, 0)` และ `(3, 4)` ต่างกันตามแนวแกนเป็น `3` กับ `4` หน่วย
จึงมีระยะห่างเท่ากับ $\sqrt{3^2 + 4^2} = 5$ และ Python คืนค่าเป็น `5.0`

## การรับจุดและวงกลมด้วยลิสต์

`distance1` รับพิกัดแยกกัน 4 ค่า แต่ `distance2` รับจุดแต่ละจุดเป็นลิสต์
รูปแบบ `[x, y]` จึงต้องแยกสมาชิกออกมาก่อน

```python
x1, y1 = point_01
x2, y2 = point_02
```

คำสั่งนี้เรียกว่า **การ unpack** ลิสต์ โดยนำสมาชิกตำแหน่งแรกไปเก็บในตัวแปร
พิกัด `x` และสมาชิกตำแหน่งที่สองไปเก็บในตัวแปรพิกัด `y`
จากนั้น `distance2` เรียก `distance1(x1, y1, x2, y2)` ต่อ
จึงไม่ต้องเขียนสูตรหาระยะห่างซ้ำอีกครั้ง

ในทำนองเดียวกัน วงกลมหนึ่งวงแทนด้วยลิสต์ `[x, y, r]` ซึ่งเก็บพิกัด
จุดศูนย์กลางและรัศมีตามลำดับ `distance3` จึง unpack ข้อมูลของวงกลมแต่ละวงเป็น
ตัวแปร 3 ตัว แล้วใช้ `distance1` หาระยะระหว่างจุดศูนย์กลาง

> [!NOTE]
>
> ข้อมูลตามโจทย์ต้องมีสมาชิกตรงตามรูปแบบ จุดต้องมี 2 ค่า และวงกลมต้องมี 3 ค่า
> มิฉะนั้น Python จะไม่สามารถ unpack ลงในตัวแปรตามจำนวนที่กำหนดได้

## การตรวจว่าวงกลมแตะหรือทับกัน

ให้ $d$ เป็นระยะระหว่างจุดศูนย์กลาง และให้ $r_1, r_2$ เป็นรัศมี
วงกลมทั้งสองแตะหรือทับกันเมื่อ

$$
d \le r_1 + r_2
$$

ซึ่งตรงกับนิพจน์ Python

```python
dist <= radius_01 + radius_02
```

-   ถ้า `dist` น้อยกว่าผลรวมรัศมี วงกลมจะทับกัน
-   ถ้า `dist` เท่ากับผลรวมรัศมี วงกลมจะแตะกันพอดี
-   ถ้า `dist` มากกว่าผลรวมรัศมี วงกลมจะแยกออกจากกัน

ฟังก์ชันคืนค่าด้วย `return dist, is_overlapping` จึงได้ผลลัพธ์เป็น tuple
`(ระยะห่าง, ค่าจริงหรือเท็จ)` ผู้เรียกสามารถรับค่าทั้งคู่พร้อมกันได้ เช่น

```python
a, b = distance3([0, 0, 1], [5, 0, 2])
```

ตัวอย่างนี้มีระยะระหว่างจุดศูนย์กลาง `5.0` แต่ผลรวมรัศมีเท่ากับ `3`
จึงได้ `a == 5.0` และ `b == False`

## การหาความยาวรอบรูปหลายเหลี่ยม

ลิสต์ `points` เรียงจุดยอดของรูปหลายเหลี่ยมตามลำดับรอบรูป
ถ้ามีจุด $p_0, p_1, \ldots, p_{k-1}$ ความยาวรอบรูปคือ

$$
P = d(p_0,p_1) + d(p_1,p_2) + \cdots
    + d(p_{k-2},p_{k-1}) + d(p_{k-1},p_0)
$$

ลูป `for i in range(1, len(points))` บวกความยาวด้านระหว่าง
`points[i - 1]` กับ `points[i]` จนครบทุกคู่ที่อยู่ติดกัน
แต่ลูปยังไม่รวมด้านที่ปิดรูป จึงต้องบวกระยะจากจุดสุดท้าย `points[-1]`
กลับไปยังจุดแรก `points[0]` อีกหนึ่งครั้ง

ตัวอย่างสี่เหลี่ยม `[[0, 0], [0, 2], [2, 2], [2, 0]]`
มีด้านยาว `2` ทั้ง 4 ด้าน จึงได้ความยาวรอบรูป `8.0`
ตามเงื่อนไขโจทย์ รูปหลายเหลี่ยมมีอย่างน้อย 3 จุด

> [!NOTE]
>
> โค้ดไม่ได้ใช้ `round()` หรือกำหนดจำนวนตำแหน่งทศนิยม ผลลัพธ์จึงเป็นค่า
> floating-point ที่ Python คำนวณได้โดยตรง เช่น `5.0` และ `8.0`
> หากระยะไม่เป็นจำนวนเต็ม Python จะแสดงเลขทศนิยมตามปกติโดยไม่มีการปัดเพิ่ม

## การทดสอบฟังก์ชันด้วย exec

โจทย์ไม่ได้กำหนดให้โปรแกรมอ่านพิกัดเอง แต่ Grader จะส่งคำสั่ง Python สำหรับ
เรียกฟังก์ชันเข้ามา เช่น `print(distance1(0, 0, 3, 4))`
บรรทัด `exec(input().strip())` อ่านคำสั่งนั้น ตัดช่องว่างที่หัวและท้ายด้วย
`.strip()` แล้วให้ `exec()` ประมวลผลคำสั่ง จึงแสดงผลจากฟังก์ชันที่ถูกทดสอบ

> [!WARNING]
>
> `exec()` สามารถรันข้อความใด ๆ ในฐานะโค้ด Python ได้ วิธีนี้ใช้เพราะข้อมูล
> มาจาก Grader ที่เชื่อถือได้เท่านั้น ไม่ควรใช้ `exec()` กับข้อความจากผู้ใช้
> หรือแหล่งข้อมูลที่ไม่เชื่อถือ

# Solution

```python
# --------------------------------------------------
# File Name : 06_Func_22.py
# Problem   : Distance
# Author    : Worralop Srichainont
# Date      : 2025-06-12
# --------------------------------------------------


# Calculate the distance between two points (x1, y1) and (x2, y2)
def distance1(x1, y1, x2, y2):
    return ((x1 - x2) ** 2 + (y1 - y2) ** 2) ** 0.5


# Calculate the distance between two points p1 and p2
# p1 and p2 are lists in the format [x, y]
def distance2(point_01, point_02):
    x1, y1 = point_01
    x2, y2 = point_02
    return distance1(x1, y1, x2, y2)


# Calculate the distance between two circles c1 and c2
# c1 and c2 are lists in the format [x, y, r]
# where x and y are the center coordinates and r is the radius
# # It returns a tuple (distance, is_overlapping)
def distance3(circle_01, circle_02):
    x1, y1, radius_01 = circle_01
    x2, y2, radius_02 = circle_02
    dist = distance1(x1, y1, x2, y2)

    is_overlapping = dist <= radius_01 + radius_02
    return dist, is_overlapping


# Calculate the perimeter of a polygon defined by a list of points
# points is a list of lists in the format [[x1, y1], [x2, y2], ...]
def perimeter(points):
    total = 0.0
    for i in range(1, len(points)):
        total += distance2(points[i - 1], points[i])
    total += distance2(points[-1], points[0])
    return total


# Execute a input string as code
exec(input().strip())
```
