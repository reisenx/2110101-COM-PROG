## การรับและแปลงเลขฐานสอง

โจทย์รับจำนวนเต็มที่ไม่ติดลบ 2 จำนวนในรูป **สตริงเลขฐานสอง**
แต่ละสตริงจึงมีเพียงตัวอักษร `0` และ `1` และคั่นกันด้วยช่องว่าง เช่น

```
100101 11001
```

`input().split()` จะแยกข้อมูลบรรทัดนี้เป็น `"100101"` และ `"11001"`
จากนั้นใช้ `int(num, 2)` แปลงแต่ละสตริงเป็นจำนวนเต็ม โดยเลข `2`
หมายถึงให้ Python อ่าน `num` ในระบบฐานสอง

ตัวอย่างเช่น

$$
(100101)_2 = 1(2^5) + 1(2^2) + 1(2^0) = 37
$$

ใน Python เขียนการแปลงนี้ได้เป็น `int("100101", 2)` ซึ่งให้ค่า `37`
ส่วน `int("11001", 2)` ให้ค่า `25`

โปรแกรมใช้ list comprehension เพื่อแปลงข้อมูลทั้งสองจำนวนในบรรทัดเดียว

```python
numbers = [int(num, 2) for num in input().split()]
```

หลังจากบรรทัดนี้ ตัวแปร `numbers` จากตัวอย่างจึงมีค่า `[37, 25]`

> [!NOTE]
>
> ต้องระบุฐานเป็น `2` ใน `int(num, 2)` เพราะ `int(num)` จะตีความสตริง
> เป็นเลขฐานสิบตามปกติ

## การหาผลบวกและแปลงกลับเป็นฐานสอง

เมื่อข้อมูลถูกแปลงเป็นจำนวนเต็มแล้ว `sum(numbers)` สามารถหาผลบวกได้ทันที
จากตัวอย่างจะได้ `37 + 25 = 62`

ฟังก์ชัน `bin(x)` แปลงจำนวนเต็ม `x` กลับเป็นสตริงเลขฐานสอง แต่จะเติม
คำนำหน้า `0b` เพื่อบอกว่าเป็นเลขฐานสอง เช่น `bin(62)` ให้ค่า `"0b111110"`
โจทย์ต้องการเพียงตัวเลข จึงใช้ `[2:]` เลือกสตริงตั้งแต่ตำแหน่งที่ `2`
เป็นต้นไปและตัด `0b` ออก

```python
bin(sum(numbers))[2:]
```

นิพจน์นี้จึงให้ `"111110"` และ `print()` แสดงผลเป็น

```
111110
```

การแปลงด้วย `int()` และ `bin()` จะไม่เก็บเลข `0` ที่อยู่ด้านหน้าจำนวน เช่น
`"000101"` จะถูกแปลงเป็น `5` และแปลงกลับเป็น `"101"` ดังนั้นคำตอบจะไม่มี
เลขศูนย์นำหน้า

กรณีที่ข้อมูลทั้งสองจำนวนเป็นศูนย์ เช่น `000000 00000` จะได้ผลบวกเป็น `0`
โดย `bin(0)` ให้ `"0b0"` และเมื่อตัด `0b` แล้ว โปรแกรมจะแสดง `0`
ตามที่โจทย์กำหนด

## ลำดับการทำงานของโปรแกรม

1. รับสตริงเลขฐานสอง 2 จำนวนและแยกด้วย `split()`
2. แปลงแต่ละสตริงเป็นจำนวนเต็มด้วย `int(num, 2)`
3. รวมค่าทั้งสองด้วย `sum(numbers)`
4. แปลงผลบวกเป็นสตริงเลขฐานสองด้วย `bin()`
5. ตัดคำนำหน้า `0b` ด้วย `[2:]` แล้วแสดงคำตอบ 1 บรรทัด

# Solution

```python
# --------------------------------------------------
# File Name : 06_Func_11.py
# Problem   : Binary Adder
# Author    : Worralop Srichainont
# Date      : 2025-06-12
# --------------------------------------------------

# Input numbers in binary format
numbers = [int(num, 2) for num in input().split()]

# Output the sum of the binary numbers
print(bin(sum(numbers))[2:])
```
