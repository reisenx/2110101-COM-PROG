## แนวคิดของการแยกฟังก์ชัน

โปรแกรมตั้งต้นในโจทย์มีงานหลายอย่างอยู่รวมกัน ทั้งการอ่านวันที่ หาราศี
ตรวจปีอธิกสุรทิน และนับจำนวนวัน อีกทั้งยังมีชุดคำสั่งที่ซ้ำกันสำหรับวันที่ 2 วัน
การ **refactor** คือการจัดโครงสร้างโปรแกรมใหม่ให้แต่ละหน้าที่อยู่ในฟังก์ชันที่ชัดเจน
โดยยังคงผลลัพธ์เดิมไว้

โค้ดเฉลยแบ่งงานดังนี้

| ฟังก์ชัน | หน้าที่ |
| :-- | :-- |
| `read_date()` | อ่านวันที่ 1 บรรทัดและคืน `[วัน, เดือน, ปี]` |
| `zodiac(d, m)` | คืนชื่อราศีของวันและเดือน |
| `days_in_feb(y)` | คืนจำนวนวันในเดือนกุมภาพันธ์ของปี `y` |
| `days_in_month(m, y)` | คืนจำนวนวันของเดือน `m` ในปี `y` |
| `days_in_between(...)` | นับจำนวนวันระหว่างวันที่ 2 วันตามวิธีของโจทย์ |
| `main()` | เรียกฟังก์ชันต่าง ๆ ตามลำดับและแสดงผล |

เมื่อแยกแบบนี้ `main()` ไม่จำเป็นต้องรู้รายละเอียดทุกสูตร แต่เลือกเรียกฟังก์ชัน
ที่ทำหน้าที่นั้นแทน ทำให้ส่วนที่เคยซ้ำกันเหลือเพียงชุดเดียว

## การอ่านและแปลงวันที่

ข้อมูลวันที่มีรูปแบบ `วัน ชื่อย่อเดือน ปี` เช่น `1 Jan 2017` ฟังก์ชัน
`read_date()` แยกข้อมูลทั้ง 3 ส่วนก่อน

```python
d, m, y = input().strip().split()
```

ค่าที่ได้จาก `input()` ยังเป็นสตริง จึงต้องแปลงวันและปีด้วย `int()` ส่วนเดือน
หาเลขลำดับจาก `MONTHS` แล้วบวก `1` เพราะ index ของลิสต์เริ่มที่ `0`

```python
MONTHS.index(m) + 1
```

ดังนั้น `1 Jan 2017` จะถูกคืนเป็น `[1, 1, 2017]` และ `2 Aug 2017`
จะถูกคืนเป็น `[2, 8, 2017]`

> [!NOTE]
>
> โปรแกรมตั้งต้นใน PDF ใช้ `date[1][:3]` จึงตัดชื่อเดือนให้เหลือ 3 ตัวอักษร
> แต่โค้ดเฉลยจริงใช้ `MONTHS.index(m)` โดยตรง ข้อมูลเดือนจึงต้องตรงกับ
> `"Jan"`, `"Feb"`, ..., `"Dec"` ทุกตัว รวมถึงตัวพิมพ์เล็ก-ใหญ่

## การหาราศี

แต่ละแถวใน `ZODIAC` เก็บชื่อราศี วันเริ่ม และวันสิ้นสุด เช่น

```python
["Virgo", [8, 22], [9, 21]]
```

วันที่ถูกเขียนเป็น `[เดือน, วัน]` เพื่อให้เปรียบเทียบลิสต์ตามลำดับได้ Python
จะเปรียบเทียบเดือนก่อน และเมื่อเดือนเท่ากันจึงเปรียบเทียบวัน เงื่อนไข

```python
start <= [m, d] <= end
```

จึงหมายถึงวันที่ `[m, d]` อยู่ในช่วงตั้งแต่ `start` ถึง `end` โดยรวมวันขอบเขต
ทั้งสองด้านด้วย ตัวอย่างเช่น `zodiac(2, 9)` ตรวจค่า `[9, 2]` ซึ่งอยู่ระหว่าง
`[8, 22]` กับ `[9, 21]` จึงคืน `"Virgo"`

ช่วงของ `Capricorn` ข้ามจากเดือนธันวาคมไปเดือนมกราคม จึงแบ่งเก็บเป็น 2 แถว
คือ `22 Dec` ถึง `31 Dec` และ `1 Jan` ถึง `20 Jan`

## ปีอธิกสุรทินและจำนวนวันในแต่ละเดือน

เดือนกุมภาพันธ์มี 29 วันเมื่อปี `y` เป็นปีอธิกสุรทินตามปฏิทินเกรกอเรียน กล่าวคือ

$$
y \bmod 4 = 0 \quad\text{และ}\quad
(y \bmod 100 \ne 0 \quad\text{หรือ}\quad y \bmod 400 = 0)
$$

เขียนเป็น Python ได้ว่า

```python
y % 4 == 0 and (y % 100 != 0 or y % 400 == 0)
```

ตัวอย่างเช่น ปี `2016` และ `2000` มี 29 วันในเดือนกุมภาพันธ์ แต่ปี `1900`
มี 28 วัน เพราะหารด้วย `100` ลงตัวแต่หารด้วย `400` ไม่ลงตัว

สำหรับเดือนกุมภาพันธ์ `days_in_month(m, y)` จะเรียก `days_in_feb(y)`
ส่วนเดือนอื่นอ่านค่าจาก `DAYS_IN_MONTH[m - 1]` การลบ `1` เกิดจากเดือนใช้เลข
`1` ถึง `12` แต่ index ของลิสต์ใช้เลข `0` ถึง `11`

## การนับจำนวนวันระหว่างสองวันที่

`days_in_between(d1, m1, y1, d2, m2, y2)` แบ่งช่วงเวลาออกเป็นส่วนเล็ก ๆ
แล้วนำมาบวกกันตามลำดับ

1. นับจากวันที่แรกถึงวันสุดท้ายของเดือนแรกด้วย
   `days_in_month(m1, y1) - d1 + 1`
2. วนบวกจำนวนวันของเดือนถัดจาก `m1` จนถึงเดือนธันวาคมของปี `y1`
3. บวกจำนวนวันของปีเต็มที่อยู่ตรงกลางด้วย
   `int((y2 - y1 - 1) * 365.25)`
4. วนบวกจำนวนวันตั้งแต่เดือนมกราคมจนถึงเดือนก่อน `m2` ของปี `y2`
5. บวก `d2 - 1` วันของเดือนสุดท้าย

การใช้ `+ 1` ในส่วนแรกและ `d2 - 1` ในส่วนสุดท้ายทำให้ผลลัพธ์เป็นจำนวนวัน
ที่ต้องเดินจากวันที่แรกไปถึงวันที่สอง เช่น จาก `1 Jan 2016` ถึง `1 Jan 2017`
ได้ `366` วัน

> [!WARNING]
>
> PDF ระบุไว้ว่าวิธีนับจำนวนวันนี้อาจคลาดเคลื่อนเล็กน้อย โค้ดเฉลยจึงคงสูตร
> `int((y2 - y1 - 1) * 365.25)` ไว้ตามโจทย์ สูตรนี้ประมาณปีเต็มตรงกลางด้วย
> `365.25` วันแล้วตัดส่วนทศนิยม จึงไม่ใช่การคำนวณปฏิทินแบบแม่นยำทุกช่วง
> ตัวอย่าง `1 Jan 2015` ถึง `2 Aug 2017` จึงได้ผลตามโจทย์เป็น `943`

ฟังก์ชันนี้ไม่มีการสลับหรือตรวจสอบลำดับวันที่ ข้อมูลทดสอบจึงต้องส่งวันที่แรก
และวันที่สองตามลำดับที่โจทย์กำหนด

## ลำดับการทำงานของฟังก์ชันหลัก

เมื่อเรียก `main()` โปรแกรมจะทำงานดังนี้

1. เรียก `read_date()` สองครั้งเพื่ออ่านวันที่แรกและวันที่สอง
2. เรียก `zodiac()` ของแต่ละวันที่
3. แสดงชื่อราศีทั้งสองในบรรทัดเดียว คั่นด้วยช่องว่าง
4. เรียก `days_in_between()` และแสดงจำนวนวันในบรรทัดถัดไป

ตัวอย่างข้อมูลที่ส่งให้โปรแกรม

```text
main()
1 Jan 2015
2 Aug 2017
```

จะแสดงผลตามลำดับดังนี้

```text
Capricorn Leo
943
```

## การทดสอบด้วยเกรดเดอร์

บรรทัดสุดท้ายรับคำสั่ง Python 1 บรรทัดแล้วสั่งทำงานด้วย `exec()` เกรดเดอร์จึง
สามารถเลือกทดสอบฟังก์ชันใดฟังก์ชันหนึ่ง เช่น `print(days_in_feb(2016))` หรือ
เรียกโปรแกรมทั้งหมดด้วย `main()` หากคำสั่งนั้นเรียก `read_date()` ข้อมูลวันที่
ในบรรทัดถัดไปจะถูกอ่านโดยฟังก์ชันตามปกติ

> [!WARNING]
>
> `exec()` สามารถสั่งทำงานโค้ด Python ใด ๆ ได้ จึงเหมาะกับข้อมูลทดสอบที่เชื่อถือได้
> จากเกรดเดอร์เท่านั้น ไม่ควรใช้กับข้อความจากผู้ใช้หรือแหล่งที่ไม่ไว้วางใจ

# Solution

```python
# --------------------------------------------------
# File Name : 06_Func_31.py
# Problem   : Refactor
# Author    : Worralop Srichainont
# Date      : 2025-06-12
# --------------------------------------------------

# List of months in short form
MONTHS = [
    "Jan",
    "Feb",
    "Mar",
    "Apr",
    "May",
    "Jun",
    "Jul",
    "Aug",
    "Sep",
    "Oct",
    "Nov",
    "Dec",
]

# List of days in each month
DAYS_IN_MONTH = [31, 28, 31, 30, 31, 30, 31, 31, 30, 31, 30, 31]

# List of zodiac signs with their date ranges
ZODIAC = [
    ["Aries", [3, 22], [4, 21]],
    ["Taurus", [4, 22], [5, 21]],
    ["Gemini", [5, 22], [6, 21]],
    ["Cancer", [6, 22], [7, 21]],
    ["Leo", [7, 22], [8, 21]],
    ["Virgo", [8, 22], [9, 21]],
    ["Libra", [9, 22], [10, 21]],
    ["Scorpio", [10, 22], [11, 21]],
    ["Sagittarius", [11, 22], [12, 21]],
    ["Capricorn", [12, 22], [12, 31]],
    ["Capricorn", [1, 1], [1, 20]],
    ["Aquarius", [1, 21], [2, 20]],
    ["Pisces", [2, 21], [3, 21]],
]


# Reads a date from input and returns a list [day, month, year]
def read_date():
    d, m, y = input().strip().split()
    return [int(d), MONTHS.index(m) + 1, int(y)]


# Returns the zodiac sign based on the day and month
def zodiac(d, m):
    for name, start, end in ZODIAC:
        if start <= [m, d] <= end:
            return name


# Returns the number of days in February for a given year
def days_in_feb(y):
    if y % 4 == 0 and (y % 100 != 0 or y % 400 == 0):
        return 29
    else:
        return 28


# Find days in a month based on the month and year
def days_in_month(m, y):
    if m == 2:
        return days_in_feb(y)
    else:
        return DAYS_IN_MONTH[m - 1]


# Calculates the number of days between two dates
def days_in_between(d1, m1, y1, d2, m2, y2):
    # Add days from the first date to the end of that month
    days = days_in_month(m1, y1) - d1 + 1

    # Add days from month m1 + 1 to the end of the year y1
    for m in range(m1 + 1, 13):
        days += days_in_month(m, y1)

    # Add days from year y1 + 1 to year y2 - 1
    days += int((y2 - y1 - 1) * 365.25)

    # Add days from the beginning of year y2 to month m2 - 1
    for m in range(1, m2):
        days += days_in_month(m, y2)

    # Add days from the beginning of month m2 to day d2
    days += d2 - 1
    return days


# Main function
def main():
    # Read two dates
    d1, m1, y1 = read_date()
    d2, m2, y2 = read_date()

    # Output the zodiac signs of the two dates
    zodiac1 = zodiac(d1, m1)
    zodiac2 = zodiac(d2, m2)
    print(zodiac1, zodiac2)

    # Output the number of days in between the two dates
    days = days_in_between(d1, m1, y1, d2, m2, y2)
    print(days)


# Execute the input string as code
exec(input().strip())
```
