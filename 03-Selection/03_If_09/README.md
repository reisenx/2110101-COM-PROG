## การนับวันตามวิธีที่โจทย์กำหนด

ข้อมูลนำเข้ามีจำนวนเต็ม 6 ค่าอยู่ในบรรทัดเดียวกัน ตามลำดับดังนี้

```text
bd bm by d m y
```

-   `bd`, `bm`, `by` คือวัน เดือน และปี พ.ศ. ที่เกิด
-   `d`, `m`, `y` คือวัน เดือน และปี พ.ศ. ที่สนใจ

โค้ดใช้ list comprehension แยกข้อความทั้ง 6 ส่วนและแปลงเป็น `int`
จากนั้นแปลง `by` และ `y` เป็นปี ค.ศ. ด้วยการลบ `543`
โจทย์รับประกันว่าปีเกิดกับปีที่สนใจเป็นคนละปี จึงแบ่งช่วงเวลาที่ต้องนับเป็น
3 ส่วนได้เสมอ

ลิสต์ `COMMON_DAYS` เก็บจำนวนวันของแต่ละเดือนในปีปกติ ส่วน `LEAP_DAYS`
เก็บจำนวนวันของปีอธิกสุรทิน ซึ่งเดือนกุมภาพันธ์มี `29` วัน
โค้ดเลือกลิสต์ของปีเกิดและปีที่สนใจด้วยเงื่อนไขปีอธิกสุรทินต่อไปนี้
โดยให้ `year` แทน `by` หรือ `y` ที่กำลังตรวจ

```python
(year % 400 == 0) or (year % 4 == 0 and year % 100 != 0)
```

เมื่อให้ `D` แทนลิสต์ที่ตรงกับปีในส่วนนั้น การนับวันทั้ง 3 ส่วนเป็นดังนี้

| ส่วนที่นับ | Python expression | วันที่ที่โค้ดนับรวม |
|---|---|---|
| หลังวันเกิดถึงสิ้นปีเกิด | `(D[bm - 1] - bd) + sum(D[bm:])` | ไม่รวมวันเกิด แต่รวมวันสุดท้ายของปีเกิด |
| ปีที่อยู่ตรงกลาง | `(y - by - 1) * 365` | คิดทุกปีเป็น `365` วัน |
| ต้นปีที่สนใจถึงวันที่สนใจ | `sum(D[:m - 1]) + d` | รวมวันที่สนใจ |

> [!WARNING]
>
> การใช้ `365` วันกับทุกปีที่อยู่ตรงกลางเป็น **วิธีประมาณที่โจทย์กำหนดให้ใช้**
> ไม่ใช่กฎปฏิทินทั่วไป ถ้าช่วงกลางมีปีอธิกสุรทินก็ยังต้องใช้
> `(y - by - 1) * 365` ตามเดิม มิฉะนั้นคำตอบอาจไม่ตรงกับ grader
> คอมเมนต์ในโค้ดที่ว่าไม่ต้องตรวจปีอธิกสุรทินจึงหมายถึงช่วงกลางตามข้อกำหนดนี้

ภาพอธิบายในโจทย์จัดปลายช่วงต่างจากโค้ดเล็กน้อย กล่าวคือ ภาพนับรวมวันเกิด
แต่ไม่รวมวันที่สนใจ ขณะที่โค้ดไม่รวมวันเกิดแต่รวมวันที่สนใจ
จำนวนวันส่วนแรกของโค้ดจึงน้อยกว่าภาพ `1` วัน และส่วนสุดท้ายมากกว่าภาพ
`1` วัน การเลื่อนสองส่วนนี้หักล้างกัน ทำให้ผลรวมเท่ากัน

## สูตร Biorhythm

ให้ $t$ คือจำนวนวัน `days` ที่คำนวณได้ ค่า Biorhythm ทั้งสามด้านเป็น

$$
\text{physical} = \sin\left(\frac{2\pi t}{23}\right)
$$

เขียนเป็น Python ได้ว่า `math.sin((2 * math.pi * days) / 23)`

$$
\text{emotional} = \sin\left(\frac{2\pi t}{28}\right)
$$

เขียนเป็น Python ได้ว่า `math.sin((2 * math.pi * days) / 28)`

$$
\text{intellectual} = \sin\left(\frac{2\pi t}{33}\right)
$$

เขียนเป็น Python ได้ว่า `math.sin((2 * math.pi * days) / 33)`

ฟังก์ชัน `math.sin()` รับมุมเป็นเรเดียน และ `math.pi` แทนค่า $\pi$
ผลลัพธ์แต่ละด้านจึงอยู่ระหว่าง `-1` ถึง `1`

## การจัดรูปแบบผลลัพธ์

โปรแกรมแสดงข้อมูล 4 ค่าในหนึ่งบรรทัดตามลำดับ คือ `days`, `physical`,
`emotional` และ `intellectual` โดย `print()` จะเว้นช่องว่างระหว่างแต่ละค่า

การเขียน `f"{physical:.2f}"` บังคับให้แสดงทศนิยม **สองตำแหน่งเสมอ**
เช่น `0.1` จะแสดงเป็น `0.10` ต่างจากการใช้ `round()` แล้วพิมพ์ค่าตรง ๆ

เนื่องจากจำนวนจริงในคอมพิวเตอร์และค่าที่ได้จาก `math.sin()` เป็นค่าประมาณ
ค่าที่ใกล้ศูนย์มากแต่อยู่ฝั่งลบอาจถูกจัดรูปแบบเป็น `-0.00` ได้
รูปแบบนี้เป็นผลลัพธ์ที่สอดคล้องกับ f-string ของโค้ด

## ตัวอย่าง 1177 วัน

พิจารณาข้อมูลตัวอย่าง

```text
20 11 2540 10 2 2544
```

เมื่อแปลงปีจะได้ปีเกิด `1997` และปีที่สนใจ `2001` ซึ่งทั้งคู่เป็นปีปกติ
โค้ดแบ่งการคำนวณได้ดังนี้

| ช่วง | การคำนวณ | จำนวนวัน |
|---|---|---:|
| หลัง 20 พฤศจิกายน ถึง 31 ธันวาคม 1997 | `(30 - 20) + 31` | `41` |
| ปี 1998, 1999 และ 2000 | `3 * 365` | `1095` |
| 1 มกราคม ถึง 10 กุมภาพันธ์ 2001 | `31 + 10` | `41` |

ดังนั้น `days = 41 + 1095 + 41 = 1177` และเมื่อนำไปแทนในสูตรทั้งสาม
โปรแกรมจะแสดงผล

```text
1177 0.89 0.22 -0.87
```

ในภาพของโจทย์ จำนวนวันเดียวกันถูกแบ่งเป็น `42 + 1095 + 40`
เพราะภาพนับรวมวันเกิดแทนการนับรวมวันที่สนใจตามที่อธิบายไว้ข้างต้น

# Solution

```python
# --------------------------------------------------
# File Name : 03_If_09.py
# Problem   : Biorhythm
# Author    : Worralop Srichainont
# Date      : 2025-06-10
# --------------------------------------------------

import math

# List of days in each month for common and leap years
COMMON_DAYS = [31, 28, 31, 30, 31, 30, 31, 31, 30, 31, 30, 31]
LEAP_DAYS = [31, 29, 31, 30, 31, 30, 31, 31, 30, 31, 30, 31]

# Input the birth date (bd), birth month (bm), birth year (by),
# the current day (d), month (m), and year (y)
bd, bm, by, d, m, y = [int(e) for e in input().split()]

# Convert the year to the year in the Gregorian calendar
by -= 543
y -= 543

# Initialize the day count
days = 0

# Calculate duration from bd/bm/by to 31/12/by
# Need to check if the birth year is a leap year
if (by % 400 == 0) or (by % 4 == 0 and by % 100 != 0):
    days += (LEAP_DAYS[bm - 1] - bd) + sum(LEAP_DAYS[bm:])
else:
    days += (COMMON_DAYS[bm - 1] - bd) + sum(COMMON_DAYS[bm:])

# Calculate duration from 01/01/(by+1) to 31/12/(y-1)
# No need to check leap year for the years in between
days += (y - by - 1) * 365

# Calculate duration from 01/01/y to d/m/y
# Need to check if the current year is a leap year
if (y % 400 == 0) or (y % 4 == 0 and y % 100 != 0):
    days += sum(LEAP_DAYS[: m - 1]) + d
else:
    days += sum(COMMON_DAYS[: m - 1]) + d

# Calculate biorhythm
physical = math.sin((2 * math.pi * days) / 23)
emotional = math.sin((2 * math.pi * days) / 28)
intellectual = math.sin((2 * math.pi * days) / 33)

# Output
print(
    days,
    f"{physical:.2f}",
    f"{emotional:.2f}",
    f"{intellectual:.2f}",
)
```
