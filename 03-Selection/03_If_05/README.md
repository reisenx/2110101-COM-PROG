## การจำแนกเครื่องหมายของจำนวน

โปรแกรมรับจำนวนเต็ม 1 ค่าด้วย `int(input())` แล้วเปรียบเทียบค่านั้นกับศูนย์
จำนวนเต็มทุกจำนวนจะอยู่ในกรณีใดกรณีหนึ่งต่อไปนี้เท่านั้น

-   `number > 0` เป็นจำนวนบวก จึงแสดง `positive`
-   `number < 0` เป็นจำนวนลบ จึงแสดง `negative`
-   ถ้าสองเงื่อนไขแรกไม่เป็นจริง ค่านั้นต้องเท่ากับศูนย์ จึงแสดง `zero`

โครงสร้าง `if` / `elif` / `else` เหมาะกับการเลือกกรณีที่ไม่ทับซ้อนกัน เพราะเมื่อพบ
เงื่อนไขที่เป็นจริงแล้ว Python จะข้ามกิ่งที่เหลือทันที ทำให้แสดงประเภทของเครื่องหมาย
เพียง 1 บรรทัด

## การตรวจจำนวนคู่และจำนวนคี่

จำนวนเต็มคู่คือจำนวนที่เขียนได้ในรูป

$$
n = 2k
$$

เมื่อ $k$ เป็นจำนวนเต็ม กล่าวอีกอย่างคือ เมื่อนำจำนวนนั้นไปหารด้วย 2
จะเหลือเศษ 0 ซึ่งเขียนเป็นเงื่อนไข Python ได้ว่า

```python
number % 2 == 0
```

ถ้าเงื่อนไขนี้เป็นจริง โปรแกรมแสดง `even` มิฉะนั้นจะแสดง `odd`
หลักการเดียวกันใช้ได้กับจำนวนลบ เช่น `-4 % 2` ได้เศษ `0` จึงเป็นจำนวนคู่

ศูนย์ก็เป็นจำนวนคู่เช่นกัน เพราะเขียนได้เป็น $0 = 2 \times 0$
และ `0 % 2` มีค่าเป็น `0`

## ลำดับการแสดงผล

โปรแกรมใช้ชุดคำสั่งเลือก 2 ชุดที่แยกจากกัน

1. ชุดแรกจำแนกว่าเป็นจำนวนบวก จำนวนลบ หรือศูนย์
2. ชุดที่สองจำแนกว่าเป็นจำนวนคู่หรือจำนวนคี่

ดังนั้นผลลัพธ์จึงมี 2 บรรทัดเสมอ โดยบรรทัดแรกเป็นเครื่องหมายของจำนวน
และบรรทัดที่สองเป็นความคู่หรือคี่ ข้อความทั้งหมดเป็นตัวพิมพ์เล็กตามที่โจทย์กำหนด

ตัวอย่างเช่น ข้อมูลเข้า `-35` ทำให้ชุดแรกแสดง `negative`
จากนั้นชุดที่สองยังทำงานต่อและแสดง `odd`

# Solution

```python
# --------------------------------------------------
# File Name : 03_If_05.py
# Problem   : Positive Negative
# Author    : Worralop Srichainont
# Date      : 2025-06-10
# --------------------------------------------------

# Input a number
number = int(input())

# Check if the number is positive, negative, or zero
if number > 0:
    print("positive")
elif number < 0:
    print("negative")
else:
    print("zero")

# Check if the number is even or odd
if number % 2 == 0:
    print("even")
else:
    print("odd")
```
