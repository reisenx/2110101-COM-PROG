## ค่าที่ฟังก์ชันส่งกลับ

ฟังก์ชันข้อนี้มีแนวคิดของสัญญาดังนี้

```python
day_of_year(d, m, y) -> int
```

`d`, `m` และ `y` เป็นจำนวนเต็มแทนวัน เดือน และปี พ.ศ. ตามลำดับ
ฟังก์ชันต้อง `return` จำนวนเต็มที่บอกว่าวันดังกล่าวเป็นวันที่เท่าไรของปี

`return` ต่างจาก `print()` ตรงที่ `return` ส่งค่ากลับไปให้คำสั่งที่เรียกฟังก์ชัน
เพื่อนำไปแสดงผลหรือคำนวณต่อ ฟังก์ชันนี้จึงไม่พิมพ์คำตอบเอง
คอมเมนต์ `# Output the day of the year` ในโค้ดจึงไม่แม่นยำ เพราะคำสั่งจริง
เป็น `return` ซึ่งส่งค่ากลับ ไม่ใช่ `print()` ที่แสดงผลทางหน้าจอ
อย่างไรก็ตาม คอมเมนต์ดังกล่าวยังคงอยู่ใน Solution ตามไฟล์คำตอบต้นฉบับ

## การคำนวณลำดับวันในปี

ก่อนตรวจปีอธิกสุรทิน ต้องแปลงปีจาก พ.ศ. เป็น ค.ศ.

$$
y_{\mathrm{ค.ศ.}} = y_{\mathrm{พ.ศ.}} - 543
$$

เขียนเป็น Python ได้ว่า `y = y - 543`

ลิสต์ `TOTAL_DAYS` เก็บจำนวนวันสะสม ณ สิ้นเดือนแต่ละเดือนของปีปกติ

```python
TOTAL_DAYS = [31, 59, 90, 120, 151, 181, 212, 243, 273, 304, 334, 365]
```

ถ้าเป็นเดือนมกราคมหรือกุมภาพันธ์ (`m <= 2`) ยังไม่ผ่านวันที่ 29 กุมภาพันธ์
จึงใช้สูตร

$$
31(m - 1) + d
$$

ซึ่งตรงกับ Python expression `31 * (m - 1) + d`

ถ้าเป็นเดือนมีนาคมเป็นต้นไป `TOTAL_DAYS[m - 2]` คือจำนวนวันถึงสิ้นเดือนก่อนหน้า
จึงนำมาบวก `d` และเพิ่มอีก `1` วันเมื่อปี ค.ศ. เป็นปีอธิกสุรทิน

$$
(y \bmod 4 = 0 \text{ และ } y \bmod 100 \ne 0)
\text{ หรือ } y \bmod 400 = 0
$$

ตรงกับเงื่อนไข Python

```python
(y % 4 == 0 and y % 100 != 0) or (y % 400 == 0)
```

ตัวอย่าง `day_of_year(2, 2, 2565)` ใช้กรณี `m <= 2` จึงได้
`31 * (2 - 1) + 2 = 33` และส่งค่า `33` กลับไป

> [!NOTE]
>
> ฟังก์ชันทำงานภายใต้ข้อมูลวันที่ที่ถูกต้องตามที่โจทย์กำหนด จึงไม่ได้ตรวจสอบ
> วันที่ที่ไม่มีอยู่จริง

## การทำงานของตัวตรวจ

ข้อมูลนำเข้าของโปรแกรมเป็นคำสั่ง Python ที่ grader ควบคุม เช่น

```python
print(day_of_year(31, 12, 2559))
```

`exec(input())` รันคำสั่งนี้เพื่อเรียกฟังก์ชัน จากนั้น `print()` ที่อยู่ในคำสั่ง
จะแสดงค่า `366` ซึ่งฟังก์ชันส่งกลับ

> [!WARNING]
>
> `exec()` สามารถรันคำสั่ง Python ใด ๆ ที่ได้รับมา จึงใช้ได้ในข้อนี้เพราะ
> ข้อมูลมาจาก grader ที่เชื่อถือได้เท่านั้น ห้ามใช้ `exec()` กับข้อมูลจาก
> ผู้ใช้หรือแหล่งที่ไม่เชื่อถือ

# Solution

```python
# --------------------------------------------------
# File Name : 03_If_F08.py
# Problem   : Day of Year (Function)
# Author    : Worralop Srichainont
# Date      : 2025-08-09
# --------------------------------------------------

# List of total days in each month
TOTAL_DAYS = [31, 59, 90, 120, 151, 181, 212, 243, 273, 304, 334, 365]


def day_of_year(d, m, y):
    # Convert the year to the year in the Gregorian calendar
    y = y - 543

    # Output the day of the year
    if m <= 2:
        return 31 * (m - 1) + d
    else:
        # Check if the year is a leap year
        if (y % 4 == 0 and y % 100 != 0) or (y % 400 == 0):
            return TOTAL_DAYS[m - 2] + d + 1
        else:
            return TOTAL_DAYS[m - 2] + d


# Execute the input string as code
exec(input())
```
