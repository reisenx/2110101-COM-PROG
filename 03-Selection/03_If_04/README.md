## การเก็บหมายเลขโทรศัพท์เป็นข้อความ

แม้หมายเลขโทรศัพท์จะประกอบด้วยตัวเลข แต่เราไม่ได้ใช้ค่านี้ในการคำนวณ
จึงควรรับข้อมูลเป็น `str` เพื่อรักษาเลข `0` ที่อยู่ข้างหน้าไว้ หากแปลงเป็น `int`
เลขศูนย์นำหน้าจะหายไปและทำให้ตรวจความยาวหรือรหัสนำหน้าไม่ได้ตามต้องการ

คำสั่ง `input().strip()` รับหมายเลขเป็นข้อความและตัดช่องว่างที่อาจติดอยู่ตรงหัวหรือท้าย
จากนั้นจึงตรวจคุณสมบัติ 2 ข้อ ได้แก่ จำนวนหลักและเลข 2 ตัวแรก

## การตรวจสอบเงื่อนไขร่วมกัน

โจทย์กำหนดให้หมายเลขโทรศัพท์เคลื่อนที่ต้องมี 10 หลัก
และขึ้นต้นด้วย `06`, `08` หรือ `09` โปรแกรมจึงเก็บข้อมูลเหล่านี้ไว้ในค่าคงที่

```python
PHONE_DIGITS = 10
VALID_NUMBERS = ["06", "08", "09"]
```

เงื่อนไขหลักประกอบด้วย

-   `len(mobile_number) == PHONE_DIGITS` ตรวจว่าข้อความยาว 10 ตัวอักษร
-   `mobile_number[:2] in VALID_NUMBERS` เลือกตัวอักษรที่ดัชนี `0` และ `1`
    (หยุดก่อนดัชนี `2`) แล้วตรวจว่าเลขนำหน้าอยู่ในรายการที่ยอมรับหรือไม่
-   `and` กำหนดให้เงื่อนไขทั้งสองข้อต้องเป็นจริงพร้อมกัน

ดังนั้น ต่อให้ขึ้นต้นด้วยรหัสที่ถูกต้อง แต่มีจำนวนหลักไม่เท่ากับ 10
ก็ต้องแสดง `Not a mobile number` เช่นเดียวกับหมายเลขที่ยาว 10 หลัก
แต่ไม่ได้ขึ้นต้นด้วยรหัสที่กำหนด

> [!NOTE]
>
> โจทย์รับประกันว่าข้อมูลเข้าประกอบด้วยตัวเลขทุกหลัก
> โค้ดจึงตรวจเฉพาะความยาวและเลขนำหน้า โดยไม่ต้องเพิ่มการตรวจชนิดตัวอักษร

## ตัวอย่างการตรวจสอบ

| ข้อมูลเข้า | ความยาว | เลขนำหน้า | ผลลัพธ์ |
|---|---:|---|---|
| `0868144444` | 10 | `08` | `Mobile number` |
| `061234567` | 9 | `06` | `Not a mobile number` |
| `0712345678` | 10 | `07` | `Not a mobile number` |

ข้อความผลลัพธ์ต้องสะกดและใช้อักษรตัวพิมพ์ใหญ่-เล็กให้ตรงตามโจทย์ทุกตัว

# Solution

```python
# --------------------------------------------------
# File Name : 03_If_04.py
# Problem   : Mobile Number
# Author    : Worralop Srichainont
# Date      : 2025-06-10
# --------------------------------------------------

# Constants
PHONE_DIGITS = 10
VALID_NUMBERS = ["06", "08", "09"]

# Input the mobile number
mobile_number = input().strip()

# Validate the mobile number
if len(mobile_number) == PHONE_DIGITS and mobile_number[:2] in VALID_NUMBERS:
    print("Mobile number")
else:
    print("Not a mobile number")
```
