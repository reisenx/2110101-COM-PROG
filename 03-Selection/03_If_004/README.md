## การเลือกหลายทาง

โจทย์รับคะแนนเป็นจำนวนจริงหนึ่งจำนวน จึงใช้ `float(input())`
แล้วเลือกเกรดเพียงหนึ่งตัวด้วยโครงสร้าง `if`–`elif`–`else`

Python ตรวจเงื่อนไขจากบนลงล่าง เมื่อพบเงื่อนไขแรกที่เป็นจริง
จะทำเฉพาะคำสั่งในแขนงนั้นและข้ามแขนงที่เหลือทั้งหมด
โค้ดจึงเรียงเกณฑ์จากคะแนนสูงไปต่ำ เริ่มที่ `s >= 80` แล้วค่อยตรวจ
`s >= 70`, `s >= 60` และ `s >= 50`

## ช่วงคะแนนและเกรด

เกณฑ์ทั้งหมดเขียนเป็นช่วงได้ดังนี้

| ช่วงคะแนน | เงื่อนไขแรกที่ผ่าน | เกรด |
|---|---|:---:|
| $s \ge 80$ | `s >= 80` | `A` |
| $70 \le s < 80$ | `s >= 70` | `B` |
| $60 \le s < 70$ | `s >= 60` | `C` |
| $50 \le s < 60$ | `s >= 50` | `D` |
| $s < 50$ | ไม่มีเงื่อนไขด้านบนเป็นจริง | `F` |

ขอบล่างของแต่ละช่วงรวมอยู่ในช่วงนั้น เพราะใช้ตัวดำเนินการ `>=`
เช่น `70.0` ได้เกรด `B` และ `50.0` ได้เกรด `D`

แม้คะแนน `85` จะทำให้ทั้ง `s >= 80` และ `s >= 70` เป็นจริง
แต่เงื่อนไข `s >= 80` มาก่อน โปรแกรมจึงแสดง `A` เพียงครั้งเดียว

## ตัวอย่างการตรวจคะแนน

-   `99.99` ผ่านเงื่อนไขแรก จึงแสดง `A`
-   `0.1` ไม่ผ่านทั้งสี่เงื่อนไข จึงเข้า `else` และแสดง `F`
-   `79.999` ไม่ผ่าน `s >= 80` แต่ผ่าน `s >= 70` จึงแสดง `B`

โปรแกรมเปรียบเทียบค่าจริงที่รับมาโดยตรง ไม่มีการปัดเศษก่อนตัดเกรด
ดังนั้น `79.999` ไม่ได้ถูกปัดเป็น `80`

# Solution

```python
# --------------------------------------------------
# File Name : 03_If_004.py
# Problem   : Grading (Flowchart)
# Author    : Worralop Srichainont
# Date      : 2025-06-10
# --------------------------------------------------

s = float(input())
if s >= 80:
    print("A")
elif s >= 70:
    print("B")
elif s >= 60:
    print("C")
elif s >= 50:
    print("D")
else:
    print("F")
```
