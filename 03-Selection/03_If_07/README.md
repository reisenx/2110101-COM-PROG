## การย่อจำนวนด้วย K M และ B

โปรแกรมเก็บหน่วยย่อไว้ตามลำดับในรายการ `SYMBOLS`

```python
SYMBOLS = ["", "K", "M", "B"]
```

ดัชนี `n` เริ่มที่ `0` จึงหมายถึงยังไม่ใช้หน่วยย่อ ทุกครั้งที่หาร `num` ด้วย
`1000` โปรแกรมจะเพิ่ม `n` ขึ้น 1 พร้อมกัน ทำให้ค่าตัวเลขและหน่วยเลื่อนไปในลำดับ
เดียวกัน

| จำนวนครั้งที่หารด้วย 1,000 | `n` | หน่วย |
|---:|---:|---|
| 0 | 0 | ไม่มีหน่วย |
| 1 | 1 | `K` |
| 2 | 2 | `M` |
| 3 | 3 | `B` |

วงวนทำงานเมื่อทั้ง `num > 1000` และ `n < 3` เป็นจริง
เงื่อนไขแรกบอกว่ายังต้องย่อค่า ส่วนเงื่อนไขที่สองจำกัดหน่วยสูงสุดไว้ที่ `B`
คำสั่ง `num /= 1000` เป็นการหารแบบ `/` จึงเปลี่ยนค่าที่ผ่านการย่อเป็น `float`

## การปัดเศษและจัดรูปแบบ

หลังจบวงวน โปรแกรมเลือกรูปแบบตามค่าที่เหลือ

-   ถ้า `num < 10` ใช้ `round(num, 1)` เพื่อปัดค่าถึงตำแหน่งทศนิยมที่ 1
-   ถ้า `num >= 10` ใช้ `round(num)` เพื่อปัดเป็นจำนวนเต็ม
-   จากนั้นต่อท้ายด้วย `SYMBOLS[n]` ซึ่งเป็นหน่วยที่ตรงกับจำนวนครั้งที่หาร

เช่น `8456` ถูกหารหนึ่งครั้งเป็น `8.456` และ `n` เป็น `1`
เนื่องจาก `8.456 < 10` จึงปัดเป็น `8.5` แล้วต่อท้าย `K` ได้ผลลัพธ์ `8.5K`

Python ใช้การปัดค่ากึ่งกลางไปหาค่าคู่ที่ใกล้ที่สุด (round half to even)
เช่น `round(2.5)` ได้ `2` แต่ `round(3.5)` ได้ `4`
ดังนั้นผลลัพธ์ต้องยึดตามพฤติกรรมของ `round()` โดยตรง

รูปแบบ `f"{...}"` ในโค้ดไม่ได้บังคับจำนวนหลักหลังจุดทศนิยม
จึงแสดงค่าที่ได้จาก `round()` ตามชนิดของค่านั้น เช่น จำนวนเต็มเดิม `5`
แสดงเป็น `5` ส่วนค่าที่ผ่านการหารแล้วเป็น `1.0` จะแสดงร่วมกับหน่วยเป็น `1.0K`

## กรณีขอบเขตที่ควรสังเกต

เงื่อนไขในวงวนใช้ `num > 1000` อย่างเคร่งครัด ไม่ใช่ `num >= 1000`
จึงเกิดผลลัพธ์ตามโค้ดดังนี้

| ข้อมูลเข้า | ผลลัพธ์ | เหตุผลสำคัญ |
|---:|---:|---|
| `1000` | `1000` | ค่าเท่ากับ 1,000 จึงยังไม่เข้าวงวน |
| `9999` | `10.0K` | `9.999` ถูกปัดเป็น `10.0` โดยไม่มีการเลื่อนหน่วยซ้ำ |
| `1000000` | `1000K` | หลังหารครั้งแรกได้ `1000.0` จึงหยุดที่หน่วย `K` |
| `1000000000` | `1000M` | หยุดเมื่อค่าหลังหารเป็น `1000.0` ที่หน่วย `M` |
| `1000000000000` | `1000B` | หารครบ 3 ครั้งและหน่วยถูกจำกัดไว้ที่ `B` |
| `2555555555555` | `2556B` | หลังหาร 3 ครั้งยังเกิน 1,000 แต่ไม่มีหน่วยถัดจาก `B` |

> [!NOTE]
>
> การปัดเศษเกิดขึ้นหลังวงวนจบแล้ว โปรแกรมจึงไม่ย้อนกลับไปเลื่อนหน่วยอีกครั้ง
> ตัวอย่างเช่น `9999` แสดงเป็น `10.0K` ไม่ใช่ `10K` หรือ `0.01M`

## ตัวอย่างการทำงาน

สำหรับข้อมูลเข้า `1301008191`

1. หารครั้งที่ 1 ได้ `1301008.191` และเลือกหน่วย `K`
2. ค่ายังมากกว่า `1000` จึงหารครั้งที่ 2 ได้ `1301.008191` และเลือกหน่วย `M`
3. ค่ายังมากกว่า `1000` จึงหารครั้งที่ 3 ได้ `1.301008191` และเลือกหน่วย `B`
4. `n` เท่ากับ `3` แล้วจึงออกจากวงวน จากนั้นปัดเหลือ 1 ตำแหน่งเป็น `1.3`

โปรแกรมจึงแสดงผล `1.3B`

# Solution

```python
# --------------------------------------------------
# File Name : 03_If_07.py
# Problem   : Abbrev Num
# Author    : Worralop Srichainont
# Date      : 2025-08-09
# --------------------------------------------------

# List of symbols for abbreviations
SYMBOLS = ["", "K", "M", "B"]

# Input a number
num = int(input())

# Calculate the abbreviated number
n = 0
while num > 1000 and n < 3:
    num /= 1000
    n += 1

# Output the abbreviated number
if num < 10:
    print(f"{round(num, 1)}{SYMBOLS[n]}")
else:
    print(f"{round(num)}{SYMBOLS[n]}")
```
