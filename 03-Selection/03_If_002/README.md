## จำนวนวันในแต่ละเดือน

ข้อมูลนำเข้าอยู่ในบรรทัดเดียว มีจำนวนเต็ม 3 จำนวนตามลำดับ คือ วัน เดือน
และปีพุทธศักราช โปรแกรมแยกข้อความด้วย `split()` แปลงแต่ละส่วนเป็น `int`
แล้วเก็บใน `d`, `m` และ `y`

การหาจำนวนวันของเดือนกุมภาพันธ์ต้องใช้กฎปีอธิกสุรทินของปีคริสต์ศักราช
จึงแปลงปีก่อนด้วย

$$
\text{ค.ศ.} = \text{พ.ศ.} - 543
$$

ตรงกับคำสั่ง Python `y = y - 543`

โปรแกรมกำหนดให้เดือนหนึ่งมี `31` วันไว้ก่อน จากนั้นเปลี่ยนเป็น `30`
เมื่อ `m` อยู่ใน `[4, 6, 9, 11]` ส่วนเดือนกุมภาพันธ์เริ่มที่ `28` วัน
และจะมี `29` วันเมื่อ

$$
y \bmod 400 = 0
\quad\text{หรือ}\quad
(y \bmod 4 = 0 \text{ และ } y \bmod 100 \ne 0)
$$

เงื่อนไขเดียวกันใน Python คือ
`y % 400 == 0 or (y % 4 == 0 and y % 100 != 0)` ในโค้ดจริงแยกตรวจ
สองกรณีนี้ด้วย `if` สองชุดและกำหนด `n = 29` เมื่อกรณีใดกรณีหนึ่งเป็นจริง

## การเพิ่ม 15 วัน

เมื่อรู้ว่าเดือนปัจจุบันมี `n` วัน โปรแกรมเพิ่มวันด้วย `d = d + 15`
แล้วตรวจตามลำดับดังนี้

1. ถ้า `d > n` แสดงว่าข้ามไปเดือนถัดไป จึงลบจำนวนวันของเดือนเดิมด้วย
   `d = d - n` และเพิ่ม `m` อีก 1
2. ถ้าเดือนใหม่มีค่าเกิน 12 ให้ลบ 12 ออกจากเดือนและเพิ่มปีอีก 1
3. บวก `543` กลับเพื่อเปลี่ยนเป็นปี พ.ศ. ก่อนแสดงผล

วันที่เริ่มต้นเป็นวันที่ถูกต้อง และการเพิ่มเพียง 15 วันจะข้ามได้ไม่เกินหนึ่งเดือน
เพราะทุกเดือนมีอย่างน้อย 28 วัน จึงใช้ `if` เพียงครั้งเดียวได้ สังเกตว่าเงื่อนไข
ต้องเป็น `d > n` ไม่ใช่ `d >= n` เพราะวันที่ `n` ยังเป็นวันสุดท้ายของเดือนเดิม

ผลลัพธ์ใช้ `f"{d}/{m}/{y}"` จึงอยู่ในรูป `วัน/เดือน/ปี` โดยไม่เติมเลข 0
นำหน้าวันหรือเดือน เช่น แสดง `1/3/2560` ไม่ใช่ `01/03/2560`

## ตัวอย่างการคำนวณ

สำหรับข้อมูล `28 2 2559` จะได้ปี ค.ศ. `2016` ซึ่งหารด้วย 4 ลงตัว
และหารด้วย 100 ไม่ลงตัว เดือนกุมภาพันธ์จึงมี 29 วัน

$$
28 + 15 = 43, \qquad 43 - 29 = 14
$$

ใน Python คือ `d = d + 15` แล้ว `d = d - n` พร้อมเพิ่มเดือนเป็น 3
จึงแสดง `14/3/2559`

แต่ข้อมูล `28 2 2560` ตรงกับปี ค.ศ. `2017` ซึ่งไม่ใช่ปีอธิกสุรทิน
เดือนกุมภาพันธ์มี 28 วัน ผลลัพธ์จึงเป็น `15/3/2560`

กรณี `31 12 2560` เมื่อเพิ่ม 15 วันจะได้วันที่ 46 จากนั้นลบ 31
และเพิ่มเดือนเป็น 13 โปรแกรมจึงปรับต่อเป็นเดือน 1 ของปีถัดไป
แล้วแสดง `15/1/2561`

# Solution

```python
# --------------------------------------------------
# File Name : 03_If_002.py
# Problem   : Next 15 Days (Flowchart)
# Author    : Worralop Srichainont
# Date      : 2025-06-10
# --------------------------------------------------

d, m, y = [int(e) for e in input().split()]

y = y - 543

n = 31

if m in [4, 6, 9, 11]:
    n = 30
else:
    if m == 2:
        n = 28
        if y % 400 == 0:
            n = 29
        if y % 4 == 0 and y % 100 != 0:
            n = 29

d = d + 15

if d > n:
    d = d - n
    m = m + 1

if m > 12:
    m = m - 12
    y = y + 1

y = y + 543

print(f"{d}/{m}/{y}")
```
