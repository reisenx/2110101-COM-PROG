## การเลือกช่วงด้วยขอบเขตบน

โจทย์รับน้ำหนักพัสดุเป็นจำนวนเต็มหน่วยกรัม แล้วเลือกค่าส่งตามช่วงของน้ำหนัก
เราสามารถเขียนช่วงเหล่านี้ด้วย `if` / `elif` / `else`
โดยเรียงขอบเขตบนจากน้อยไปมาก

Python ตรวจเงื่อนไขจากบนลงล่างและทำงานเฉพาะกิ่งแรกที่เป็นจริง
ดังนั้นเมื่อมาถึง `elif weight <= 250` เรารู้อยู่แล้วว่า `weight <= 100`
เป็นเท็จ ช่วงของกิ่งนี้จึงหมายถึง `100 < weight <= 250` โดยไม่ต้องเขียนเงื่อนไข
ด้านล่างซ้ำอีกครั้ง

## ช่วงอัตราค่าส่ง

| น้ำหนักพัสดุ (กรัม) | เงื่อนไขที่ตรวจ | ค่าส่ง/ผลลัพธ์ |
|---|---|---:|
| ไม่เกิน 100 | `weight <= 100` | `18` บาท |
| มากกว่า 100 แต่ไม่เกิน 250 | `weight <= 250` | `22` บาท |
| มากกว่า 250 แต่ไม่เกิน 500 | `weight <= 500` | `28` บาท |
| มากกว่า 500 แต่ไม่เกิน 1,000 | `weight <= 1000` | `38` บาท |
| มากกว่า 1,000 แต่ไม่เกิน 2,000 | `weight <= 2000` | `58` บาท |
| มากกว่า 2,000 | `else` | `Reject` |

เครื่องหมาย `<=` ทำให้น้ำหนักตรงขอบเขตยังอยู่ในช่วงนั้น เช่น `100`, `250`,
`500`, `1000` และ `2000` จะได้ผลลัพธ์ `18`, `22`, `28`, `38` และ `58`
ตามลำดับ ส่วนค่าที่มากกว่า `2000` เท่านั้นจึงเข้าสู่ `else`

## ตัวอย่างการไล่เงื่อนไข

เมื่อข้อมูลเข้าเป็น `300` โปรแกรมตรวจตามลำดับดังนี้

1. `300 <= 100` เป็นเท็จ จึงไปยังเงื่อนไขถัดไป
2. `300 <= 250` เป็นเท็จ จึงไปยังเงื่อนไขถัดไป
3. `300 <= 500` เป็นจริง โปรแกรมจึงแสดง `28` และไม่ตรวจเงื่อนไขที่เหลือ

การเรียงขอบเขตบนตามลำดับจึงช่วยให้แต่ละน้ำหนักถูกเลือกเข้าเพียงช่วงเดียว

# Solution

```python
# --------------------------------------------------
# File Name : 03_If_06.py
# Problem   : Registered Mail
# Author    : Worralop Srichainont
# Date      : 2025-06-10
# --------------------------------------------------

# Input weight
weight = int(input())

# Calculate the cost based on weight
if weight <= 100:
    print(18)
elif weight <= 250:
    print(22)
elif weight <= 500:
    print(28)
elif weight <= 1000:
    print(38)
elif weight <= 2000:
    print(58)
else:
    print("Reject")
```
