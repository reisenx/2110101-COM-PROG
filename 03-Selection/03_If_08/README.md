## การสะสมจำนวนวันก่อนหน้า

โจทย์รับจำนวนเต็ม 3 ค่า ได้แก่ วัน `d` เดือน `m` และปีพุทธศักราช `y`
โดยรับค่าละหนึ่งบรรทัด แล้วต้องแสดงว่าเป็นวันที่เท่าไรเมื่อนับจากต้นปี

การหาคำตอบทำได้โดยนำ **จำนวนวันทั้งหมดของเดือนก่อนหน้า** มาบวกกับ `d`
ลิสต์ `TOTAL_DAYS` จึงเก็บจำนวนวันสะสม ณ วันสุดท้ายของแต่ละเดือนในปีปกติ

```python
TOTAL_DAYS = [31, 59, 90, 120, 151, 181, 212, 243, 273, 304, 334, 365]
```

ตัวอย่างเช่น `TOTAL_DAYS[10]` มีค่า `334` ซึ่งเป็นจำนวนวันตั้งแต่เดือนมกราคม
ถึงสิ้นเดือนพฤศจิกายน ดังนั้นวันที่ 5 ธันวาคมของปีปกติจึงเป็นวันที่
`334 + 5 = 339` ของปี

สำหรับเดือนหลังเดือนกุมภาพันธ์ โค้ดใช้ `TOTAL_DAYS[m - 2]`
เพราะเลขเดือนเริ่มจาก `1` แต่ตำแหน่งในลิสต์เริ่มจาก `0` และเราต้องการสมาชิก
ที่แทน **เดือนก่อนหน้า** เดือน `m`

## การตรวจสอบปีอธิกสุรทิน

ปีที่รับมาเป็น พ.ศ. แต่กฎปีอธิกสุรทินใช้กับปี ค.ศ. จึงต้องแปลงปีก่อน

$$
y_{\mathrm{ค.ศ.}} = y_{\mathrm{พ.ศ.}} - 543
$$

เขียนเป็น Python ได้ว่า `y -= 543`

ปี ค.ศ. จะเป็นปีอธิกสุรทินเมื่อหารด้วย `400` ลงตัว หรือหารด้วย `4` ลงตัว
แต่หารด้วย `100` ไม่ลงตัว

$$
(y \bmod 4 = 0 \text{ และ } y \bmod 100 \ne 0)
\text{ หรือ } y \bmod 400 = 0
$$

เขียนเป็น Python ได้ดังนี้

```python
(y % 4 == 0 and y % 100 != 0) or (y % 400 == 0)
```

วันที่ในเดือนมกราคมและกุมภาพันธ์ยังไม่ผ่านวันที่ 29 กุมภาพันธ์
จึงไม่ต้องเพิ่มวันพิเศษ ส่วนเดือนมีนาคมเป็นต้นไปต้องบวกอีก `1` วันเมื่อเป็น
ปีอธิกสุรทิน

## ขั้นตอนการคำนวณ

1. รับ `d`, `m` และ `y` ด้วย `int(input())` คนละบรรทัด
2. แปลงปีจาก พ.ศ. เป็น ค.ศ. ด้วย `y -= 543`
3. ถ้า `m <= 2` จำนวนวันก่อนหน้าเป็น `31 * (m - 1)` จึงคำนวณด้วย
   `31 * (m - 1) + d`
4. ถ้า `m > 2` ให้นำ `TOTAL_DAYS[m - 2]` มาบวก `d` และบวก `1`
   เพิ่มเมื่อเป็นปีอธิกสุรทิน
5. แสดงคำตอบซึ่งเป็นจำนวนเต็มหนึ่งค่า

ตัวอย่าง วันที่ 31 ธันวาคม พ.ศ. 2559 มีปี ค.ศ. เท่ากับ `2016`
ซึ่งหารด้วย `4` ลงตัวและหารด้วย `100` ไม่ลงตัว จึงคำนวณได้ว่า

$$
334 + 31 + 1 = 366
$$

ดังนั้นวันที่นี้เป็นวันที่ `366` ของปี

> [!NOTE]
>
> โค้ดนี้ทำงานภายใต้ข้อมูลวันที่ที่ถูกต้องตามที่โจทย์กำหนด จึงไม่ได้ตรวจสอบว่า
> วันและเดือนที่รับมาประกอบกันเป็นวันที่จริงหรือไม่

# Solution

```python
# --------------------------------------------------
# File Name : 03_If_08.py
# Problem   : Day of Year
# Author    : Worralop Srichainont
# Date      : 2025-06-10
# --------------------------------------------------

# List of total days in each month
TOTAL_DAYS = [31, 59, 90, 120, 151, 181, 212, 243, 273, 304, 334, 365]

# Input the day, month, and year
d = int(input())
m = int(input())
y = int(input())

# Convert the year to the year in the Gregorian calendar
y -= 543

# Output the day of the year
if m <= 2:
    print((TOTAL_DAYS[0] * (m - 1)) + d)
else:
    # Check if the year is a leap year
    if (y % 4 == 0 and y % 100 != 0) or (y % 400 == 0):
        print(TOTAL_DAYS[m - 2] + d + 1)
    else:
        print(TOTAL_DAYS[m - 2] + d)
```
