## ฟังก์ชันที่ส่งค่าความจริง

ฟังก์ชันข้อนี้มีแนวคิดของสัญญาดังนี้

```python
is_mobile_number(number) -> bool
```

`number` เป็น `str` ที่เก็บตัวเลขของหมายเลขโทรศัพท์ การเก็บเป็นข้อความ
ทำให้เลข `0` ตัวแรกยังคงอยู่ ส่วนค่าที่ส่งกลับเป็น `bool` คือ `True`
เมื่อเป็นหมายเลขโทรศัพท์เคลื่อนที่ตามเกณฑ์ และเป็น `False` เมื่อไม่ผ่านเกณฑ์

ฟังก์ชันใช้ `return` ส่งค่าความจริงกลับไปยังผู้เรียกโดยตรง
จึงไม่ได้แสดงผลด้วย `print()` ภายในฟังก์ชัน

## การตรวจสอบหมายเลขโทรศัพท์

หมายเลขที่ถูกต้องต้องผ่านทั้งสองเงื่อนไขพร้อมกัน

1. มีความยาว `10` ตัว ตรวจด้วย `len(number) == 10`
2. สองตัวแรกเป็น `"06"`, `"08"` หรือ `"09"` ตรวจด้วย
   `number[:2] in ["06", "08", "09"]`

`number[:2]` คือการ slice ข้อความตั้งแต่ตำแหน่งแรกจนถึงก่อนตำแหน่งที่ `2`
จึงได้อักขระสองตัวแรก ส่วน `in` ตรวจว่าค่าที่ได้เป็นสมาชิกของลิสต์ที่กำหนด

โค้ดเชื่อมเงื่อนไขด้วย `and` และส่งผลลัพธ์ของนิพจน์ทั้งหมดกลับได้ในบรรทัดเดียว

```python
return len(number) == 10 and number[:2] in ["06", "08", "09"]
```

Python ประมวลผล `and` แบบ **short-circuit** หากความยาวไม่เท่ากับ `10`
เงื่อนไขแรกเป็น `False` แล้ว จึงไม่จำเป็นต้องตรวจคำนำหน้าต่อ

โจทย์รับประกันว่า `number` มีเฉพาะตัวเลข โค้ดจึงตรวจเพียงความยาวและคำนำหน้า
โดยไม่ต้องเพิ่มการตรวจอักขระชนิดอื่น

## ตัวอย่างการพิจารณา

| `number` | ความยาว | คำนำหน้า | ผลลัพธ์ |
|---|---:|---|---|
| `"08888888"` | `8` | `08` | `False` เพราะความยาวไม่ครบ |
| `"0700100010"` | `10` | `07` | `False` เพราะคำนำหน้าไม่ถูกต้อง |
| `"0868144444"` | `10` | `08` | `True` |
| `"0900999999"` | `10` | `09` | `True` |

จะเห็นว่าคำนำหน้าถูกต้องเพียงอย่างเดียวไม่พอ และความยาวถูกต้องเพียงอย่างเดียว
ก็ไม่พอเช่นกัน เพราะเงื่อนไขทั้งสองเชื่อมกันด้วย `and`

## การทำงานของตัวตรวจ

ข้อมูลนำเข้าของโปรแกรมเป็นคำสั่ง Python ที่ grader ควบคุม เช่น

```python
print(is_mobile_number("0646664444"))
```

`exec(input())` อ่านและรันคำสั่งนี้ คำสั่งภายนอกจึงเป็นผู้เรียกฟังก์ชันและ
`print()` ค่า `True` หรือ `False` ที่ฟังก์ชันส่งกลับ

> [!WARNING]
>
> `exec()` สามารถรันคำสั่ง Python ใด ๆ ที่ได้รับมา จึงใช้ได้ในข้อนี้เพราะ
> ข้อมูลมาจาก grader ที่เชื่อถือได้เท่านั้น ห้ามใช้ `exec()` กับข้อมูลจาก
> ผู้ใช้หรือแหล่งที่ไม่เชื่อถือ

# Solution

```python
# --------------------------------------------------
# File Name : 03_If_F04.py
# Problem   : Mobile Number (Function)
# Author    : Worralop Srichainont
# Date      : 2025-06-11
# --------------------------------------------------


# This function checks if a given string is a valid mobile number.
def is_mobile_number(number):
    return len(number) == 10 and number[:2] in ["06", "08", "09"]


# Execute the input string as code
exec(input())
```
