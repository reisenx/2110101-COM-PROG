## การแปลงผังงานเป็นเงื่อนไข

โจทย์รับจำนวนเต็ม `a`, `b`, `c` และ `d` ในบรรทัดเดียวกัน
คั่นด้วยช่องว่าง แล้วให้เดินตามผังงานจนถึงจุดแสดงผล
คำสั่ง `if` และ `else` ใช้แทนทางแยกของผังงาน
ส่วนการเยื้องบรรทัดบอกว่าคำสั่งใดอยู่ภายในแขนงใด

ตัวอย่างเช่น ส่วนนี้จะทำงานเฉพาะเมื่อ `a > b` เท่านั้น

```python
if a > b:
    a, b = b, a

    if not d >= a:
        c = c + a
```

หลังสลับ `a` กับ `b` แล้ว เงื่อนไขถัดไปจะอ่านค่า `a` ที่สลับแล้ว
นอกจากนี้ `not d >= a` หมายถึงปฏิเสธข้อความ “`d` มากกว่าหรือเท่ากับ
`a`” จึงเขียนความหมายที่อ่านง่ายได้เป็น `d < a`

## การทำงานแยกตามแขนง

โปรแกรมมีแขนงหลักสองฝั่ง

**กรณี `a > b`**

1. สลับ `a` กับ `b` แบบพร้อมกัน
2. ถ้า `d < a` ให้เพิ่ม `a` เข้าไปใน `c`
3. มิฉะนั้น ถ้า `c > d` ให้ลด `c` ลงด้วย `a`
4. ไม่ว่าข้อย่อยใดจะเกิดขึ้น สุดท้ายกำหนด `b = a + c + d`

`else` จับคู่กับ `if not d >= a` ตามระดับการเยื้อง และมี `if c > d`
ซ้อนอยู่ภายใน `else` อีกชั้นหนึ่ง โดยทั้งชุดยังอยู่ภายใน `if a > b`

**กรณี `a <= b`**

เงื่อนไขลูกโซ่ `c > a >= b` มีความหมายเท่ากับ
`c > a and a >= b` เงื่อนไขนี้รวมกับข้อเท็จจริงจากแขนงหลักว่า
`a <= b` ดังนั้นจะเพิ่ม `a` เข้าไปใน `d` ได้เฉพาะกรณี `a == b`
และ `c > a` เท่านั้น

หลังจากนั้นโปรแกรมตรวจ `d > c` ด้วย `if` อีกชุดหนึ่งซึ่งเป็นอิสระจากชุดแรก
ถ้าจริงจะใช้ `b = b + 2` มิฉะนั้นใช้ `b = 2 * b` การตรวจนี้จึงเห็นค่า `d`
ที่อาจเพิ่งเปลี่ยนจาก `d = d + a`

สุดท้าย `print(a, b, c, d)` แสดงค่าทั้งสี่ในบรรทัดเดียว
โดย `print()` คั่นแต่ละค่าด้วยช่องว่างหนึ่งช่องให้โดยอัตโนมัติ

## ตัวอย่างการไล่ค่า

เมื่อข้อมูลนำเข้าเป็น `4 3 2 1` เงื่อนไข `a > b` เป็นจริง

1. สลับแล้วได้ `a = 3` และ `b = 4`
2. `not d >= a` เป็นจริง เพราะ `1 < 3` จึงได้ `c = 2 + 3 = 5`
3. กำหนด `b = 3 + 5 + 1 = 9`

ผลลัพธ์จึงเป็น `3 9 5 1`

อีกกรณีหนึ่ง เมื่อข้อมูลเป็น `2 2 2 2` จะเข้าแขนง `else`
เงื่อนไข `c > a >= b` เป็นเท็จเพราะ `c > a` ไม่จริง และ `d > c`
ก็เป็นเท็จเพราะค่าทั้งคู่เท่ากัน จึงคำนวณ `b = 2 * b` และแสดง
`2 4 2 2` ตัวอย่างนี้แสดงให้เห็นว่าเครื่องหมายเท่ากับมีผลต่อเส้นทางในผังงาน

# Solution

```python
# --------------------------------------------------
# File Name : 03_If_003.py
# Problem   : Flowchart 01
# Author    : Worralop Srichainont
# Date      : 2025-06-10
# --------------------------------------------------

a, b, c, d = [int(e) for e in input().split()]

if a > b:
    a, b = b, a

    if not d >= a:
        c = c + a
    else:
        if c > d:
            c = c - a

    b = a + c + d
else:
    if c > a >= b:
        d = d + a

    if d > c:
        b = b + 2
    else:
        b = 2 * b

print(a, b, c, d)
```
