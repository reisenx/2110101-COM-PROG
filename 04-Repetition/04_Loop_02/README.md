## แนวคิด Bisection

**Bisection** เป็นวิธีค้นหาคำตอบในช่วงที่ทราบว่าคำตอบอยู่ภายในแน่นอน
แต่ละรอบเลือกจุดกึ่งกลางของช่วง แล้วตัดครึ่งที่ไม่มีคำตอบทิ้ง ทำให้ช่วงค้นหา
แคบลงครึ่งหนึ่งเรื่อย ๆ

กำหนดขอบล่างเป็น `lower` ขอบบนเป็น `upper` และหาจุดกึ่งกลางด้วย

```python
x = (lower + upper) / 2
```

ถ้าค่าที่ได้จาก `x` มากกว่าเป้าหมาย แสดงว่า `x` สูงเกินไป จึงเลื่อนขอบบนลงมา
เป็น `upper = x` แต่ถ้ายังน้อยกว่าหรือเท่ากับเป้าหมาย จะเลื่อนขอบล่างขึ้นเป็น
`lower = x`

## การประมาณค่า log10

ค่าที่ต้องการคือ $x = \log_{10}a$ ซึ่งมีความหมายเดียวกับ

$$
10^x = a
$$

ใน Python การยกกำลังใช้ตัวดำเนินการ `**` ดังนั้น $10^x$ เขียนเป็น
`10**x` โปรแกรมไม่คำนวณลอการิทึมโดยตรง แต่ปรับ `x` จน `10**x`
ใกล้กับข้อมูลนำเข้า `num`

โจทย์กำหนด $1 \le a \le 600$ ทำให้ $\log_{10}a$ ไม่ติดลบ และคำตอบอยู่ใน
ช่วง `[0, a]` ได้แน่นอน โปรแกรมจึงเริ่มด้วย

```python
lower = 0
upper = num
```

ในแต่ละรอบมี 2 กรณี

-   ถ้า `10**x > num` ค่า `x` มากเกินไป จึงเปลี่ยนช่วงเป็น
    `[lower, x]`
-   มิฉะนั้น ค่า `x` ยังไม่มากเกินไป จึงเปลี่ยนช่วงเป็น `[x, upper]`

เพราะฟังก์ชัน $10^x$ เพิ่มขึ้นตลอดเมื่อ `x` เพิ่มขึ้น การเลือกครึ่งช่วงแบบนี้
จึงยังรักษาคำตอบจริงไว้ในช่วงเสมอ ตัวอย่างเช่น เมื่อ `num = 100`
ช่วงจะค่อย ๆ แคบเข้าหา `x = 2` เพราะ `10**2 == 100`

## เงื่อนไขหยุดและการปัดเศษ

โปรแกรมทำซ้ำขณะที่ค่าคลาดเคลื่อนยังมากกว่าเกณฑ์

$$
\left|a-10^x\right| > 10^{-10}\max\left(a,10^x\right)
$$

ซึ่งตรงกับ Python

```python
abs(num - 10**x) > (10**-10) * max(num, 10**x)
```

การคูณด้วย `max(num, 10**x)` ทำให้เกณฑ์พิจารณาตามขนาดของตัวเลข
เมื่อนิพจน์นี้เป็นเท็จ แสดงว่า `10**x` ใกล้ `num` ตามเงื่อนไขใน PDF แล้ว
จึงนำ `x` ไปแสดงผล

คำสั่ง `round(x, 6)` ปัดค่าเป็นตัวเลขไม่เกิน 6 ตำแหน่งหลังจุดทศนิยม
จึงได้ `2.39794` สำหรับ `250.0` และ `2.0` สำหรับ `100` ตามตัวอย่าง

> [!NOTE]
>
> แม้ข้อความโจทย์จะบอกให้แสดง 6 ตำแหน่ง แต่โค้ดเฉลยใช้ `round()`
> ซึ่งไม่เติมเลขศูนย์ท้ายให้ครบ 6 หลัก ผลลัพธ์จึงอาจมีเลขหลังจุดทศนิยม
> น้อยกว่า 6 ตำแหน่งตามพฤติกรรมของโค้ดเฉลย

ลำดับโดยรวมคือรับ `num` เป็น `float` ตั้งช่วง `[0, num]` หาจุดกึ่งกลาง
ตรวจ `10**x` แล้วลดช่วงลงครึ่งหนึ่งซ้ำไปจนผ่านเกณฑ์ ก่อนปัดและแสดงคำตอบ

# Solution

```python
# --------------------------------------------------
# File Name : 04_Loop_02.py
# Problem   : Bisection Log 10
# Author    : Worralop Srichainont
# Date      : 2025-06-11
# --------------------------------------------------

# Input a number
num = float(input())

# Initialize variables
lower = 0
upper = num
x = (lower + upper) / 2

# Bisection method
while abs(num - 10**x) > (10**-10) * max(num, 10**x):
    if 10**x > num:
        upper = x
    else:
        lower = x
    x = (lower + upper) / 2

# Output the result
print(round(x, 6))
```
