## การวนผ่านตัวอักษรในสตริง

สตริงในภาษา Python เป็นลำดับของตัวอักษร เราจึงใช้วงวน `for`
หยิบตัวอักษรออกมาตรวจทีละตัวได้ โดยในแต่ละรอบ ตัวแปร `char`
จะเก็บตัวอักษรปัจจุบันเพียงหนึ่งตัว

```python
new_text = ""
for char in text:
    # เลือกตัวอักษรที่จะนำไปต่อท้าย new_text
```

ตัวแปร `new_text` เริ่มจากสตริงว่าง แล้วใช้ `+=` ต่ออักขระที่แปลงแล้วไปทางขวา
วิธีนี้ทำให้ลำดับของตัวอักษรเหมือนกับข้อมูลนำเข้าเสมอ เปลี่ยนเฉพาะวงเล็บที่โจทย์กำหนด

## การสลับวงเล็บ

โจทย์ให้สลับวงเล็บกลมกับวงเล็บเหลี่ยม โดยวงเล็บเปิดยังคงเป็นวงเล็บเปิด
และวงเล็บปิดยังคงเป็นวงเล็บปิด

| อักขระเดิม | อักขระใหม่ |
| :---: | :---: |
| `(` | `[` |
| `[` | `(` |
| `)` | `]` |
| `]` | `)` |

โค้ดใช้ชุดคำสั่ง `if` / `elif` ตรวจตารางนี้ ส่วนกรณี `else`
จะนำตัวอักษรเดิมมาต่อท้ายโดยไม่แก้ไข ดังนั้นตัวอักษร ตัวเลข ช่องว่าง
และเครื่องหมายอื่น ๆ ภายในบรรทัดจะยังอยู่เหมือนเดิม ตัวอย่างเช่น

```text
ข้อมูลนำเข้า: [a + (b)]
ผลลัพธ์:     (a + [b])
```

การทำงานนี้เป็นเพียงการแทนตัวอักษรทีละตัว ไม่ได้ตรวจว่าวงเล็บจับคู่กันครบ
หรือเรียงซ้อนกันอย่างถูกต้อง หากข้อมูลนำเข้าไม่มีวงเล็บทั้งสี่ชนิด
ผลลัพธ์จึงเหมือนข้อมูลนำเข้า

## ลำดับการทำงาน

1. รับข้อความหนึ่งบรรทัดด้วย `input().strip()` แล้วเก็บใน `text`
2. สร้าง `new_text` เป็นสตริงว่าง
3. วนอ่าน `char` ทุกตัวใน `text` แล้วต่อวงเล็บที่สลับแล้ว
   หรืออักขระเดิมเข้าไปใน `new_text`
4. แสดงสตริงที่สร้างเสร็จด้วย `print(new_text)`

เมธอด `.strip()` ลบช่องว่างที่ต้นและท้ายบรรทัดก่อนเริ่มแปลง
แต่ไม่ลบช่องว่างที่อยู่ระหว่างข้อความ หากบรรทัดว่างหรือมีเพียงช่องว่าง
โปรแกรมจะแสดงบรรทัดว่างหนึ่งบรรทัด

# Solution

```python
# --------------------------------------------------
# File Name : 04_Loop_04.py
# Problem   : Parentheses
# Author    : Worralop Srichainont
# Date      : 2025-06-11
# --------------------------------------------------

# Input text
text = input().strip()

# Construct new text by replacing parentheses
new_text = ""
for char in text:
    if char == "(":
        new_text += "["
    elif char == ")":
        new_text += "]"
    elif char == "[":
        new_text += "("
    elif char == "]":
        new_text += ")"
    else:
        new_text += char

# Output the new text
print(new_text)
```
