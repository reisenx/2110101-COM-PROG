## การออกแบบฟังก์ชัน grade_mcq

ฟังก์ชัน `grade_mcq(sol, ans)` รับสตริงสองตัว

-   `sol` เก็บเฉลย โดยอักขระตำแหน่งที่ `i` คือเฉลยของข้อที่ `i + 1`
-   `ans` เก็บคำตอบของผู้ทำข้อสอบในลำดับเดียวกัน

หน้าที่ของฟังก์ชันคือ **คืนค่า** จำนวนตำแหน่งที่อักขระในสองสตริงตรงกัน
ด้วย `return` ไม่ใช่แสดงผลเองด้วย `print()` ผู้ตรวจจึงสามารถนำค่าที่คืนไปใช้ต่อ
หรือสั่ง `print(grade_mcq(...))` เพื่อแสดงคะแนนได้

ก่อนตรวจคำตอบต้องเปรียบเทียบความยาว เพราะคำตอบสองชุดจะเทียบกันทีละข้อได้
ก็ต่อเมื่อมีจำนวนข้อเท่ากัน หาก `len(ans) != len(sol)`
ฟังก์ชันจะคืน `-1` เพื่อบอกว่าข้อมูลไม่สมบูรณ์

> [!NOTE]
>
> ในเอกสารโจทย์มีข้อความว่า `sol` และ `and` แต่จากชื่อฟังก์ชันและโค้ด
> คำที่ถูกต้องคือพารามิเตอร์ `ans`

## การตรวจและนับคะแนน

เมื่อความยาวเท่ากัน โปรแกรมเริ่ม `score = 0` แล้ววนผ่านดัชนีทุกตำแหน่ง

```python
for i in range(len(ans)):
    if ans[i] == sol[i]:
        score += 1
```

เงื่อนไข `ans[i] == sol[i]` เป็นการเปรียบเทียบแบบตรงตัวและแยกตัวพิมพ์เล็ก
กับตัวพิมพ์ใหญ่ เช่น `"A"` ไม่เท่ากับ `"a"` หากตรงกันจึงเพิ่มคะแนน `1`
เมื่อจบลูป ฟังก์ชันคืนคะแนนสะสม

ตัวอย่าง `sol = "AAABC"` และ `ans = "AABCC"` ตรงกันที่ตำแหน่ง 0, 1 และ 4
จึงคืนค่า `3` การนับนี้ดูคำตอบ **ตำแหน่งเดียวกัน** ไม่ได้นับเพียงว่า
ตัวอักษรแต่ละชนิดปรากฏทั้งหมดกี่ครั้ง

ช่องว่างก็เป็นอักขระหนึ่งตัวเหมือนอักขระอื่น ตัวอย่างในโจทย์ที่ส่ง
`"BBBXXBBB BBBB BBB"` จึงนำช่องว่างมาร่วมตรวจตามตำแหน่งด้วย
และได้คะแนน `0` สำหรับเฉลยที่เป็น `"A"` ทุกตำแหน่ง

กรณีสำคัญของฟังก์ชันมีดังนี้

| เงื่อนไข | ค่าที่คืน |
|---|---|
| ความยาวต่างกัน | `-1` |
| ความยาวเท่ากัน | จำนวนตำแหน่งที่ตรงกัน ตั้งแต่ `0` ถึง `len(sol)` |
| ทั้งสองสตริงว่าง | `0` เพราะไม่มีตำแหน่งให้ตรวจ |

## การเรียกฟังก์ชันด้วย exec

บรรทัดสุดท้าย `exec(input())` มีไว้สำหรับระบบตรวจคำตอบ ระบบจะส่งคำสั่ง Python
เข้ามาหนึ่งบรรทัด เช่น

```python
print(grade_mcq("AAABC", "AABCC"))
```

`exec()` ประมวลผลคำสั่งนั้นในโปรแกรมเดียวกัน จึงเรียกฟังก์ชันที่เราเขียนไว้ได้
และตัวอย่างข้างต้นจะแสดง `3` บรรทัดนี้เป็นส่วนหนึ่งของรูปแบบผู้ตรวจ จึงต้องคงไว้

> [!WARNING]
>
> `exec()` สามารถรันคำสั่ง Python ใด ๆ ได้ จึงห้ามใช้กับข้อความจากผู้ใช้หรือ
> แหล่งข้อมูลที่ไม่น่าเชื่อถือ ในข้อนี้ใช้ได้เพราะข้อมูลมาจากระบบตรวจที่โจทย์กำหนด

# Solution

```python
# --------------------------------------------------
# File Name : 04_Loop_F03.py
# Problem   : MCQ (Function)
# Author    : Worralop Srichainont
# Date      : 2025-06-11
# --------------------------------------------------


# Create a function to grade multiple-choice questions (MCQ)
def grade_mcq(sol, ans):
    # Initialize score
    score = 0

    # Returns a score
    if len(ans) == len(sol):
        for i in range(len(ans)):
            if ans[i] == sol[i]:
                score += 1
        return score
    return -1


# Execute the input string as code
exec(input())
```
