## การออกแบบฟังก์ชัน print_triangle

ฟังก์ชัน `print_triangle(h)` รับความสูง `h` ซึ่งเป็นจำนวนเต็ม
แล้ว **แสดงผล** สามเหลี่ยมหน้าจั่วสูง `h` แถว โดยฐานกว้าง
\(2h-1\) ตัวอักษร ตรงกับนิพจน์ Python `2 * h - 1`

โจทย์ระบุว่าฟังก์ชันไม่ต้องคืนค่า โค้ดจึงสะสมรูปทั้งหมดไว้ในสตริง `triangle`
แล้วเรียก `print(triangle)` เพียงครั้งเดียว เมื่อฟังก์ชันทำงานจบโดยไม่มี `return`
Python จะคืนค่า `None` โดยอัตโนมัติ แต่ `None` ไม่ถูกแสดงในการเรียกปกติอย่าง
`print_triangle(3)`

รูปใช้ `.` แทนช่องว่างภายในพื้นที่สามเหลี่ยม และใช้ `*` เป็นเส้นขอบ
แต่ละแถวจึงสร้างได้จากการทำซ้ำสตริง เช่น `"." * 2` ได้ `".."`

## สูตรของแต่ละแถว

ลูป `for i in range(h - 1)` สร้างส่วนยอดจนถึงแถวก่อนฐาน
โดย `i` เริ่มจาก `0` สูตรของแถวเหล่านี้คือ

| ส่วนของแถว | จำนวน | Python |
|---|---:|---|
| จุดนำหน้า | \(h-i-1\) | `"." * (h - i - 1)` |
| ดาวดวงแรก | \(1\) | `"*"` |
| จุดระหว่างดาว เมื่อ `i > 0` | \(2i-1\) | `"." * ((2 * i) - 1)` |
| ดาวดวงที่สอง เมื่อ `i > 0` | \(1\) | `"*"` |

แถวแรก (`i == 0`) มีดาวเพียงดวงเดียว จึงไม่เข้าบล็อก `if i > 0`
ส่วนแถวถัดไปมีดาวสองดวงและจุดคั่นตามสูตร หลังสร้างแต่ละแถว
โค้ดเติม `"\n"` เพื่อขึ้นบรรทัดใหม่ จึงไม่มีจุดต่อท้ายดาวขอบขวา

เมื่อ `h = 3` การสร้างสตริงเป็นดังนี้

```text
i = 0: ".." + "*"               -> ..*
i = 1: "." + "*" + "." + "*" -> .*.*
ฐาน:    "*" * (2 * 3 - 1)        -> *****
```

จากนั้นโค้ดสร้างฐานแยกจากลูปด้วยดาว \(2h-1\) ดวง
หรือ `"*" * ((2 * h) - 1)` ทำให้ฐานเต็มตลอดความกว้าง

> [!NOTE]
>
> เมื่อ `h = 1` ลูป `range(h - 1)` ไม่มีรอบ และโปรแกรมแสดงฐาน `*`
> เพียงแถวเดียวได้ตามธรรมชาติ โค้ดนี้ออกแบบสำหรับความสูงเป็นจำนวนเต็มบวก

## การเรียกฟังก์ชันด้วย exec

ข้อมูลเข้าของโจทย์ไม่ใช่เพียงตัวเลข `h` แต่เป็นคำสั่ง Python หนึ่งบรรทัด เช่น

```python
print_triangle(3)
```

`exec(input())` รับคำสั่งนี้จากระบบตรวจแล้วประมวลผล จึงเรียก
`print_triangle()` ที่ประกาศไว้ก่อนหน้าได้ บรรทัดดังกล่าวเป็นส่วนหนึ่งของรูปแบบ
การตรวจฟังก์ชันและต้องไม่ลบออก

> [!WARNING]
>
> `exec()` สามารถรันคำสั่ง Python ใด ๆ ได้ จึงห้ามใช้กับข้อความจากผู้ใช้หรือ
> แหล่งข้อมูลที่ไม่น่าเชื่อถือ ในข้อนี้ใช้ได้เพราะข้อมูลมาจากระบบตรวจที่โจทย์กำหนด

# Solution

```python
# --------------------------------------------------
# File Name : 04_Loop_F06.py
# Problem   : Print Triangle (Function)
# Author    : Worralop Srichainont
# Date      : 2025-06-11
# --------------------------------------------------


# Construct a function to print a triangle pattern
def print_triangle(h):
    triangle = ""
    for i in range(h - 1):
        # Add leading dots
        triangle += "." * (h - i - 1)
        # Add the first star
        triangle += "*"
        # Add dots between stars and the second star
        if i > 0:
            triangle += "." * ((2 * i) - 1)
            triangle += "*"
        # Add newline character
        triangle += "\n"
    # Add base of the triangle
    triangle += "*" * ((2 * h) - 1)

    # Output the triangle
    print(triangle)


# Execute the input string as code
exec(input())
```
