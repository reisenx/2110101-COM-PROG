## การแยกคำออกจากข้อความ

ก่อนจะนับคำ เราต้องแยกข้อความหนึ่งบรรทัดออกเป็นคำเสียก่อน
ข้อมูลตามโจทย์อาจมีเครื่องหมายวรรคตอน 6 ชนิด ได้แก่ `"`, `(`, `)`, `,`, `.`
และ `'` เครื่องหมายเหล่านี้ทำหน้าที่คั่นคำเหมือนช่องว่าง

โค้ดจึงวนอ่าน `text` ทีละตัว ถ้าพบเครื่องหมายหนึ่งในรายการ

```python
['"', "(", ")", ",", ".", "'"]
```

ก็จะต่อช่องว่าง `" "` เข้า `new_text` แต่ถ้าเป็นอักขระอื่นจะต่ออักขระเดิม
จากนั้น `new_text.split()` จะแยกข้อความตรงช่องว่าง และข้ามช่องว่างที่ติดกันหลายตัว
เช่น `one,(two)` ถูกเตรียมเป็น `one  two ` และได้รายการคำ
`["one", "two"]`

แม้คอมเมนต์ในโค้ดจะเขียนว่า `Remove symbol from the text`
แต่พฤติกรรมจริงคือ **แทนเครื่องหมายด้วยช่องว่าง** ไม่ใช่ลบทิ้ง
ความแตกต่างนี้สำคัญ เพราะถ้าลบ `,` จาก `one,two` โดยตรง
คำทั้งสองจะติดกันเป็น `onetwo`

## การนับคำที่ตรงกัน

ตัวแปร `key` เก็บคำที่สนใจ ส่วน `words` เป็นรายการคำที่แยกแล้ว
โปรแกรมเริ่ม `count = 0` และเพิ่มค่าทีละ `1` เฉพาะเมื่อ
`word == key` เท่านั้น การเปรียบเทียบสตริงด้วย `==` ต้องเหมือนกันทุกตัวอักษร
รวมถึงตัวพิมพ์ใหญ่และตัวพิมพ์เล็ก

ตัวอย่างเช่น เมื่อ `key` คือ `the` ในข้อความ
`The word "the" is the answer.` จะนับได้ `2` เพราะ `The`
ที่ขึ้นต้นด้วยตัวพิมพ์ใหญ่ไม่เท่ากับ `the`

เครื่องหมายวรรคตอนที่วางติดกันหลายตัวไม่ทำให้เกิดคำว่าง เพราะ `.split()`
จะข้ามช่องว่างซ้ำให้เอง และถ้าไม่มีคำใดตรงกับ `key` ค่า `count`
จะคงเป็น `0`

## ลำดับการทำงาน

1. รับคำที่สนใจหนึ่งบรรทัดเป็น `key` และรับข้อความอีกหนึ่งบรรทัดเป็น `text`
2. ใช้ `.strip()` ตัดช่องว่างที่ต้นและท้ายของทั้งสองบรรทัด
3. สร้าง `new_text` โดยแทนเครื่องหมายวรรคตอนทั้ง 6 ชนิดด้วยช่องว่าง
4. ใช้ `new_text.split()` สร้างรายการ `words`
5. วนเปรียบเทียบทุก `word` กับ `key` แล้วสะสมจำนวนที่ตรงกันใน `count`
6. แสดงจำนวนเต็ม `count`

โค้ดถือเป็นตัวคั่นเฉพาะเครื่องหมายทั้ง 6 ชนิดที่โจทย์ระบุ
ถ้ามีสัญลักษณ์ชนิดอื่น โค้ดจะคงสัญลักษณ์นั้นไว้เป็นส่วนหนึ่งของคำ
แต่ข้อมูลทดสอบตามข้อกำหนดจะไม่มีกรณีดังกล่าว

# Solution

```python
# --------------------------------------------------
# File Name : 04_Loop_05.py
# Problem   : Count Word
# Author    : Worralop Srichainont
# Date      : 2025-06-11
# --------------------------------------------------

# Input interested word
key = input().strip()

# Input text
text = input().strip()

# Remove symbol from the text
new_text = ""
for char in text:
    if char in ['"', "(", ")", ",", ".", "'"]:
        new_text += " "
    else:
        new_text += char

# Split the new text into words
words = new_text.split()

# Count the occurrences of the interested word
count = 0
for word in words:
    if word == key:
        count += 1

# Output the count
print(count)
```
