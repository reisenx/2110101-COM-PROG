## การตรวจคำตอบทีละตำแหน่ง

สตริงเก็บตัวอักษรเป็นลำดับ และเข้าถึงตัวอักษรแต่ละตำแหน่งได้ด้วยดัชนี
ซึ่งเริ่มจาก `0` เช่น ถ้า `text = "ABC"` จะมี `text[0] == "A"` และ
`text[2] == "C"`

โจทย์ให้บรรทัดแรกเป็นเฉลย และบรรทัดที่สองเป็นคำตอบของนักเรียน
ถ้าสตริงยาวเท่ากัน โปรแกรมจึงวนดัชนีทุกตำแหน่งด้วย
`for i in range(len(answer))` แล้วเพิ่ม `score` เมื่อ
`answer[i] == solution[i]`

การเปรียบเทียบสตริงของ Python สนใจตัวพิมพ์เล็ก-ใหญ่ และต้องตรงกันทุกอักขระ
เช่น `"A"` ไม่เท่ากับ `"a"` นอกจากนี้ช่องว่างภายในสตริงก็นับเป็นหนึ่งตำแหน่ง
เช่นเดียวกับตัวอักษรอื่น

ทั้งสองบรรทัดถูกอ่านด้วย `input().strip()` ซึ่งลบช่องว่างเฉพาะต้นและท้าย
สตริง แต่ไม่ลบช่องว่างที่อยู่ตรงกลาง ดังนั้นข้อมูลตัวอย่างที่มีช่องว่างคั่นกลุ่ม
คำตอบยังถูกตรวจตามตำแหน่งจริงทั้งหมด

## การตรวจสอบความยาว

ก่อนเปรียบเทียบทีละตำแหน่ง ต้องตรวจว่าเฉลยและคำตอบมีจำนวนข้อเท่ากันด้วย

```python
if len(answer) == len(solution):
```

ถ้าความยาวต่างกัน เราไม่สามารถจับคู่คำตอบได้ครบทุกข้อ โปรแกรมจึงไม่คำนวณ
คะแนนและแสดง `Incomplete answer` ทันที การตรวจนี้ยังช่วยป้องกันไม่ให้เข้าถึง
ดัชนีที่ไม่มีอยู่ในสตริงที่สั้นกว่า

> [!NOTE]
>
> ตาม PDF บรรทัดแรกคือ **เฉลย** และบรรทัดที่สองคือ **คำตอบของนักเรียน**
> แต่โค้ดเก็บบรรทัดแรกในตัวแปรชื่อ `answer` และบรรทัดที่สองในตัวแปรชื่อ
> `solution` ซึ่งเป็นชื่อที่สลับความหมายกัน การตั้งชื่อนี้ไม่เปลี่ยนผลลัพธ์
> เพราะการตรวจความยาวและการเปรียบเทียบ `==` ให้ผลเหมือนเดิมไม่ว่าจะวาง
> สตริงใดไว้ด้านซ้ายหรือด้านขวา

## ลำดับการทำงาน

1. รับเฉลยจากบรรทัดแรกและคำตอบของนักเรียนจากบรรทัดที่สอง แล้วใช้
   `.strip()` กับทั้งสองสตริง
2. กำหนดคะแนนเริ่มต้น `score = 0`
3. ถ้าสตริงยาวไม่เท่ากัน ให้แสดง `Incomplete answer`
4. ถ้ายาวเท่ากัน ให้วน `i` ตั้งแต่ `0` ถึงตำแหน่งสุดท้าย
5. ทุกตำแหน่งที่ตัวอักษรเท่ากัน เพิ่ม `score` ขึ้น 1
6. เมื่อครบทุกตำแหน่ง แสดงคะแนนรวมเป็นจำนวนเต็ม

ตัวอย่าง `AAABC` กับ `AABCC` ตรงกันที่ตำแหน่งที่ 1, 2 และ 5
เมื่อนับแบบที่มนุษย์ใช้ จึงได้คะแนน `3` (ดัชนี Python คือ `0`, `1` และ `4`)

# Solution

```python
# --------------------------------------------------
# File Name : 04_Loop_03.py
# Problem   : MCQ
# Author    : Worralop Srichainont
# Date      : 2025-06-11
# --------------------------------------------------

# Input answer and solution
answer = input().strip()
solution = input().strip()

# Initialize score
score = 0

# Output the score
if len(answer) == len(solution):
    for i in range(len(answer)):
        if answer[i] == solution[i]:
            score += 1
    print(score)
else:
    print("Incomplete answer")
```
