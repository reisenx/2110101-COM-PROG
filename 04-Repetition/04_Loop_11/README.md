## แนวคิด Run-Length Encoding

Run-Length Encoding หรือ RLE ย่อข้อมูลที่มีอักขระเดิมเรียงติดกัน
โดยแทนแต่ละช่วงด้วย "อักขระ จำนวนครั้ง" ช่วงที่ติดกันเช่นนี้เรียกว่า `run`

สิ่งสำคัญคือเรานับอักขระที่ **อยู่ติดกัน** ไม่ใช่นับความถี่รวมทั้งสตริง
ตัวอย่าง `ABBA` มี `A` สองตัวก็จริง แต่สองตัวนั้นอยู่คนละช่วง
ผลลัพธ์จึงเป็น

```text
A 1 B 2 A 1
```

ข้อมูลตามโจทย์เป็นสตริงที่ประกอบด้วยตัวอักษรภาษาอังกฤษตัวใหญ่
ผลลัพธ์วางอักขระและจำนวนของแต่ละ `run` ตามลำดับเดิม
โดยคั่นทุกค่าด้วยช่องว่างหนึ่งตัว

## การติดตาม run ปัจจุบัน

โปรแกรมต้องจำข้อมูลของช่วงที่กำลังนับอยู่สองค่า

-   `char` คืออักขระของ `run` ปัจจุบัน
-   `count` คือจำนวนอักขระที่พบติดกันใน `run` นั้น

โค้ดกำหนด `char = text[0]` และ `count = 1` จากอักขระตัวแรก
แล้วเริ่มวงวนที่ดัชนี `1` เพราะตัวแรกถูกนับไปแล้ว เมื่ออ่านตัวถัดไป
จะเกิดได้สองกรณี

-   ถ้า `text[i] == char` แสดงว่ายังอยู่ใน `run` เดิม จึงเพิ่ม `count`
-   ถ้าไม่เท่ากัน แสดงว่า `run` เดิมจบแล้ว จึงต่อ `char` และ `count`
    เข้า `rle` ก่อนเปลี่ยน `char` เป็นตัวใหม่และเริ่ม `count = 1`

จำนวนครั้งเป็นชนิด `int` จึงต้องใช้ `str(count)` ก่อนนำมาต่อกับสตริง
โค้ดเติมช่องว่างท้ายข้อมูลของทุก `run` ที่จบระหว่างวงวน
แต่ส่วนสุดท้ายจะไม่เติมช่องว่างท้าย ทำให้ผลลัพธ์มีช่องว่างคั่นพอดี

> [!NOTE]
>
> เมื่อวงวนจบ `run` สุดท้ายยังค้างอยู่ใน `char` และ `count`
> เพราะไม่มีอักขระตัวใหม่มาทำให้เข้าแขนง `else` จึงต้องต่อข้อมูลชุดสุดท้าย
> หลังวงวนเสมอ ไม่เช่นนั้นผลลัพธ์จะหายไปหนึ่ง `run`

## ลำดับการทำงาน

1. รับข้อความด้วย `input().strip()` และเก็บใน `text`
2. เริ่มผลลัพธ์ `rle` เป็นสตริงว่าง แล้วใช้ตัวแรกเริ่ม `char` และ `count`
3. วนตั้งแต่ตัวอักษรลำดับที่สอง ถ้าเหมือน `char` ให้เพิ่ม `count`
4. ถ้าไม่เหมือน ให้บันทึก `run` เดิม แล้วเริ่มนับ `run` ใหม่
5. หลังวงวน บันทึก `run` สุดท้ายโดยไม่เติมช่องว่างต่อท้าย
6. แสดงสตริง RLE ด้วย `print(rle)`

กรณีมีตัวอักษรเพียงตัวเดียว วงวนจะไม่มีรอบ แต่ขั้นตอนบันทึกชุดสุดท้าย
ยังทำให้ได้ผลลัพธ์ เช่น `A` เป็น `A 1` ถ้าทุกตัวเหมือนกันจะได้เพียงหนึ่ง `run`
และถ้าตัวอักษรสลับกันทุกตำแหน่ง แต่ละ `run` จะมีจำนวนเป็น `1`

Solution นี้สมมติว่าข้อมูลมีอย่างน้อยหนึ่งตัวอักษร เพราะเข้าถึง `text[0]`
ทันที หากรับบรรทัดว่างจะเกิด `IndexError` จึงต้องอาศัยรูปแบบข้อมูลตามโจทย์

# Solution

```python
# --------------------------------------------------
# File Name : 04_Loop_11.py
# Problem   : RLE
# Author    : Worralop Srichainont
# Date      : 2025-06-11
# --------------------------------------------------

# Input text
text = input().strip()

# Construct RLE string
rle = ""

# Initialize counter
char = text[0]
count = 1

# Iterate through the text
for i in range(1, len(text)):
    if text[i] == char:
        count += 1
    else:
        rle += char + " " + str(count) + " "
        char = text[i]
        count = 1

# Append the last character and its count
rle += char + " " + str(count)

# Output the RLE string
print(rle)
```
