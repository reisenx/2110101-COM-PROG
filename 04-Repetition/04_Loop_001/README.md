## ความน่าจะเป็นของวันเกิดซ้ำ

สมมติว่า 1 ปีมี 365 วัน และวันเกิดแต่ละวันมีโอกาสเกิดขึ้นเท่ากัน ถ้ามีคน
`k` คน ความน่าจะเป็นที่ **ทุกคนเกิดคนละวัน** คือ

$$
t_k = \frac{365}{365} \times \frac{364}{365} \times \cdots
      \times \frac{365-k+1}{365}
$$

เมื่อเพิ่มคนลำดับที่ `k` เข้ามา เราจึงคำนวณค่าถัดไปจากค่าเดิมได้ด้วย

$$
t_k = t_{k-1}\frac{365-k+1}{365}
$$

ซึ่งตรงกับนิพจน์ Python
`t = (t * (365 - k + 1)) / 365` ในโปรแกรม

เหตุการณ์ “มีอย่างน้อย 2 คนเกิดวันเดียวกัน” เป็นเหตุการณ์ตรงข้ามกับ
“ทุกคนเกิดคนละวัน” ดังนั้นความน่าจะเป็นที่โจทย์สนใจคือ

$$
P(\text{มีวันเกิดซ้ำ}) = 1-t_k
$$

โปรแกรมต้องหา `k` ที่น้อยที่สุดซึ่งทำให้ `1 - t >= p` ตัวอย่างเช่น เมื่อ
`p = 0.7` จะยังไม่ถึงเกณฑ์เมื่อมี 29 คน แต่เมื่อมี 30 คน
ความน่าจะเป็นของวันเกิดซ้ำประมาณ `0.7063` จึงแสดงผล `30`

## การแปลงผังงานเป็นโปรแกรม

ผังงานเริ่มจาก `k = 1` และ `t = 1` แล้วคูณความน่าจะเป็นของคนลำดับที่ `k`
เข้าไปก่อนตรวจเงื่อนไข โปรแกรมจึงทำแบบเดียวกันโดยคำนวณ `t` หนึ่งครั้งก่อน
เข้าสู่ลูป

เงื่อนไขในผังงานคือหยุดเมื่อ `1 - t >= p` ส่วนในโค้ดเขียนกลับด้านเป็น
`while t > 1 - p:` ซึ่งหมายถึง “ตราบใดที่ยังไม่ถึงเกณฑ์ ให้เพิ่ม `k` แล้ว
คำนวณ `t` ใหม่” ทั้งสองเงื่อนไขจึงให้ผลเหมือนกัน

> [!NOTE]
>
> PDF ระบุเพียงว่าอ่านจำนวนจริง แต่เพราะ `p` เป็นค่าความน่าจะเป็น
> ค่าที่มีความหมายควรอยู่ในช่วง `0 <= p <= 1` เมื่อ `p = 0` โปรแกรมแสดง
> `1` ทันที และเมื่อ `p = 1` โปรแกรมแสดง `366` เพราะคนที่ 366
> ต้องมีวันเกิดซ้ำกับหนึ่งใน 365 วันแน่นอน หากป้อน `p > 1` เงื่อนไข
> `t > 1 - p` จะเป็นจริงตลอดและลูปนี้จะไม่จบ

## ลำดับการทำงาน

1. รับค่าเป้าหมาย `p` ด้วย `float(input())`
2. กำหนดจำนวนคนเริ่มต้นเป็น `k = 1` และความน่าจะเป็นที่ยังไม่ซ้ำเป็น
   `t = 1`
3. ปรับค่า `t` ให้เป็นความน่าจะเป็นสำหรับคนจำนวน `k` คน
4. ถ้า `t > 1 - p` แสดงว่ายังมีโอกาสวันเกิดซ้ำน้อยกว่า `p` จึงเพิ่ม `k`
   หนึ่งคนและคำนวณ `t` รอบใหม่
5. เมื่อลูปจบ แสดง `k` ซึ่งเป็นจำนวนคนแรกที่ทำให้ความน่าจะเป็นถึงเกณฑ์

# Solution

```python
# --------------------------------------------------
# File Name : 04_Loop_001.py
# Problem   : Birthday Paradox (Flowchart)
# Author    : Worralop Srichainont
# Date      : 2025-06-11
# --------------------------------------------------

p = float(input())

k = 1
t = 1

t = (t * (365 - k + 1)) / 365

while t > 1 - p:
    k += 1
    t = (t * (365 - k + 1)) / 365

print(k)
```
