## การรับข้อมูลด้วยค่า sentinel

โจทย์ไม่ได้บอกจำนวนข้อมูลล่วงหน้า แต่กำหนดให้บรรทัดสุดท้ายเป็นตัวอักษร
`q` เราเรียกค่าพิเศษที่ใช้บอกให้หยุดรับข้อมูลแบบนี้ว่า **sentinel**

โปรแกรมจึงใช้ `while True` เพื่อรับข้อมูลทีละบรรทัด แล้วใช้
`input().strip()` ลบช่องว่างที่ต้นและท้ายบรรทัดก่อนตรวจค่า ถ้าข้อความที่ได้คือ
`"q"` จะสั่ง `break` ออกจากลูปทันที โดยไม่นำ `q` ไปนับเป็นข้อมูล

sentinel ของข้อนี้เป็นตัวพิมพ์เล็กเท่านั้น ดังนั้น `q` และข้อความอย่าง
`"  q  "` หลังใช้ `.strip()` จะหยุดลูป แต่ `Q` ไม่ใช่ sentinel

ระหว่างรับข้อมูล โปรแกรมไม่จำเป็นต้องเก็บตัวเลขทั้งหมดไว้ในลิสต์ เพียงสะสม

-   ผลรวมไว้ใน `total`
-   จำนวนข้อมูลไว้ใน `num_count`

เมื่ออ่านจำนวนจริงหนึ่งค่า `num` จึงแปลงด้วย `float(num)` แล้วบวกเข้าผลรวม
พร้อมเพิ่มตัวนับหนึ่งครั้ง

## การคำนวณค่าเฉลี่ย

ถ้ามีข้อมูล $n$ ค่า คือ $x_1, x_2, \ldots, x_n$ ค่าเฉลี่ยคำนวณได้จาก

$$
\bar{x} = \frac{x_1+x_2+\cdots+x_n}{n}
$$

ในโปรแกรม `total` แทนผลรวมด้านบน และ `num_count` แทน $n$ จึงเขียนเป็น

```python
average = total / num_count
```

ต้องตรวจ `num_count > 0` ก่อนหารเสมอ เพราะถ้าป้อน `q` ตั้งแต่บรรทัดแรก
จะไม่มีข้อมูลและหารด้วยศูนย์ไม่ได้ กรณีนั้นโปรแกรมแสดงข้อความ `No Data`

สำหรับกรณีที่มีข้อมูล โปรแกรมใช้ `round(average, 2)` เพื่อปัดค่าตัวเลขให้เหลือ
ไม่เกิน 2 ตำแหน่งหลังจุดทศนิยม ตัวอย่าง `25.375` จึงได้ผลลัพธ์ `25.38`

> [!NOTE]
>
> `round()` คืนค่าเป็นตัวเลข ไม่ได้จัดรูปแบบให้มีเลขท้ายครบ 2 ตำแหน่งเสมอ
> ดังนั้นค่าเฉลี่ย `15` จะแสดงเป็น `15.0` ตามตัวอย่างใน PDF ไม่ใช่ `15.00`
> นอกจากนี้ `float` เก็บจำนวนจริงแบบเลขฐานสอง ค่าที่อยู่ใกล้กึ่งกลางพอดีบางค่า
> จึงอาจปัดต่างจากที่คาดจากตัวเลขฐานสิบบนกระดาษเล็กน้อย

## ลำดับการทำงาน

1. กำหนด `total = 0` และ `num_count = 0`
2. รับข้อมูลทีละบรรทัดและตัดช่องว่างหัวท้ายด้วย `.strip()`
3. ถ้าได้ `q` ให้ออกจากลูป มิฉะนั้นแปลงเป็น `float` แล้วสะสมผลรวมและจำนวน
4. ถ้า `num_count > 0` ให้หารผลรวมด้วยจำนวนข้อมูล ปัดด้วย
   `round(average, 2)` แล้วแสดงผล
5. ถ้าไม่มีข้อมูลเลย ให้แสดง `No Data`

# Solution

```python
# --------------------------------------------------
# File Name : 04_Loop_01.py
# Problem   : Average
# Author    : Worralop Srichainont
# Date      : 2025-06-11
# --------------------------------------------------

# Initialize total and num_count
total = 0
num_count = 0

# Input numbers until 'q' is entered
while True:
    num = input().strip()
    if num == "q":
        break
    total += float(num)
    num_count += 1

# Calculate and print the average
if num_count > 0:
    average = total / num_count
    print(round(average, 2))
else:
    print("No Data")
```
