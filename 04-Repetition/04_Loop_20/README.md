## การรับข้อมูลจนพบคำสั่ง

ข้อนี้ใช้หลักการแบ่งตัวเลขเป็นเส้นทางสลับเหมือน Zig Zag 1
แต่ไม่บอกจำนวนคู่ข้อมูลไว้ล่วงหน้า โปรแกรมจึงใช้ `while True`
อ่านทีละบรรทัดไปเรื่อย ๆ จนพบบรรทัดคำสั่ง ซึ่งทำหน้าที่เป็น **sentinel**
หรือค่าที่บอกให้หยุดรับข้อมูล

```python
data = input().strip().split()
```

`.split()` ทำให้ข้อมูลหนึ่งคู่ เช่น `"20 -20"` กลายเป็น `['20', '-20']`
ซึ่งมีสมาชิกสองตัว ส่วนคำสั่ง `Zig-Zag` หรือ `Zag-Zig` มีสมาชิกเพียงตัวเดียว
โค้ดจึงตรวจ `len(data) == 1` เพื่อแยกคำสั่งออกจากคู่ตัวเลข
ตามโจทย์รับรองว่าบรรทัดข้อมูลมีจำนวนเต็มสองจำนวน และบรรทัดสุดท้ายเป็นหนึ่งในสองคำสั่งนี้

ตัวแปร `line` เริ่มจาก `0` และนับจำนวนคู่ที่อ่านไปแล้ว จึงแบ่งตัวเลขได้ดังนี้

| คู่ข้อมูล | เงื่อนไข | ชุด `a` | ชุด `b` |
|---|---|---|---|
| คู่ที่ 1, 3, 5, ... | `line % 2 == 0` | `x` | `y` |
| คู่ที่ 2, 4, 6, ... | `line % 2 == 1` | `y` | `x` |

## การเก็บค่าน้อยสุดและมากสุด

โจทย์ต้องการให้ข้อนี้ไม่ใช้ลิสต์ เราจึงไม่จำเป็นต้องจำตัวเลขทุกตัว
แต่เก็บเฉพาะค่าน้อยสุดและมากสุดที่พบแล้วของแต่ละชุดในตัวแปร
`min_a`, `max_a`, `min_b` และ `max_b` วิธีนี้เรียกว่าอัปเดตผลแบบสะสม

คู่ข้อมูลแรกสำคัญเป็นพิเศษ โค้ดกำหนดค่าเริ่มต้นจากข้อมูลจริงทันที

```python
min_a, max_a = x, x
min_b, max_b = y, y
```

การเริ่มจากข้อมูลจริงช่วยให้คำตอบถูกต้องแม้ข้อมูลทั้งหมดเป็นจำนวนบวก
หรือทั้งหมดเป็นจำนวนลบ หากเริ่มจาก `0` แล้วไม่แทนค่าดังกล่าว
เลขศูนย์อาจกลายเป็นค่าน้อยสุดหรือมากสุดทั้งที่ไม่ได้อยู่ในข้อมูล

ตั้งแต่คู่ที่สองเป็นต้นไป โปรแกรมเลือก `x` และ `y` เข้าชุดตามความเป็นคู่หรือคี่
ของ `line` แล้วอัปเดตค่า เช่น

```python
min_a, max_a = min(min_a, y), max(max_a, y)
```

บรรทัดนี้เปรียบเทียบ `y` กับขอบเขตเดิมของชุด `a` โดยไม่ต้องเก็บ `y`
ไว้ในลิสต์ ดังนั้นไม่ว่าจะรับข้อมูลกี่คู่ โปรแกรมก็ใช้ตัวแปรจำนวนคงที่
หรือหน่วยความจำเพิ่มเติมระดับ `O(1)`

เมื่อพบคำสั่ง โปรแกรมแสดงผลตามลำดับต่อไปนี้ แล้วใช้ `break` จบลูป

| คำสั่ง | ผลลัพธ์ |
|---|---|
| `Zig-Zag` | `min_a` ตามด้วย `max_b` |
| `Zag-Zig` | `min_b` ตามด้วย `max_a` |

เช่น ข้อมูล `(-10, 10)`, `(20, -20)`, `(-30, 30)` ทำให้ชุด `a`
มีขอบเขต `-30` ถึง `-10` และชุด `b` มีขอบเขต `10` ถึง `30`
จึงได้ `-30 30` สำหรับ `Zig-Zag` และ `10 -10` สำหรับ `Zag-Zig`

> [!NOTE]
>
> วิธีในโค้ดสมมติว่ามีคู่ข้อมูลอย่างน้อยหนึ่งคู่ก่อนคำสั่งตามรูปแบบโจทย์
> หากรับคำสั่งเป็นบรรทัดแรก ตัวแปรขอบเขตจะยังเป็นค่าเริ่มต้น `0`
> ซึ่งไม่ใช่ผลที่นิยามไว้สำหรับชุดข้อมูลว่าง

## ลำดับการทำงาน

1. อ่านบรรทัดแล้วแยกด้วย `.split()`
2. ถ้ามีข้อมูลหนึ่งคำ ให้แสดงค่าจากตัวแปรขอบเขตตามคำสั่งและหยุดลูป
3. ถ้ามีข้อมูลสองคำ ให้แปลง `x` และ `y` เป็น `int`
4. ถ้าเป็นคู่แรก ให้ใช้ `x` และ `y` กำหนดขอบเขตเริ่มต้นของทั้งสองชุด
5. สำหรับคู่ถัดไป ให้เลือกชุดตาม `line` แล้วอัปเดตค่าน้อยสุดและมากสุด
6. เพิ่ม `line` ขึ้น `1` และกลับไปรับบรรทัดถัดไป

# Solution

```python
# --------------------------------------------------
# File Name : 04_Loop_20.py
# Problem   : Zig Zag 2
# Author    : Worralop Srichainont
# Date      : 2025-06-11
# --------------------------------------------------

# Initialize variables
line = 0
min_a, max_a = 0, 0
min_b, max_b = 0, 0

# Loop to read input values
while True:
    # Read input data
    data = input().strip().split()

    # Output the result
    if len(data) == 1:
        cmd = data[0]
        if cmd == "Zig-Zag":
            print(min_a, max_b)
        elif cmd == "Zag-Zig":
            print(min_b, max_a)
        break

    # Get the numbers
    x, y = int(data[0]), int(data[1])

    # Update min and max values based on the line number
    if line == 0:
        min_a, max_a = x, x
        min_b, max_b = y, y
    else:
        if line % 2 == 0:
            min_a, max_a = min(min_a, x), max(max_a, x)
            min_b, max_b = min(min_b, y), max(max_b, y)
        else:
            min_a, max_a = min(min_a, y), max(max_a, y)
            min_b, max_b = min(min_b, x), max(max_b, x)

    # Increment the line number
    line += 1
```
