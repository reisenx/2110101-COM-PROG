## การกำหนดช่วงค้นหา

โจทย์รับจำนวนจริง `a` ซึ่งรับประกันว่า $a \ge 1$ และต้องหา $x$ ที่ทำให้

$$
10^x = a
$$

ดังนั้น $x = \log_{10} a$ เนื่องจาก $a \ge 1$ เราจึงทราบว่า
$x \ge 0$ และกำหนดขอบล่างเป็น `lower = 0` ได้

ขอบบนไม่ควรกว้างถึง `a` เพราะจะทำให้การแบ่งครึ่งช่วงช้าและอาจคำนวณ
`10**x` ด้วยเลขชี้กำลังที่ใหญ่เกินจำเป็น โค้ดจึงนับจำนวนครั้งที่หาร `temp`
ด้วย `10` แบบปัดเศษลงจนเหลือ `0`

```python
upper = 0
temp = num
while temp > 0:
    temp //= 10
    upper += 1
```

สำหรับจำนวนบวก จำนวนรอบที่นับได้มีค่า

$$
U = 1 + \lfloor \log_{10} a \rfloor
$$

เช่น `a = 120` จะเปลี่ยน `temp` ตามลำดับ `120`, `12`, `1`, `0`
จึงได้ `upper = 3` และมั่นใจว่า $\log_{10}120$ อยู่ในช่วง `[0, 3]`

## การประมาณค่า log10 ด้วย Bisection

ฟังก์ชัน $10^x$ เพิ่มขึ้นเมื่อ `x` เพิ่มขึ้น จึงใช้วิธี Bisection
แบ่งครึ่งช่วงที่ครอบคำตอบได้ เริ่มจากจุดกึ่งกลาง

```python
x = (lower + upper) / 2
```

ในแต่ละรอบเปรียบเทียบ `10**x` กับ `num`

-   ถ้า `10**x > num` แสดงว่า `x` มากกว่าคำตอบ จึงเลื่อนขอบบนด้วย
    `upper = x`
-   มิฉะนั้น `x` ยังไม่เกินคำตอบ จึงเลื่อนขอบล่างด้วย `lower = x`

จากนั้นคำนวณกึ่งกลางใหม่ด้วย `(lower + upper) / 2`
ช่วงจะเล็กลงครึ่งหนึ่งทุกครั้ง โดยยังมี $\log_{10}a$ อยู่ภายในเสมอ
โปรแกรมจึงหาได้ทั้งกรณีที่ `a` เป็นกำลังของ `10` และกรณีที่คำตอบ
มีทศนิยม โดยไม่เรียกฟังก์ชันลอการิทึมสำเร็จรูป

## เงื่อนไขหยุดและการปัดเศษ

แทนที่จะรอให้ `x` เท่ากับคำตอบทุกหลัก โปรแกรมถือว่า `num` กับ `10**x`
ใกล้กันเพียงพอเมื่อ

$$
\left|a - 10^x\right| \le 10^{-10}\max\left(a, 10^x\right)
$$

โค้ดจึงทำวงวนต่อขณะที่เงื่อนไขตรงข้ามยังเป็นจริง

```python
abs(num - 10**x) > (10**-10) * max(num, 10**x)
```

การใช้ `max(num, 10**x)` ทำให้เกณฑ์ความคลาดเคลื่อนปรับตามขนาดของจำนวน
เมื่อออกจากวงวนจึงปัด `x` ด้วย `round(x, 6)` แล้วแสดงผล

> [!NOTE]
>
> ข้อความโจทย์ระบุให้แสดงทศนิยม 6 ตำแหน่ง แต่โค้ดคำตอบใช้
> `print(round(x, 6))` ซึ่งปัดให้เหลือ **ไม่เกิน** 6 ตำแหน่ง
> และไม่เติมเลขศูนย์ท้าย เช่น `a = 100` แสดง `2.0` ไม่ใช่ `2.000000`
> พฤติกรรมนี้ตรงกับตัวอย่างและเป็นพฤติกรรมของ Solution ที่อธิบายอยู่

กรณีขอบเขต `a = 1` จะได้ค่าประมาณที่ปัดเป็น `0.0`
ส่วนค่าที่ไม่ใช่กำลังของ `10` เช่น `123456` จะแสดง `5.091512`
ข้อรับประกัน $a \ge 1$ มีความสำคัญต่อทั้งขอบล่างและวงวนหาขอบบน

# Solution

```python
# --------------------------------------------------
# File Name : 04_Loop_10.py
# Problem   : Bisection Log 10 [2]
# Author    : Worralop Srichainont
# Date      : 2025-06-11
# --------------------------------------------------

# Input a number
num = float(input())

# Initialize lower bound
lower = 0

# Calculate upper bound
upper = 0
temp = num
while temp > 0:
    temp //= 10
    upper += 1

# Initialize x as the midpoint
x = (lower + upper) / 2

# Bisection method
while abs(num - 10**x) > (10**-10) * max(num, 10**x):
    if 10**x > num:
        upper = x
    else:
        lower = x
    x = (lower + upper) / 2

# Output the result
print(round(x, 6))
```
