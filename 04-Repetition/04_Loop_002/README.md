## แนวคิดการแบ่งส่วนข้อมูล

การทำ **partition** คือการเลือกข้อมูลหนึ่งตัวเป็นหลัก หรือ **pivot**
แล้วจัดข้อมูลที่เหลือออกเป็น 2 กลุ่ม ในข้อนี้เลือกสมาชิกตัวสุดท้ายด้วย
`p = d[-1]` และต้องจัดให้

-   สมาชิกทางซ้ายของ `p` มีค่าน้อยกว่าหรือเท่ากับ `p`
-   สมาชิกทางขวาของ `p` มีค่ามากกว่า `p`

การแบ่งส่วนยังไม่ใช่การเรียงลำดับทั้งรายการ สมาชิกภายในแต่ละกลุ่มจึงไม่จำเป็น
ต้องเรียงจากน้อยไปมาก ตัวอย่างเช่น ข้อมูล `5 4 3 2 1` เลือก `1` เป็น
pivot ไม่มีสมาชิกก่อนหน้าตัวใดน้อยกว่าหรือเท่ากับ `1` เลย เมื่อสลับ pivot
มาไว้ด้านหน้า ผลลัพธ์จึงเป็น `[1, 4, 3, 2, 5]`

ข้อมูลนำเข้าอ่านด้วย
`d = [int(e) for e in input().split()]` จึงได้ลิสต์ของจำนวนเต็ม ส่วน
`print(d)` แสดงผลในรูปแบบลิสต์ของ Python ซึ่งมีวงเล็บเหลี่ยม เครื่องหมายจุลภาค
และช่องว่าง เช่น `[1, 2, 3]`

## ตัวแปรและเงื่อนไขคงรูป

ตัวแปรสำคัญมีหน้าที่ดังนี้

| ตัวแปร | หน้าที่ |
|---|---|
| `p` | ค่า pivot ซึ่งเป็นสมาชิกตัวสุดท้ายของ `d` |
| `i` | ตำแหน่งสุดท้ายของกลุ่มที่มีค่า `<= p` เริ่มที่ `-1` เพราะตอนแรกกลุ่มนี้ยังว่าง |
| `j` | ตำแหน่งของสมาชิกที่กำลังตรวจ เริ่มที่ `0` |
| `n` | จำนวนสมาชิกทั้งหมดในลิสต์ |

ก่อนเริ่มการตรวจแต่ละรอบ ช่วงที่ประมวลผลแล้วจะรักษาเงื่อนไขเดิมเสมอว่า

-   `d[0]` ถึง `d[i]` เป็นกลุ่มที่มีค่า `<= p`
-   `d[i + 1]` ถึง `d[j - 1]` เป็นกลุ่มที่มีค่า `> p`
-   `d[j]` ถึง `d[n - 2]` ยังไม่ได้ตรวจ และ pivot ยังอยู่ที่ `d[-1]`

เงื่อนไขที่ยังคงเป็นจริงทุกครั้งแบบนี้เรียกว่า **เงื่อนไขคงรูปของลูป**
(loop invariant) ถ้า `d[j] <= p` โปรแกรมจะขยายกลุ่มซ้ายโดยเพิ่ม `i`
แล้วใช้คำสั่ง

```python
d[i], d[j] = d[j], d[i]
```

เพื่อสลับสมาชิกที่เพิ่งพบเข้าไปในกลุ่มนั้น แต่ถ้า `d[j] > p` ไม่ต้องสลับ
จากนั้นเพิ่ม `j` เพื่อพิจารณาสมาชิกถัดไป

## ลำดับการทำงาน

1. อ่านจำนวนเต็มทั้งหมดในหนึ่งบรรทัดเก็บใน `d`
2. เลือก `d[-1]` เป็น `p` และกำหนด `i = -1`, `j = 0`
3. วนตรวจเฉพาะตำแหน่ง `0` ถึง `n - 2` เพราะตำแหน่งสุดท้ายคือ pivot
4. เมื่อพบค่า `<= p` ให้เพิ่ม `i` แล้วสลับ `d[i]` กับ `d[j]`
   ค่าเท่ากับ pivot จึงถูกจัดไว้ทางซ้ายด้วย
5. หลังตรวจครบ สลับ pivot กับ `d[i + 1]` ทำให้ pivot อยู่ระหว่างสองกลุ่ม
6. แสดงลิสต์ `d`

ถ้ามีข้อมูลเพียงหนึ่งตัว ลูป `while j < n - 1` จะไม่ทำงาน และคำสั่งสุดท้าย
จะสลับสมาชิกตัวนั้นกับตัวเอง จึงแสดงลิสต์เดิมได้ตามปกติ ส่วนข้อมูลนำเข้าต้องมี
อย่างน้อยหนึ่งตัว เพราะโปรแกรมต้องอ่าน pivot จาก `d[-1]`

# Solution

```python
# --------------------------------------------------
# File Name : 04_Loop_002.py
# Problem   : Partition (Flowchart)
# Author    : Worralop Srichainont
# Date      : 2025-06-11
# --------------------------------------------------

d = [int(e) for e in input().split()]

p = d[-1]
i = -1
j = 0
n = len(d)

while j < n - 1:
    if d[j] <= p:
        i += 1
        d[i], d[j] = d[j], d[i]
    j += 1

d[i + 1], d[-1] = d[-1], d[i + 1]

print(d)
```
