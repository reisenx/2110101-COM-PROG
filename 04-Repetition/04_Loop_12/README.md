## การแบ่งข้อมูลแบบสลับ

โจทย์ให้ข้อมูลจำนวนเต็มครั้งละหนึ่งคู่ `x y` รวมทั้งหมด `n` คู่
แต่ไม่ได้หาค่าน้อยสุดและมากสุดจากคอลัมน์ `x` และ `y` ตรง ๆ
เราต้องแบ่งตัวเลขเป็นเส้นทางสลับกันสองชุดก่อน

โปรแกรมใช้ลิสต์ `a` และ `b` เก็บตัวเลขของแต่ละเส้นทาง โดยตัวแปร `i`
เริ่มนับจาก `0` ดังนั้น `i = 0` คือข้อมูลคู่ที่ 1, `i = 1` คือข้อมูลคู่ที่ 2
และเป็นเช่นนี้ต่อไป

| ลำดับคู่ข้อมูล | เงื่อนไขของ `i` | เพิ่มลงใน `a` | เพิ่มลงใน `b` |
|---|---|---|---|
| คู่ที่ 1, 3, 5, ... | `i % 2 == 0` | `x` | `y` |
| คู่ที่ 2, 4, 6, ... | `i % 2 == 1` | `y` | `x` |

คำสั่ง `a += [x]` จึงหมายถึงการนำ `x` หนึ่งค่าไปต่อท้ายลิสต์ `a`
ส่วนบรรทัดที่มีลำดับเป็นเลขคู่ตามการนับของโจทย์จะสลับตำแหน่ง `x` กับ `y`
ก่อนเก็บ ตัวอย่างเช่น เมื่อรับข้อมูล

```text
-10 10
20 -20
-30 30
```

จะได้ `a = [-10, -20, -30]` และ `b = [10, 20, 30]`

## คำสั่ง Zig-Zag และ Zag-Zig

หลังรับข้อมูลครบ `n` คู่ โปรแกรมอ่านคำสั่งเป็นสตริงและใช้ `.strip()`
ตัดช่องว่างที่อาจติดอยู่หน้าหรือท้ายคำสั่ง จากนั้นเลือกผลลัพธ์ตามตารางนี้

| คำสั่ง | ค่าที่ 1 | ค่าที่ 2 | Python |
|---|---|---|---|
| `Zig-Zag` | ค่าน้อยสุดของ `a` | ค่ามากสุดของ `b` | `print(min(a), max(b))` |
| `Zag-Zig` | ค่าน้อยสุดของ `b` | ค่ามากสุดของ `a` | `print(min(b), max(a))` |

จากตัวอย่างข้างต้น ถ้าคำสั่งเป็น `Zig-Zag` จะได้ `-30 30`
แต่ถ้าเป็น `Zag-Zig` จะได้ `10 -10` สังเกตว่าตำแหน่งแรกเป็นค่าน้อยสุด
และตำแหน่งที่สองเป็นค่ามากสุดของคนละชุดเสมอ ไม่ได้เรียงคำตอบทั้งสองค่าใหม่

จำนวนลบ จำนวนบวก และค่าที่เท่ากันไม่ต้องแยกกรณีพิเศษ เพราะ `min()` และ `max()`
จัดการค่าเหล่านี้ได้โดยตรง ส่วน `print()` ที่รับอาร์กิวเมนต์สองตัวจะแสดงผลทั้งสองค่า
คั่นด้วยช่องว่างหนึ่งช่อง

> [!NOTE]
>
> โค้ดนี้ต้องมีข้อมูลอย่างน้อยหนึ่งคู่ เพื่อให้ `a` และ `b` มีสมาชิกก่อนเรียก
> `min()` และ `max()` ซึ่งสอดคล้องกับรูปแบบข้อมูลของโจทย์

## ลำดับการทำงาน

1. อ่าน `n` ด้วย `int(input())` เพื่อทราบจำนวนคู่ข้อมูล
2. สร้างลิสต์ว่าง `a` และ `b`
3. วนซ้ำ `n` รอบ อ่าน `x` และ `y` เป็น `int` แล้วแบ่งลงสองลิสต์ตามความเป็นคู่หรือคี่ของ `i`
4. อ่านคำสั่ง `Zig-Zag` หรือ `Zag-Zig`
5. หาค่าน้อยสุดและค่ามากสุดจากลิสต์ตามคำสั่ง แล้วแสดงผลตามลำดับที่โจทย์กำหนด

# Solution

```python
# --------------------------------------------------
# File Name : 04_Loop_12.py
# Problem   : Zig Zag 1
# Author    : Worralop Srichainont
# Date      : 2025-06-11
# --------------------------------------------------

# Input number of rows
n = int(input())

# Initialize lists
a = []
b = []

# Loop to read input values
for i in range(n):
    x, y = [int(e) for e in input().split()]
    if i % 2 == 0:
        a += [x]
        b += [y]
    else:
        a += [y]
        b += [x]

# Output the results
cmd = input().strip()
if cmd == "Zig-Zag":
    print(min(a), max(b))
elif cmd == "Zag-Zig":
    print(min(b), max(a))
```
