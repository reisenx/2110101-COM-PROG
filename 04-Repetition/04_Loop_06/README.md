## รูปแบบของสามเหลี่ยม

โปรแกรมรับความสูงเป็นจำนวนเต็ม `n` โดยโจทย์กำหนดให้ $n \ge 2$
แล้วสร้างสามเหลี่ยมหน้าจั่วสูง `n` บรรทัด ฐานจึงมีความกว้าง

$$
2n - 1
$$

ตำแหน่งที่ว่างในรูปใช้จุด `.` แทน และขอบสามเหลี่ยมใช้ดอกจัน `*`
เราสร้างอักขระซ้ำได้ด้วยตัวดำเนินการ `*` ของสตริง เช่น
`"." * 3` ได้ `"..."` และ `"*" * 5` ได้ `"*****"`

โค้ดแบ่งรูปเป็นสองส่วนชัดเจน

-   วงวน `for i in range(n - 1)` สร้างยอดและแถวกลาง รวม `n - 1` แถว
-   หลังจบวงวนจึงสร้างฐานซึ่งเป็นดอกจันทั้งหมดอีกหนึ่งแถว

ดังนั้นฐานไม่ต้องใช้เงื่อนไขพิเศษอยู่ภายในวงวน

## สูตรของแต่ละแถว

ตัวแปร `i` เริ่มจาก `0` ทำให้สูตรของแต่ละแถวเป็นดังนี้

| ส่วนของรูป | ค่า `i` | อักขระที่สร้าง |
|---|---:|---|
| ยอด | `0` | จุดนำหน้า $n - 1$ ตัว แล้วตามด้วย `*` หนึ่งตัว |
| แถวกลาง | $1 \le i \le n - 2$ | จุดนำหน้า $n-i-1$ ตัว, `*`, จุดด้านใน $2i-1$ ตัว และ `*` |
| ฐาน | นอกวงวน | `*` จำนวน $2n-1$ ตัว |

สูตรคณิตศาสตร์เหล่านี้ตรงกับนิพจน์ Python ดังนี้

-   จุดนำหน้า $n-i-1$ ตัว: `"." * (n - i - 1)`
-   จุดระหว่างขอบ $2i-1$ ตัว: `"." * ((2 * i) - 1)`
-   ฐานกว้าง $2n-1$ ตัว: `"*" * ((2 * n) - 1)`

เมื่อ `i == 0` โปรแกรมเพิ่มเฉพาะดอกจันตัวแรก เงื่อนไข `if i > 0`
จึงป้องกันไม่ให้ยอดมีจุดด้านในและดอกจันตัวที่สอง ตัวอย่างเมื่อ `n = 3`
จะได้

```text
..*
.*.*
*****
```

แต่ละแถวจบที่ `*` ตัวขวาสุดทันที โปรแกรมไม่ได้เติมจุดต่อท้ายแถว
ความกว้าง $2n-1$ จึงหมายถึงความกว้างของฐาน ไม่ใช่ความยาวของทุกบรรทัด

## ลำดับการทำงาน

1. รับความสูงด้วย `int(input())` แล้วเก็บใน `n`
2. เริ่มตัวสะสม `triangle` เป็นสตริงว่าง
3. สำหรับ `i` ตั้งแต่ `0` ถึง `n - 2` ให้ต่อจุดนำหน้าและดอกจันตัวแรก
4. ถ้า `i > 0` ให้ต่อจุดด้านในและดอกจันตัวที่สอง
5. ต่อ `"\n"` หลังทุกแถวที่ไม่ใช่ฐาน
6. หลังจบวงวน ต่อฐานที่มี `*` จำนวน $2n-1$ ตัว
7. แสดงรูปทั้งหมดด้วย `print(triangle)` ซึ่งเติมอักขระขึ้นบรรทัดใหม่หลังฐาน

ที่ขอบเขตต่ำสุดตามโจทย์ `n = 2` วงวนสร้าง `.*` หนึ่งแถว
แล้วโปรแกรมต่อฐาน `***` จึงได้ครบสองบรรทัดพอดี

# Solution

```python
# --------------------------------------------------
# File Name : 04_Loop_06.py
# Problem   : Print Triangle
# Author    : Worralop Srichainont
# Date      : 2025-06-11
# --------------------------------------------------

# Input the height of the triangle
n = int(input())

# Construct the triangle
triangle = ""
for i in range(n - 1):
    # Add leading dots
    triangle += "." * (n - i - 1)
    # Add the first star
    triangle += "*"
    # Add dots between stars and the second star
    if i > 0:
        triangle += "." * ((2 * i) - 1)
        triangle += "*"
    # Add newline character
    triangle += "\n"
# Add base of the triangle
triangle += "*" * ((2 * n) - 1)

# Output the triangle
print(triangle)
```
