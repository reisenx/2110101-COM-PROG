## การออกแบบฟังก์ชัน RLE

**Run-Length Encoding (RLE)** คือการย่ออักขระที่เหมือนกันและวางติดกัน
ให้เป็นคู่ `[อักขระ, จำนวนครั้ง]` ตัวอย่างเช่น

```text
AAABBCCCA -> [['A', 3], ['B', 2], ['C', 3], ['A', 1]]
```

`'A'` ชุดแรกและ `'A'` ตัวสุดท้ายต้องอยู่คนละรายการ เพราะมีอักขระอื่นคั่นอยู่
ดังนั้น RLE นับความยาวของแต่ละ **run** หรือช่วงที่ติดกัน
ไม่ใช่นับความถี่รวมของอักขระทั้งสตริง

ฟังก์ชันในโค้ดมีรูปแบบ `RLE(text)` รับสตริงหนึ่งตัวและคืนลิสต์
สมาชิกแต่ละตัวเป็นลิสต์ย่อย `[char, count]` โดย `char` เป็นสตริงความยาวหนึ่ง
และ `count` เป็น `int` ชื่อพารามิเตอร์ `text` ต่างจาก `t` ในเอกสารโจทย์
การเรียกแบบระบุตำแหน่งตามตัวอย่าง เช่น `RLE("ABBAA")` จึงไม่ได้รับผลกระทบ
แต่ถ้าเรียกด้วยชื่อพารามิเตอร์ ต้องใช้ชื่อจากโค้ดจริงเป็น `RLE(text="ABBAA")`
ไม่ใช่ `RLE(t="ABBAA")`

ฟังก์ชันเปรียบเทียบอักขระแบบตรงตัว จึงแยกตัวพิมพ์เล็กและตัวพิมพ์ใหญ่
เช่น `'z'` กับ `'Z'` เป็นคนละ run ช่องว่างและเครื่องหมายต่าง ๆ ก็เป็นอักขระ
ที่สามารถถูกเก็บและนับได้เช่นเดียวกัน

## การสร้างรายการ run

ก่อนอ่าน `text[0]` โปรแกรมตรวจสตริงว่างก่อน

```python
if text == "":
    return []
```

ขั้นตอนนี้ป้องกันการเข้าถึงตำแหน่งที่ไม่มีอยู่ และทำให้ `RLE("")` คืน `[]`
ตามตัวอย่างโจทย์ สำหรับสตริงที่ไม่ว่าง โปรแกรมเริ่ม run แรกด้วย
`char = text[0]` และ `count = 1` แล้ววนตั้งแต่ตำแหน่งที่ `1`

-   ถ้า `text[i] == char` แสดงว่ายังอยู่ใน run เดิม จึงเพิ่ม `count`
-   ถ้าอักขระเปลี่ยน ให้เพิ่ม `[char, count]` ลงใน `rle`
    แล้วเริ่ม run ใหม่ด้วยอักขระปัจจุบันและ `count = 1`

คำสั่ง `rle += [[char, count]]` มีวงเล็บลิสต์สองชั้น
จึงเพิ่ม `[char, count]` เป็นสมาชิกหนึ่งตัวของลิสต์ผลลัพธ์

เมื่อออกจากลูป run สุดท้ายยังไม่ได้พบอักขระใหม่มาปิด run
จึงต้องเพิ่ม `[char, count]` อีกหนึ่งครั้งก่อน `return rle`
ขั้นตอนสุดท้ายนี้สำคัญทั้งกรณีสตริงมีอักขระเดียวและกรณีที่ทุกอักขระเหมือนกัน

ตัวอย่าง `RLE("ABBAA")` ทำงานเป็นช่วงดังนี้

| run | รายการที่เพิ่ม |
|---|---|
| `A` | `['A', 1]` |
| `BB` | `['B', 2]` |
| `AA` | `['A', 2]` |

จึงคืน `[['A', 1], ['B', 2], ['A', 2]]` การวนตรวจสตริงใช้เวลา
`O(len(text))` และลิสต์ผลลัพธ์มีหนึ่งรายการต่อหนึ่ง run

## การเรียกฟังก์ชันด้วย exec

ระบบตรวจส่งคำสั่ง Python เข้ามาหนึ่งบรรทัด เช่น

```python
print(RLE("ABBAA"))
```

`exec(input())` ประมวลผลคำสั่งนั้นในโปรแกรมเดียวกัน จึงเรียก `RLE()`
และแสดงลิสต์ที่ฟังก์ชันคืนได้ บรรทัดนี้เป็นส่วนหนึ่งของรูปแบบผู้ตรวจ
และต้องไม่ลบออก

> [!WARNING]
>
> `exec()` สามารถรันคำสั่ง Python ใด ๆ ได้ จึงห้ามใช้กับข้อความจากผู้ใช้หรือ
> แหล่งข้อมูลที่ไม่น่าเชื่อถือ ในข้อนี้ใช้ได้เพราะข้อมูลมาจากระบบตรวจที่โจทย์กำหนด

# Solution

```python
# --------------------------------------------------
# File Name : 04_Loop_F11.py
# Problem   : RLE (Function)
# Author    : Worralop Srichainont
# Date      : 2025-08-09
# --------------------------------------------------


def RLE(text):
    # Empty string check
    if text == "":
        return []

    # Construct RLE list
    rle = []

    # Initialize counter
    char = text[0]
    count = 1

    # Iterate through the text
    for i in range(1, len(text)):
        if text[i] == char:
            count += 1
        else:
            rle += [[char, count]]
            char = text[i]
            count = 1

    # Append the last character and its count
    rle += [[char, count]]
    # Return the RLE list
    return rle


# Execute input string as code
exec(input())
```
