# แนวคิดการแปลงผังงาน

โจทย์นี้ไม่ได้ให้หาสูตรลัด แต่ให้เขียนโปรแกรมตามลูกศรและเงื่อนไขในผังงาน
สัญลักษณ์ตัดสินใจจึงแปลงเป็น `if`/`elif`/`else` ส่วนลูกศรที่ย้อนกลับไปตรวจเงื่อนไขเดิมแปลงเป็น `while`

คำสั่งลักษณะ `d, e = e, d` คือการสลับค่าพร้อมกัน เช่น ถ้าเดิม `d = 2`
และ `e = 4` หลังคำสั่งจะได้ `d = 4` และ `e = 2`

## รับข้อมูลและเลือกเส้นทาง

บรรทัดแรกมีจำนวนเต็ม `n`, `a` และ `b` คั่นด้วยช่องว่าง

```python
n, a, b = [int(e) for e in input().split()]
```

`input().split()` แยกข้อความเป็น 3 ส่วน, `int(e)` แปลงแต่ละส่วนเป็นจำนวนเต็ม
แล้วกระจายผลลัพธ์ให้ตัวแปรทั้งสามตามลำดับ จากนั้นโปรแกรมเลือกเส้นทางดังนี้

-   ถ้า `a > b` ให้ทำงานด้วยลูปและรับ `c` ตามจำนวนรอบของลูป
-   ถ้า `a <= b` ให้รับ `c`, `d`, `e`, `f` อย่างละหนึ่งบรรทัด รวม 4 บรรทัด

# กรณีที่ a มากกว่า b

เริ่มต้น `d` และ `e` เป็น `-1` แล้วทำลูปตราบใดที่ `n < a`
แต่ละรอบรับ `c` หนึ่งค่าและปรับ `d`, `e` ดังนี้

| เงื่อนไข | คำสั่ง | ผลที่เกิดขึ้น |
|:--|:--|:--|
| `c > d` | `d, e = c, d` | ให้ `c` เป็นค่าหลัก และเลื่อนค่าเดิมของ `d` ไปไว้ที่ `e` |
| `c <= d` และ `c > e` | `e = c` | เก็บ `c` ไว้ที่ `e` |
| `c <= d` และ `c <= e` | ไม่เปลี่ยนค่า | `c` ไม่ผ่านทั้งสองเงื่อนไข |

เมื่อจบรอบ โปรแกรมเพิ่มค่า `n` ตามความสัมพันธ์

$$
n_{\text{next}} = n + b
$$

ซึ่งตรงกับคำสั่ง Python `n = n + b` แล้วกลับไปตรวจ `n < a` อีกครั้ง
เมื่อลูปหยุดจึงไปแสดง `d` และ `e`

มองอย่างแม่นยำ `d` และ `e` คือสองค่ามากที่สุดเมื่อพิจารณาค่า `c` ที่อ่านมา
ร่วมกับค่าเริ่มต้น `-1` สองค่า ถ้าอ่าน `c` อย่างน้อย 2 ค่าและทุกค่ามากกว่า `-1`
จึงมองได้ว่าเป็นการเก็บค่ามากที่สุดสองอันดับของข้อมูลที่อ่านมา

ถ้าเริ่มต้นด้วย `n >= a` ลูปจะไม่ทำงานและโปรแกรมแสดง `-1 -1` ทันที
โจทย์รับประกันว่าข้อมูลจะไม่ทำให้ลูปทำงานไม่สิ้นสุด

# กรณีที่ a น้อยกว่าหรือเท่ากับ b

โปรแกรมรับจำนวนเต็มเพิ่ม 4 บรรทัดตามลำดับ `c`, `d`, `e`, `f`
แล้วทำเงื่อนไขและการสลับค่าตามผังงานทีละขั้น ห้ามข้ามหรือสลับลำดับขั้น

1.  ถ้า `e < f` ให้สลับด้วย `e, f = f, e`
2.  ถ้า `d < e` ให้สลับด้วย `d, e = e, d`
3.  ถ้า `c < d` ให้สลับด้วย `c, d = d, c`
4.  ตรวจค่าปัจจุบันของ `d`, `e`, `f`
    -   ถ้า `d > e` และ `d > f` ใช้ `pass` ซึ่งหมายถึงไม่เปลี่ยนค่าใด
    -   ถ้า `d > e` แต่ `d <= f` ให้สลับ `d, f`
    -   ถ้า `d <= e` และ `e > f` ให้สลับ `d, e`
    -   นอกเหนือจากนั้นให้สลับ `d, f`

เครื่องหมายเปรียบเทียบเป็นแบบเข้มงวด เช่น เมื่อ `d == e` เงื่อนไข
`d > e` เป็นเท็จและโปรแกรมจะไปตรวจเส้นทางถัดไป

> [!WARNING]
> ชุดเงื่อนไขนี้ไม่ได้รับประกันว่าจะเรียงค่าทั้ง 4 ตัวจากมากไปน้อย
> หน้าที่ของโปรแกรมคือทำตามผังงานตามลำดับ ไม่ควรแทนที่ด้วย `sorted()`

หลังจบเส้นทางใดก็ตาม คำสั่ง `print(d, e)` แสดง `d` ก่อน `e`
ในบรรทัดเดียวโดยมีช่องว่างคั่น

# ตัวอย่างการทำงาน

ตัวอย่างแรกเป็นกรณี `a > b` โดยเริ่มจาก `n = 2`, `a = 8`, `b = 3`
และรับ `c` เป็น 3 กับ 4

| รอบ | `c` | `d` | `e` | `n` หลังบวก `b` |
|:--:|:--:|:--:|:--:|:--:|
| เริ่มต้น | - | `-1` | `-1` | `2` |
| 1 | `3` | `3` | `-1` | `5` |
| 2 | `4` | `4` | `3` | `8` |

เมื่อ `n` เป็น 8 เงื่อนไข `n < a` เป็นเท็จ จึงแสดง `4 3`

อีกตัวอย่างหนึ่งเริ่มด้วย `10 2 8` จึงเป็นกรณี `a <= b` และรับ
`c = 10`, `d = 2`, `e = 3`, `f = 4`

1.  `e < f` เป็นจริง จึงได้ `e = 4`, `f = 3`
2.  `d < e` เป็นจริง จึงได้ `d = 4`, `e = 2`
3.  `c < d` เป็นเท็จ จึงไม่สลับ
4.  ทั้ง `d > e` และ `d > f` เป็นจริง จึงทำ `pass`

สุดท้ายโปรแกรมแสดง `4 2`

# Solution

```python
# --------------------------------------------------
# File Name : 2566_2_Q1_02.py
# Problem   : Flowchart
# Author    : Worralop Srichainont
# Date      : 2025-07-13
# --------------------------------------------------

n, a, b = [int(e) for e in input().split()]

if a > b:
    d, e = -1, -1
    while n < a:
        c = int(input())
        if c > d:
            d, e = c, d
        elif c > e:
            e = c
        n = n + b
else:
    c = int(input())
    d = int(input())
    e = int(input())
    f = int(input())
    if e < f:
        e, f = f, e
    if d < e:
        d, e = e, d
    if c < d:
        c, d = d, c
    if d > e:
        if d > f:
            pass
        else:
            d, f = f, d
    elif e > f:
        d, e = e, d
    else:
        d, f = f, d
print(d, e)
```
