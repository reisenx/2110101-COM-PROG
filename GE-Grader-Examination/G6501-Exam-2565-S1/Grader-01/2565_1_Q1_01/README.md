## การอ่านผังงาน

โจทย์ข้อนี้ให้เราเปลี่ยนขั้นตอนในผังงานให้เป็นโปรแกรม เริ่มจากรับจำนวนเต็ม
`4` จำนวนบนบรรทัดเดียวกัน แล้วเก็บตามลำดับในตัวแปร `a`, `b`, `c` และ `d`

```python
a, b, c, d = [int(e) for e in input().split()]
```

ผังงานใช้รูปสี่เหลี่ยมข้าวหลามตัดแทนการตรวจสอบเงื่อนไข เมื่อคำตอบเป็นจริง
ให้ไปตามลูกศร `Y` และเมื่อเป็นเท็จให้ไปตามลูกศร `N` เงื่อนไขแต่ละจุด
เขียนเป็นภาษา Python ได้ดังนี้

| เงื่อนไขในผังงาน | เงื่อนไขใน Python | ความหมาย |
|---|---|---|
| $a > b$ | `a > b` | `a` มากกว่า `b` หรือไม่ |
| $d \ge a$ | `d >= a` | `d` ยังมากกว่าหรือเท่ากับ `a` หรือไม่ |
| $c > d$ | `c > d` | `c` มากกว่า `d` หรือไม่ |
| $c$ เป็นเลขคู่ | `c % 2 == 0` | เศษจากการหาร `c` ด้วย `2` เท่ากับ `0` หรือไม่ |
| $d > c$ | `d > c` | `d` มากกว่า `c` หรือไม่ |

เงื่อนไขแรกแบ่งการทำงานออกเป็นสองเส้นทางใหญ่ คือกรณี `a > b`
และกรณี `a <= b`

---

## เส้นทางด้านซ้ายของผังงาน

เมื่อ `a > b` โปรแกรมจะสลับค่าของ `a` กับ `b` ก่อน

```python
a, b = b, a
```

จากนั้นทำงานซ้ำตราบใดที่ `d >= a` โดยเลือกเปลี่ยนค่าทีละหนึ่งหน่วย

-   ถ้า `c > d` ให้เพิ่ม `a` ขึ้น `1`
-   ถ้า `c <= d` ให้ลด `d` ลง `1`

สูตรในผังงานและคำสั่ง Python ที่ตรงกันคือ

$$
a \leftarrow a+1
$$

```python
a += 1
```

และ

$$
d \leftarrow d-1
$$

```python
d -= 1
```

ในแต่ละรอบ `a` จะเพิ่มขึ้นหรือ `d` จะลดลง จึงทำให้ทั้งสองค่าเข้าใกล้กัน
และวงวนจะหยุดเมื่อเงื่อนไข `d >= a` เป็นเท็จ หรือก็คือเมื่อ `d < a`

> [!NOTE]
>
> เครื่องหมายเท่ากับมีผลต่อเส้นทางของผังงาน ถ้า `d == a` จะยังเข้าวงวน
> เพราะใช้ `>=` แต่ถ้า `c == d` จะไปลด `d` เพราะเงื่อนไข `c > d`
> เป็นเท็จ

---

## เส้นทางด้านขวาของผังงาน

เส้นทางนี้ทำงานเมื่อ `a <= b` โดยพิจารณาก่อนว่า `c` เป็นเลขคู่หรือเลขคี่

### เมื่อ c เป็นเลขคู่

ถ้า `c % 2 == 0` ให้เปลี่ยนเฉพาะ `d` ตามสูตร

$$
d \leftarrow d+a
$$

ซึ่งตรงกับคำสั่ง `d = d + a` แล้วจึงไปแสดงผลทันที

### เมื่อ c เป็นเลขคี่

ถ้า `c` เป็นเลขคี่ โปรแกรมจะตรวจสอบ `d > c` อีกครั้ง

-   ถ้า `d > c` ให้คำนวณ $c \leftarrow c+d$ ด้วย `c = c + d`
-   ถ้า `d <= c` ให้คำนวณ $b \leftarrow b+a$ ด้วย `b = b + a`

หลังจากจบเงื่อนไขย่อย ไม่ว่าจะผ่านทางใด โปรแกรมจะคำนวณ

$$
a \leftarrow b+c
$$

ด้วยคำสั่ง `a = b + c` เป็นขั้นตอนสุดท้ายของเส้นทางนี้

> [!NOTE]
>
> ถ้า `a == b` จะเข้ามาทำงานในเส้นทางด้านขวา และถ้า `d == c`
> จะเลือกคำสั่ง `b = b + a` เพราะทั้ง `a > b` และ `d > c`
> ใช้เครื่องหมาย `>` ซึ่งไม่รวมกรณีที่ค่าเท่ากัน

---

## ตัวอย่างการทำงาน

**ตัวอย่างที่ 1:** `1 2 3 4`

เนื่องจาก `1 > 2` เป็นเท็จ จึงไปทางขวา ค่า `c` คือ `3` ซึ่งเป็นเลขคี่
และ `d > c` เพราะ `4 > 3` ดังนั้น

1. คำนวณ `c = c + d` ได้ `c = 7`
2. คำนวณ `a = b + c` ได้ `a = 2 + 7 = 9`

ค่าท้ายสุดจึงเป็น `a = 9`, `b = 2`, `c = 7` และ `d = 4`

**ตัวอย่างที่ 2:** `4 3 5 6`

เนื่องจาก `4 > 3` เป็นจริง โปรแกรมจึงสลับ `a` กับ `b` ก่อน
แล้วติดตามค่าในวงวนได้ดังนี้

| ขั้นตอน | `a` | `b` | `c` | `d` | การทำงาน |
|---|---:|---:|---:|---:|---|
| หลังสลับค่า | 3 | 4 | 5 | 6 | เริ่มตรวจ `d >= a` |
| รอบที่ 1 | 3 | 4 | 5 | 5 | `c > d` เป็นเท็จ จึงลด `d` |
| รอบที่ 2 | 3 | 4 | 5 | 4 | `c > d` เป็นเท็จ จึงลด `d` |
| รอบที่ 3 | 4 | 4 | 5 | 4 | `c > d` เป็นจริง จึงเพิ่ม `a` |
| รอบที่ 4 | 5 | 4 | 5 | 4 | `c > d` เป็นจริง จึงเพิ่ม `a` |

เมื่อได้ `d = 4` และ `a = 5` เงื่อนไข `d >= a` เป็นเท็จ วงวนจึงหยุด
และได้คำตอบ `5 4 5 4`

## การแสดงผล

หลังจากทำงานครบตามเส้นทางแล้ว โปรแกรมแสดงค่าของ `a`, `b`, `c` และ `d`
ตามลำดับด้วย

```python
print(a, b, c, d)
```

เมื่อส่งค่าหลายค่าให้ `print()` โปรแกรมจะคั่นแต่ละค่าด้วยช่องว่างหนึ่งช่อง
โดยอัตโนมัติ โจทย์นี้ใช้จำนวนเต็มทั้งหมด จึงไม่มีการปัดเศษหรือกำหนดจำนวน
ตำแหน่งทศนิยม

# Solution

```python
# --------------------------------------------------
# File Name : 2565_1_Q1_01.py
# Problem   : Flowchart
# Author    : Worralop Srichainont
# Date      : 2025-07-11
# --------------------------------------------------

a, b, c, d = [int(e) for e in input().split()]
if a > b:
    a, b = b, a
    while d >= a:
        if c > d:
            a += 1
        else:
            d -= 1
else:
    if c % 2 == 0:
        d = d + a
    else:
        if d > c:
            c = c + d
        else:
            b = b + a
        a = b + c
print(a, b, c, d)
```
