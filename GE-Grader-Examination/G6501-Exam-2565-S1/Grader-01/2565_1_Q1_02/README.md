## ภาพรวมของ Multiplexer

Multiplexer เป็นอุปกรณ์ที่เลือกข้อมูลหนึ่งทางจากข้อมูลหลายทางตามค่าตัวเลือก
แนวคิดเดียวกันนี้ถูกนำมาใช้ในโจทย์ โดยให้ฟังก์ชัน `main()` อ่านตัวเลือก
`s1` และ `s2` แล้วเลือกเรียกหนึ่งในฟังก์ชัน `f1`, `f2`, `f3` หรือ `f4`

โจทย์รับประกันว่าค่า `a`, `b` และ `c`

-   เป็นจำนวนเต็มตั้งแต่ `-1000` ถึง `1000`
-   มีอย่างน้อยหนึ่งค่าที่มากกว่า `0`
-   มีอย่างน้อยหนึ่งค่าที่น้อยกว่า `0`

เงื่อนไขนี้ทำให้ `f1` หาจำนวนบวกได้เสมอ และ `f2` หาจำนวนลบได้เสมอ
จึงไม่จำเป็นต้องตรวจสอบกรณีที่ลิสต์ว่างเพิ่มเติม

## การคัดเลือกจำนวนบวกและจำนวนลบ

### ฟังก์ชัน f1

ฟังก์ชัน `f1` ต้องคืนจำนวนบวกที่มีค่าน้อยที่สุดจาก `a`, `b` และ `c`
ถ้าให้ $P$ เป็นกลุ่มของค่าที่มากกว่า `0` จะเขียนได้ว่า

$$
P = \{x \in \{a,b,c\} \mid x>0\}, \qquad f1(a,b,c)=\min(P)
$$

ในภาษา Python โปรแกรมสร้างลิสต์ `positives` แล้วเพิ่มเฉพาะค่าที่ผ่าน
เงื่อนไข `> 0` ก่อนใช้ `min(positives)`

```python
positives = []
if a > 0:
    positives += [a]
```

โปรแกรมตรวจ `b` และ `c` ด้วยวิธีเดียวกัน ค่า `0` ไม่ถูกนำมาพิจารณา
เพราะไม่ใช่จำนวนบวก

### ฟังก์ชัน f2

ฟังก์ชัน `f2` ทำงานคล้ายกัน แต่เก็บเฉพาะค่าที่น้อยกว่า `0` ไว้ใน
`negatives` ถ้าให้ $N$ เป็นกลุ่มของจำนวนลบ จะได้

$$
N = \{x \in \{a,b,c\} \mid x<0\}, \qquad f2(a,b,c)=\max(N)
$$

คำว่า “จำนวนลบที่มีค่ามากที่สุด” หมายถึงจำนวนที่อยู่ใกล้ `0` มากที่สุด
ตัวอย่างเช่น `max(-20, -18)` มีค่าเป็น `-18` ไม่ใช่ `-20`

```python
negatives = []
if a < 0:
    negatives += [a]
```

หลังจากตรวจครบทั้งสามค่า โปรแกรมคืนผลด้วย `max(negatives)` ส่วนค่า `0`
ไม่ถูกเก็บเพราะไม่ใช่จำนวนลบ

## การหาตัวเลขหลักแรกและหลักสุดท้าย

ทั้ง `f3` และ `f4` เริ่มจากหาค่าสัมบูรณ์ของผลบวก

$$
s = |a+b+c|
$$

ซึ่งตรงกับคำสั่ง Python

```python
sums = abs(a + b + c)
```

การใช้ `abs()` ทำให้ไม่มีเครื่องหมายลบอยู่หน้าตัวเลข จากนั้นโปรแกรมแปลง
`sums` เป็นข้อความเพื่อเลือกตัวอักษรแต่ละตำแหน่ง

-   `str(sums)[0]` เลือกตัวเลขหลักแรกหรือหลักซ้ายสุดสำหรับ `f3`
-   `str(sums)[-1]` เลือกตัวเลขหลักสุดท้ายหรือหลักขวาสุดสำหรับ `f4`

ตัวอย่างเช่น เมื่อ `a + b + c` เท่ากับ `-12` จะได้ `abs(-12) == 12`
และ `str(12) == "12"` ดังนั้นหลักแรกคือ `"1"` และหลักสุดท้ายคือ `"2"`
ถ้าผลบวกเป็น `0` ทั้งสองฟังก์ชันจะคืน `"0"`

> [!NOTE]
>
> โจทย์ระบุให้ `f3` และ `f4` คืนจำนวนเต็ม แต่โค้ดเฉลยจริงใช้
> `str(sums)[0]` และ `str(sums)[-1]` จึงคืนข้อความชนิด `str` ที่มีความยาว
> หนึ่งตัวอักษร เช่น `"1"` ไม่ใช่จำนวนเต็ม `1` เมื่อใช้ `print()`
> ผลที่เห็นบนหน้าจอจะเหมือนกันเพราะเครื่องหมายคำพูดไม่ถูกแสดงออกมา

## การเลือกฟังก์ชันด้วยตัวเลือก

ฟังก์ชัน `main()` รับจำนวนเต็ม `5` ค่าในลำดับ `s1 s2 a b c`
แล้วเปรียบเทียบลิสต์ `[s1, s2]` เพื่อเลือกผลลัพธ์

| `s1` | `s2` | ฟังก์ชันที่เรียก | ผลลัพธ์ |
|---:|---:|---|---|
| 0 | 0 | `f1(a, b, c)` | จำนวนบวกที่น้อยที่สุด |
| 0 | 1 | `f2(a, b, c)` | จำนวนลบที่มากที่สุด |
| 1 | 0 | `f3(a, b, c)` | หลักแรกของค่าสัมบูรณ์ของผลบวก |
| 1 | 1 | `f4(a, b, c)` | หลักสุดท้ายของค่าสัมบูรณ์ของผลบวก |

ถ้า `s1` หรือ `s2` เป็นค่าอื่น คู่ตัวเลือกจะไม่ตรงกับทั้งสี่กรณี
โปรแกรมจึงแสดงคำว่า `Error`

## การรับคำสั่งจากระบบตรวจคำตอบ

บรรทัดสุดท้ายของโปรแกรมคือ

```python
exec(input().strip())
```

ระบบตรวจคำตอบใช้บรรทัดนี้เพื่อส่งคำสั่ง Python มาเป็นข้อมูลเข้าบรรทัดแรก
เช่น `print(f1(2, -18, 4))` สำหรับทดสอบฟังก์ชันโดยตรง หรือ `main()`
สำหรับทดสอบการเลือกฟังก์ชัน

ถ้าบรรทัดแรกเป็น `main()` ฟังก์ชัน `main` จะเรียก `input()` อีกครั้ง
ข้อมูลเข้าจึงมีสองบรรทัดตามลำดับดังนี้

```text
main()
1 1 -2 -18 4
```

บรรทัดแรกเรียก `main()` ส่วนบรรทัดที่สองเป็นค่า `s1 s2 a b c`

> [!WARNING]
>
> `exec()` สามารถสั่งให้ Python ประมวลผลข้อความใด ๆ เป็นโค้ดได้
> ในโจทย์นี้ใช้เพื่อรองรับรูปแบบของระบบตรวจคำตอบเท่านั้น ห้ามนำวิธีนี้ไปใช้
> กับข้อมูลจากผู้ใช้หรือแหล่งที่ไม่น่าเชื่อถือ เพราะอาจทำให้โค้ดอันตราย
> ถูกเรียกทำงานได้

## ตัวอย่างการทำงาน

**ตัวอย่างที่ 1:** เรียก `f1` โดยตรง

```text
print(f1(2, -18, 4))
```

โปรแกรมเก็บจำนวนบวกเป็น `[2, 4]` แล้วคืน `min([2, 4])` ซึ่งเท่ากับ `2`

**ตัวอย่างที่ 2:** เรียก `f2` โดยตรง

```text
print(f2(-20, -18, 4))
```

โปรแกรมเก็บจำนวนลบเป็น `[-20, -18]` แล้วคืน `max([-20, -18])`
จึงแสดง `-18`

**ตัวอย่างที่ 3:** เรียก `main`

```text
main()
1 1 -2 -18 4
```

คู่ตัวเลือก `[1, 1]` ทำให้เรียก `f4(-2, -18, 4)` ผลบวกเท่ากับ `-16`
ค่าสัมบูรณ์คือ `16` และหลักสุดท้ายคือ `"6"` จึงแสดงผล `6`

โปรแกรมข้อนี้ใช้จำนวนเต็มและการเลือกหลักของตัวเลขเท่านั้น จึงไม่มีการปัดเศษ
หรือกำหนดตำแหน่งทศนิยม และ `print()` จะแสดงผลหนึ่งบรรทัดต่อหนึ่งคำสั่งทดสอบ

# Solution

```python
# --------------------------------------------------
# File Name : 2565_1_Q1_02.py
# Problem   : Multiplexer
# Author    : Worralop Srichainont
# Date      : 2025-07-11
# --------------------------------------------------


# Returns the minimum positive integer from a, b, c
def f1(a, b, c):
    positives = []
    if a > 0:
        positives += [a]
    if b > 0:
        positives += [b]
    if c > 0:
        positives += [c]
    return min(positives)


# Returns the maximum negative integer from a, b, c
def f2(a, b, c):
    negatives = []
    if a < 0:
        negatives += [a]
    if b < 0:
        negatives += [b]
    if c < 0:
        negatives += [c]
    return max(negatives)


# Returns the first digit of the absolute sum of a, b, c
def f3(a, b, c):
    sums = abs(a + b + c)
    return str(sums)[0]


# Returns the last digit of the absolute sum of a, b, c
def f4(a, b, c):
    sums = abs(a + b + c)
    return str(sums)[-1]


# Main function to read input and call the appropriate function based on s1 and s2
def main():
    s1, s2, a, b, c = [int(e) for e in input().split()]
    if [s1, s2] == [0, 0]:
        print(f1(a, b, c))
    elif [s1, s2] == [0, 1]:
        print(f2(a, b, c))
    elif [s1, s2] == [1, 0]:
        print(f3(a, b, c))
    elif [s1, s2] == [1, 1]:
        print(f4(a, b, c))
    else:
        print("Error")


# Execute a input string as code
exec(input().strip())
```
