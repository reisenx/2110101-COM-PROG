## แนวคิดของการคำนวณนิพจน์

ข้อมูลเข้าเป็นข้อความของจำนวนเต็มที่เชื่อมด้วยเครื่องหมาย `+` หรือ `-`
โดยไม่มีช่องว่าง เช่น `1+20-300+4000` เราสามารถมองจำนวนทุกตัว
พร้อมเครื่องหมายด้านหน้าเป็น “จำนวนที่มีเครื่องหมาย” ได้ดังนี้

```text
1+20-300+4000  →  1, +20, -300, +4000
```

เมื่อกำหนดให้จำนวนที่มีเครื่องหมายเหล่านี้เป็น $t_1,t_2,\ldots,t_n$
ค่าของนิพจน์คือผลรวม

$$
\text{result} = t_1+t_2+\cdots+t_n = \sum_{i=1}^{n} t_i
$$

ในภาษา Python สูตรนี้ตรงกับ `sum(numbers)` เมื่อ `numbers` เป็นลิสต์
ที่เก็บจำนวนแต่ละตัวพร้อมเครื่องหมายเรียบร้อยแล้ว วิธีนี้จึงคำนวณทั้งการบวก
และการลบได้โดยไม่ต้องใช้ `eval()`

## การสร้างข้อความที่แบ่งแต่ละจำนวน

ปัญหาคือข้อมูลเข้าไม่มีช่องว่างให้ `split()` แบ่งจำนวน โปรแกรมจึงวนดู
ข้อความทีละตัวอักษรด้วย `for char in input().strip()` แล้วสร้างข้อความใหม่
ไว้ใน `equation`

```python
equation = ""
for char in input().strip():
    if char in "+-":
        equation += " "
    equation += char
```

คำสั่ง `char in "+-"` เป็นจริงเมื่อ `char` เป็น `+` หรือ `-` โปรแกรมจะเติม
ช่องว่าง **ก่อน** เครื่องหมาย แล้วจึงเติมตัวเครื่องหมายตามหลัง ทำให้เครื่องหมาย
ยังติดอยู่กับจำนวนตัวถัดไป

ตัวอย่างการเปลี่ยนข้อความเป็นดังนี้

```text
1+20-300+4000  →  1 +20 -300 +4000
```

โจทย์อนุญาตให้จำนวนตัวแรกเป็นจำนวนลบ เช่น `-1000+25` เมื่อพบ `-`
ที่ตำแหน่งแรก โปรแกรมจะสร้างข้อความ ` -1000 +25` ซึ่งมีช่องว่างนำหน้า
แต่ไม่มีปัญหา เพราะ `split()` จะละเว้นช่องว่างส่วนเกินที่หัวข้อความ

---

## การแปลงข้อความและหาผลรวม

หลังจากมีช่องว่างคั่นแต่ละจำนวนแล้ว `equation.split()` จะให้ข้อความย่อย
ที่มีเครื่องหมายติดอยู่ เช่น

```python
"1 +20 -300 +4000".split()
# ได้ ["1", "+20", "-300", "+4000"]
```

ฟังก์ชัน `int()` แปลงข้อความที่มีเครื่องหมาย `+` หรือ `-` นำหน้าได้โดยตรง
เช่น `int("+20") == 20` และ `int("-300") == -300` โปรแกรมจึงวนแปลง
ทุกส่วนแล้วสะสมไว้ในลิสต์ `numbers`

```python
numbers = []
for num in equation.split():
    numbers += [int(num)]
```

สุดท้าย `sum(numbers)` หาผลรวมของจำนวนที่มีเครื่องหมายทั้งหมด และ `print()`
แสดงผลเป็นจำนวนเต็มหนึ่งบรรทัด

## ตัวอย่างการทำงาน

**ตัวอย่างที่ 1:** `9999-999+99-9`

| ขั้นตอน | ค่า |
|---|---|
| เติมช่องว่างก่อนเครื่องหมาย | `9999 -999 +99 -9` |
| ผลจาก `split()` | `"9999"`, `"-999"`, `"+99"`, `"-9"` |
| ค่าใน `numbers` | `9999`, `-999`, `99`, `-9` |
| ผลจาก `sum(numbers)` | `9090` |

โปรแกรมจึงแสดงผล `9090`

**ตัวอย่างที่ 2:** `-1-2-3-4-5`

จำนวนตัวแรกเป็นลบได้ตามข้อกำหนด เมื่อเติมช่องว่างและแปลงเป็นจำนวนเต็ม
จะได้ลิสต์ `[-1, -2, -3, -4, -5]` ผลรวมจึงเท่ากับ `-15`

**ตัวอย่างที่ 3:** `20`

ข้อมูลเข้าไม่มีเครื่องหมายคั่น โปรแกรมจึงไม่เพิ่มช่องว่าง `split()` ได้เพียง
`"20"` และ `sum([20])` เท่ากับ `20` แสดงให้เห็นว่านิพจน์ที่มีจำนวนเดียว
ก็ใช้ขั้นตอนเดียวกันได้

## ขอบเขตของข้อมูลเข้า

ระบบตรวจคำตอบจะส่งเฉพาะนิพจน์ที่เป็นไปตามรูปแบบของโจทย์ จึงไม่ต้องรองรับ
เครื่องหมายอื่น ทศนิยม วงเล็บ ข้อความ ช่องว่าง เครื่องหมาย `+` ที่หัวนิพจน์
หรือเครื่องหมายที่ไม่มีจำนวนตามหลัง

โจทย์ยังห้ามเพิ่ม `import` และห้ามใช้ `eval()` หรือ `exec()` โปรแกรมนี้จึง
แยกจำนวนด้วยการวนดูข้อความและใช้ `int()` เท่านั้น การคำนวณทั้งหมดเป็น
จำนวนเต็มแบบตรงตัว ไม่มีการปัดเศษหรือกำหนดจำนวนตำแหน่งทศนิยม

# Solution

```python
# --------------------------------------------------
# File Name : 2565_1_Q1_03.py
# Problem   : Simple Expression Calculator
# Author    : Worralop Srichainont
# Date      : 2025-07-11
# --------------------------------------------------

# Input equation and add spaces before operators
equation = ""
for char in input().strip():
    if char in "+-":
        equation += " "
    equation += char

# Split the equation string into numbers
numbers = []
for num in equation.split():
    numbers += [int(num)]

# Calculate the sum of the numbers and print the result
print(sum(numbers))
```
