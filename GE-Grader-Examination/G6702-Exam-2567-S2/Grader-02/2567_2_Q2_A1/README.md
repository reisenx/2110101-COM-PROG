## ภาพรวมการทำงาน

โจทย์ให้จำนวนเต็ม `a`, `b`, `c`, `d` และ `e` มาในบรรทัดเดียว
จากนั้นเลือกทำงานหนึ่งในสองเส้นทางตามค่า `e`

-   ถ้า `e == 1` โปรแกรมจะจัดลำดับค่าเป็นคู่ ๆ แล้วเลือกค่าหนึ่งมาแสดงผล
-   ถ้า `e != 1` โปรแกรมจะเปรียบเทียบค่าที่อยู่ติดกันซ้ำ ๆ ขณะที่ `e < 3`

การสลับค่าใช้รูปแบบของ Python ดังนี้

```python
a, b = b, a
```

คำสั่งนี้สลับค่า `a` กับ `b` ได้โดยไม่ต้องสร้างตัวแปรพัก

## เส้นทางเมื่อ e เท่ากับ 1

โปรแกรมเริ่มจากจัดแต่ละคู่ให้อยู่ในลำดับจากมากไปน้อย

1. ถ้า `a < b` ให้สลับค่า จึงได้ `a >= b`
2. ถ้า `c < d` ให้สลับค่า จึงได้ `c >= d`
3. เปรียบเทียบ `a` กับ `c` แล้วเดินตามเงื่อนไขในผังงาน

หลังจากจัดสองคู่แล้ว การเลือกค่าที่แสดงผลทำงานดังนี้

-   ถ้า `a >= c` โปรแกรมเปรียบเทียบ `b` กับ `c`
    -   ถ้า `b >= c` แสดง `b`
    -   มิฉะนั้นแสดง `c`
-   ถ้า `a < c` โปรแกรมตรวจ `a >= b`
    -   เงื่อนไขนี้เป็นจริงเสมอหลังจากจัดคู่แรกแล้ว จึงแสดง `a`
    -   กิ่งที่แสดง `d` ยังคงอยู่ตามผังงาน แต่จะเดินไปไม่ถึงด้วยลำดับคำสั่งชุดนี้

> [!NOTE]
>
> ผังงานใน PDF เขียนเงื่อนไขของกิ่งนี้เป็น `a >= d` แต่โค้ดคำตอบมาตรฐาน
> ใช้ `a >= b` README นี้อธิบายการทำงานของโค้ดตามที่มีอยู่จริง จึงทำให้กิ่ง
> ที่แสดง `d` เดินไปไม่ถึง และยังคงส่วน Solution ไว้โดยไม่แก้ไข

กรณีค่าคู่ใดเท่ากัน เงื่อนไข `<` เป็นเท็จ จึงไม่สลับคู่นั้น
ส่วนเงื่อนไข `>=` นับกรณีเท่ากันเป็นจริง

## เส้นทางเมื่อ e ไม่เท่ากับ 1

ลูป `while e < 3` ทำหนึ่งรอบด้วยการเปรียบเทียบคู่ที่ติดกันจากซ้ายไปขวา

```python
if a >= b:
    a, b = b, a
if b >= c:
    b, c = c, b
if c >= d:
    c, d = d, c
```

เมื่อค่าด้านซ้ายมากกว่าหรือเท่ากับค่าด้านขวา โปรแกรมจะสลับคู่นั้น
ค่าที่มากจึงค่อย ๆ เคลื่อนไปทางขวา คล้ายหนึ่งรอบของการเรียงลำดับแบบ Bubble Sort
ท้ายรอบเพิ่ม `e` ขึ้น `1` และวนต่อจน `e` มีค่าเป็น `3`

-   ถ้าเริ่มด้วย `e = 0` จะทำทั้งหมด 3 รอบ ซึ่งเพียงพอสำหรับการเรียง 4 ค่า
    จากน้อยไปมาก แล้ว `b` คือค่าลำดับที่ 2
-   ถ้าเริ่มด้วย `e = 2` จะทำเพียง 1 รอบ จึงแสดงค่า `b` หลังจากเปรียบเทียบหนึ่งรอบ
-   ถ้าเริ่มด้วย `e >= 3` จะไม่เข้าลูป และแสดงค่า `b` เดิมทันที

การใช้ `>=` ทำให้ค่าที่เท่ากันถูกสลับด้วย แต่ค่าตัวเลขที่แสดงผลไม่เปลี่ยน

## ตัวอย่างการทำงาน

เมื่อรับข้อมูล `8 2 1 3 1` จะเดินในเส้นทาง `e == 1`

1. คู่ `(a, b)` เป็น `(8, 2)` จึงไม่ต้องสลับ
2. คู่ `(c, d)` เป็น `(1, 3)` จึงสลับเป็น `(3, 1)`
3. `a >= c` เป็นจริง แต่ `b >= c` เป็นเท็จ จึงแสดง `c`

ผลลัพธ์คือ `3`

---

# Solution

```python
# --------------------------------------------------
# File Name : 2567_2_Q2_A1.py
# Problem   : Flowchart
# Author    : Worralop Srichainont
# Date      : 2025-07-29
# --------------------------------------------------

a, b, c, d, e = [int(e) for e in input().split()]
if e == 1:
    if a < b:
        a, b = b, a
    if c < d:
        c, d = d, c
    if a >= c:
        if b >= c:
            print(b)
        else:
            print(c)
    else:
        if a >= b:
            print(a)
        else:
            print(d)
else:
    while e < 3:
        if a >= b:
            a, b = b, a
        if b >= c:
            b, c = c, b
        if c >= d:
            c, d = d, c
        e += 1
    print(b)
```
