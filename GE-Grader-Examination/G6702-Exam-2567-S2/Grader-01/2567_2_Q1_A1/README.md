## แยกการทำงานเป็นสามกรณี

โปรแกรมรับจำนวนเต็ม `a`, `b` และ `c` จากบรรทัดแรก แล้วเปรียบเทียบ `a` กับ
`b` เพื่อเลือกเส้นทางในผังงาน การเปรียบเทียบแบ่งได้ครบสามกรณีดังนี้

-   ถ้า `a < b` ให้นำ `c` ไปเขียนเป็นเลขฐานสอง
-   ถ้า `a > b` ให้รับ `d` เพิ่ม แล้วสลับและคำนวณค่าตามลำดับในผังงาน
-   ถ้า `a == b` ให้รับจำนวนจริง `e` และ `f` เพิ่ม แล้วคำนวณดอกเบี้ยทบต้น

เงื่อนไขทั้งสามไม่ทำงานพร้อมกัน เมื่อเข้าเส้นทางหนึ่งแล้ว โปรแกรมจะทำเฉพาะ
คำสั่งของเส้นทางนั้นก่อนแสดงผล

---

## กรณีแปลงจำนวนเป็นฐานสอง

เมื่อ `a < b` โปรแกรมเก็บค่าเดิมของ `c` ไว้ใน `d` ก่อน เพราะระหว่างแปลงฐาน
ค่า `c` จะถูกหารซ้ำจนเหลือ `0`

หลักการแปลงจำนวนเต็มฐานสิบเป็นฐานสองคือ หารด้วย `2` ซ้ำ ๆ แล้วเก็บเศษจาก
`c % 2` เศษที่พบทีหลังต้องอยู่หน้าหลักเดิม โปรแกรมจึงนำเศษไปเติมด้านหน้า
ข้อความ `x` และลดค่า `c` ด้วยการหารปัดเศษลง

```python
r = c % 2
x = str(r) + x
c = c // 2
```

โปรแกรมกำหนด `x = "B"` ตั้งแต่ต้น เพื่อให้ผลลัพธ์ลงท้ายด้วย `B` ตามรูปแบบ
ในโจทย์ ตัวอย่างเช่น เมื่อ `c = 8` จะได้เศษตามลำดับเป็น `0`, `0`, `0`, `1`
และข้อความค่อย ๆ เปลี่ยนเป็น `0B`, `00B`, `000B`, `1000B` ดังนั้นผลที่พิมพ์
คือ `8 1000B`

> [!NOTE]
>
> ค่า `c = 0` ต้องจัดการแยกต่างหาก เพราะเงื่อนไข `while c > 0` จะไม่ทำงาน
> เลย โปรแกรมจึงเติม `0` ข้างหน้า `B` โดยตรงและได้ `0B`

## กรณีสลับค่าและคำนวณ

เมื่อ `a > b` โปรแกรมรับจำนวนเต็ม `d` เพิ่มอีกหนึ่งบรรทัด แล้วทำงานจากบนลงล่าง
ตามผังงาน โดยค่าที่เปลี่ยนในขั้นก่อนหน้าจะถูกนำไปใช้ในขั้นถัดไปเสมอ

1. ถ้า `a > c` ให้สลับ `a` กับ `b` แล้วสลับ `a` กับ `c` จากนั้นเพิ่ม `a`
   อีก `1` และทำให้ `b` เป็น `2` เท่า
2. ใช้ค่าใหม่ที่ได้มาตรวจ `b > d` ถ้าเป็นจริงให้สลับ `b` กับ `d` เพิ่ม `a`
   อีก `2` และทำให้ `b` เป็น `3` เท่า
3. คำนวณค่าผลลัพธ์สองตัวสุดท้ายตามสูตร

   $$c = a + 2b$$

   $$d = c - 3a$$

   ซึ่งเขียนใน Python เป็น `c = a + (2 * b)` และ `d = c - (3 * a)`

ตัวอย่างเช่น อินพุต `8 4 6` และ `d = 10` ผ่านเงื่อนไขทั้งสองชุด หลังชุดแรก
ได้ `a = 7`, `b = 16` และหลังชุดที่สองได้ `a = 9`, `b = 30` จึงคำนวณ
`c = 69`, `d = 42` และพิมพ์ `9 30 69 42`

การเปรียบเทียบใช้เครื่องหมาย `>` ไม่ใช่ `>=` ดังนั้นถ้า `a == c` หรือ
`b == d` โปรแกรมจะข้ามชุดคำสั่งของเงื่อนไขนั้น

## กรณีคำนวณดอกเบี้ยทบต้น

เมื่อ `a == b` โปรแกรมรับ `e` เป็นเงินต้นและ `f` เป็นอัตราดอกเบี้ยร้อยละ
จากนั้นใช้สูตรดอกเบี้ยทบต้น โดยทบต้นปีละ `a` ครั้ง เป็นเวลา `c` ปี

$$\text{out} = e\left(1 + \frac{f}{100a}\right)^{ac}$$

สูตรเดียวกันใน Python คือ
`out = e * (1 + (f / (100 * a))) ** (a * c)` โดย `**` คือเครื่องหมาย
ยกกำลัง

สุดท้ายใช้ `round(out, 2)` ปัดผลลัพธ์ให้มีทศนิยมไม่เกิน `2` ตำแหน่ง
เนื่องจากค่าที่ส่งให้ `print()` ยังเป็นตัวเลข Python จึงไม่เติมเลขศูนย์ท้ายให้ครบ
สองตำแหน่งเสมอ เช่น ผลลัพธ์อาจแสดงเป็น `314.9` แทน `314.90`

# Solution

```python
# --------------------------------------------------
# File Name : 2567_2_Q1_A1.py
# Problem   : Flowchart
# Author    : Worralop Srichainont
# Date      : 2025-07-29
# --------------------------------------------------

a, b, c = [int(e) for e in input().split()]
if a < b:
    d = c
    x = "B"
    if c == 0:
        x = str(c) + x
    else:
        while c > 0:
            r = c % 2
            x = str(r) + x
            c = c // 2
    print(d, x)

else:
    if a > b:
        d = int(input())
        if a > c:
            a, b = b, a
            a, c = c, a
            a = a + 1
            b = b * 2

        if b > d:
            b, d = d, b
            a = a + 2
            b = b * 3

        c = a + (2 * b)
        d = c - (3 * a)
        print(a, b, c, d)
    else:
        e = float(input())
        f = float(input())
        out = e * (1 + (f / (100 * a))) ** (a * c)
        print(round(out, 2))
```
