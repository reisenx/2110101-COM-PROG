## ภาพรวมการตัดสินใจ

โจทย์รับจำนวนเต็ม `a`, `b`, `c`, `d` และ `e` จากบรรทัดเดียว แล้วเลือกทำงานตามผังงาน
โดยตรวจค่า `e` ก่อน

-   ถ้า `e >= 6` จะสร้างลำดับฟีโบนักชีและตรวจการลู่เข้าของอัตราส่วน
-   ถ้า `e < 6` และ `a >= b` จะบวกหรือหมุนค่าทั้งสี่ตามผลของ `c >= d`
-   ถ้า `e < 6` และ `a < b` จะมอง `a`, `b`, `c` เป็น ชั่วโมง นาที วินาที
    แล้วเพิ่มเวลาอีก `d` วินาที

สังเกตว่าเงื่อนไขใช้ `>=` ดังนั้นกรณี `e == 6`, `a == b` หรือ `c == d`
ต้องเข้าทางฝั่ง `Yes` ของเงื่อนไขนั้นด้วย

## เส้นทางที่ 1 ลำดับฟีโบนักชี

เมื่อ `e >= 6` โปรแกรมจะกำหนด `a = 1`, `b = 1` และสร้างลำดับ

$$1, 1, 2, 3, 5, 8, \ldots$$

ด้วยคำสั่ง

```python
a, b = b, a + b
```

การกำหนดค่าพร้อมกันทำให้ `a` ใหม่ได้รับ `b` เดิม และ `b` ใหม่ได้รับผลรวมของ
`a` กับ `b` เดิม จึงเลื่อนไปยังจำนวนฟีโบนักชีคู่ถัดไปได้ในแต่ละรอบ

อัตราส่วนของจำนวนที่ติดกันคือ $b/a$ ซึ่งใน Python เขียนเป็น `b / a`
โปรแกรมเก็บอัตราส่วนรอบก่อนหน้าไว้ใน `p` โดยเริ่มจาก `p = 10` เพื่อให้ลูป
ทำงานอย่างน้อยหนึ่งรอบ แล้วทำซ้ำตราบใดที่

$$\left|p-\frac{b}{a}\right| \ge 10^{-e}$$

ซึ่งตรงกับ `abs(p - (b / a)) >= 10 ** (-e)` ในโปรแกรม เมื่อผลต่างน้อยกว่า
$10^{-e}$ จึงหยุดและแสดง `b` กับ `c` โดย `c` คือจำนวนรอบที่เลื่อนไปในลำดับ
ตัวอย่างเช่น `e = 10` ได้ผลลัพธ์ `317811 26`

> [!NOTE]
>
> เครื่องหมาย `/` ให้ค่าชนิดทศนิยมแบบ floating point เมื่อ `e` มีค่ามากมาก
> อัตราส่วนสองรอบที่ใกล้กันอาจถูกเก็บเป็นค่าทศนิยมเดียวกัน ทำให้ผลต่างเป็น `0`
> และลูปหยุดได้ เช่นตัวอย่าง `e = 100` ในโจทย์ ทั้งนี้ค่า `a`, `b`, `c`
> เดิมจะถูกแทนที่ ส่วน `d` ไม่ถูกแก้ไขแต่ก็ไม่ถูกนำมาใช้ในเส้นทางนี้

## เส้นทางที่ 2 การบวกหรือหมุนค่า

เส้นทางนี้เกิดเมื่อ `e < 6` และ `a >= b` จากนั้นโปรแกรมตรวจ `c >= d`

-   ถ้า `c >= d` จะแสดงผลรวม `a + b + c + d` เพียงค่าเดียว
-   ถ้า `c < d` จะใช้ `d, a, b, c = a, b, c, d` เพื่อหมุนค่า

การกำหนดค่าพร้อมกันในกรณีหลังใช้ค่าทางขวามือชุดเดิมทั้งหมด จึงได้

```text
a ใหม่ = b เดิม
b ใหม่ = c เดิม
c ใหม่ = d เดิม
d ใหม่ = a เดิม
```

ดังนั้นอินพุต `4 1 5 3612 1` จะแสดง `1 5 3612 4` ส่วนอินพุต
`4 1 5000 3612 1` มี `c >= d` จึงแสดงผลรวมเป็น `8617`

## เส้นทางที่ 3 การคำนวณเวลา

เมื่อ `e < 6` และ `a < b` โปรแกรมตีความ `a:b:c` เป็นเวลาเริ่มต้น แล้วเพิ่ม
`d` วินาที ขั้นแรกแปลงทุกอย่างเป็นวินาที

$$T = 3600a + 60b + c + d$$

ตรงกับ

```python
e = (a * 3600) + (b * 60) + c + d
```

ตัวแปร `e` ไม่ต้องใช้ตัดสินใจอีกแล้ว จึงถูกนำมาเก็บเวลารวม จากนั้นใช้
`e % (24 * 60 * 60)` หรือ $T \bmod 86400$ เพื่อวนเวลากลับเข้าช่วงหนึ่งวัน
หากเวลาเกินเที่ยงคืน

โปรแกรมแยกเวลากลับเป็นสามส่วนดังนี้

-   ชั่วโมง: `a = e // 3600`
-   นาที: `b = (e - (a * 3600)) // 60`
-   วินาที: `c = e % 60`

ตัวอย่าง `1 2 40 20 1` เพิ่มเวลา `20` วินาทีจาก `1:02:40` จึงแสดง
`1 3 0` ส่วนการเพิ่ม `86400` วินาทีหรือหนึ่งวันเต็มจะได้เวลาเดิม

ผลลัพธ์ใช้ `print(a, b, c)` จึงคั่นแต่ละค่าด้วยช่องว่างและไม่เติมเลขศูนย์นำหน้า

# Solution

```python
# --------------------------------------------------
# File Name : 2567_2_Q3_A1.py
# Problem   : Flowchart
# Author    : Worralop Srichainont
# Date      : 2025-07-30
# --------------------------------------------------

a, b, c, d, e = [int(e) for e in input().split()]

if e >= 6:
    a = 1
    b = 1
    c = 0
    p = 10

    while abs(p - (b / a)) >= 10 ** (-e):
        p = b / a
        a, b = b, a + b
        c = c + 1

    print(b, c)

else:
    if a >= b:
        if c >= d:
            print(a + b + c + d)
        else:
            d, a, b, c = a, b, c, d
            print(a, b, c, d)
    else:
        e = (a * 3600) + (b * 60) + c + d
        e = e % (24 * 60 * 60)
        a = e // 3600
        b = (e - (a * 3600)) // 60
        c = e % 60

        print(a, b, c)
```
