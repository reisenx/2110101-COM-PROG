## การรับข้อมูลและเลือกเส้นทาง

โจทย์ข้อนี้ให้เราเขียนโปรแกรมตามผังงาน โดยรับจำนวนเต็ม `a`, `b` และ `c`
จากข้อมูล 1 บรรทัด

```python
a, b, c = [int(e) for e in input().split()]
```

คำสั่ง `input().split()` แยกข้อมูลตามช่องว่าง จากนั้น `int(e)`
เปลี่ยนข้อมูลแต่ละตัวให้เป็นจำนวนเต็ม แล้วจึงเก็บลงในตัวแปรตามลำดับ

หลังจากนั้น โปรแกรมใช้ `abs()` เพื่อหาค่าสัมบูรณ์ ซึ่งเป็นค่าที่ไม่ติดเครื่องหมาย
เช่น `abs(-10)` มีค่าเท่ากับ `10` แล้วเปรียบเทียบ `abs(a)` กับ `abs(b)`

-   ถ้า `abs(a) > abs(b)` โปรแกรมจะเข้าสู่เส้นทางการลบซ้ำ
-   ถ้า `abs(a) <= abs(b)` โปรแกรมจะเข้าสู่เส้นทางการบวกซ้ำ

ดังนั้น เมื่อค่าสัมบูรณ์เท่ากัน เช่น `a = 3` และ `b = -3`
โปรแกรมจะเลือกเส้นทางการบวกซ้ำ เพราะเงื่อนไขใช้เครื่องหมาย `>` ไม่ใช่ `>=`

## เส้นทางที่หนึ่ง การลบซ้ำ

เส้นทางนี้เริ่มจากกำหนดตัวแปรดังนี้

```python
r, s = 0, 0
ta = abs(a)
tb = abs(b)
```

ตัวแปร `ta` เก็บค่าที่เหลืออยู่ ส่วน `tb` เก็บ `abs(b)` ไว้เป็นค่าที่นำมาลบ
และ `s` นับจำนวนครั้งที่ลบ เมื่อ `ta > tb` โปรแกรมจะทำสองคำสั่งนี้ซ้ำ

```python
ta = ta - tb
s = s + 1
```

หลังลบไป `s` ครั้ง ความสัมพันธ์ของตัวแปรคือ
$ta = |a| - s|b|$ ซึ่งตรงกับ Python ว่า
`ta = abs(a) - s * abs(b)` เมื่อออกจากลูป โปรแกรมกำหนด `r = ta`

ตัวอย่าง `5 3 1` มีการเปลี่ยนแปลงดังนี้

1. เริ่มจาก `ta = 5`, `tb = 3` และ `s = 0`
2. เนื่องจาก `5 > 3` จึงได้ `ta = 5 - 3 = 2` และ `s = 1`
3. ค่า `2 > 3` เป็นเท็จ จึงหยุดลูปและกำหนด `r = 2`

จะได้ `s = 1` และ `r = 2`

> [!NOTE]
>
> เงื่อนไขในลูปคือ `ta > tb` แบบเคร่งครัด หาก `ta == tb` ลูปจะหยุดทันที
> เช่น `a = 6` และ `b = 3` จะได้ `s = 1`, `r = 3` ไม่ใช่ `s = 2`,
> `r = 0` ดังนั้น `s` และ `r` ในผังงานนี้ไม่ใช่ผลจาก `//` และ `%`
> ตามปกติของ Python

ก่อนแสดงผล โปรแกรมตรวจเครื่องหมายของ `a` และ `b`

-   ถ้าทั้งคู่เป็นบวก หรือทั้งคู่เป็นลบ จะคงเครื่องหมายของ `s` และ `r` ไว้
-   ถ้าเครื่องหมายต่างกัน จะเปลี่ยนเป็น `s = -s` และ `r = -r`

สำหรับ `5 3 1` ตัวแปร `a` และ `b` เป็นบวกทั้งคู่ จึงแสดงผล
`5 3 1 2` ส่วน `-10 3 2` ลูปคำนวณได้ `s = 3`, `r = 1`
แต่ `a` และ `b` มีเครื่องหมายต่างกัน จึงเปลี่ยนเป็น `s = -3`, `r = -1`
และแสดงผล `-10 3 -3 -1` สังเกตว่าเส้นทางนี้ไม่ได้ใช้ค่า `c`

> [!WARNING]
>
> ถ้า `a != 0` แต่ `b == 0` จะเข้าสู่เส้นทางนี้โดยมี `tb = 0`
> คำสั่ง `ta = ta - tb` จึงไม่ทำให้ `ta` ลดลง และลูปจะทำงานไม่สิ้นสุด
> ชุดข้อมูลทดสอบที่เป็นไปตามผังงานจึงต้องไม่ส่งกรณีนี้เข้ามา

## เส้นทางที่สอง การบวกซ้ำ

เมื่อ `abs(a) <= abs(b)` โปรแกรมจะคำนวณผลคูณของ `b` และ `c`
ด้วยการบวก `abs(b)` ซ้ำทั้งหมด `abs(c)` ครั้ง แทนการใช้เครื่องหมาย `*`
โดยตรง

ถ้า `b` และ `c` เป็นบวกทั้งคู่หรือเป็นลบทั้งคู่ ผลคูณต้องเป็นบวก
โปรแกรมจึงเริ่มจาก `p = 0` แล้วใช้ลูป `for` ทำคำสั่ง
`p = p + abs(b)` จำนวน `abs(c)` รอบ

```python
p = 0
tc = abs(c)
for _ in range(tc):
    p = p + abs(b)
```

เมื่อจบลูปจะได้ $p = |b| \times |c|$ และเพราะ `b`, `c`
มีเครื่องหมายเหมือนกัน ค่านี้จึงเท่ากับ $p = bc$ ตัวอย่าง `2 -5 -3`
ทำให้ `p` เพิ่มครั้งละ `5` จำนวน `3` ครั้ง จึงแสดงผล `-5 -3 15`

ถ้า `b` และ `c` ไม่ได้มีเครื่องหมายเดียวกัน โปรแกรมใช้ลูป `while`
โดยเริ่มจาก `p = abs(b)` แล้วบวก `abs(b)` อีก `abs(c)` ครั้ง
เมื่อจบลูปจึงมีค่าเกินมา `abs(b)` หนึ่งครั้ง โปรแกรมนำส่วนเกินออกและใส่
เครื่องหมายลบด้วย

```python
p = -(p - abs(b))
```

ผลลัพธ์จึงเป็น $p = -|b| \times |c| = bc$ เมื่อ `b` และ `c`
มีเครื่องหมายต่างกัน ตัวอย่าง `3 12 -4` บวก `12` ซ้ำ `4` ครั้ง
แล้วเปลี่ยนเครื่องหมาย จึงแสดงผล `12 -4 -48`

กรณีที่ `b` หรือ `c` เป็น `0` จะเข้ามาทางลูป `while` เช่นกัน
และคำสั่งปรับค่าท้ายสุดจะทำให้ `p = 0` ซึ่งยังตรงกับผลคูณ `b * c`

## การแสดงผล

คำสั่ง `print()` แสดงค่าแต่ละตัวคั่นด้วยช่องว่าง 1 ช่อง โดยลำดับผลลัพธ์
ขึ้นอยู่กับเส้นทางที่เลือก

-   เส้นทางการลบซ้ำแสดง `a b s r` ด้วย `print(a, b, s, r)`
-   เส้นทางการบวกซ้ำแสดง `b c p` ด้วย `print(b, c, p)`

จึงต้องตรวจเงื่อนไขแรกให้ถูกต้องก่อน เพราะผลลัพธ์ของทั้งสองเส้นทาง
มีทั้งจำนวนค่าและลำดับค่าที่ต่างกัน

# Solution

```python
# --------------------------------------------------
# File Name : 2565_3_Q1_01.py
# Problem   : Flowchart
# Author    : Worralop Srichainont
# Date      : 2025-07-12
# --------------------------------------------------

a, b, c = [int(e) for e in input().split()]

if abs(a) > abs(b):
    r, s = 0, 0
    ta = abs(a)
    tb = abs(b)
    while ta > tb:
        ta = ta - tb
        s = s + 1
    r = ta
    if (a > 0 and b > 0) or (a < 0 and b < 0):
        pass
    else:
        s = -s
        r = -r
    print(a, b, s, r)
else:
    if (b > 0 and c > 0) or (b < 0 and c < 0):
        p = 0
        tc = abs(c)
        for _ in range(tc):
            p = p + abs(b)
    else:
        p = abs(b)
        tc = abs(c)
        while tc > 0:
            p = p + abs(b)
            tc = tc - 1
        p = -(p - abs(b))
    print(b, c, p)
```
