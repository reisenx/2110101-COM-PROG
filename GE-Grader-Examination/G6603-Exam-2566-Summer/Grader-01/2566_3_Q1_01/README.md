## ทำความเข้าใจช่วงตัวอักษรซ้ำ

โจทย์ต้องการหา **ตัวอักษรที่ซ้ำติดกันเป็นช่วงยาวที่สุด** ไม่ใช่ตัวอักษรที่
ปรากฏรวมกันบ่อยที่สุดทั้งข้อความ เช่น ในข้อความ `ABABAAA` ตัวอักษร `A`
ปรากฏทั้งหมด 5 ครั้ง แต่ช่วงที่ยาวที่สุดคือ `AAA` จึงมีความยาวเท่ากับ `3`

เราสามารถอ่านตัวอักษรจากซ้ายไปขวาเพียงรอบเดียว ระหว่างทางให้เก็บข้อมูล 2
ส่วน ได้แก่ ช่วงที่กำลังอ่านอยู่ และช่วงที่ยาวที่สุดที่พบแล้ว

## ตัวแปรสำหรับจดจำข้อมูล

โปรแกรมกำหนดค่าเริ่มต้นจากตัวอักษรตัวแรก เพราะข้อความตามเงื่อนไขของโจทย์มี
ตัวอักษรอย่างน้อย 1 ตัว

| ตัวแปร | ความหมาย | ค่าเริ่มต้น |
|---|---|---|
| `char` | ตัวอักษรของช่วงปัจจุบัน | `text[0]` |
| `count` | ความยาวของช่วงปัจจุบัน | `1` |
| `max_char` | ตัวอักษรของช่วงที่ยาวที่สุด | `text[0]` |
| `max_count` | ความยาวของช่วงที่ยาวที่สุด | `1` |

ตัวแปร `char` และ `count` จึงเปลี่ยนไปตามช่วงที่กำลังอ่าน ส่วน `max_char` และ
`max_count` จะเปลี่ยนเฉพาะเมื่อพบช่วงที่ยาวกว่าคำตอบเดิม

## ขั้นตอนการทำงาน

ลูปเริ่มที่ตำแหน่ง `1` เพราะตัวอักษรตำแหน่ง `0` ถูกนำมาใช้กำหนดค่าเริ่มต้น
แล้ว

```python
for i in range(1, len(text)):
```

สำหรับตัวอักษรแต่ละตัว มีกรณีที่ต้องพิจารณาดังนี้

1. ถ้า `text[i] == char` แสดงว่ายังอยู่ในช่วงเดิม จึงเพิ่มความยาวด้วย
   `count += 1`
2. ถ้า `text[i] != char` แสดงว่าช่วงเดิมจบแล้ว โปรแกรมจะเปรียบเทียบ
   `count` กับ `max_count` และบันทึกคำตอบใหม่เมื่อ `count > max_count`
3. หลังจบช่วงเดิม ให้เริ่มช่วงใหม่ด้วย `char = text[i]` และ `count = 1`

การเปรียบเทียบช่วงเดิมเกิดขึ้นเมื่อพบตัวอักษรของ **ช่วงถัดไป** แต่ช่วงสุดท้าย
ไม่มีตัวอักษรถัดไปมาทำให้เข้าเงื่อนไข `else` จึงต้องตรวจอีกครั้งหลังจบลูป

```python
if count > max_count:
    max_count = count
    max_char = char
```

สุดท้าย `print(max_char, max_count)` แสดงตัวอักษร เว้นวรรค และความยาวของช่วง
ตามรูปแบบผลลัพธ์ที่โจทย์กำหนด

## ตัวอย่างการทำงาน

พิจารณาข้อมูล `AAABBCCCXXXXXAAAAYYZZZ` โดยมองเป็นช่วง จะได้
`AAA | BB | CCC | XXXXX | AAAA | YY | ZZZ`

| ช่วงที่จบ | `count` | คำตอบที่ยาวที่สุดหลังตรวจช่วง |
|---|---:|---|
| `AAA` | 3 | `A 3` |
| `BB` | 2 | `A 3` |
| `CCC` | 3 | `A 3` |
| `XXXXX` | 5 | `X 5` |
| `AAAA` | 4 | `X 5` |
| `YY` | 2 | `X 5` |
| `ZZZ` | 3 | `X 5` |

ช่วง `XXXXX` ยาวที่สุด โปรแกรมจึงแสดงผล

```text
X 5
```

## ข้อควรระวังและประสิทธิภาพ

-   ถ้าข้อมูลมีตัวอักษรเพียงตัวเดียว ลูปจะไม่ทำงาน แต่ค่าเริ่มต้นทำให้โปรแกรม
    ยังแสดงตัวอักษรนั้นและความยาว `1` ได้ถูกต้อง
-   โค้ดใช้เงื่อนไข `>` ไม่ใช่ `>=` ดังนั้นถ้ามีหลายช่วงยาวเท่ากัน จะเก็บช่วง
    แรกไว้ อย่างไรก็ตาม PDF รับประกันว่าช่วงที่ยาวที่สุดมีเพียงช่วงเดียว
-   `input().strip()` ตัดช่องว่างที่หัวและท้ายข้อมูลออก และโค้ดเข้าถึง
    `text[0]` ทันที จึงสมมติว่าข้อมูลหลังตัดช่องว่างแล้วไม่เป็นข้อความว่าง
-   เมื่อข้อความยาว $n$ ตัวอักษร โปรแกรมตรวจแต่ละตำแหน่งครั้งเดียว จึงใช้
    เวลา $O(n)$ และใช้ตัวแปรจำนวนคงที่ หรือพื้นที่เพิ่มเติม $O(1)$

# Solution

```python
# --------------------------------------------------
# File Name : 2566_3_Q1_01.py
# Problem   : Longest Repeating Characters
# Author    : Worralop Srichainont
# Date      : 2025-07-15
# --------------------------------------------------

# Input text
text = input().strip()

# Initialize counter
max_char = text[0]
char = text[0]

max_count = 1
count = 1

# Iterate through the text
for i in range(1, len(text)):
    if text[i] == char:
        count += 1
    else:
        if count > max_count:
            max_count = count
            max_char = char
        char = text[i]
        count = 1

# Check the last character count
if count > max_count:
    max_count = count
    max_char = char

# Output the maximum character repeated and its count
print(max_char, max_count)
```
