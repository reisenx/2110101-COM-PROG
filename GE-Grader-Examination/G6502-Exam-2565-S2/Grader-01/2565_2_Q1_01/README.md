## การเลื่อนตำแหน่งในสตริง

ข้อมูลในโจทย์เป็นสตริงที่ประกอบด้วยตัวเลข `0` ถึง `9` การเก็บข้อมูลเป็นสตริง
ทำให้เราย้ายตำแหน่งของแต่ละอักขระได้โดยตรง และยังรักษาเลข `0`
ที่อยู่ด้านหน้าไว้ได้ เช่น ผลลัพธ์ `0232` จะไม่กลายเป็น `232`

การเลื่อนสตริงไปทางซ้าย `n` ตำแหน่ง ทำได้โดยแบ่งสตริงตรงตำแหน่ง `idx`
แล้วนำส่วนหลังมาต่อหน้าส่วนแรก

$$idx = n \bmod len(s)$$

เขียนเป็น Python ได้ว่า `idx = n % len(s)` และต่อสตริงด้วย
`s[idx:] + s[:idx]` ตัวอย่างเช่น `s = "0246"` และ `n = 3` จะได้
`idx = 3` จึงแบ่งเป็น `"6"` กับ `"024"` และได้ผลลัพธ์ `"6024"`

ส่วนการเลื่อนไปทางขวา โค้ดหาตำแหน่งแบ่งจาก

$$idx = len(s) - (n \bmod len(s))$$

แล้วใช้ `s[idx:] + s[:idx]` เช่นเดิม เช่น `s = "2023"` และ `n = 3`
จะได้ `idx = 1` จึงนำ `"023"` ไปไว้หน้า `"2"` และได้ `"0232"`

การใช้ `% len(s)` ทำให้จำนวนครั้งที่เลื่อนวนกลับมาอยู่ในช่วงความยาวของสตริง
ถ้าเลื่อนครบหนึ่งรอบพอดี สตริงจึงไม่เปลี่ยนแปลง

> [!NOTE]
>
> ใน PDF มีตัวอย่าง `rotate_left("01234", 3)` เป็น `340120`
> ซึ่งยาวกว่าสตริงเดิม แต่ตามนิยามการเลื่อนตำแหน่งและตามโค้ด ผลลัพธ์จริงคือ
> `34012` เพราะการเลื่อนไม่ได้เพิ่มหรือลบอักขระ

## การหาเศษของตัวเลขแต่ละหลัก

ฟังก์ชัน `str_mod()` พิจารณาทีละอักขระ โดยแปลงอักขระนั้นเป็นจำนวนเต็ม
หาเศษจากการหาร แล้วแปลงกลับเป็นสตริงเพื่อนำไปต่อกับผลลัพธ์

$$result_i = int(s[i]) \bmod n$$

สูตรนี้ตรงกับคำสั่ง `int(digit) % mod` ใน Python ตัวอย่างเช่น
`str_mod("2110101", 2)` จะหาเศษเมื่อหารด้วย `2` ทีละหลัก จึงได้
`"0110101"` สังเกตว่าเลข `0` ตัวแรกยังคงอยู่ เพราะผลลัพธ์ถูกเก็บเป็นสตริง

โจทย์กำหนดให้ตัวหารของ `str_mod()` อยู่ในช่วง `1` ถึง `9`
จึงไม่มีการหารด้วยศูนย์ หากเรียกฟังก์ชันด้วย `mod = 0` จะเกิด
`ZeroDivisionError`

## ขั้นตอนการทำงานของโปรแกรม

ฟังก์ชัน `main()` รับสตริงตัวเลขอย่างน้อย 2 หลัก แล้วใช้สองหลักขวาสุดเป็นคำสั่ง
โดยไม่ได้ตัดสองหลักนี้ออกจากสตริง

1. `number[-2]` คือหลักรองสุดท้าย นำมาแปลงเป็น `cmd`
2. `number[-1]` คือหลักสุดท้าย นำมาแปลงเป็น `n`
3. ถ้า `cmd` เป็น `1` ให้เลื่อน `number` ไปทางซ้าย `n` ตำแหน่ง
4. ถ้า `cmd` เป็น `2` ให้เลื่อน `number` ไปทางขวา `n` ตำแหน่ง
5. ถ้า `cmd` เป็น `3` ให้หาเศษของทุกหลักด้วย `n`
6. ถ้า `cmd` เป็นค่าอื่น จะไม่เปลี่ยน `number`
7. แสดงผลสตริงสุดท้ายหนึ่งบรรทัด

ตัวอย่างเช่น เมื่อรับ `65535` จะได้ `cmd = 3` และ `n = 5`
โปรแกรมจึงคำนวณเศษของทุกหลักใน `65535` เมื่อหารด้วย `5` และแสดง `10030`
แต่เมื่อรับ `2566` จะได้ `cmd = 6` จึงแสดง `2566` เหมือนข้อมูลเดิม

บรรทัด `exec(input().strip())` มีไว้ให้ grader ส่งคำสั่งทดสอบเข้ามา เช่น
`print(rotate_left("0246", 3))` เพื่อทดสอบฟังก์ชันโดยตรง หรือ `main()`
เพื่อเริ่มรับข้อมูลและทำงานผ่านฟังก์ชันหลัก ดังนั้นลำดับข้อมูลของกรณี `main()` คือ
บรรทัดแรกเป็นคำสั่ง `main()` และบรรทัดถัดไปจึงเป็นสตริงตัวเลขของโจทย์

> [!WARNING]
>
> `exec()` สามารถรันโค้ด Python ใด ๆ ที่รับเข้ามาได้ บรรทัดนี้เหมาะกับข้อมูลทดสอบ
> ที่เชื่อถือได้จาก grader เท่านั้น ไม่ควรใช้ `exec()` กับข้อมูลจากผู้ใช้ที่ไม่รู้แหล่งที่มา

# Solution

```python
# --------------------------------------------------
# File Name : 2565_2_Q1_01.py
# Problem   : Decryption
# Author    : Worralop Srichainont
# Date      : 2025-07-11
# --------------------------------------------------


# Rotate a string to the left by n positions
def rotate_left(num, n):
    idx = n % len(num)
    return num[idx:] + num[:idx]


# Rotate a string to the right by n positions
def rotate_right(num, n):
    idx = len(num) - (n % len(num))
    return num[idx:] + num[:idx]


# Modulo each digit of a string by a given modulus
def str_mod(num, mod):
    result = ""
    for digit in num:
        result += str(int(digit) % mod)
    return result


# Main function
def main():
    # Input a string of digits
    number = input().strip()
    # Extract the last two digits as command and n
    cmd = int(number[-2])
    n = int(number[-1])

    # Rotate left number by n positions
    if cmd == 1:
        number = rotate_left(number, n)
    # Rotate right number by n positions
    elif cmd == 2:
        number = rotate_right(number, n)
    # Modulo each digit of number by n
    elif cmd == 3:
        number = str_mod(number, n)
    # Output
    print(number)


# Execute a input string as code
exec(input().strip())
```
