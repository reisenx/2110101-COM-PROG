## การรับข้อมูลและแยกเส้นทาง

โปรแกรมรับจำนวนเต็ม 4 จำนวนจากหนึ่งบรรทัด แล้วเก็บตามลำดับไว้ในตัวแปร
`a`, `b`, `c` และ `d`

```python
a, b, c, d = [int(e) for e in input().split()]
```

จุดตัดสินใจแรกของผังงานคือ `d > a` ซึ่งแบ่งการทำงานออกเป็นสองเส้นทาง
ถ้า `d` เท่ากับ `a` เงื่อนไขนี้เป็นเท็จ จึงเข้าสู่เส้นทางที่ `d`
ไม่มากกว่า `a`

---

## เส้นทางที่ d มากกว่า a

โปรแกรมกำหนดตัวนับ `n = 0` แล้วทำซ้ำตราบใดที่ `a < d`
ในแต่ละรอบจะปรับค่าดังนี้

$$n \leftarrow n + 1$$

$$a \leftarrow a + |b|$$

$$d \leftarrow d - |c|$$

คำสั่ง Python ที่ตรงกับค่าสัมบูรณ์ $|b|$ และ $|c|$ คือ `abs(b)` และ
`abs(c)` ดังนั้นแม้ `b` หรือ `c` เป็นจำนวนลบ `a` ก็จะไม่ลดลง
และ `d` ก็จะไม่เพิ่มขึ้น

ลองไล่ค่าจากข้อมูล `1 4 2 10` จะได้ตารางดังนี้

| สถานะ | `n` | `a` | `d` | `a < d` |
|---|---:|---:|---:|:---:|
| ก่อนเข้าลูป | 0 | 1 | 10 | จริง |
| หลังรอบที่ 1 | 1 | 5 | 8 | จริง |
| หลังรอบที่ 2 | 2 | 9 | 6 | เท็จ |

เมื่อตรวจพบว่า `a < d` เป็นเท็จ ลูปจะหยุดและแสดง `n`, `a`, `d`
ตามลำดับ ตัวอย่างนี้จึงได้ `2 9 6` การที่ค่าทั้งสองเท่ากันพอดีก็ทำให้ลูปหยุด
เช่นเดียวกับกรณีที่ `a` ข้ามไปมากกว่า `d`

> [!WARNING]
>
> ถ้าเริ่มต้นด้วย `d > a` แต่ `b` และ `c` เป็น `0` ทั้งคู่ ค่า `a` และ `d`
> จะไม่เปลี่ยนเลย ทำให้เงื่อนไข `a < d` เป็นจริงตลอดและลูปไม่จบ
> โปรแกรมจึงอาศัยข้อมูลทดสอบที่ทำให้ระยะระหว่าง `a` กับ `d` ลดลง

## เส้นทางที่ d ไม่มากกว่า a

เมื่อ `d > a` เป็นเท็จ โปรแกรมเริ่มจากสลับ `a` กับ `d` ด้วย
`a, d = d, a` จากนั้นจัดสมาชิกในแต่ละคู่ให้เรียงจากน้อยไปมาก

-   ถ้า `a > b` ให้สลับ `a` กับ `b` ทำให้ได้ `a <= b`
-   ถ้า `c > d` ให้สลับ `c` กับ `d` ทำให้ได้ `c <= d`

Python สามารถสลับสองค่าในคำสั่งเดียว เช่น `a, b = b, a`
โดยไม่ต้องสร้างตัวแปรพัก หลังจัดลำดับแล้ว โปรแกรมเปรียบเทียบปลายขวาของคู่แรก
คือ `b` กับปลายซ้ายของคู่ที่สองคือ `c`

| เงื่อนไข | ผลลัพธ์ |
|---|---|
| `b == c` | แสดง `a`, `b`, `d` ตามลำดับ |
| `b > c` | แสดงค่าเฉลี่ย $(b + c) / 2$ |
| `b < c` | แสดง `a`, `b`, `c`, `d` ตามลำดับ |

สูตรค่าเฉลี่ยเขียนเป็น Python ว่า `(b + c) / 2` เครื่องหมาย `/`
ให้ผลลัพธ์เป็น `float` เสมอ จึงอาจแสดง `.0` ได้ เช่น ถ้าค่าเฉลี่ยเท่ากับ
จำนวนเต็ม `3` ผลลัพธ์ของนิพจน์จะเป็น `3.0` ส่วนข้อมูล `2 3 4 1`
ถูกจัดลำดับจนได้ `b = 3` และ `c = 2` จึงแสดง `(3 + 2) / 2` เป็น `2.5`

การส่งหลายค่าให้ `print()` เช่น `print(a, b, c, d)`
จะแสดงค่าเหล่านั้นในบรรทัดเดียวโดยคั่นแต่ละค่าด้วยช่องว่างหนึ่งช่อง

# Solution

```python
# --------------------------------------------------
# File Name : 2565_2_Q1_03.py
# Problem   : Flowchart
# Author    : Worralop Srichainont
# Date      : 2025-07-11
# --------------------------------------------------

a, b, c, d = [int(e) for e in input().split()]

if d > a:
    n = 0
    while a < d:
        n = n + 1
        a = a + abs(b)
        d = d - abs(c)
    print(n, a, d)
else:
    a, d = d, a
    if a > b:
        a, b = b, a
    if c > d:
        c, d = d, c
    if b == c:
        print(a, b, d)
    else:
        if b > c:
            print((b + c) / 2)
        else:
            print(a, b, c, d)
```
