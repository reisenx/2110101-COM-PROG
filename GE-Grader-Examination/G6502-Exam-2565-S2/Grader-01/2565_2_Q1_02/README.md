## การแบ่งช่วงค่า AQI

โปรแกรมรับค่า AQI จำนวน 7 ค่าในบรรทัดเดียว ค่าทั้งเจ็ดเรียงตามวันที่ `1` ถึง
`7` และถูกแปลงเป็นจำนวนเต็มเก็บไว้ในลิสต์ `aqi`

```python
aqi = [int(e) for e in input().split()]
```

จากนั้นพิจารณาค่าแต่ละวันด้วย `if` และ `elif` เพื่อจัดไว้ในหนึ่งในห้าระดับ

| ระดับ | ความหมาย | ช่วงตามโจทย์ | เงื่อนไขใน Python |
|:---:|---|---|---|
| 1 | คุณภาพอากาศดีมาก | $AQI < 25$ | `aqi[i] < 25` |
| 2 | คุณภาพอากาศดี | $25 \le AQI < 50$ | `25 <= aqi[i] < 50` |
| 3 | ปานกลาง | $50 \le AQI < 100$ | `50 <= aqi[i] < 100` |
| 4 | เริ่มมีผลกระทบต่อสุขภาพ | $100 \le AQI < 200$ | `100 <= aqi[i] < 200` |
| 5 | มีผลกระทบต่อสุขภาพ | $200 \le AQI$ | `aqi[i] >= 200` |

เครื่องหมายเท่ากับที่ขอบช่วงมีความสำคัญ เช่น `25` อยู่ระดับ `2`, `50`
อยู่ระดับ `3`, `100` อยู่ระดับ `4` และ `200` อยู่ระดับ `5`
การเรียงเงื่อนไขจากค่าน้อยไปหาค่ามากช่วยให้ค่าแต่ละค่าตรงกับเพียงหนึ่งแขนง

## การสร้างแผนภาพ

ผลลัพธ์เริ่มด้วยหัวตารางและเส้นคั่น ซึ่งต้องมีอักขระและช่องว่างตรงตามโจทย์

```text
AQI|1 2 3 4 5
-------------
```

หลังเครื่องหมาย `|` แต่ละแถวมีพื้นที่กว้าง 9 อักขระ ตำแหน่งระดับ `1` ถึง `5`
อยู่ห่างกันตำแหน่งละหนึ่งจุด โปรแกรมวาง `+` ที่ระดับของวันนั้น
และเติมตำแหน่งอื่นด้วย `.` ดังนี้

| ระดับ | ข้อความ 9 อักขระหลังขีดตั้ง |
|:---:|:---|
| 1 | `+........` |
| 2 | `..+......` |
| 3 | `....+....` |
| 4 | `......+..` |
| 5 | `........+` |

ลูป `for i in range(7)` เข้าถึงข้อมูลจากตำแหน่ง `0` ถึง `6`
แต่หมายเลขวันที่ต้องเริ่มจาก `1` จึงแสดง `i + 1` แล้วตามด้วย `..|`
ตัวอย่างเช่น ถ้าค่าลำดับที่สามเป็น `50` จะอยู่ระดับ `3` และแสดงแถว

```text
3..|....+....
```

ลำดับผลลัพธ์ทั้งหมดคือ หัวตาราง เส้นคั่น แถวของวันที่ `1` ถึง `7`
ตามลำดับข้อมูลเข้า และเส้นคั่นปิดท้ายอีกหนึ่งบรรทัด โค้ดอาศัยเงื่อนไขของโจทย์
ว่ามีข้อมูลครบ 7 ค่าเสมอ หากมีน้อยกว่านั้น การเข้าถึง `aqi[i]`
จะเกินขอบเขตของลิสต์

# Solution

```python
# --------------------------------------------------
# File Name : 2565_2_Q1_02.py
# Problem   : AQI
# Author    : Worralop Srichainont
# Date      : 2025-07-11
# --------------------------------------------------

# Input
aqi = [int(e) for e in input().split()]

# Output
print("AQI|1 2 3 4 5")
print("-------------")
for i in range(7):
    if aqi[i] < 25:
        print(f"{i + 1}..|+........")
    elif 25 <= aqi[i] < 50:
        print(f"{i + 1}..|..+......")
    elif 50 <= aqi[i] < 100:
        print(f"{i + 1}..|....+....")
    elif 100 <= aqi[i] < 200:
        print(f"{i + 1}..|......+..")
    elif aqi[i] >= 200:
        print(f"{i + 1}..|........+")
print("-------------")
```
