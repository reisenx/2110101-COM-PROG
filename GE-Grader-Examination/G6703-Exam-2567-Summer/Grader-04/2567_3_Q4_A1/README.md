## ภาพรวมของผังงาน

โจทย์รับจำนวนเต็ม `a`, `b`, `c` และ `d` จากบรรทัดเดียว แล้วเลือกทำงานตาม
เงื่อนไขในผังงาน การอ่านข้อมูลใช้ list comprehension เพื่อแปลงข้อความทุกตัวเป็น
`int`

```python
a, b, c, d = [int(num) for num in input().split()]
```

ทางแยกแรกคือการเปรียบเทียบ `a <= b`

-   ถ้าเป็นจริง โปรแกรมจะตรวจลำดับของตัวเลขต่อ และอาจหาค่าเฉลี่ยหรือเรียงตัวเลข
-   ถ้าเป็นเท็จ หรือก็คือ `a > b` โปรแกรมจะประมาณค่า $\sqrt{a}$

สังเกตว่าเครื่องหมาย `<=` รวมกรณีที่ตัวเลขเท่ากันด้วย เช่น เมื่อ `a == b`
โปรแกรมจะเข้าทาง `a <= b`

## กรณี a น้อยกว่าหรือเท่ากับ b

เมื่อ `a <= b` ผังงานแบ่งได้เป็น 3 กรณีหลัก

| เงื่อนไข | สิ่งที่โปรแกรมแสดงผล |
|---|---|
| `a <= b <= c <= d` | ค่าเฉลี่ยของ `b` และ `c` |
| `a <= b <= c` และ `d < c` | ตัวเลขทั้ง 4 ตัวที่เรียงจากน้อยไปมาก |
| `a <= b` แต่ `b > c` | ค่าเฉลี่ยของ `a`, `c` และ `d` |

### ค่าเฉลี่ยของตัวกลางสองตัว

ถ้า `a <= b`, `b <= c` และ `c <= d` ตัวเลขเรียงจากน้อยไปมากอยู่แล้ว
ตัวกลางจึงเป็น `b` กับ `c` ค่าเฉลี่ยคำนวณจาก

$$
\text{average} = \frac{b+c}{2}
$$

ซึ่งตรงกับนิพจน์ Python `(b + c) / 2` ตัวอย่างเช่น `1 2 3 4`
ทำให้ได้ `(2 + 3) / 2` และแสดงผล `2.5`

### การแทรก d ลงในลำดับ a b c

ถ้า `a <= b <= c` แต่ `d < c` แปลว่า `a`, `b`, `c` เรียงอยู่แล้ว
เหลือเพียงหาตำแหน่งของ `d` ผังงานจึงเปรียบเทียบ `d` กับ `b` และ `a`
ตามลำดับ

-   ถ้า `d <= a` ลำดับคือ `d, a, b, c`
-   ถ้า `a < d <= b` ลำดับคือ `a, d, b, c`
-   ถ้า `b < d < c` ลำดับคือ `a, b, d, c`

ตัวอย่าง `3 4 5 2` เข้ากรณี `d <= a` จึงแสดง `2 3 4 5` ส่วน
`3 4 9 6` เข้ากรณี `b < d < c` จึงแสดง `3 4 6 9`

### ค่าเฉลี่ยของสามตัว

ถ้า `a <= b` แต่ `b > c` ผังงานไม่ตรวจลำดับต่อ และหาค่าเฉลี่ยของ `a`, `c`
และ `d` โดยตรง

$$
\text{average} = \frac{a+c+d}{3}
$$

ใน Python เขียนเป็น `(a + c + d) / 3` เช่นข้อมูล `1 6 2 5` ให้ค่าจริง
`2.6666666666666665`

## กรณี a มากกว่า b

เมื่อ `a > b` โปรแกรมใช้ **Binary Search** เพื่อประมาณค่า $\sqrt{a}$
โดยเก็บขอบเขตคำตอบไว้ในตัวแปร `x` และ `y`

1. กำหนดขอบล่าง `x = 0` และขอบบน `y = a`
2. หาจุดกึ่งกลางด้วย `m = (x + y) / 2`
3. ตรวจความคลาดเคลื่อน $|m^2-a|$ ด้วย `abs((m**2) - a)`
4. ถ้า `m**2 < a` แสดงว่า `m` ยังเล็กไป จึงเลื่อนขอบล่างเป็น `x = m`
5. มิฉะนั้น `m` ใหญ่เกินไปหรือพอดี จึงเลื่อนขอบบนเป็น `y = m`
6. คำนวณจุดกึ่งกลางใหม่ แล้วทำซ้ำจนความคลาดเคลื่อนไม่เกิน
   $10^{-b}$

เงื่อนไขของลูป

$$
|m^2-a| > 10^{-b}
$$

เขียนใน Python เป็น
`abs((m**2) - a) > 10 ** (-b)` ยิ่ง `b` มาก ค่า $10^{-b}$ ยิ่งเล็ก
โปรแกรมจึงต้องประมาณคำตอบให้ละเอียดขึ้น ตัวแปร `c` และ `d` ไม่ถูกใช้ในทางแยกนี้

# Solution

```python
# --------------------------------------------------
# File Name : 2567_3_Q4_A1.py
# Problem   : Flowchart
# Author    : Worralop Srichainont
# Date      : 2025-08-01
# --------------------------------------------------

a, b, c, d = [int(num) for num in input().split()]

if a <= b:
    if b <= c:
        if c <= d:
            print((b + c) / 2)
        else:
            if d <= b:
                if d <= a:
                    print(d, a, b, c)
                else:
                    print(a, d, b, c)
            else:
                print(a, b, d, c)
    else:
        print((a + c + d) / 3)

else:
    x, y = 0, a
    m = (x + y) / 2

    while abs((m**2) - a) > 10 ** (-b):
        if (m**2) < a:
            x = m
        else:
            y = m
        m = (x + y) / 2

    print(m)
```
