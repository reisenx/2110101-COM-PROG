## ภาพรวมการเลือกเส้นทาง

โจทย์รับจำนวนเต็ม `a`, `b`, `c`, `d` และ `e` จากข้อมูลนำเข้าหนึ่งบรรทัด
จากนั้นเลือกทำงานหนึ่งในสามกรณีตามเงื่อนไขในผังงาน

| เงื่อนไข | สิ่งที่โปรแกรมทำ |
|---|---|
| `a >= e` | เรียงจำนวนทั้งห้าจากน้อยไปมาก แล้วแสดงผลทั้งห้าจำนวน |
| `a < e` และ `a == 1` | หาค่าเฉลี่ยของสองจำนวนกลางใน `b`, `c`, `d`, `e` |
| `a < e` และ `a != 1` | คำนวณคำตอบจากสูตร แล้วปัดด้วย `round(..., 2)` |

เงื่อนไขด้านนอกใช้ `if a >= e` ส่วนกรณีที่เงื่อนไขนี้เป็นเท็จจะเข้า
`else` ซึ่งหมายความว่า `a < e` โดยอัตโนมัติ

---

## กรณีเรียงจำนวนทั้งห้า

เมื่อ `a >= e` โปรแกรมใช้แนวคิดคล้าย **Bubble Sort** โดยเปรียบเทียบสมาชิก
ที่อยู่ติดกันจากซ้ายไปขวา ได้แก่ `a` กับ `b`, `b` กับ `c`, `c` กับ `d`
และ `d` กับ `e`

ถ้าค่าทางซ้ายมากกว่าหรือเท่ากับค่าทางขวา จะสลับค่าด้วยคำสั่งลักษณะนี้

```python
if a >= b:
    a, b = b, a
```

หลังเปรียบเทียบครบหนึ่งรอบ ค่าที่มากที่สุดของรอบนั้นจะถูกดันไปทางขวา
โปรแกรมทำซ้ำตั้งแต่ `i = 0` จนถึง `i = 4` รวมทั้งหมด 5 รอบ
จึงเพียงพอที่จะทำให้จำนวนทั้งห้าเรียงจากน้อยไปมาก แม้จำนวนที่เท่ากันจะถูก
สลับตำแหน่งก็ไม่กระทบค่าที่แสดงผล

## กรณีหาค่าเฉลี่ยของสองจำนวนกลาง

กรณี `a < e` และ `a == 1` โปรแกรมสนใจสี่ค่า `b`, `c`, `d`, `e`
ก่อนอื่นจะเปรียบเทียบและสลับค่าที่อยู่ติดกันหนึ่งรอบ

```python
if b >= c:
    b, c = c, b
if c >= d:
    c, d = d, c
if d >= e:
    d, e = e, d
```

การทำเช่นนี้ทำให้ค่ามากที่สุดในสี่ค่านี้ไปอยู่ที่ `e` จากนั้นเงื่อนไขซ้อนกัน
จะเลือกสองค่าที่มากที่สุดจาก `b`, `c`, `d` ซึ่งก็คือสองจำนวนตรงกลางของ
`b`, `c`, `d`, `e` เดิม แล้วนำมาหาค่าเฉลี่ย

ถ้าให้สองจำนวนกลางเป็น `x` และ `y` จะได้

$$
\text{average} = \frac{x + y}{2}
$$

และเขียนในภาษา Python ได้เป็น `(x + y) / 2` เครื่องหมาย `/` ทำให้ผลลัพธ์
เป็น `float` เช่น ค่าเฉลี่ยของ `3` กับ `7` จะแสดงเป็น `5.0`

---

## กรณีคำนวณจากสูตร

เมื่อ `a < e` และ `a != 1` คำตอบกำหนดโดยสูตร

$$
\text{ans} = \frac{\sqrt{b^2 + c^2 + d^2}}{a^2}
$$

ส่วนที่ตรงกันในภาษา Python คือ

```python
ans = (((b**2) + (c**2) + (d**2)) ** 0.5) / (a**2)
```

-   `x**2` หมายถึง $x^2$
-   `x**0.5` หมายถึง $\sqrt{x}$
-   `round(ans, 2)` ปัดผลลัพธ์ให้เหลือไม่เกิน 2 ตำแหน่งทศนิยม

> [!NOTE]
>
> `round(..., 2)` ไม่ได้บังคับให้แสดงเลขหลังจุดครบสองหลักเสมอ เช่น
> `round(5.0, 2)` ยังคงแสดงเป็น `5.0`

> [!WARNING]
>
> สูตรนี้หารด้วย `a**2` หากเข้าเส้นทางนี้ด้วย `a == 0` โปรแกรมจะเกิด
> `ZeroDivisionError`

---

## ตัวอย่างการทำงาน

**ตัวอย่างที่ 1:** ข้อมูล `8 7 1 3 0` มี `a >= e` จึงเรียงทั้งห้าค่าและได้

```text
0 1 3 7 8
```

**ตัวอย่างที่ 2:** ข้อมูล `1 8 7 0 3` มี `a < e` และ `a == 1`
หลังสลับค่าที่ติดกันจะได้ `b, c, d, e` เป็น `7, 0, 3, 8`
สองจำนวนกลางของข้อมูลเดิมคือ `3` และ `7` จึงได้ `(3 + 7) / 2 = 5.0`

**ตัวอย่างที่ 3:** ข้อมูล `2 8 7 4 3` เข้าเส้นทางสูตร

$$
\frac{\sqrt{8^2 + 7^2 + 4^2}}{2^2}
= \frac{\sqrt{129}}{4}
\approx 2.8395
$$

เมื่อใช้ `round(ans, 2)` จึงแสดงผลเป็น `2.84`

# Solution

```python
# --------------------------------------------------
# File Name : 2567_3_Q1_A1.py
# Problem   : Flowchart
# Author    : Worralop Srichainont
# Date      : 2025-07-31
# --------------------------------------------------

a, b, c, d, e = [int(num) for num in input().split()]

if a >= e:
    i = 0
    n = 4

    while i <= n:
        if a >= b:
            a, b = b, a

        if b >= c:
            b, c = c, b

        if c >= d:
            c, d = d, c

        if d >= e:
            d, e = e, d

        i += 1
    print(a, b, c, d, e)


else:
    if a == 1:
        if b >= c:
            b, c = c, b

        if c >= d:
            c, d = d, c

        if d >= e:
            d, e = e, d

        if b <= c:
            if b <= d:
                print((c + d) / 2)
            else:
                print((b + c) / 2)

        else:
            if c <= d:
                print((b + d) / 2)
            else:
                print((b + c) / 2)
    else:
        ans = (((b**2) + (c**2) + (d**2)) ** 0.5) / (a**2)
        print(round(ans, 2))
```
