## อ่านข้อมูลและเลือกเส้นทางของผังงาน

โจทย์รับจำนวนเต็ม `a`, `b`, `c` และ `d` จากบรรทัดเดียว แล้วเดินตามผังงาน
โดยเริ่มจากตรวจสอบค่า `a`

```python
a, b, c, d = [int(num) for num in input().split()]
```

-   ถ้า `a == 1` จะสลับค่า `c` กับ `d` ก่อน แล้วเลือกวิธีคำนวณจาก `b`
-   ถ้า `a != 1` จะตรวจต่อว่า `a != 10` หรือ `a == 10`

เมื่อจบเส้นทางใดเส้นทางหนึ่ง โปรแกรมจะแสดงค่า `a b c d` ตามลำดับ

---

## กรณีที่ a เท่ากับ 1

คำสั่ง

```python
c, d = d, c
```

สลับค่าของตัวแปรทั้งสองพร้อมกัน เช่น เดิม `c = 10` และ `d = 4` หลังสลับจะได้
`c = 4` และ `d = 10` จากนั้นจึงพิจารณา `b`

-   `b == 1` ทำ `c = c + d`
-   `b != 1` และ `b < 5` ทำ `c = c - d`
-   `5 <= b <= 10` ทำ `c = c / d`
-   `b > 10` ไม่เปลี่ยนค่า `c` เพิ่มเติม

เครื่องหมาย `/` เป็นการหารแบบจำนวนจริง ผลลัพธ์จึงอาจเป็น `float` ตัวอย่างเช่น
อินพุต `1 5 10 4` จะสลับเป็น `c = 4`, `d = 10` แล้วคำนวณ

```python
c = 4 / 10  # 0.4
```

จึงแสดงผลเป็น `1 5 0.4 10`

## กรณีที่ a ไม่เท่ากับ 1

### เมื่อ `a != 10`

เงื่อนไขของ `b` ในส่วนนี้เป็นคำสั่ง `if` แยกกัน ไม่ใช่ `if`–`elif`
ดังนั้นเมื่อเงื่อนไขจริงหลายข้อ โปรแกรมจะทำหลายคำสั่งต่อเนื่องกัน และแต่ละคำสั่ง
จะใช้ค่า `c` ที่เพิ่งเปลี่ยนจากคำสั่งก่อนหน้า

1. ถ้า `b > 1` ให้บวก `d` เข้าไปใน `c`
2. ถ้า `b > 2` ให้แทน `c` ด้วยเศษจากการหาร `c % d`
3. ถ้า `b > 3` ให้คำนวณ `c = c + c**d` แต่ถ้าไม่จริงให้ลด `c` ลง `1`

ตัวอย่างอินพุต `5 4 2 9` ทำงานดังนี้

```python
c = 2 + 9      # 11
c = 11 % 9     # 2
c = 2 + (2**9) # 514
```

จึงได้ผลลัพธ์ `5 4 514 9` โดย `**` คือการยกกำลัง และ `%` คือการหาเศษ
จากการหาร

### เมื่อ `a == 10`

โปรแกรมทำซ้ำตราบใดที่ `a > d`

```python
a = a - b
c += 1
```

แต่ละรอบลด `a` ลง `b` และเพิ่ม `c` ขึ้น `1` ส่วน `b` และ `d` ไม่เปลี่ยน
ลูปหยุดเมื่อ `a <= d`

> [!WARNING]
>
> เส้นทางนี้อาศัย `b` ที่เป็นจำนวนบวกเพื่อให้ `a` ลดลงจนลูปจบ หาก `a > d`
> แต่ `b <= 0` ลูปอาจไม่สิ้นสุด

## ลำดับการคำนวณและผลลัพธ์

จุดสำคัญคืออ่านเงื่อนไขจากบนลงล่าง และติดตามค่าปัจจุบันของตัวแปรหลังทุกคำสั่ง
โดยเฉพาะสาขา `a != 1` และ `a != 10` ซึ่งอาจเปลี่ยน `c` มากกว่าหนึ่งครั้ง

สุดท้ายคำสั่ง

```python
print(a, b, c, d)
```

จะแสดงทั้งสี่ค่าคั่นด้วยช่องว่าง หากเคยใช้ `/` ค่า `c` จะแสดงในรูปจำนวนจริง
เช่น `0.4` หรือ `5.5`

# Solution

```python
# --------------------------------------------------
# File Name : 2567_3_Q5_A1.py
# Problem   : Flowchart
# Author    : Worralop Srichainont
# Date      : 2025-08-01
# --------------------------------------------------

a, b, c, d = [int(num) for num in input().split()]

if a == 1:
    c, d = d, c

    if b == 1:
        c = c + d
    else:
        if b < 5:
            c = c - d
        else:
            if b <= 10:
                c = c / d

else:
    if a != 10:
        if b > 1:
            c = c + d

        if b > 2:
            c = c % d

        if b > 3:
            c = c + (c**d)
        else:
            c -= 1

    else:
        while a > d:
            a = a - b
            c += 1

print(a, b, c, d)
```
