## การอ่านผังงาน

โจทย์รับจำนวนเต็ม `a`, `b`, `c`, `d` และ `e` จากบรรทัดเดียวกัน
แล้วเดินตามลูกศรในผังงานเพื่อเปลี่ยนค่าของตัวแปรบางตัว

```python
a, b, c, d, e = [int(num) for num in input().split()]
```

เงื่อนไขแรกคือ `a > 0` ซึ่งแบ่งการทำงานออกเป็น 2 ทางหลัก

-   ถ้าเป็นจริง แสดงว่า `a` เป็นจำนวนบวก จากนั้นจึงตรวจว่า `a` เป็นจำนวนคู่หรือคี่
-   ถ้าเป็นเท็จ แสดงว่า `a` เป็น `0` หรือจำนวนลบ และจะเข้าสู่การทำซ้ำ

การอ่านผังงานต้องทำตามลำดับลูกศรเสมอ เพราะค่าที่เปลี่ยนในขั้นหนึ่ง
อาจถูกนำไปตรวจสอบในเงื่อนไขถัดไป

## กรณีจำนวนบวก

เมื่อ `a > 0` โปรแกรมใช้เศษจากการหารด้วย `2` เพื่อตรวจสอบจำนวนคู่

```python
if a % 2 == 0:
```

ถ้าเศษเป็น `0` แสดงว่า `a` เป็นจำนวนคู่ มิฉะนั้น `a` เป็นจำนวนคี่

### เมื่อเป็นจำนวนคู่

ค่าของ `b` จะถูกเปลี่ยนตามเงื่อนไขต่อไปนี้

| เงื่อนไข | การเปลี่ยนค่า `b` |
|---|---|
| `b < c` | คูณด้วย `e` จาก `b *= e` |
| `b >= c` และ `b < d` | หารปัดลงด้วย `e` จาก `b //= e` แล้วลบ `e` ด้วย `b -= e` |
| `b >= c` และ `b >= d` | ลบ `e` ด้วย `b -= e` |

สังเกตว่า `b -= e` อยู่หลังเงื่อนไข `b < d` จึงต้องทำทั้งกรณีที่หารและไม่หาร
ตัวอย่างเช่น อินพุต `2 4 3 6 3` ทำให้ `b >= c` และ `b < d`
จึงได้ `b = 4 // 3 = 1` ก่อน แล้วจึงได้ `b = 1 - 3 = -2`

เครื่องหมาย `//` คือการหารปัดลง เช่น `7 // 3` ได้ `2` และ `-7 // 3` ได้ `-3`
โดยข้อมูลที่ทำให้มาถึงคำสั่งนี้ต้องมี `e` ไม่เท่ากับ `0`

### เมื่อเป็นจำนวนคี่

ทางเดินนี้มีการตรวจสอบ 2 ครั้งต่อเนื่องกัน

1. ถ้า `b > c` ให้สลับค่าด้วย `b, c = c, b`
2. นำค่า `b` หลังจากขั้นแรกไปเปรียบเทียบกับ `d`
   -   ถ้า `b > d` ให้สลับค่าด้วย `b, d = d, b`
   -   มิฉะนั้น รวมถึงกรณี `b == d` ให้เพิ่ม `e` ด้วย `b += e`

> [!NOTE]
>
> เงื่อนไขที่สองไม่ได้ใช้ค่า `b` เดิมเสมอไป หากขั้นแรกมีการสลับ `b` กับ `c`
> โปรแกรมจะนำค่าใหม่ของ `b` ไปเปรียบเทียบกับ `d`

ตัวอย่างเช่น `1 7 6 6 5` สลับ `b` กับ `c` ก่อน ทำให้ `b` กลายเป็น `6`
จากนั้น `b > d` เป็นเท็จเพราะ `6 == 6` จึงเพิ่ม `e` และได้ `b = 11`

## กรณีศูนย์หรือจำนวนลบ

เมื่อ `a <= 0` โปรแกรมทำซ้ำตราบใดที่ `a <= d`

```python
while a <= d:
    a += 1
    if a > b:
        break
    b -= 1
```

ในแต่ละรอบจะเพิ่ม `a` ก่อน แล้วจึงเปรียบเทียบค่าใหม่ของ `a` กับ `b`

-   ถ้า `a > b` คำสั่ง `break` จะออกจากลูปทันที ดังนั้นรอบนั้นจะไม่ทำ `b -= 1`
-   ถ้า `a <= b` จึงลด `b` ลง `1` แล้วกลับไปตรวจ `a <= d` สำหรับรอบถัดไป
-   ถ้าตอนเริ่มต้น `a > d` ลูปจะไม่ทำงานเลย
-   ถ้า `a == d` ลูปยังทำงานอีกหนึ่งรอบ เพราะเงื่อนไขใช้ `<=`

ตัวอย่าง `-5 4 3 1 3` จะเพิ่ม `a` และลด `b` ไปพร้อมกันจนได้ `a = 0`,
`b = -1` จากนั้นรอบถัดไปเพิ่ม `a` เป็น `1` ทำให้ `a > b` เป็นจริง
จึงออกจากลูปโดยไม่ลด `b` อีกครั้ง ผลลัพธ์คือ `1 -1 3 1 3`

## การแสดงผล

ไม่ว่าจะเดินผ่านทางใด โปรแกรมจะแสดงค่าปัจจุบันของตัวแปรทั้ง 5 ตัว
ตามลำดับเดิมและคั่นด้วยช่องว่าง

```python
print(a, b, c, d, e)
```

ดังนั้นต้องติดตามทุกการคูณ การหาร การบวก การลบ และการสลับค่าให้ครบ
โดยเฉพาะคำสั่งที่อยู่ต่อกันในทางเดินเดียวกัน

# Solution

```python
# --------------------------------------------------
# File Name : 2567_3_Q3_A1.py
# Problem   : Flowchart
# Author    : Worralop Srichainont
# Date      : 2025-07-31
# --------------------------------------------------

a, b, c, d, e = [int(num) for num in input().split()]

if a > 0:
    if a % 2 == 0:
        if b < c:
            b *= e
        else:
            if b < d:
                b //= e
            b -= e
    else:
        if b > c:
            b, c = c, b

        if b > d:
            b, d = d, b
        else:
            b += e

else:
    while a <= d:
        a += 1
        if a > b:
            break
        b -= 1

print(a, b, c, d, e)
```
