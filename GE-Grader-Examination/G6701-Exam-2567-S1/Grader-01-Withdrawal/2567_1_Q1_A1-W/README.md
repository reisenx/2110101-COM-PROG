## การแปลงผังงานเป็นโปรแกรม

โจทย์รับจำนวนเต็ม `a`, `b`, `c` และ `d` จากบรรทัดเดียว จากนั้นให้ทำงานตาม
ลูกศรในผังงาน การเขียนโปรแกรมจึงเริ่มจากแยกทางเดินหลักด้วยเงื่อนไข `a == 1`
แล้ววางเงื่อนไขย่อยและวงวนไว้ในระดับการเยื้องที่ตรงกับผังงาน

คำสั่งกำหนดค่าแบบย่อที่พบในโปรแกรม เช่น `c += c + d` มีความหมายเดียวกับ
`c = c + (c + d)` ส่วน `c -= 1` หมายถึง `c = c - 1` ค่าทางขวามือจะถูก
คำนวณจากค่าปัจจุบันก่อน แล้วจึงนำผลลัพธ์กลับไปเก็บในตัวแปรทางซ้าย

## กรณี a เท่ากับ 1

เมื่อ `a == 1` โปรแกรมเปลี่ยน `a` เป็น `b + c + d` ก่อน แล้วเลือกวิธีเปลี่ยน
`c` จากค่า `b`

-   ถ้า `b == 1` ใช้ `c += c + d` ดังนั้นค่าใหม่ของ `c` คือ `2 * c + d`
-   ถ้า `b == 2` ใช้ `c += c - d` ดังนั้นค่าใหม่ของ `c` คือ `2 * c - d`
-   สำหรับค่า `b` อื่น จะตรวจ `b > 4` และ `b > 5` แยกกันตามลำดับ
    ถ้าเงื่อนไขแรกเป็นจริง `c` จะเปลี่ยนก่อน แล้วเงื่อนไขถัดไปจึงใช้ค่า `c`
    ที่เปลี่ยนแล้ว

> [!WARNING]
>
> `else` ช่วงท้ายจับคู่กับ `if b > 5` ไม่ได้จับคู่กับ `if b > 4` ดังนั้นเมื่อ
> `b == 5` โปรแกรมทำทั้ง `c += c * d` และ `c += c // d` ตามลำดับ แต่เมื่อ
> `b > 5` จะทำ `c += c * d` แล้วตามด้วย `c += c % d`

ตัวดำเนินการ `//` คือการหารปัดลง ส่วน `%` คือการหาเศษจากการหาร ทั้งสองคำสั่ง
ใช้ค่า `c` ล่าสุด ณ จุดที่ทำงาน

ตัวอย่างอินพุต `1 1 1 1` จะได้ `a = 1 + 1 + 1 = 3` และ
`c = 1 + (1 + 1) = 3` จึงแสดง `3` ก่อน แล้วแสดงค่าตัวแปรทั้งหมดเป็น
`3 1 3 1`

## กรณี a ไม่เท่ากับ 1

อีกทางหนึ่งเป็นวงวน `while b < c` ในแต่ละรอบโปรแกรมทำงานตามลำดับดังนี้

1. เพิ่ม `b` ขึ้น `1`
2. ถ้า `b > a` ให้ `break` ออกจากวงวนทันที คำสั่งที่เหลือในรอบนั้นจะไม่ทำงาน
3. ลด `c` ลง `1`
4. ถ้า `a > d` ให้ `break` ออกจากวงวน โดยยังไม่ทำ `a += c`
5. ถ้ายังไม่ออกจากวงวน ให้เพิ่ม `a` ด้วยค่า `c` ล่าสุด

เช่น อินพุต `2 0 3 6` เริ่มจาก `b < c` รอบแรกเปลี่ยนเป็น
`a = 4, b = 1, c = 2` รอบที่สองเปลี่ยนเป็น `a = 5, b = 2, c = 1`
จากนั้น `b < c` เป็นเท็จ จึงได้ผลลัพธ์ `5 2 1 6`

> [!NOTE]
>
> `break` ออกจากวงวน `while` เท่านั้น หลังออกจากวงวนโปรแกรมยังทำคำสั่ง
> `print(a, b, c, d)` ที่อยู่ท้ายโปรแกรมเสมอ

## ลำดับการแสดงผล

-   ทางเดิน `a == 1` แสดงผลสองบรรทัด: ค่า `c` หลังคำนวณ แล้วตามด้วย
    `a b c d`
-   ทางเดิน `a != 1` แสดงผลเพียงบรรทัดสุดท้าย `a b c d`
-   `d` ไม่เคยถูกกำหนดค่าใหม่ จึงมีค่าเท่ากับข้อมูลนำเข้าตลอดการทำงาน

# Solution

```python
# --------------------------------------------------
# File Name : 2567_1_Q1_A1-W.py
# Problem   : Flowchart
# Author    : Worralop Srichainont
# Date      : 2025-07-28
# --------------------------------------------------

a, b, c, d = [int(e) for e in input().split()]

if a == 1:
    a = b + c + d
    if b == 1:
        c += c + d
    else:
        if b == 2:
            c += c - d
        else:
            if b > 4:
                c += c * d
            if b > 5:
                c += c % d
            else:
                c += c // d
    print(c)
else:
    while b < c:
        b += 1
        if b > a:
            break

        c -= 1

        if a > d:
            break
        a += c

print(a, b, c, d)
```
