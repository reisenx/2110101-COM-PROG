## แนวคิดในการแก้ปัญหา

โจทย์ต้องการนับ **จำนวนวิธีเลือกจำนวนเหรียญ** ให้รวมกันได้ `N` บาท โดยเหรียญ
`1`, `2` และ `5` บาทใช้ได้ชนิดละไม่เกิน `9` เหรียญ ส่วนเหรียญ `10`
บาทใช้ได้ไม่จำกัดจำนวน

วิธีหนึ่ง ๆ จึงเขียนแทนได้ด้วยจำนวนเหรียญ 4 ค่า ได้แก่ จำนวนเหรียญ `1`, `2`,
`5` และ `10` บาท หากจำนวนเหรียญชนิดใดต่างกัน จะถือว่าเป็นคนละวิธี

โปรแกรมไม่จำเป็นต้องลองจำนวนเหรียญ `10` บาทโดยตรง เพราะเมื่อเลือกจำนวนเหรียญ
อีกสามชนิดแล้ว จำนวนเงินที่เหลือจะเป็นตัวกำหนดจำนวนเหรียญ `10` บาทเพียงค่าเดียว

---

## การแจกแจงจำนวนเหรียญ

ค่าคงที่ `COINS_LIMIT` เท่ากับ `9` และ `range(COINS_LIMIT + 1)` จึงสร้างค่า
ตั้งแต่ `0` ถึง `9` ครบทั้ง 10 ค่า การใช้ลูปซ้อนกันสามชั้นทำให้โปรแกรมลองทุก
ชุดของ

-   `fives` จำนวนเหรียญ `5` บาท
-   `twos` จำนวนเหรียญ `2` บาท
-   `ones` จำนวนเหรียญ `1` บาท

การเริ่มจาก `0` สำคัญ เพราะวิธีทอนเงินที่ไม่ใช้เหรียญบางชนิดก็เป็นคำตอบที่เป็นไปได้
เช่น เงิน `15` บาทสามารถใช้เหรียญ `10` บาท 1 เหรียญกับเหรียญ `5` บาท 1
เหรียญ โดยไม่ใช้เหรียญ `1` และ `2` บาทเลย

ลูปทั้งสามรวมกันตรวจเพียง $10^3 = 1000$ ชุด ไม่ขึ้นกับค่า `N`
จึงครอบคลุมทุกชุดภายใต้ข้อจำกัดโดยไม่ใช้เวลามาก

---

## การตรวจสอบเหรียญสิบบาท

เมื่อกำหนดจำนวนเหรียญสามชนิดแล้ว เงินที่ยังขาดอยู่คือ

$$
r = N - (5f + 2t + o)
$$

โดย `f`, `t` และ `o` แทนจำนวนเหรียญ `5`, `2` และ `1` บาทตามลำดับ
ซึ่งตรงกับ Python ดังนี้

```python
remaining_money = total_money - (fives * 5) - (twos * 2) - ones
```

ชุดนี้เป็นวิธีทอนเงินที่ถูกต้องเมื่อครบสองเงื่อนไข

1. `remaining_money >= 0` หมายถึงเหรียญที่เลือกมายังมีมูลค่าไม่เกิน `N`
2. `remaining_money % 10 == 0` หมายถึงเงินที่เหลือหารด้วย `10` ลงตัว

ถ้าผ่านทั้งสองข้อ เงินที่เหลือจะใช้เหรียญ `10` บาทได้พอดีจำนวน
`remaining_money // 10` เหรียญ โปรแกรมจึงเพิ่ม `total_sol_count` อีก `1`

> [!NOTE]
>
> ไม่ต้องจำกัดจำนวนเหรียญ `10` บาท เพราะโจทย์อนุญาตให้ใช้ได้ไม่จำกัด
> และแต่ละชุดของ `fives`, `twos`, `ones` จะกำหนดจำนวนเหรียญ `10`
> บาทได้เพียงค่าเดียว จึงไม่มีการนับวิธีเดิมซ้ำ

---

## ลำดับการทำงานของโปรแกรม

1. รับจำนวนเงิน `N` เป็นจำนวนเต็มเก็บใน `total_money`
2. ลองจำนวนเหรียญ `5`, `2` และ `1` บาททุกค่าตั้งแต่ `0` ถึง `9`
3. คำนวณ `remaining_money` ของแต่ละชุด
4. ถ้าเงินที่เหลือไม่ติดลบและหาร `10` ลงตัว ให้นับเป็นหนึ่งวิธี
5. เมื่อครบทุกชุด แสดง `total_sol_count` เป็นจำนวนเต็มหนึ่งบรรทัด

ตัวอย่างเช่น เมื่อ `N = 1` มีเพียงชุด `ones = 1`, `twos = 0`,
`fives = 0` และเหรียญ `10` บาทจำนวน `0` เหรียญ จึงแสดงผล `1`

---

# Solution

```python
# --------------------------------------------------
# File Name : 2567_1_Q3_C1-S.py
# Problem   : Coin Change
# Author    : Worralop Srichainont
# Date      : 2025-07-29
# --------------------------------------------------

# Coins limit for 1 baht, 2 baht, and 5 baht
COINS_LIMIT = 9

# Initialize the total solution count
total_sol_count = 0

# Input total money
total_money = int(input())

# Loop through all combinations on 5 baht, 2 baht, and 1 baht coins
for fives in range(COINS_LIMIT + 1):
    for twos in range(COINS_LIMIT + 1):
        for ones in range(COINS_LIMIT + 1):
            # Calculate the remaining money after using the coins
            remaining_money = total_money - (fives * 5) - (twos * 2) - ones

            # Check if the remaining money is possible to pay with only 10 baht coins
            if remaining_money >= 0 and remaining_money % 10 == 0:
                total_sol_count += 1

# Output the total solution count
print(total_sol_count)
```
