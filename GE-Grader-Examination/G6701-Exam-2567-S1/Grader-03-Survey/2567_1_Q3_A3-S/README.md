## รูปแบบข้อมูลไพ่

อินพุตหนึ่งบรรทัดแทนไพ่หลายใบ โดยมี `|` คั่น เช่น
`|Q♥|10♦|2♣|3♥|A♣|` ไพ่แต่ละใบประกอบด้วย

-   เลขไพ่ `A`, `2` ถึง `10`, `J`, `Q` หรือ `K`
-   สัญลักษณ์หน้าไพ่หนึ่งตัวเป็นอักขระสุดท้าย

โปรแกรมเตรียมข้อมูลด้วย

```python
cards = input().strip("| ").split("|")
```

`strip("| ")` ตัดขีดแนวตั้งและช่องว่างที่หัวหรือท้ายบรรทัด
จากนั้น `split("|")` แยกข้อความที่เหลือเป็นลิสต์ของไพ่ทีละใบ

---

## การแยกเลขไพ่กับหน้าไพ่

ภายในลูป ตัวแปร `card` ยังมีทั้งเลขไพ่และหน้าไพ่ เช่น `"10♥"`
คำสั่ง

```python
card = card[:-1]
```

เลือกทุกอักขระยกเว้นตัวสุดท้าย จึงตัดหน้าไพ่ออกและเหลือเฉพาะ `"10"`
วิธีนี้รองรับทั้งเลขไพ่หนึ่งตัวและ `10` ที่มีสองตัวอักษร เพราะตัดจากด้านท้ายเสมอ

หน้าไพ่ไม่มีผลต่อคะแนน จึงไม่จำเป็นต้องแยกว่าเป็นโพดำ โพแดง
ข้าวหลามตัด หรือดอกจิก

---

## การคิดคะแนน

หลังตัดหน้าไพ่ออก โปรแกรมให้คะแนนตามเลขไพ่

| เลขไพ่ | คะแนนต่อใบ | เงื่อนไขใน Python |
|:---:|---:|:---|
| `A` | 1 | `card == "A"` |
| `K`, `Q`, `J` | 10 | `card in ["K", "Q", "J"]` |
| `2` ถึง `10` | เท่ากับตัวเลข | `int(card)` |

คะแนนของแต่ละใบถูกบวกสะสมใน `score` ไพ่ที่มีเลขและหน้าเหมือนกันสามารถซ้ำได้
และทุกใบที่ปรากฏจะถูกนำมาคิดคะแนนแยกกัน

ตัวอย่าง `|Q♥|10♦|2♣|3♥|A♣|` ให้คะแนน
$10+10+2+3+1=26$

## ลำดับการทำงานและผลลัพธ์

1. ตัดเครื่องหมายรอบนอกและแบ่งอินพุตเป็นไพ่แต่ละใบ
2. เดินไพ่จากซ้ายไปขวา
3. ตัดหน้าไพ่ แล้วแปลงเลขไพ่เป็นคะแนน
4. บวกคะแนนเข้า `score`
5. แสดงคะแนนรวมเป็นจำนวนเต็มหนึ่งค่า

ลำดับไพ่ไม่มีผลต่อผลบวก แต่โปรแกรมยังประมวลผลทุกใบตามลำดับอินพุต
และไม่ลบไพ่ซ้ำ

# Solution

```python
# --------------------------------------------------
# File Name : 2567_1_Q3_A3-S.py
# Problem   : Card Score
# Author    : Worralop Srichainont
# Date      : 2025-07-28
# --------------------------------------------------

# Input cards as a list.
cards = input().strip("| ").split("|")

# Initialize score to 0
score = 0

# Convert each card to its score and sum them up.
for card in cards:
    # Remove any symbol at the end from the card.
    card = card[:-1]

    # Determine the score based on the card value.
    if card == "A":
        score += 1
    elif card in ["K", "Q", "J"]:
        score += 10
    else:
        score += int(card)

# Output the the total score.
print(score)
```
