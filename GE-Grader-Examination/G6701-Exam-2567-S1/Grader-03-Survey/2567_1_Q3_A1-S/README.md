## การแปลผังงานเป็นโปรแกรม

โปรแกรมรับจำนวนเต็ม `a`, `b`, `c` และ `d` จากบรรทัดเดียวตามลำดับ
จากนั้นแยกเส้นทางหลักด้วยเงื่อนไข `a == 1`

การกำหนดค่าแบบย่อที่พบในโปรแกรมมีความหมายดังนี้

-   `b += 1` เท่ากับ `b = b + 1`
-   `c += c + d` เท่ากับ `c = c + (c + d)`
-   `c += c * d` เท่ากับ `c = c + (c * d)`
-   `c += c % d` เท่ากับ `c = c + (c % d)` โดย `%` คือเศษจากการหาร

ค่าด้านขวาถูกคำนวณจากค่าปัจจุบันก่อน แล้วจึงนำผลกลับไปเก็บในตัวแปรเดิม

---

## กรณี a เท่ากับ 1

โปรแกรมเปลี่ยน `a` ก่อนด้วย `a = b + c + d` แล้วพิจารณา `b`

-   ถ้า `b == 1` จะทำ `c += c + d` แล้วไม่เข้าส่วน `else`
-   ถ้า `b != 1` จะตรวจ `b > 4` และ `b > 5` แยกจากกัน
    -   เมื่อ `b <= 4` ค่า `c` ไม่เปลี่ยน
    -   เมื่อ `b == 5` ทำเฉพาะ `c += c * d`
    -   เมื่อ `b > 5` ทำทั้งสองคำสั่งตามลำดับ โดย `c % d` ใช้ค่า `c`
        ที่อัปเดตจากคำสั่งแรกแล้ว

> [!WARNING]
>
> เงื่อนไข `b > 4` และ `b > 5` เป็น `if` สองตัวที่เป็นอิสระต่อกัน
> ไม่ใช่ `if`/`elif` ดังนั้นเมื่อ `b > 5` ต้องทำทั้งสองส่วน

ตัวอย่าง `a b c d` เป็น `1 6 9 5`

1. เปลี่ยน `a` เป็น $6+9+5=20$
2. เพราะ `6 > 4` จึงเปลี่ยน `c` เป็น $9+9\times5=54$
3. เพราะ `6 > 5` ด้วย จึงเปลี่ยน `c` เป็น $54+(54\bmod5)=58$

เส้นทางนี้มี `print(c)` อยู่ภายใน จึงแสดง `58` ก่อนบรรทัดสรุปค่าทั้งสี่ตัว

## กรณี a ไม่เท่ากับ 1

เมื่อ `a != 1` โปรแกรมเพิ่ม `b` ทีละ `1` ตราบใดที่ `b < c`
หลังเพิ่มแต่ละครั้งจะตรวจ `b > a`

-   ถ้าเป็นจริง `break` จะหยุดเฉพาะลูป `while` ทันที
-   ถ้าไม่เป็นจริง ลูปจะกลับไปตรวจ `b < c` อีกครั้ง

ดังนั้นลูปหยุดได้สองแบบ คือ `b` เพิ่มจนไม่น้อยกว่า `c`
หรือ `b` เพิ่มจนมากกว่า `a` แล้วพบ `break` ตัวแปร `a`, `c` และ `d`
ไม่ถูกเปลี่ยนในเส้นทางนี้

ตัวอย่าง `2 0 3 6` ทำให้ `b` เพิ่มเป็น `1`, `2` และ `3`
เมื่อเป็น `3` จะมี `b > a` จึงออกจากลูป และได้ค่าท้ายสุด `2 3 3 6`

---

## ลำดับการแสดงผล

-   ถ้า `a` เดิมเท่ากับ `1` จะแสดงสองบรรทัด: ค่า `c` หลังคำนวณก่อน
    แล้วจึงแสดง `a b c d`
-   ถ้า `a` เดิมไม่เท่ากับ `1` จะแสดงเพียงบรรทัด `a b c d`

คำสั่ง `print(a, b, c, d)` อยู่นอก `if`/`else` จึงทำงานเสมอ
และ `print()` คั่นค่าทั้งสี่ด้วยช่องว่างให้อัตโนมัติ

# Solution

```python
# --------------------------------------------------
# File Name : 2567_1_Q3_A1-S.py
# Problem   : Flowchart
# Author    : Worralop Srichainont
# Date      : 2025-07-28
# --------------------------------------------------

a, b, c, d = [int(e) for e in input().split()]

if a == 1:
    a = b + c + d
    if b == 1:
        c += c + d
    else:
        if b > 4:
            c += c * d
        if b > 5:
            c += c % d
    print(c)
else:
    while b < c:
        b += 1
        if b > a:
            break
print(a, b, c, d)
```
