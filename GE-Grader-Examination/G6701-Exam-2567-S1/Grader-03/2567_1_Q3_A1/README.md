## ภาพรวมการทำงาน

โจทย์ให้แปลงผังงานเป็นโปรแกรม โดยรับจำนวนเต็ม `a`, `b`, `c` และ `d`
จากบรรทัดเดียว จากนั้นเลือกเส้นทางหลักด้วยเงื่อนไข `a > 1`

-   ถ้าเป็นจริง โปรแกรมจะทำงานในลูปที่เปลี่ยนค่า `b` และ `c`
-   ถ้าเป็นเท็จ หรือ `a <= 1` โปรแกรมจะคำนวณ `a` ใหม่ แล้วเลือกสูตรตามช่วงของ
    `b`

ค่าของตัวแปรถูกแก้ไขระหว่างทาง ดังนั้นทุกเงื่อนไขต้องใช้ **ค่าปัจจุบัน**
ของตัวแปร ณ จุดนั้น

---

## เส้นทางที่หนึ่ง

เมื่อ `a > 1` โปรแกรมทำลูป `while b < d` โดยแต่ละรอบมีลำดับดังนี้

1. เพิ่ม `b` ก่อนหนึ่งหน่วยด้วย `b = b + 1`
2. ตรวจค่า `b` ที่เพิ่มแล้ว
3. ถ้า `b > c` ให้เพิ่ม `c` อีก `3` ด้วย `c = c + 3`
4. ถ้า `b <= c` ให้ใช้ `break` ออกจากลูปทันที

จุดสำคัญคือโปรแกรมตรวจ `b > c` **หลังจาก** เพิ่ม `b` แล้ว และ `break`
ออกเฉพาะลูป `while` จากนั้นยังไปแสดง `a b c d` ที่บรรทัดสุดท้ายเสมอ

ตัวอย่างอินพุต `2 4 6 8` เริ่มจาก `b < d` จึงเพิ่ม `b` เป็น `5`
แต่ `5 > 6` เป็นเท็จ ลูปจบด้วย `break` และแสดงผล `2 5 6 8`

## เส้นทางที่สอง

เมื่อ `a <= 1` คำสั่งแรกคือ

$$
a = b + c + d
$$

ซึ่งตรงกับ `a = b + c + d` ใน Python จากนั้นแบ่งตามค่า `b` เดิมเป็นช่วงต่าง ๆ

### กรณี `b > 7`

-   ถ้า `7 < b <= 9` ให้คำนวณ `c = 3 * d`
-   ถ้า `b > 9` ให้เริ่มจาก `c = (2 * d) + 2`
    -   ถ้า `b > 12` ให้เขียนทับ `c` ด้วย `c = 4 * d`
    -   ถ้า `b > 15` ให้คำนวณ `d = c - a`
    -   มิฉะนั้นให้คำนวณ `d = c + (2 * a)`

เงื่อนไข `b > 12` และ `b > 15` เป็นการตรวจคนละขั้น จึงต้องรักษาลำดับนี้ไว้
โดยเฉพาะเมื่อ `b > 15` ทั้งสองเงื่อนไขจะเป็นจริง

### กรณี `b <= 7`

-   ถ้า `b > 5` ให้ `b = c + d`
-   ถ้า `2 < b <= 5` ให้ `b = 2 * c`
-   ถ้า `b <= 2` ให้ `b = c - d`

## ลำดับการแสดงผล

โปรแกรมอาจแสดงหนึ่งหรือสองบรรทัด ขึ้นอยู่กับเส้นทางที่ผ่าน

-   เมื่อ `a > 1` จะแสดงเฉพาะบรรทัดสุดท้าย `a b c d`
-   เมื่อค่า `a` เดิมไม่เกิน `1` และ `b > 9` จะแสดง `c d` ก่อน
-   เมื่อค่า `a` เดิมไม่เกิน `1` และ `b <= 7` จะแสดง `a b` ก่อน
-   ช่วง `7 < b <= 9` ไม่มีผลลัพธ์ระหว่างทาง
-   หลังจบทุกเส้นทางจะแสดงค่าปัจจุบันของ `a b c d` เสมอ

จึงต้องเรียงคำสั่ง `print()` ตามผังงาน ไม่สามารถรวมผลลัพธ์ทั้งหมดเป็นบรรทัดเดียวได้

## ตัวอย่างการไล่ค่า

สำหรับอินพุต `-5 13 -9 1`

1. `a <= 1` จึงคำนวณ `a = 13 + (-9) + 1 = 5`
2. `b > 9` จึงได้ `c = (2 * 1) + 2 = 4`
3. `b > 12` เป็นจริง จึงเขียนทับ `c = 4 * 1 = 4`
4. `b > 15` เป็นเท็จ จึงได้ `d = 4 + (2 * 5) = 14`
5. แสดง `4 14` จาก `print(c, d)` แล้วแสดง `5 13 4 14` จาก
   `print(a, b, c, d)`

# Solution

```python
# --------------------------------------------------
# File Name : 2567_1_Q3_A1.py
# Problem   : Flowchart
# Author    : Worralop Srichainont
# Date      : 2025-07-28
# --------------------------------------------------

a, b, c, d = [int(e) for e in input().split()]
if a > 1:
    while b < d:
        b = b + 1
        if b > c:
            c = c + 3
        else:
            break
else:
    a = b + c + d
    if b > 7:
        if b > 9:
            c = (2 * d) + 2
            if b > 12:
                c = 4 * d
            if b > 15:
                d = c - a
            else:
                d = c + (2 * a)
            print(c, d)
        else:
            c = 3 * d
    else:
        if b > 5:
            b = c + d
        else:
            if b > 2:
                b = 2 * c
            else:
                b = c - d
        print(a, b)
print(a, b, c, d)
```
