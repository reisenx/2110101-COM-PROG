## การแยกทางเดินของผังงาน

โปรแกรมรับจำนวนเต็ม `a`, `b`, `c` และ `d` จากบรรทัดเดียว แล้วแยกผังงานเป็น
สองทางด้วย `if a == 1` ทางแรกคำนวณค่าใหม่โดยเลือกจากช่วงของ `b` ส่วนอีกทาง
ใช้วงวน `while b < c`

ระดับการเยื้องใน Python บอกว่าเงื่อนไขใดอยู่ภายในเงื่อนไขอื่น จึงต้องอ่านจาก
เงื่อนไขด้านนอกเข้าด้านในตามลำดับ ไม่ควรพิจารณา `if` ทุกบรรทัดแยกจากกัน

## กรณี a เท่ากับ 1

โปรแกรมเปลี่ยน `a` ก่อนด้วย

```python
a = b + c + d
```

บรรทัดนี้ใช้ค่า `b`, `c` และ `d` เดิมจากข้อมูลนำเข้า หลังจากนั้นจึงกำหนดค่า
`c` ใหม่จากช่วงของ `b` และค่า `d` ค่าเดิมของ `c` จะไม่ถูกใช้ในสูตรช่วงนี้

ตัวอย่างอินพุต `1 4 0 7` คำนวณ `a = 4 + 0 + 7 = 11` และเพราะ `b = 4`
จึงกำหนด `c = d = 7` ผลลัพธ์เป็น `11 4 7 7`

## การแบ่งช่วงของ b

เงื่อนไขซ้อนกันแบ่งค่าของ `b` ได้ครบทุกช่วงดังตาราง

| ช่วงของ `b` | ค่าใหม่ของ `c` | Python |
|---:|---:|---|
| `b > 9` | $4d$ | `c = 4 * d` |
| `8 <= b <= 9` | $5d$ | `c = 5 * d` |
| `6 <= b <= 7` | $6d$ | `c = 6 * d` |
| `4 <= b <= 5` | $d$ | `c = d` |
| `1 <= b <= 3` | $2d$ | `c = 2 * d` |
| `b <= 0` | $3d$ | `c = 3 * d` |

เช่น `b = 5` ไม่ผ่าน `b > 5` แต่ผ่าน `b > 3` จึงได้ `c = d` ส่วน
`b = 6` ผ่าน `b > 5` แต่ไม่ผ่าน `b > 9` และ `b > 7` จึงได้ `c = 6 * d`
การตรวจค่าบริเวณขอบเช่น `0`, `3`, `5`, `7` และ `9` ช่วยป้องกันการเลือกช่วงผิด

## กรณี a ไม่เท่ากับ 1

ตราบใดที่ `b < c` โปรแกรมจะทำหนึ่งรอบตามลำดับนี้

1. เพิ่ม `b` ด้วย `b += 1`
2. ตรวจค่า `b` ที่เพิ่มแล้วกับ `a`
3. ถ้า `b > a` ให้เพิ่ม `a` ด้วยค่า `c` ปัจจุบัน
4. ลด `c` ลง `1` ไม่ว่าเงื่อนไข `b > a` จะจริงหรือเท็จ

ส่วนของวงวนในโค้ดจึงเขียนตามลำดับดังนี้

```python
b += 1
if b > a:
    a += c
    c -= 1
else:
    c -= 1
```

โค้ดใน Solution เขียน `c -= 1` ไว้ทั้งแขน `if` และ `else` ซึ่งให้พฤติกรรม
เดียวกัน ลำดับยังมีความสำคัญ เพราะเมื่อเงื่อนไขเป็นจริง `a += c` ใช้ค่า `c`
**ก่อน** ลดลงหนึ่ง

ตัวอย่าง `0 2 4 2` เข้าสู่วงวนหนึ่งรอบ: `b` เปลี่ยนเป็น `3`, เงื่อนไข
`3 > 0` เป็นจริงจึงได้ `a = 0 + 4 = 4` แล้ว `c` ลดเป็น `3` ตอนนี้
`b < c` เป็นเท็จ ผลลัพธ์จึงเป็น `4 3 3 2`

## การสิ้นสุดและผลลัพธ์

ทุกครั้งที่วน `b` เพิ่มขึ้น `1` และ `c` ลดลง `1` ทำให้ทั้งสองค่าเข้าใกล้กัน
วงวนหยุดเมื่อ `b < c` เป็นเท็จ หรือก็คือ `b >= c` หากข้อมูลเริ่มต้นมี
`b >= c` อยู่แล้ว วงวนจะไม่ทำงานเลย

หลังจบทางเดินใดก็ตาม โปรแกรมแสดง `a`, `b`, `c`, `d` ตามลำดับในบรรทัดเดียว
ด้วย `print(a, b, c, d)` โดย `print` ใส่ช่องว่างคั่นค่าให้อัตโนมัติ และตัวแปร
`d` ไม่ถูกเปลี่ยนในทุกกรณี

# Solution

```python
# --------------------------------------------------
# File Name : 2567_1_Q2_A1.py
# Problem   : Flowchart
# Author    : Worralop Srichainont
# Date      : 2025-07-28
# --------------------------------------------------

a, b, c, d = [int(e) for e in input().split()]
if a == 1:
    a = b + c + d
    if b > 5:
        if b > 9:
            c = 4 * d
        else:
            if b > 7:
                c = 5 * d
            else:
                c = 6 * d
    else:
        if b > 3:
            c = d
        else:
            if b > 0:
                c = 2 * d
            else:
                c = 3 * d
else:
    while b < c:
        b += 1
        if b > a:
            a += c
            c -= 1
        else:
            c -= 1
print(a, b, c, d)
```
