## การเตรียมอัตราผลตอบแทน

สินค้ามี 4 ชนิด และสี่บรรทัดแรกให้อัตราผลตอบแทนของสินค้าชนิดที่ `1` ถึง
`4` ตามลำดับ ค่าในข้อมูลเข้าเป็น **เปอร์เซ็นต์** จึงต้องหารด้วย `100`
ก่อนนำไปคูณกับยอดขาย

ตัวอย่างเช่น อัตรา `2.4` เปอร์เซ็นต์มีค่าในรูปทศนิยมเป็น

$$
\frac{2.4}{100} = 0.024
$$

ตรงกับ Python คือ `float(input().strip()) / 100` โปรแกรมเก็บค่าทศนิยมทั้งสี่
ไว้ใน `BENEFITS` โดยดัชนี `0`, `1`, `2`, `3` แทนสินค้าชนิดที่ `1`, `2`,
`3`, `4` ตามลำดับ

---

## การอ่านรายการขาย

หลังอัตราผลตอบแทน โปรแกรมรับจำนวนรายการขาย `n` แล้วอ่านข้อมูลอีก `n` บรรทัด
แต่ละบรรทัดมีสามส่วน

```text
วันเดือนปี ชนิดสินค้า ยอดขาย
```

หลัง `split()` จะได้ `data[0]` เป็นวันที่, `data[1]` เป็นชนิดสินค้า และ
`data[2]` เป็นยอดขาย โจทย์นี้ใช้วันที่เป็นข้อมูลประกอบเท่านั้น
การคำนวณจึงอ่านแต่ไม่ได้นำ `data[0]` ไปใช้

ชนิดสินค้าในข้อมูลเข้าเริ่มนับจาก `1` แต่ดัชนีของ list เริ่มจาก `0`
โปรแกรมจึงแปลงด้วย

```python
type = int(data[1]) - 1
```

เช่น สินค้าชนิดที่ `1` ใช้ `BENEFITS[0]` และสินค้าชนิดที่ `4` ใช้
`BENEFITS[3]`

> [!WARNING]
>
> อย่าลืมลบ `1` จากชนิดสินค้าก่อนใช้เป็นดัชนี มิฉะนั้นจะเลือกอัตราผิดชนิด
> และสินค้าชนิดที่ `4` จะพยายามเข้าถึงดัชนีที่ไม่มีอยู่

## สูตรคำนวณผลตอบแทน

ถ้าสินค้าชนิด $t$ มีอัตราผลตอบแทน $p_t$ เปอร์เซ็นต์ และมียอดขาย
$s$ ผลตอบแทนของรายการนั้นคือ

$$
benefit = \frac{p_t}{100} \times s
$$

เนื่องจาก `BENEFITS[type]` ถูกหารด้วย `100` ไว้แล้ว Python จึงคำนวณด้วย

```python
total_benefit += BENEFITS[type] * sales
```

เครื่องหมาย `+=` ทำให้ผลตอบแทนของรายการขายทุกวันและทุกชนิดถูกสะสมเข้า
`total_benefit` รายการสินค้าชนิดเดิมที่เกิดหลายครั้งจึงถูกนำมารวมทุกครั้ง

ตัวอย่างเช่น อัตราสินค้าชนิดที่ `2` เท่ากับ `5%` และยอดขาย `20,000`
บาท จะเพิ่มผลตอบแทน `0.05 * 20000 = 1000` บาท

---

## การปัดเศษและรูปแบบผลลัพธ์

โปรแกรมเก็บและรวมยอดขายด้วย `float` แล้วปัดเศษ **เพียงครั้งเดียวหลังรวมครบทุก
รายการ** ด้วย `round(total_benefit, 2)` การปัดผลตอบแทนทีละรายการอาจทำให้
ผลรวมต่างออกไป จึงต้องรักษาลำดับนี้

`round(x, 2)` หมายถึงแสดงค่าไม่เกิน 2 ตำแหน่งหลังจุดทศนิยม แต่ไม่ได้บังคับให้มี
ครบ 2 ตำแหน่งเสมอ ตัวอย่างเช่นผลรวมอาจแสดงเป็น `4950.0` แทน `4950.00`

ผลลัพธ์มีหนึ่งบรรทัด เป็นผลตอบแทนรวมที่ปัดด้วยกติกาของ `round()` ใน Python

---

# Solution

```python
# --------------------------------------------------
# File Name : 2567_1_Q4_A2-S.py
# Problem   : Sales Revenue
# Author    : Worralop Srichainont
# Date      : 2025-07-29
# --------------------------------------------------

# Input benefits percentage for each type
BENEFITS = [0.0, 0.0, 0.0, 0.0]
for i in range(4):
    BENEFITS[i] = float(input().strip()) / 100

# Initialize total benefit money
total_benefit = 0.0

# Input sales records
n = int(input().strip())
for _ in range(n):
    # Extract sales type and money gained
    data = input().strip().split()
    type = int(data[1]) - 1
    sales = float(data[2])

    # Calculate benefit for this sale and add to total
    total_benefit += BENEFITS[type] * sales

# Output total benefit rounded to 2 decimal places
print(round(total_benefit, 2))
```
