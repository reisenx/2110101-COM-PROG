## การจับคู่ข้อความกับปุ่มกด

โทรศัพท์แบบปุ่มกดใช้ปุ่มตัวเลขหนึ่งปุ่มแทนตัวอักษรหลายตัว
จำนวนครั้งที่กดจะบอกว่าต้องการตัวอักษรลำดับใดบนปุ่มนั้น เช่น
`a` ใช้ `2`, `b` ใช้ `22` และ `c` ใช้ `222`

| ปุ่ม | ตัวอักษรที่กดได้ | รหัสของตัวอักษร |
|:---:|:---:|:---|
| `2` | `a b c` | `2 22 222` |
| `3` | `d e f` | `3 33 333` |
| `4` | `g h i` | `4 44 444` |
| `5` | `j k l` | `5 55 555` |
| `6` | `m n o` | `6 66 666` |
| `7` | `p q r s` | `7 77 777 7777` |
| `8` | `t u v` | `8 88 888` |
| `9` | `w x y z` | `9 99 999 9999` |
| `0` | ช่องว่าง | `0` |

โจทย์ต้องแปลงข้อมูลได้ทั้งสองทิศทาง จึงสร้าง `dict` สองชุด

-   `TEXT_TO_KEYS` ใช้ตัวอักษรเป็น key และใช้รหัสปุ่มกดเป็น value
-   `KEYS_TO_TEXT` ใช้รหัสปุ่มกดเป็น key และใช้ตัวอักษรเป็น value

การมี `dict` สำหรับแต่ละทิศทางทำให้ค้นหาค่าที่ต้องการได้โดยตรง
โดยไม่ต้องเขียนเงื่อนไขแยกสำหรับตัวอักษรทุกตัว

> [!NOTE]
>
> ช่องว่างที่คั่นรหัสแต่ละชุดกับรหัส `0` มีหน้าที่ต่างกัน
> ช่องว่างเป็นตัวแบ่งว่าการกดของตัวอักษรหนึ่งจบลงแล้ว ส่วน `0`
> แทนช่องว่างที่ต้องปรากฏอยู่จริงในข้อความ

## การแปลงข้อความเป็นปุ่มกด

ฟังก์ชัน `text2keys(text)` เริ่มจากแปลงข้อความเป็นตัวพิมพ์เล็กด้วย
`text.lower()` เพื่อให้ `A` และ `a` ใช้รหัสเดียวกัน
จากนั้นวนดูตัวอักษรทีละตัวตามลำดับเดิม

```python
result = []
for char in text.lower():
    if char in TEXT_TO_KEYS:
        result.append(TEXT_TO_KEYS[char])
```

เงื่อนไข `char in TEXT_TO_KEYS` ทำให้เก็บเฉพาะตัวอักษรภาษาอังกฤษและช่องว่าง
อักขระอื่น เช่น `,`, `.`, `!` หรือตัวเลข จะถูกข้ามไปตามข้อกำหนด
เมื่อเก็บรหัสครบแล้วจึงใช้ `" ".join(result)` เชื่อมรหัสทุกชุดด้วยช่องว่างหนึ่งตัว

ลองพิจารณา `text2keys("I am busy.")`

| อักขระ | หลังแปลงเป็นตัวพิมพ์เล็ก | รหัสที่เก็บ |
|:---:|:---:|:---:|
| `I` | `i` | `444` |
| ช่องว่าง | ช่องว่าง | `0` |
| `a` | `a` | `2` |
| `m` | `m` | `6` |
| ช่องว่าง | ช่องว่าง | `0` |
| `b u s y` | `b u s y` | `22 88 7777 999` |
| `.` | `.` | ไม่เก็บ |

ผลลัพธ์จึงเป็น

```text
444 0 2 6 0 22 88 7777 999
```

ถ้ามีช่องว่างติดกันหลายตัว แต่ละตัวจะถูกแปลงเป็น `0` แยกกัน เช่น
`text2keys("A  B!?")` ได้ `"2 0 0 22"`
และถ้าไม่มีอักขระที่รองรับเลย ฟังก์ชันจะคืนสตริงว่าง `""`

## การแปลงปุ่มกดเป็นข้อความ

ฟังก์ชัน `keys2text(keys)` ทำงานย้อนกลับ โดยใช้ `keys.split()`
แบ่งสตริงออกเป็นรหัสทีละชุด แล้วค้นหาตัวอักษรจาก `KEYS_TO_TEXT`

```python
result = ""
for key in keys.split():
    if key in KEYS_TO_TEXT:
        result += KEYS_TO_TEXT[key]
```

`split()` จะตัดช่องว่างที่ใช้คั่นรหัสออก แต่เมื่อพบ token `"0"`
`dict` จะคืนช่องว่างมาเติมในข้อความ ดังนั้น
`keys2text("444 0 2 6 0 22 88 7777 999")` จึงได้
`"i am busy"`

รหัสที่ไม่มีใน `KEYS_TO_TEXT` จะถูกข้าม เช่น `"99999"`
ไม่แทนตัวอักษรใด ส่วนช่องว่างนำหน้า ช่องว่างท้ายสตริง
หรือช่องว่างคั่นหลายตัวไม่มีผล เพราะ `split()` จะไม่สร้าง token ว่าง

## การรับคำสั่งจาก Grader

โจทย์ไม่ได้รับข้อความสำหรับแปลงโดยตรง แต่รับคำสั่งภาษา Python หนึ่งบรรทัด
เช่น `print(text2keys("I am busy."))` แล้วใช้
`exec(input().strip())` รันคำสั่งนั้น เพื่อให้ Grader เรียกทดสอบฟังก์ชันได้

> [!WARNING]
>
> `exec()` สามารถรันคำสั่ง Python ใด ๆ ที่ได้รับมาได้
> จึงเหมาะกับข้อมูลทดสอบที่เชื่อถือได้จาก Grader เท่านั้น
> ไม่ควรใช้ `exec()` กับข้อความจากผู้ใช้หรือแหล่งที่ไม่น่าเชื่อถือ

# Solution

```python
# --------------------------------------------------
# File Name : 08_Dict_24.py
# Problem   : Texting
# Author    : Worralop Srichainont
# Date      : 2025-06-12
# --------------------------------------------------

# Initialize dictionaries for conversion between keys and text
TEXT_TO_KEYS = {
    " ": "0",
    "a": "2",
    "b": "22",
    "c": "222",
    "d": "3",
    "e": "33",
    "f": "333",
    "g": "4",
    "h": "44",
    "i": "444",
    "j": "5",
    "k": "55",
    "l": "555",
    "m": "6",
    "n": "66",
    "o": "666",
    "p": "7",
    "q": "77",
    "r": "777",
    "s": "7777",
    "t": "8",
    "u": "88",
    "v": "888",
    "w": "9",
    "x": "99",
    "y": "999",
    "z": "9999",
}
KEYS_TO_TEXT = {
    "0": " ",
    "2": "a",
    "22": "b",
    "222": "c",
    "3": "d",
    "33": "e",
    "333": "f",
    "4": "g",
    "44": "h",
    "444": "i",
    "5": "j",
    "55": "k",
    "555": "l",
    "6": "m",
    "66": "n",
    "666": "o",
    "7": "p",
    "77": "q",
    "777": "r",
    "7777": "s",
    "8": "t",
    "88": "u",
    "888": "v",
    "9": "w",
    "99": "x",
    "999": "y",
    "9999": "z",
}


# Function to convert text to keys
def text2keys(text):
    result = []
    for char in text.lower():
        if char in TEXT_TO_KEYS:
            result.append(TEXT_TO_KEYS[char])
    return " ".join(result)


# Function to convert keys to text
def keys2text(keys):
    result = ""
    for key in keys.split():
        if key in KEYS_TO_TEXT:
            result += KEYS_TO_TEXT[key]
    return result


# Execute the input string as code
exec(input().strip())
```
