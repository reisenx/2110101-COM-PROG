## แนวคิดของโจทย์

สตริงสองสตริงเป็น anagram กันเมื่อมีตัวอักษรแต่ละชนิดจำนวนเท่ากัน ส่วนลำดับของตัวอักษรไม่สำคัญ เช่น `listen` กับ `silent` มีตัวอักษรชุดเดียวกัน แม้จะเรียงคนละแบบ

โจทย์ข้อนี้กำหนดเพิ่มเติมว่า

- ตัวพิมพ์เล็กและตัวพิมพ์ใหญ่ถือเป็นตัวเดียวกัน
- อักขระที่ไม่ใช่ตัวอักษร เช่น ช่องว่าง ตัวเลข และเครื่องหมายต่าง ๆ ไม่ต้องนำมาพิจารณา
- ต้องลบตัวอักษรให้น้อยที่สุด เพื่อให้ตัวอักษรที่เหลือของทั้งสองสตริงเป็น anagram กัน

ดังนั้นเราไม่จำเป็นต้องลองลบหรือสลับตัวอักษรจริง ๆ เพียงนับว่าตัวอักษรแต่ละตัวปรากฏกี่ครั้งในแต่ละสตริง แล้วเปรียบเทียบจำนวนก็เพียงพอ

## เตรียมและนับตัวอักษร

โปรแกรมอ่านสตริงสองบรรทัดและเก็บไว้ใน `texts`

```python
texts = []
for _ in range(2):
    texts.append(input().strip())
```

`.strip()` ตัดช่องว่างที่หัวและท้ายบรรทัดออก จากนั้นโปรแกรมสร้าง dictionary สองตัวไว้ในลิสต์ `char_counts`

```python
char_counts = [{}, {}]
```

- `char_counts[0]` เก็บจำนวนตัวอักษรของสตริงแรก
- `char_counts[1]` เก็บจำนวนตัวอักษรของสตริงที่สอง

ระหว่างนับ โปรแกรมใช้ `.lower()` ทำให้ตัวอักษรเป็นตัวพิมพ์เล็ก และใช้ `.isalpha()` เลือกเฉพาะตัวอักษร

```python
for char in texts[i].lower():
    if char.isalpha() and char not in char_counts[i]:
        char_counts[i][char] = 1
    elif char.isalpha() and char in char_counts[i]:
        char_counts[i][char] += 1
```

ถ้ายังไม่มี `char` เป็น key ใน dictionary จะเริ่มนับที่ 1 แต่ถ้ามีอยู่แล้วจะเพิ่มค่าอีก 1 ส่วนอักขระที่ `.isalpha()` ให้ค่า `False` จะไม่เข้าเงื่อนไขใดเลย

ตัวอย่าง `"Debit card!!!"` เมื่อนำตัวพิมพ์ใหญ่เล็กและเครื่องหมายออกจากการพิจารณา จะนับเหมือนข้อความ `"debitcard"`

## หาตัวอักษรที่ต้องลบน้อยที่สุด

สมมติว่าตัวอักษร $c$ ปรากฏในสตริงแรก $A_c$ ครั้ง และในสตริงที่สอง $B_c$ ครั้ง ทั้งสองสตริงสามารถเก็บตัวอักษรนี้ร่วมกันได้เพียง

$$
\min(A_c, B_c)
$$

ครั้ง ส่วนที่เกินมาของแต่ละฝั่งต้องถูกลบ ดังนั้น

$$
\text{จำนวนที่ลบจากสตริงแรก}
= \max(A_c-B_c, 0)
$$

$$
\text{จำนวนที่ลบจากสตริงที่สอง}
= \max(B_c-A_c, 0)
$$

นี่เป็นจำนวนลบน้อยที่สุด เพราะถ้าเก็บตัวอักษรที่เกินไว้ จำนวนตัวอักษรของสองฝั่งจะยังไม่เท่ากัน แต่ถ้าลบมากกว่านี้ก็เป็นการลบโดยไม่จำเป็น

โปรแกรมพิจารณาทีละสตริงด้วยตัวแปร `i` และใช้ `1 - i` แทนดัชนีของอีกสตริง

| `i` | สตริงปัจจุบัน | `1 - i` | อีกสตริง |
|:---:|:---:|:---:|:---:|
| `0` | สตริงแรก | `1` | สตริงที่สอง |
| `1` | สตริงที่สอง | `0` | สตริงแรก |

ถ้าตัวอักษรมีอยู่ทั้งสองฝั่ง โปรแกรมหาผลต่าง

```python
diff = count - char_counts[1 - i][char]
if diff > 0:
    remove_chars[i][char] = diff
```

ถ้าผลต่างไม่เป็นบวก แสดงว่าสตริงปัจจุบันไม่มีตัวอักษรส่วนเกิน จึงไม่ต้องบันทึกการลบ แต่ถ้าตัวอักษรไม่มีในอีกสตริงเลย จำนวนทั้งหมดของตัวอักษรนั้นต้องถูกลบ

```python
remove_chars[i][char] = count
```

`remove_chars` จึงเป็นลิสต์ที่มี dictionary สองตัว แต่ละ dictionary เก็บคู่ `ตัวอักษร: จำนวนที่ต้องลบ` ของสตริงหนึ่งบรรทัด

## ตัวอย่างการคำนวณ

ให้สตริงสองบรรทัดเป็น

```text
XxYZzZ
ZYYXyyy
```

หลังเปลี่ยนเป็นตัวพิมพ์เล็กและนับเฉพาะตัวอักษร จะได้

| ตัวอักษร | สตริงแรก | สตริงที่สอง | ลบจากสตริงแรก | ลบจากสตริงที่สอง |
|:---:|---:|---:|---:|---:|
| `x` | 2 | 1 | 1 | 0 |
| `y` | 1 | 5 | 0 | 4 |
| `z` | 3 | 1 | 2 | 0 |

เมื่อลบตามตาราง ทั้งสองฝั่งจะเหลือ `x`, `y` และ `z` อย่างละหนึ่งตัว จึงนำไปสลับลำดับให้เหมือนกันได้ และไม่มีวิธีที่ใช้จำนวนการลบน้อยกว่านี้

## จัดรูปแบบผลลัพธ์

โปรแกรมพิมพ์สตริงเดิมที่ผ่าน `.strip()` ก่อน แล้วพิมพ์รายการตัวอักษรที่ต้องลบ

```python
print(texts[i])
```

รายการถูกเรียงด้วย

```python
sorted(remove_chars[i].items())
```

จึงแสดงตัวอักษรตามลำดับพจนานุกรม ไม่ใช่ตามตำแหน่งที่พบในข้อความ และตัวอักษรที่แสดงเป็นตัวพิมพ์เล็กเพราะนับจาก `texts[i].lower()`

รูปแบบข้อความขึ้นอยู่กับจำนวนที่ต้องลบ

| จำนวน | รูปแบบ | ตัวอย่าง |
|---:|---|---|
| 1 | ไม่มี `'s` ต่อท้าย | ` - remove 1 x` |
| มากกว่า 1 | มี `'s` ต่อท้าย | ` - remove 2 z's` |
| ไม่มีตัวที่ต้องลบ | แสดง `None` | ` - None` |

ช่องว่างหนึ่งช่องที่ต้นบรรทัดก่อน `-` เป็นส่วนหนึ่งของรูปแบบผลลัพธ์

## ลำดับการทำงานของโปรแกรม

1. อ่านสตริงสองบรรทัดเข้า `texts`
2. สร้าง dictionary นับตัวอักษรสำหรับแต่ละบรรทัด
3. เปลี่ยนตัวอักษรเป็นตัวพิมพ์เล็กและข้ามอักขระที่ไม่ใช่ตัวอักษร
4. เปรียบเทียบจำนวนของตัวอักษรทุกตัวกับอีกสตริง
5. เก็บเฉพาะผลต่างที่เป็นบวกลง `remove_chars`
6. พิมพ์สตริงแรกและรายการลบที่เรียงแล้ว
7. พิมพ์สตริงที่สองและรายการลบที่เรียงแล้ว

## ข้อควรระวัง

- ต้องเปรียบเทียบ “จำนวน” ของตัวอักษร ไม่ใช่เพียงตรวจว่าตัวอักษรนั้นมีอยู่หรือไม่
- ต้องใช้ `.lower()` ก่อนนับ เพื่อให้ `A` และ `a` เป็นตัวเดียวกัน
- `.isalpha()` ของ Python ยอมรับตัวอักษรในภาษาอื่นด้วย ไม่ได้จำกัดเฉพาะ `A` ถึง `Z`
- เครื่องหมายและตัวเลขไม่ถูกนับ แต่ยังปรากฏในบรรทัดข้อความเดิมที่โปรแกรมพิมพ์
- `.strip()` ทำให้ช่องว่างหัวและท้ายบรรทัดไม่ปรากฏในผลลัพธ์ ขณะที่ช่องว่างภายในยังอยู่
- ถ้าจำนวนตัวอักษรทุกตัวเท่ากันอยู่แล้ว หรือทั้งสองบรรทัดไม่มีตัวอักษรเลย โปรแกรมจะแสดง ` - None` ให้แต่ละบรรทัด

# Solution

```python
# --------------------------------------------------
# File Name : P2_05_Anagram2.py
# Problem   : Part-II Anagram 2
# Author    : Worralop Srichainont
# Date      : 2025-06-17
# --------------------------------------------------

# Input two strings
texts = []
for _ in range(2):
    texts.append(input().strip())

# Initialize dictionaries to count characters in both strings
char_counts = [{}, {}]

# Count characters in both strings
for i in range(2):
    for char in texts[i].lower():
        if char.isalpha() and char not in char_counts[i]:
            char_counts[i][char] = 1
        elif char.isalpha() and char in char_counts[i]:
            char_counts[i][char] += 1

# Initialize lists to store characters to be removed from each string
remove_chars = [{}, {}]

# Compare character counts and determine which characters to remove
for i in range(2):
    for char, count in char_counts[i].items():
        # The character exists in both strings
        if char in char_counts[1 - i]:
            diff = count - char_counts[1 - i][char]
            if diff > 0:
                remove_chars[i][char] = diff
        # The character exists only in the current string
        else:
            remove_chars[i][char] = count

# Output the characters to be removed from each string
for i in range(2):
    # Output the current string
    print(texts[i])
    # Output the characters to be removed
    if len(remove_chars[i]) > 0:
        for char, count in sorted(remove_chars[i].items()):
            if count > 1:
                print(f" - remove {count} {char}'s")
            else:
                print(f" - remove {count} {char}")
    else:
        print(" - None")
```
