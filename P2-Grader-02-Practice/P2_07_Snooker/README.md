## ทำความเข้าใจข้อมูลผลการแทง

โจทย์กำหนดให้ลูกสนุกเกอร์แต่ละสีมีอักษรแทนสีและคะแนนดังนี้

| ลูก | Red | Yellow | Green | Brown | Blue | Pink | Black |
|:---:|:---:|:---:|:---:|:---:|:---:|:---:|:---:|
| อักษร | `R` | `Y` | `G` | `W` | `B` | `P` | `K` |
| คะแนน | 1 | 2 | 3 | 4 | 5 | 6 | 7 |

ข้อมูลผลการแทงหนึ่งบรรทัดมีอักขระ 2 หรือ 3 ตัว โดยอ่านจากซ้ายไปขวา

-   ตัวแรกเป็นหมายเลขผู้เล่น คือ `1` หรือ `2`
-   ตัวที่สองเป็นลูกแรกที่ลงหลุม ถ้าเป็น `X` แปลว่าแทงไม่สำเร็จ
-   ตัวที่สามจะมีเฉพาะเมื่อลูกแรกเป็น `R` และใช้แทนลูกแถมที่ลงหลุม
    ถ้าเป็น `X` แปลว่าลูกแถมไม่ลงหลุม

ตัวอย่างเช่น

| ข้อมูล | ความหมาย | คะแนนที่ได้ |
|:---:|---|---:|
| `1B` | ผู้เล่น 1 แทงลูกสีน้ำเงินลงหลุม | 5 |
| `2X` | ผู้เล่น 2 แทงไม่สำเร็จ | 0 |
| `1RB` | ผู้เล่น 1 แทงลูกแดงและลูกสีน้ำเงินลงหลุม | \(1 + 5 = 6\) |
| `2RX` | ผู้เล่น 2 แทงลูกแดงลงหลุม แต่ลูกแถมไม่ลง | \(1 + 0 = 1\) |

โปรแกรมต้องสะสมคะแนนไปเรื่อย ๆ จนกว่าจะพบการแทงลูกแรกเป็นสีดำ
จากนั้นจึงแสดงคะแนนของผู้เล่น 1 และผู้เล่น 2 ตามลำดับ

## เก็บคะแนนด้วยดิกชันนารี

ผลการแทงหลังหมายเลขผู้เล่นมีรูปแบบอยู่ไม่กี่แบบ
จึงสามารถสร้างดิกชันนารี `SCORES` เพื่อจับคู่ข้อความกับคะแนนได้โดยตรง เช่น

```python
SCORES = {
    "X": 0,
    "B": 5,
    "RX": 1,
    "RB": 6,
    "RK": 8,
}
```

สำหรับผลที่ขึ้นต้นด้วย `R` คะแนนทางคณิตศาสตร์คือ

\[
\text{คะแนนผลการแทง} = 1 + \text{คะแนนของลูกแถม}
\]

เช่น `RB` มีคะแนน \(1 + 5 = 6\) ซึ่งใน Python เตรียมค่าไว้เป็น
`SCORES["RB"] == 6` ส่วน `RX` ได้เฉพาะคะแนนลูกแดง จึงมีค่าเท่ากับ `1`

วิธีนี้ทำให้ตอนประมวลผลไม่ต้องเขียนเงื่อนไขแยกทุกสี เพียงนำข้อความผลการแทง
ไปค้นใน `SCORES` ก็ได้คะแนนที่ต้องบวกทันที

คะแนนรวมของผู้เล่นทั้งสองเก็บไว้ในลิสต์

```python
player_scores = [0, 0]
```

ตำแหน่ง `0` เป็นคะแนนของผู้เล่น 1 และตำแหน่ง `1` เป็นคะแนนของผู้เล่น 2

## แยกผู้เล่นและผลการแทง

เมื่ออ่านข้อมูลหนึ่งบรรทัดมาเก็บใน `data` ตัวอย่างเช่น `"2RP"`
เราจะแยกข้อมูลเป็นสองส่วน

```python
player = int(data[0]) - 1
ball = data[1:]
```

`data[0]` คืออักขระตัวแรก จึงต้องแปลงจากสตริงเป็นจำนวนเต็มด้วย `int()`
จากนั้นลบ `1` เพื่อเปลี่ยนหมายเลขผู้เล่นให้เป็นตำแหน่งในลิสต์

\[
\text{ตำแหน่งในลิสต์} = \text{หมายเลขผู้เล่น} - 1
\]

ซึ่งตรงกับ Python คือ `int(data[0]) - 1` ดังนั้นผู้เล่น 1 ใช้ตำแหน่ง `0`
และผู้เล่น 2 ใช้ตำแหน่ง `1`

ส่วน `data[1:]` ตัดข้อความตั้งแต่ตำแหน่ง `1` จนจบ ทำให้ `"2RP"`
ถูกแยกเป็น `player == 1` และ `ball == "RP"` แล้วจึงสะสมคะแนนด้วย

```python
player_scores[player] += SCORES[ball]
```

## วนรับข้อมูลจนจบเฟรม

โจทย์ไม่ได้บอกจำนวนบรรทัดล่วงหน้า โปรแกรมจึงใช้ `while True`
อ่านและประมวลผลทีละบรรทัด แล้วหยุดเมื่อ `ball == "K"`

ลำดับการทำงานในแต่ละรอบคือ

1.  อ่านข้อมูลและแยกผู้เล่นกับผลการแทง
2.  บวกคะแนนของผลการแทงนั้นให้ผู้เล่น
3.  ตรวจว่าลูกแรกเป็นสีดำหรือไม่ ถ้าใช่จึง `break`

เพราะการบวกคะแนนเกิดก่อน `break` คะแนน 7 แต้มของลูกดำลูกสุดท้าย
จึงถูกรวมอยู่ในคะแนนทั้งหมดด้วย

> [!WARNING]
>
> เฟรมจบเฉพาะเมื่อ `ball == "K"` เท่านั้น กล่าวคือ ลูกแรกเป็นสีดำ
> ข้อมูล `RK` หมายถึงลูกแรกเป็นสีแดงและลูกแถมเป็นสีดำ จึงได้ 8 คะแนน
> แต่เกมยังไม่จบ และเงื่อนไข `ball == "K"` ก็เป็นเท็จสำหรับ `"RK"`

ข้อแตกต่างนี้สำคัญมาก ตัวอย่างของโจทย์จึงสามารถมี `RK` หลายครั้ง
ก่อนจะปิดท้ายด้วย `K` ได้

## สรุปผลการแข่งขัน

เมื่อออกจากลูป โปรแกรมแสดงคะแนนสองค่าในบรรทัดแรก

```python
print(player_scores[0], player_scores[1])
```

`print()` คั่นค่าทั้งสองด้วยช่องว่างหนึ่งช่องตามรูปแบบที่โจทย์ต้องการ
จากนั้นเปรียบเทียบคะแนนเพื่อแสดงบรรทัดที่สองให้ตรงตัวพิมพ์ทุกตัว

-   คะแนนเท่ากัน แสดง `Tie`
-   ผู้เล่น 1 มีคะแนนมากกว่า แสดง `Player 1 wins`
-   นอกเหนือจากนั้น แสดง `Player 2 wins`

โจทย์นี้ไม่มีการปัดเศษ เพราะคะแนนทั้งหมดเป็นจำนวนเต็ม

## ตัวอย่างการทำงาน

จากตัวอย่างที่เสมอกัน ผู้เล่น 1 ได้คะแนนจากผลการแทงดังนี้

\[
6 + 8 + 1 + 2 + 3 + 4 + 5 + 0 = 29
\]

ซึ่งตรงกับ Python ที่นำคะแนนของ `RB`, `RK`, `RX`, `Y`, `G`, `W`, `B`
และ `X` มาบวกตามลำดับ ส่วนผู้เล่น 2 ได้

\[
4 + 7 + 5 + 0 + 6 + 7 = 29
\]

ดังนั้นผลลัพธ์เป็น

```text
29 29
Tie
```

> [!NOTE]
>
> `1RY` กับ `1Y` เป็นคนละผลการแทง: `1RY` ได้ \(1 + 2 = 3\) คะแนน
> แต่ `1Y` ได้ 2 คะแนน ควรอ่านแต่ละตัวอย่างในเอกสารโจทย์อย่างระมัดระวัง

# Solution

```python
# --------------------------------------------------
# File Name : P2_07_Snooker.py
# Problem   : Part-II Snooker
# Author    : Worralop Srichainont
# Date      : 2025-06-17
# --------------------------------------------------

# Initialize the score mapping for snooker balls
SCORES = {
    "X": 0,
    "Y": 2,
    "G": 3,
    "W": 4,
    "B": 5,
    "P": 6,
    "K": 7,
    "RX": 1,
    "RY": 3,
    "RG": 4,
    "RW": 5,
    "RB": 6,
    "RP": 7,
    "RK": 8,
}

# Initialize player scores
player_scores = [0, 0]

# Both players start the game
while True:
    # Read input data
    data = input().strip()
    player = int(data[0]) - 1
    ball = data[1:]
    # Update the score for the current player
    player_scores[player] += SCORES[ball]
    # The game ends when a player pots the black ball
    if ball == "K":
        break

# Output the scores and the winner
print(player_scores[0], player_scores[1])
if player_scores[0] == player_scores[1]:
    print("Tie")
elif player_scores[0] > player_scores[1]:
    print("Player 1 wins")
else:
    print("Player 2 wins")
```
