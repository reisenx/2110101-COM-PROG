## สร้างตารางและหาจุดเริ่มต้น

ฟังก์ชัน `spiral_square(n)` ต้องคืนลิสต์สองมิติขนาด
$n \times n$ โดยโจทย์กำหนดให้ `n` เป็นจำนวนเต็มบวกคี่
เริ่มจากสร้างตารางที่ทุกช่องเป็น `0`

```python
matrix = [[0] * n for _ in range(n)]
```

`for _ in range(n)` ทำให้แต่ละแถวเป็นลิสต์คนละตัว
จึงแก้ไขช่องหนึ่งได้โดยไม่ทำให้ช่องในแถวอื่นเปลี่ยนตาม

เพราะ `n` เป็นจำนวนคี่ ตารางจึงมีช่องกึ่งกลางเพียงช่องเดียว
ตำแหน่งนั้นหาได้จาก

$$
row = col = \left\lfloor\frac{n}{2}\right\rfloor
$$

ซึ่งเขียนใน Python เป็น

```python
row = n // 2
col = n // 2
matrix[row][col] = 1
```

ตัวอย่างเช่น เมื่อ `n = 7` จุดเริ่มต้นคือ `(3, 3)`
เพราะดัชนีของทั้งแถวและคอลัมน์เริ่มนับจาก `0`

## กำหนดทิศทางด้วยพิกัด

ในลิสต์สองมิติ ดัชนีแถวเพิ่มขึ้นเมื่อเลื่อนลง
และดัชนีคอลัมน์เพิ่มขึ้นเมื่อเลื่อนไปทางขวา
โค้ดจึงแทนการเคลื่อนที่แต่ละทิศด้วยคู่ `(dr, dc)`

| `mode` | ทิศทาง | `(dr, dc)` | การเปลี่ยนพิกัด |
| :-: | :-- | :-: | :-- |
| `0` | ขวา | `(0, 1)` | คอลัมน์เพิ่มขึ้น 1 |
| `1` | ขึ้น | `(-1, 0)` | แถวลดลง 1 |
| `2` | ซ้าย | `(0, -1)` | คอลัมน์ลดลง 1 |
| `3` | ลง | `(1, 0)` | แถวเพิ่มขึ้น 1 |

```python
DIRECTIONS = ((0, 1), (-1, 0), (0, -1), (1, 0))

row += DIRECTIONS[mode][0]
col += DIRECTIONS[mode][1]
```

หลังเดินครบหนึ่งแขนของก้นหอย โปรแกรมเปลี่ยนไปใช้ทิศถัดไปด้วย

```python
mode = (mode + 1) % 4
```

เครื่องหมาย `%` ทำให้ค่าหลัง `3` วนกลับเป็น `0`
ลำดับทิศจึงวนเป็น ขวา → ขึ้น → ซ้าย → ลง → ขวา ไปเรื่อย ๆ

## เติมตัวเลขเป็นก้นหอย

ตัวแปร `num` เริ่มที่ `1` ตรงกลางตาราง
ทุกครั้งที่ขยับไปช่องใหม่ โปรแกรมเพิ่ม `num` ก่อน
แล้วจึงเก็บค่าลงใน `matrix[row][col]`

ความยาวของแขนก้นหอยเพิ่มเป็น
`1, 1, 2, 2, 3, 3, ...`
ดังนั้นในแต่ละค่า `step` โค้ดจึงเดินสองแขนที่ยาวเท่ากัน
และเปลี่ยนทิศหลังจบแต่ละแขน ลูป
`for step in range(1, n)` ทำให้ `step` มีค่าตั้งแต่ `1`
ถึง `n - 1` ตามลำดับ

เมื่อ `n = 3` ลำดับการเดินเป็นดังนี้

1. เริ่มด้วย `1` ตรงกลาง
2. เดินขวา 1 ช่อง ได้ `2`
3. เดินขึ้น 1 ช่อง ได้ `3`
4. เดินซ้าย 2 ช่อง ได้ `4, 5`
5. เดินลง 2 ช่อง ได้ `6, 7`
6. เดินขวาอีก `n - 1 = 2` ช่อง ได้ `8, 9`

แขนสุดท้ายในขั้นตอนที่ 6 เติมแถวล่างของตารางให้ครบ
จึงได้ผลลัพธ์

```text
5 4 3
6 1 2
7 8 9
```

## ทำไมจึงเติมครบทุกช่อง

เริ่มต้นมีเลข `1` อยู่แล้วหนึ่งช่อง ลูปหลักเดินสองแขน
สำหรับทุกความยาวตั้งแต่ `1` ถึง `n - 1`
และลูปสุดท้ายเดินเพิ่มอีก `n - 1` ช่อง จำนวนช่องทั้งหมดจึงเป็น

$$
1 + 2\sum_{k=1}^{n-1}k + (n-1)
= 1 + n(n-1) + (n-1)
= n^2
$$

สูตรเดียวกันเขียนเป็น Python ได้ว่า

```python
1 + 2 * sum(range(1, n)) + (n - 1) == n**2
```

เมื่อ `n = 1` ลูปทั้งสองส่วนไม่เดินเลย ตารางจึงเป็น `[[1]]`
และยังมีครบ $1^2$ ช่อง

โค้ดไม่ได้ตรวจว่า `n` เป็นจำนวนเต็มบวกคี่หรือไม่
จึงต้องเรียกฟังก์ชันด้วยค่าที่ตรงตามเงื่อนไขของโจทย์
ค่า `0`, ค่าติดลบ หรือจำนวนคู่เป็นข้อมูลนอกขอบเขต
และอาจทำให้เข้าถึงตำแหน่งนอกตาราง

## จัดรูปแบบผลลัพธ์

`print_square()` แสดงตารางจากแถวบนลงแถวล่าง
และจากซ้ายไปขวา โดยแปลงแต่ละจำนวนเป็นข้อความด้วย

```python
f"  {num}"[-3:]
```

ขั้นแรกเติมช่องว่างสองตัวด้านหน้า แล้วใช้ `[-3:]`
เลือกอักขระสามตัวสุดท้าย

| `num` | หลังเติมช่องว่าง | ผลจาก `[-3:]` |
| --: | :--: | :--: |
| `7` | `"  7"` | `"  7"` |
| `42` | `"  42"` | `" 42"` |
| `315` | `"  315"` | `"315"` |
| `1000` | `"  1000"` | `"000"` |

จากนั้น `" ".join(...)` ใส่ช่องว่างอีกหนึ่งตัวระหว่างช่องของตาราง
ค่าที่มีไม่เกินสามหลักจึงเรียงเป็นคอลัมน์กว้างสามอักขระ
โดยไม่มีการปัดเศษ

อย่างไรก็ตาม `[-3:]` จะตัดหลักด้านหน้าของค่าที่มีมากกว่าสามหลักจริง ๆ
ดังตัวอย่าง `1000` ด้านบน โจทย์ไม่ได้ระบุขอบเขตบนของ `n`
จึงควรอธิบายพฤติกรรมนี้ตามโค้ด โดยไม่ตีความว่าเป็นการปัดเศษ

## รับคำสั่งทดสอบจาก Grader

ข้อมูลนำเข้าของข้อนี้ไม่ใช่ตัวเลข `n` โดยตรง
แต่เป็นคำสั่ง Python หนึ่งบรรทัดที่ Grader ใช้เรียกฟังก์ชัน
เช่น

```text
print_square(spiral_square(3))
```

`spiral_square()` มีหน้าที่คืนตาราง ส่วน `print_square()`
มีหน้าที่แสดงตาราง คำสั่งตัวอย่างจึงแสดงผลเป็น

```text
  5   4   3
  6   1   2
  7   8   9
```

บรรทัดสุดท้ายของโปรแกรมใช้ `exec(input().strip())`
เพื่อทำงานตามคำสั่งทดสอบที่ได้รับ

> [!WARNING]
>
> `exec()` สามารถรันคำสั่ง Python ใด ๆ ได้ จึงเหมาะเฉพาะกรณีนี้
> ที่ข้อมูลมาจาก Grader ที่เชื่อถือได้ ห้ามใช้ `exec()`
> กับข้อความจากผู้ใช้หรือแหล่งที่ไม่เชื่อถือ

# Solution

```python
# --------------------------------------------------
# File Name : P3_05_Spiral.py
# Problem   : Part-III Spiral Square
# Author    : Worralop Srichainont
# Date      : 2025-08-09
# --------------------------------------------------

# List of directions to move in the spiral
# Order: Right, Up, Left, Down
DIRECTIONS = ((0, 1), (-1, 0), (0, -1), (1, 0))


# Generate an n x n spiral matrix
def spiral_square(n):
    # Create an n x n matrix filled with zeros
    matrix = [[0] * n for _ in range(n)]

    # Initialize the first number and the direction mode
    num = 1
    mode = 0

    # Starting position at the center of the matrix
    row = n // 2
    col = n // 2
    matrix[row][col] = num

    # Iterate from 1 to n-1 to define the length of each spiral arm
    for step in range(1, n):
        # Move in the current direction for 'step' times
        for _ in range(step):
            num += 1
            row += DIRECTIONS[mode][0]
            col += DIRECTIONS[mode][1]
            matrix[row][col] = num

        # Change direction for the next arm of the spiral
        mode = (mode + 1) % 4

        # Move in the current direction for 'step' times
        for _ in range(step):
            num += 1
            row += DIRECTIONS[mode][0]
            col += DIRECTIONS[mode][1]
            matrix[row][col] = num

        # Change direction for the next arm of the spiral
        mode = (mode + 1) % 4

    # Complete the final row of the spiral
    for _ in range(n - 1):
        num += 1
        row += DIRECTIONS[mode][0]
        col += DIRECTIONS[mode][1]
        matrix[row][col] = num

    # Return the completed spiral matrix
    return matrix


# Prints the matrix with formatted spacing.
def print_square(matrix):
    for row in matrix:
        print(" ".join([f"  {num}"[-3:] for num in row]))


# Execute an input string as code
exec(input().strip())
```
