## รูปแบบข้อความในแฟ้ม

โจทย์เก็บข้อความไว้ในแฟ้ม โดยแทนช่องว่างทุกตัวด้วยเครื่องหมายจุด (`.`)
แต่ละบรรทัดในแฟ้มไม่ขึ้นต้นหรือจบด้วยจุด
และโจทย์รับรองว่าไม่มีบรรทัดว่าง

โปรแกรมรับข้อมูล `2` บรรทัด

1.  ชื่อแฟ้มหรือพาธของแฟ้ม
2.  จำนวนเต็มบวก `k < 100` ซึ่งกำหนดความกว้างของผลลัพธ์

บรรทัดแรกของผลลัพธ์เป็นไม้บรรทัดยาว `k` ตำแหน่ง
จากนั้นจึงแสดงข้อความโดยให้แต่ละบรรทัดยาวไม่เกิน `k` ตัวอักษร
และใส่ข้อความให้ได้มากที่สุดโดยไม่ตัดคำกลางคำ

ถ้าข้อความในแฟ้มมีหลายบรรทัด
คำสุดท้ายของบรรทัดเดิมกับคำแรกของบรรทัดใหม่ต้องคั่นด้วยจุดหนึ่งตัว
เช่นข้อมูล

```text
one.two
three.four
```

จะถูกมองต่อเนื่องเป็น `one.two.three.four`
บรรทัดในแฟ้มจึงไม่บังคับให้ผลลัพธ์ขึ้นบรรทัดใหม่ตาม

ไฟล์ตัวอย่างใน repository อยู่ที่ `src/data.txt`, `src/data1.txt`
และ `src/data2.txt` แม้ใน PDF จะแสดงชื่อสั้น ๆ ว่า `data.txt` เป็นต้น
ฟังก์ชัน `open()` จะเปิดพาธตามข้อความที่ผู้ใช้ป้อนโดยตรง

## สร้างบรรทัดบอกตำแหน่ง

ไม้บรรทัดใช้เครื่องหมายขีดเป็นหลัก
และแทนตำแหน่งที่ `10`, `20`, ... ด้วยหมายเลข `1`, `2`, ...
เนื่องจาก `k < 100` หมายเลขเหล่านี้จึงมีเพียงหลักเดียว

แบ่ง `k` ออกเป็นจำนวนช่วงที่ครบ `10` ตัวอักษรและจำนวนที่เหลือได้ด้วย

\[
q=\left\lfloor\frac{k}{10}\right\rfloor
\qquad\text{และ}\qquad
r=k\bmod 10
\]

ใน Python ตรงกับ `limit // 10` และ `limit % 10`
แต่ละช่วงเต็มสร้างจากขีด `9` ตัวตามด้วยหมายเลขของช่วง

```python
for i in range(limit // 10):
    line += f"{'-' * 9}{i + 1}"
line += "-" * (limit % 10)
```

ตัวอย่างไม้บรรทัด

```text
k = 7   -------
k = 10  ---------1
k = 26  ---------1---------2------
```

การหารแบบปัดลงด้วย `//` ใช้เพื่อนับช่วงเต็มเท่านั้น
จึงไม่มีการปัดเศษค่าที่จะแสดงผล

## อ่านแฟ้มและแยกข้อความ

คำสั่ง `with open(filename) as file:` เปิดแฟ้ม
และปิดแฟ้มให้อัตโนมัติเมื่อออกจากบล็อก `with`
โปรแกรมอ่านทีละบรรทัดแล้วใช้

```python
line.strip().split(".")
```

`strip()` ตัดช่องว่างและอักขระขึ้นบรรทัดใหม่ที่ขอบของสตริง
ส่วน `split(".")` แยกข้อความทุกตำแหน่งที่พบจุด
รายการจากทุกบรรทัดถูกนำมาต่อกันด้วย

```python
words += line.strip().split(".")
```

เมื่อนำสมาชิกเหล่านี้กลับมาเชื่อมด้วย `".".join(...)`
Python จะใส่จุดหนึ่งตัวระหว่างสมาชิกทุกคู่
จึงเกิดจุดหนึ่งตัวตรงรอยต่อระหว่างบรรทัดของแฟ้มตามโจทย์

จุดที่ติดกันหลายตัวทำให้ `split()` สร้างสตริงว่างไว้ระหว่างจุด เช่น

```python
"1.22...333".split(".")
# ["1", "22", "", "", "333"]
```

เมื่อนำรายการนี้มา `join` อีกครั้ง สตริงว่างสองตัวจะช่วยรักษาจุดสามตัว
ที่อยู่ภายในข้อความไว้ ดังนั้นแม้ comment ใน Solution จะเรียกรายการนี้ว่า
`words` แต่สมาชิกบางตัวอาจเป็นสตริงว่าง ไม่ได้เป็นคำจริงทุกตัว

## จัดข้อความแบบ Greedy

วิธี **Greedy** คือทดลองเติมข้อความลงในบรรทัดปัจจุบันไปเรื่อย ๆ
ตราบใดที่ยังไม่เกิน `limit` เพื่อให้แต่ละบรรทัดมีข้อความมากที่สุด
โดยใช้ดัชนี `2` ตัว

-   `start` ชี้สมาชิกตัวแรกที่ยังไม่ได้แสดง
-   `end` ชี้ตำแหน่งถัดจากสมาชิกตัวสุดท้ายที่กำลังทดลอง

ช่วง `words[start:end]` จึงใช้ `end` แบบไม่รวมตำแหน่งปลาย
ข้อความที่กำลังทดลองสร้างด้วย

```python
line = ".".join(words[start:end]).strip(".")
```

`strip(".")` ลบเฉพาะจุดที่ต้นและท้าย
แต่ไม่เปลี่ยนจุดที่อยู่ภายในบรรทัด
จากนั้นโปรแกรมเปรียบเทียบ `len(line)` กับ `limit`
โดยนับทั้งตัวอักษรและจุด

ตัวอย่างจาก `data2.txt` เมื่อ `k = 7`
โปรแกรมทดลองเพิ่มข้อความตามลำดับ

```text
1          ยาว 1  ตัวอักษร
1.22       ยาว 4  ตัวอักษร
1.22.22    ยาว 7  ตัวอักษร
1.22.22.1  ยาว 9  ตัวอักษร จึงเกินกำหนด
```

โปรแกรมจึงแสดง `1.22.22` แล้วให้ `1`
ซึ่งเป็นสมาชิกที่ทำให้เกิน ไปเริ่มบรรทัดถัดไป
ขั้นตอนเดียวกันนี้ทำซ้ำจนใช้สมาชิกครบ

ถ้าข้อความที่กำลังทดลองยังไม่เกินกำหนด โปรแกรมเพิ่ม `end`
เพื่อทดลองสมาชิกถัดไป เมื่อ `end > len(words)`
การ slice ยังคงคืนสมาชิกที่เหลือทั้งหมดได้อย่างปลอดภัย
โปรแกรมจึงแสดงบรรทัดสุดท้ายแล้วจบลูป

## จัดการบรรทัดที่เกินกำหนด

เมื่อ `len(line) > limit` โปรแกรมแยกเป็น `2` กรณี

**กรณีที่มีสมาชิกมากกว่าหนึ่งตัว**

สมาชิกตัวล่าสุดเป็นตัวที่ทำให้บรรทัดยาวเกินกำหนด
จึงแสดงเฉพาะช่วงก่อนหน้าด้วย

```python
print(".".join(words[start : end - 1]).strip("."))
start = end - 1
```

จากนั้นเลื่อน `start` ไปยังสมาชิกตัวล่าสุด
เพื่อให้สมาชิกนั้นเป็นตัวแรกของบรรทัดใหม่

**กรณีที่สมาชิกเพียงตัวเดียวยาวเกินกำหนด**

โจทย์ห้ามตัดคำ จึงต้องยอมให้บรรทัดนี้ยาวเกิน `limit`
โปรแกรมแสดงทั้งคำแล้วเลื่อน `start` ผ่านคำนั้น

```python
print(line)
start = end
```

ตัวอย่างเช่น `88888888` ยาว `8` ตัวอักษร
เมื่อ `limit = 7` ก็ยังต้องแสดง `88888888` ทั้งคำ
ส่วนคำที่ยาวเท่ากับ `limit` พอดียังคงอยู่ในกรณีที่ไม่เกินกำหนด

> [!WARNING]
>
> เนื่องจากจุดที่ติดกันสร้างสมาชิกสตริงว่าง
> เมื่อ `limit` เล็กมาก สมาชิกว่างหลายตัวอาจรวมกันเป็นช่วงที่ถูกแสดง
> เช่น Solution กับ `src/data1.txt` และ `k = 1`
> จะแสดงบรรทัดว่างหนึ่งบรรทัดระหว่าง `22` กับ `333`
> นี่คือพฤติกรรมของลูปตามโค้ดจริง แม้โจทย์ไม่ได้ระบุให้เพิ่มบรรทัดว่าง

โปรแกรมอาศัยข้อกำหนดว่า `k` เป็นจำนวนเต็มบวกน้อยกว่า `100`
และพาธของแฟ้มเปิดอ่านได้ จึงไม่มีเงื่อนไขตรวจข้อผิดพลาดสำหรับสองกรณีนี้
การจัดรูปแบบไม่มีการเติมช่องว่าง ไม่มีการปัดเศษ
และไม่แสดงจุดที่ต้นหรือท้ายบรรทัด

# Solution

```python
# --------------------------------------------------
# File Name : P3_03_Text.py
# Problem   : Part-III Text Formatting
# Author    : Worralop Srichainont
# Date      : 2025-06-17
# --------------------------------------------------


# Print a ruler with dashes and numbers
def print_ruler(limit):
    line = ""
    for i in range(limit // 10):
        line += f"{'-' * 9}{i + 1}"
    line += "-" * (limit % 10)
    print(line)


# Extract words from a file and return them as a list
def extract_words_from_file(filename):
    words = []
    with open(filename) as file:
        for line in file:
            words += line.strip().split(".")
    return words


# Input the filename and limit
filename = input().strip()
limit = int(input())

# Output the ruler
print_ruler(limit)
# Extract words from the file
words = extract_words_from_file(filename)

# Initialize start and end indices for word processing
start, end = 0, 0
# Process until all words are processed
while start < len(words):
    # Construct the line from words[start:end]
    line = ".".join(words[start:end]).strip(".")

    # Check if the end index exceeds the length of words
    if end > len(words):
        print(line)
        break

    # If the line exceeds the limit, print the current line and reset start
    if len(line) > limit:
        # Output the line without the last word to fit the limit
        if end - start > 1:
            print(".".join(words[start : end - 1]).strip("."))
            start = end - 1
        # The length of only one word exceeds the limit
        else:
            print(line)
            start = end
    # If the line does not exceed the limit, increment end
    else:
        end += 1
```
