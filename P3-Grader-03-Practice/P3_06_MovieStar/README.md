## กลับมุมมองจากภาพยนตร์เป็นดารา

ข้อมูลแต่ละบรรทัดในโจทย์เริ่มจากชื่อภาพยนตร์
แล้วตามด้วยชื่อนักแสดงนำสองคน แต่ตอนตอบคำถาม
เรารู้ชื่อดาราและต้องการค้นหาภาพยนตร์ทั้งหมดของดาราคนนั้น

ถ้าเก็บข้อมูลตามรูปแบบเดิม จะต้องไล่ตรวจภาพยนตร์ทุกเรื่องในทุกคำถาม
โค้ดจึงกลับมุมมองของข้อมูลเป็น

$$
\texttt{actor\_to\_movies[actor]}
=
[\texttt{movie}_1, \texttt{movie}_2, \ldots]
$$

พจนานุกรมลักษณะนี้เรียกว่า **ดัชนีย้อนกลับ**
เพราะใช้ชื่อดาราเป็นกุญแจเพื่อย้อนกลับไปหารายชื่อภาพยนตร์

ตัวอย่างเช่น ถ้ามีข้อมูล

```text
Movie A, Ann, Bob
Movie B, Ann, Cat
```

ข้อมูลที่ต้องการเก็บคือ

```python
{
    "Ann": ["Movie A", "Movie B"],
    "Bob": ["Movie A"],
    "Cat": ["Movie B"],
}
```

## แยกข้อมูลแต่ละบรรทัด

ข้อมูลนำเข้าบรรทัดแรกคือจำนวนภาพยนตร์ `n`
จากนั้นมีข้อมูลภาพยนตร์ `n` บรรทัด
โค้ดแยกแต่ละบรรทัดด้วยข้อความ `", "`
ซึ่งประกอบด้วยจุลภาคตามด้วยช่องว่างหนึ่งตัว

```python
data = input().strip().split(", ")
movie = data[0].strip()
actors = data[1:]
```

ตำแหน่ง `data[0]` เป็นชื่อภาพยนตร์
และสมาชิกที่เหลือใน `data[1:]` เป็นชื่อดารา
ตามรูปแบบของโจทย์ ลิสต์ `actors` จะมีสองชื่อ

> [!NOTE]
>
> โค้ดใช้ `split(", ")` จึงคาดหวังตัวคั่นที่เป็นจุลภาคและช่องว่าง
> **ตรงตามนี้** ถ้าเขียน `Movie A,Ann,Bob` โดยไม่มีช่องว่าง
> จะไม่ถูกแยกแบบเดียวกัน แม้แนวทางในเอกสารโจทย์ที่ใช้
> `split(",")` แล้ว `strip()` ทีละช่องจะยืดหยุ่นกว่า

แม้โจทย์กำหนดดาราสองคนต่อเรื่อง แต่การใช้ `data[1:]`
ทำให้โค้ดจริงสามารถวนเก็บดารามากกว่าสองคนได้เช่นกัน
อย่างไรก็ตาม ข้อมูลที่ใช้ตอบโจทย์ยังต้องเป็นไปตามรูปแบบที่กำหนด

## สร้างพจนานุกรมที่เก็บลิสต์ภาพยนตร์

สำหรับดาราทุกคนใน `actors` โปรแกรมตรวจว่ามีกุญแจนั้น
ใน `actor_to_movies` แล้วหรือยัง

```python
if actor not in actor_to_movies:
    actor_to_movies[actor] = []
actor_to_movies[actor].append(movie)
```

ถ้ายังไม่เคยพบชื่อดารา จะสร้างลิสต์ว่างก่อน
จากนั้น `append(movie)` เพิ่มภาพยนตร์เรื่องปัจจุบันไว้ท้ายลิสต์

เพราะโปรแกรมอ่านภาพยนตร์จากบรรทัดแรกไปบรรทัดสุดท้าย
ลิสต์ของดาราแต่ละคนจึงเรียงชื่อภาพยนตร์ตามลำดับที่ปรากฏในข้อมูลนำเข้า
ตรงกับลำดับที่โจทย์ต้องการ โดยไม่ต้องใช้ `sort()`

โค้ดไม่ได้ตรวจหรือกำจัดข้อมูลซ้ำ
ถ้าคู่ดารากับภาพยนตร์เดิมปรากฏซ้ำ `append()`
ก็จะเก็บชื่อภาพยนตร์ซ้ำตามจำนวนครั้งที่พบ

## ค้นหาและแสดงผล

หลังอ่านข้อมูลภาพยนตร์ครบ โปรแกรมรับรายชื่อดาราที่ต้องการค้นหา
ในบรรทัดสุดท้าย และแยกด้วยตัวคั่น `", "` แบบเดียวกัน

```python
query_actors = input().strip().split(", ")
```

ลูปพิจารณาชื่อตามลำดับใน `query_actors`
จึงแสดงคำตอบในลำดับเดียวกับที่ถาม ไม่มีการเรียงชื่อดาราใหม่

ถ้าพบชื่อดารา `", ".join(actor_to_movies[actor])`
จะเชื่อมชื่อภาพยนตร์ด้วยจุลภาคและช่องว่างหนึ่งตัว
แล้วแสดงผลในรูปแบบ

```text
actor -> movie 1, movie 2
```

ถ้าไม่พบกุญแจของดาราคนนั้น จะแสดง

```text
actor -> Not found
```

ตัวอย่างเช่น พจนานุกรมจากหัวข้อก่อนหน้าจะให้ผลดังนี้

```text
Ann -> Movie A, Movie B
Dan -> Not found
```

ช่องว่างรอบ `->`, ตัวพิมพ์ใน `Not found`
และลำดับชื่อภาพยนตร์เป็นส่วนหนึ่งของรูปแบบผลลัพธ์
ข้อนี้ไม่มีการคำนวณหรือปัดเศษตัวเลข

## ลำดับการทำงานของโปรแกรม

1. รับ `n` แล้วอ่านข้อมูลภาพยนตร์จำนวน `n` บรรทัด
2. แยกชื่อภาพยนตร์และรายชื่อดาราด้วย `split(", ")`
3. เพิ่มภาพยนตร์ลงในลิสต์ของดาราแต่ละคน
4. รับรายชื่อดาราที่ต้องการค้นหาจากบรรทัดสุดท้าย
5. แสดงหนึ่งบรรทัดต่อหนึ่งชื่อ ตามลำดับที่ถาม
   ถ้าไม่พบให้ใช้ `Not found`

ถ้าถามชื่อเดิมซ้ำ โปรแกรมจะแสดงคำตอบซ้ำตามลำดับคำถาม
และถ้า `n = 0` พจนานุกรมจะว่าง
ชื่อดาราทุกคนในบรรทัดคำถามจึงได้ผลลัพธ์เป็น `Not found`

# Solution

```python
# --------------------------------------------------
# File Name : P3_06_MovieStar.py
# Problem   : Part-III Movie Stars
# Author    : Worralop Srichainont
# Date      : 2025-06-17
# --------------------------------------------------

# Initialize a dictionary to store actor names and their movies
actor_to_movies = {}

# Input the number of movies
n = int(input())
for _ in range(n):
    data = input().strip().split(", ")
    movie = data[0].strip()
    actors = data[1:]

    for actor in actors:
        if actor not in actor_to_movies:
            actor_to_movies[actor] = []
        actor_to_movies[actor].append(movie)

# Input query
query_actors = input().strip().split(", ")
# Find and print the movies for each queried actor
for actor in query_actors:
    if actor in actor_to_movies:
        movies = ", ".join(actor_to_movies[actor])
        print(f"{actor} -> {movies}")
    else:
        print(f"{actor} -> Not found")
```
