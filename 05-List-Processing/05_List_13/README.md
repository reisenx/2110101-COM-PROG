## การรับข้อมูลทั้งสามชุด

โจทย์ส่งจำนวนเต็มมาเป็นสามชุด แต่ละชุดใช้รูปแบบไม่เหมือนกัน โปรแกรมจึงอ่าน
ทีละชุดและต่อข้อมูลทั้งหมดไว้ใน `numbers` ตามลำดับที่มาถึงก่อน

**ชุดที่ 1:** บรรทัดแรกเป็นจำนวน `n` จากนั้นอ่านอีก `n` บรรทัด
บรรทัดละหนึ่งจำนวน แล้วเพิ่มด้วย `append()`

```python
n = int(input())
for _ in range(n):
    numbers.append(int(input()))
```

**ชุดที่ 2:** จำนวนทั้งหมดอยู่ในบรรทัดเดียวและคั่นด้วยช่องว่าง
`split()` แยกบรรทัดเป็นข้อความย่อย ก่อนที่ `int()` จะเปลี่ยนแต่ละข้อความเป็น
จำนวนเต็ม แล้ว `+=` จะนำสมาชิกเหล่านั้นมาต่อท้าย `numbers`

```python
numbers += [int(num) for num in input().split()]
```

ถ้าชุดที่ 2 ไม่มีข้อมูล บรรทัดนี้จะเป็นบรรทัดว่าง `split()` จึงได้ลิสต์ว่าง
และไม่มีสมาชิกใดถูกเพิ่ม

**ชุดที่ 3:** อ่านจำนวนทีละบรรทัดไปเรื่อย ๆ เมื่อพบ `-1` ให้ `break`
ออกจากลูปทันที ค่า `-1` เป็นเพียงเครื่องหมายจบข้อมูล จึงไม่ถูกเก็บในลิสต์

เมื่ออ่านครบทั้งสามชุดแล้ว index ของ `numbers` จะแทนลำดับของข้อมูลทั้งหมด
โดยไม่เริ่มนับใหม่เมื่อเปลี่ยนชุด

---

## การเพิ่มด้านหลังและด้านหน้า

โปรแกรมสร้าง `rearranged_numbers` เป็นลิสต์ว่าง แล้วลุยข้อมูลตาม index `i`

-   เมื่อ `i` เป็นจำนวนคู่ (`i % 2 == 0`) ใช้ `append()` เพิ่มค่าที่ท้ายลิสต์
-   เมื่อ `i` เป็นจำนวนคี่ (`i % 2 != 0`) ใช้ `insert(0, ...)` เพิ่มค่าที่ index
    `0` หรือด้านหน้าลิสต์

ดังนั้นข้อมูลตัวแรกซึ่งมี index `0` จะถูกเพิ่มด้านหลังตามที่โจทย์กำหนด
จากนั้นจึงสลับเป็นด้านหน้า ด้านหลัง ด้านหน้า ไปเรื่อย ๆ

## ผลของตำแหน่งคู่และคี่

ลองพิจารณาข้อมูลรวม `[1, 2, 3, 4, 5, 6]`

| `i` | ค่า | คำสั่ง | ลิสต์หลังเพิ่ม |
|---:|---:|---|---|
| `0` | `1` | เพิ่มด้านหลัง | `[1]` |
| `1` | `2` | เพิ่มด้านหน้า | `[2, 1]` |
| `2` | `3` | เพิ่มด้านหลัง | `[2, 1, 3]` |
| `3` | `4` | เพิ่มด้านหน้า | `[4, 2, 1, 3]` |
| `4` | `5` | เพิ่มด้านหลัง | `[4, 2, 1, 3, 5]` |
| `5` | `6` | เพิ่มด้านหน้า | `[6, 4, 2, 1, 3, 5]` |

ค่าที่มี index คี่จะถูกแทรกก่อนสมาชิกเดิมทุกครั้ง จึงปรากฏทางซ้ายในลำดับย้อนกลับ
ส่วนค่าที่มี index คู่จะต่อทางขวาตามลำดับเดิม

## รูปแบบผลลัพธ์และกรณีพิเศษ

คำสั่ง `print(rearranged_numbers)` แสดงลิสต์ตามรูปแบบของ Python โดยมี
วงเล็บเหลี่ยมและใช้จุลภาคตามด้วยช่องว่างคั่นสมาชิก เช่น

```text
[6, 4, 2, 1, 3, 5]
```

ถ้าทั้งสามชุดไม่มีข้อมูลที่ต้องเพิ่ม เช่น ชุดแรกมี `n = 0` ชุดที่ 2 เป็น
บรรทัดว่าง และชุดที่ 3 เริ่มด้วย `-1` ลูปจัดเรียงจะไม่ทำงานและผลลัพธ์เป็น `[]`

> [!WARNING]
>
> เมื่ออ่านข้อมูลชุดที่ 3 ค่า `-1` ใช้เป็นเครื่องหมายจบและจะไม่ถูกเพิ่มลงในลิสต์
> แต่ถ้า `-1` อยู่ในชุดที่ 1 หรือชุดที่ 2 โค้ดนี้จะมองเป็นข้อมูลจำนวนเต็มตามปกติ

# Solution

```python
# --------------------------------------------------
# File Name : 05_List_13.py
# Problem   : Back and Front
# Author    : Worralop Srichainont
# Date      : 2025-06-11
# --------------------------------------------------

# Initialize numbers list
numbers = []

# Input first set of numbers
n = int(input())
for _ in range(n):
    numbers.append(int(input()))

# Input second set of numbers
numbers += [int(num) for num in input().split()]

# Input the third set of numbers
while True:
    num = int(input())
    if num == -1:
        break
    numbers.append(num)

# Rearrange the numbers
rearranged_numbers = []
for i in range(len(numbers)):
    # Insert at the back first, then at the front
    if i % 2 == 0:
        rearranged_numbers.append(numbers[i])
    else:
        rearranged_numbers.insert(0, numbers[i])

# Output the rearranged numbers
print(rearranged_numbers)
```
