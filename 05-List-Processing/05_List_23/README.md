## ระยะจากจุดกำเนิด

จุดกำเนิดมีพิกัด $(0, 0)$ ระยะของจุด $(x, y)$ จากจุดกำเนิดคำนวณด้วย
ทฤษฎีบทพีทาโกรัส

$$
d = \sqrt{(x - 0)^2 + (y - 0)^2} = \sqrt{x^2 + y^2}
$$

โค้ดรับ `x` และ `y` เป็น `float` แล้วเขียนสูตรนี้ใน Python เป็น

```python
distance = (x**2 + y**2) ** 0.5
```

เครื่องหมาย `**` คือการยกกำลัง ดังนั้น `x**2` และ `y**2` ทำให้พิกัดลบ
กลายเป็นค่าบวกก่อนนำมารวมกัน ส่วน `** 0.5` คือการหารากที่สอง
จุดที่อยู่ตรงจุดกำเนิดเองจะมีระยะ `0.0`

## การสร้างข้อมูลสำหรับเรียง

บรรทัดแรกระบุจำนวนจุด `n` และโจทย์รับรองว่า `n >= 3` จากนั้นโปรแกรมอ่าน
พิกัดทีละจุด พร้อมสร้างลิสต์ย่อยในรูปแบบ

```python
[distance, order, x, y]
```

ลูป `for order in range(n)` เริ่มนับตัวแปร `order` จาก `0`
แต่โจทย์กำหนดให้จุดแรกมีหมายเลข `1` จึงเก็บ `order + 1` ลงใน record

ตัวอย่างเช่น หากจุดที่ 4 คือ `(3.0, 3.0)` จะเก็บข้อมูลเป็น

```python
[(3.0**2 + 3.0**2) ** 0.5, 4, 3.0, 3.0]
```

การวาง `distance` ไว้เป็นสมาชิกตัวแรกสำคัญมาก เพราะเมื่อเรียก
`points.sort()` Python จะเปรียบเทียบสมาชิกตัวแรกของลิสต์ย่อยก่อน
จึงเรียงจุดจากระยะน้อยไปมาก

## การหาจุดอันดับสาม

หลังเรียงแล้ว `points[0]` คือจุดที่ใกล้ที่สุด `points[1]` คืออันดับสอง
และ `points[2]` คืออันดับสาม เพราะ index ของลิสต์เริ่มจาก `0`

โจทย์รับรองว่าทุกจุดมีระยะจากจุดกำเนิดต่างกัน จึงไม่มีกรณีที่ต้องตัดสินว่า
จุดใดควรได้อันดับก่อนเมื่อระยะเท่ากัน

```python
order, x, y = points[2][1:]
```

slice `[1:]` ตัดค่า `distance` ที่ไม่ต้องแสดงออก แล้ว unpack สมาชิกที่เหลือ
ไปยัง `order`, `x` และ `y` ตามลำดับ

## รูปแบบผลลัพธ์

คำตอบต้องอยู่ในรูป `#ลำดับ: (x, y)` โค้ดจึงใช้ f-string รวมหมายเลขลำดับ
กับ tuple `(x, y)`

```python
print(f"#{order}: {(x, y)}")
```

เนื่องจากพิกัดถูกอ่านด้วย `float()` แม้ข้อมูลนำเข้าจะเขียนเป็น `3`
ค่าที่แสดงจะเป็น `3.0` รูปแบบมาตรฐานของ tuple ใส่เครื่องหมายจุลภาคและ
ช่องว่างระหว่างพิกัดให้อัตโนมัติ โค้ดไม่ได้สั่งปัดเศษหรือกำหนดจำนวน
ตำแหน่งทศนิยม จึงแสดงค่า `float` ตามรูปแบบปกติของ Python

# Solution

```python
# --------------------------------------------------
# File Name : 05_List_23.py
# Problem   : Third Closest
# Author    : Worralop Srichainont
# Date      : 2025-06-12
# --------------------------------------------------

# Input number of points
n = int(input())

# Input points
points = []
for order in range(n):
    x, y = [float(num) for num in input().split()]
    # Calculate distance from origin
    distance = (x**2 + y**2) ** 0.5
    # Store point with its distance and order
    points.append([distance, order + 1, x, y])

# Sort points by distance from origin
points.sort()

# Output the third closest point
order, x, y = points[2][1:]
print(f"#{order}: {(x, y)}")
```
