## โครงสร้างข้อมูลและลำดับเกรด

ข้อมูลนักเรียนหนึ่งคนอยู่ในลิสต์รูป `[เลขประจำตัว, เกรด]` และ `grades`
เป็นลิสต์ที่รวมข้อมูลเหล่านี้ เช่น

```python
grades = [["222", "B"], ["111", "A"], ["444", "D"], ["33", "C+"]]
```

เลขประจำตัวและเกรดเก็บเป็น `str` ทั้งคู่ ส่วนค่าคงที่ `GRADES` เรียงเกรดจาก
ดีที่สุดไปแย่ที่สุด

```python
GRADES = ["A", "B+", "B", "C+", "C", "D+", "D", "F"]
```

ดังนั้นเกรดที่ดีกว่าจะมีอินเด็กซ์น้อยกว่า เช่น `"B"` อยู่ที่อินเด็กซ์ `2`
และเกรดที่สูงขึ้นหนึ่งระดับคือ `"B+"` ที่อินเด็กซ์ `1`

---

## ฟังก์ชัน `index_of`

`index_of(grades, id)` มีหน้าที่ค้นหาเลขประจำตัวใน `grades` โดยวนอินเด็กซ์
จาก `0` ไปจนถึงตำแหน่งสุดท้าย และเปรียบเทียบ `grades[idx][0]` กับ `id`

-   ถ้าพบ จะคืนอินเด็กซ์นั้นทันทีด้วย `return idx`
-   ถ้าตรวจครบแล้วยังไม่พบ จะคืน `-1`

การคืนทันทีทำให้กรณีที่มีเลขประจำตัวซ้ำกัน ฟังก์ชันคืนตำแหน่งแรกที่พบ
ฟังก์ชันนี้อ่านข้อมูลเพื่อเปรียบเทียบเท่านั้น จึงไม่เปลี่ยนลำดับหรือสมาชิกใด ๆ
ใน `grades`

---

## ฟังก์ชัน `upgrade`

`upgrade(grades, student_ids)` วนเลขประจำตัวใน `student_ids` ตามลำดับ
และเรียก `index_of()` เพื่อหาตำแหน่งของนักเรียนแต่ละคน

```python
idx = index_of(grades, student_id)
```

ถ้า `idx` เป็น `-1` แสดงว่าไม่มีเลขประจำตัวนั้น โปรแกรมจะข้ามไปโดยไม่แก้ไข
ข้อมูล ถ้าพบจึงค่อยเปลี่ยนเกรดที่ `grades[idx][1]`

---

## การเลื่อนเกรดขึ้นหนึ่งระดับ

เมื่อพบข้อมูลนักเรียน โปรแกรมหาอินเด็กซ์ของเกรดเดิมก่อน

```python
old_grade = GRADES.index(grades[idx][1])
```

การเลื่อนเกรดขึ้นหนึ่งระดับจึงเท่ากับลดอินเด็กซ์ลง `1` ถ้าให้
$i_{old}$ เป็นอินเด็กซ์ของเกรดเดิม จะได้

$$
i_{new} = \max(0, i_{old} - 1)
$$

ซึ่งตรงกับ Python

```python
new_grade = GRADES[max(0, old_grade - 1)]
```

ตัวอย่างเช่น `"D"` มีอินเด็กซ์ `6` เมื่อลดเหลือ `5` จะได้ `"D+"`
ส่วน `"A"` มีอินเด็กซ์ `0` อยู่แล้ว `max(0, -1)` ยังคงเป็น `0` จึงไม่มีเกรด
ที่สูงกว่า `"A"`

---

## การเรียงข้อมูลและค่าที่คืน

หลังพิจารณาเลขประจำตัวครบทั้งหมด โปรแกรมเรียก `grades.sort()` การเรียงลิสต์
ซ้อนจะเปรียบเทียบสมาชิกตัวแรกก่อน จึงเรียงตามเลขประจำตัวซึ่งเป็น `str`
จากน้อยไปมากตามที่โจทย์กำหนด เช่น `"222"` มาก่อน `"33"` เพราะเปรียบเทียบ
อักขระตัวแรกเป็น `"2" < "3"`

ทั้งการเปลี่ยนเกรดและการเรียงเกิดขึ้นกับลิสต์ `grades` เดิมโดยตรง ฟังก์ชันไม่มี
คำสั่ง `return` จึงคืนค่า `None` โดยปริยาย ผู้เรียกต้องดูผลจากตัวแปร `grades`
หลังเรียกฟังก์ชัน

---

## กรณีที่ควรสังเกต

-   เลขประจำตัวที่ไม่พบใน `grades` จะถูกข้าม
-   ถ้าเลขประจำตัวเดียวกันปรากฏหลายครั้งใน `student_ids` จะถูกเลื่อนเกรดซ้ำ
    ครั้งละหนึ่งระดับจนถึง `"A"` ได้
-   ถ้า `grades` มีเลขประจำตัวซ้ำ `index_of()` จะพบและแก้ไขเฉพาะรายการแรก
    ในแต่ละครั้ง
-   โค้ดถือว่าเกรดทุกค่าเป็นหนึ่งในค่าที่กำหนดไว้ใน `GRADES`
-   PDF ใช้ชื่อพารามิเตอร์ `ID` และ `IDs` แต่โค้ดใช้ `id` และ `student_ids`
    ตามลำดับ ชื่อที่ต่างกันไม่เปลี่ยนความหมายของพารามิเตอร์
-   ในตัวอย่างคำอธิบายของ PDF มีคำว่า `upgrades(...)` แต่ชื่อฟังก์ชันที่โจทย์
    กำหนดและโค้ดเฉลยใช้จริงคือ `upgrade(...)` แบบเอกพจน์

## การทำงานของตัวตรวจคำตอบ

บรรทัด `exec(input())` ทั้งสามบรรทัดมีไว้รับคำสั่ง Python จากระบบตรวจคำตอบ
เช่น คำสั่งสร้าง `grades`, เรียกฟังก์ชัน และพิมพ์ผลลัพธ์ แต่ละบรรทัดรับและรัน
คำสั่งหนึ่งบรรทัดตามรูปแบบของ grader จึงต้องเก็บทั้งสามบรรทัดไว้ตามโจทย์

> [!WARNING]
>
> `exec()` สามารถรันคำสั่ง Python ใด ๆ ที่ได้รับ ควรใช้เฉพาะกับคำสั่งจากระบบ
> ตรวจคำตอบที่เชื่อถือได้เท่านั้น ห้ามนำข้อมูลจากผู้ใช้หรือแหล่งที่ไม่เชื่อถือ
> มาให้ `exec()` รัน เพราะอาจเกิดการอ่าน แก้ไข หรือลบข้อมูลบนเครื่องได้

# Solution

```python
# --------------------------------------------------
# File Name : 05_List_F22.py
# Problem   : Upgrade 2 (Function)
# Author    : Worralop Srichainont
# Date      : 2025-06-12
# --------------------------------------------------

# List of letter grades
GRADES = ["A", "B+", "B", "C+", "C", "D+", "D", "F"]


# Find the index of a student ID in the grades list
def index_of(grades, id):
    idx = 0
    for idx in range(len(grades)):
        student_id = grades[idx][0]
        if student_id == id:
            return idx
    return -1


# Upgrade the grades of students based on their IDs
# After upgrading, sort students by ID in ascending order
def upgrade(grades, student_ids):
    for student_id in student_ids:
        idx = index_of(grades, student_id)

        if idx > -1:
            old_grade = GRADES.index(grades[idx][1])
            new_grade = GRADES[max(0, old_grade - 1)]
            grades[idx][1] = new_grade
    grades.sort()


# Execute the input string as code
exec(input())
```
