## ความหมายของยอด

ตำแหน่ง `i` เป็นยอดเมื่อค่าที่ตำแหน่งนั้นมากกว่าค่าที่อยู่ติดกันทั้งด้านซ้าย
และด้านขวา ถ้าเขียนเป็นสูตรจะได้

$$
x_i > x_{i-1} \quad \text{และ} \quad x_i > x_{i+1}
$$

ใน Python เงื่อนไขเดียวกันเขียนได้เป็น

```python
numbers[i] > numbers[i - 1] and numbers[i] > numbers[i + 1]
```

ต้องใช้ `>` ทั้งสองด้าน เพราะโจทย์กำหนดให้มากกว่าอย่างเคร่งครัด ถ้าค่าตรงกลาง
เท่ากับเพื่อนบ้านด้านใดด้านหนึ่ง ตำแหน่งนั้นไม่ใช่ยอด

---

## การเลือกอินเด็กซ์ที่ต้องตรวจ

สมาชิกตัวแรกที่อินเด็กซ์ `0` ไม่มีเพื่อนบ้านด้านซ้าย และสมาชิกตัวสุดท้ายไม่มี
เพื่อนบ้านด้านขวา ทั้งสองตำแหน่งจึงเป็นยอดตามนิยามนี้ไม่ได้ โปรแกรมตรวจเฉพาะ
อินเด็กซ์ภายในด้วย

```python
range(1, len(numbers) - 1)
```

ช่วงนี้เริ่มที่ `1` และสิ้นสุดก่อน `len(numbers) - 1` จึงไม่เข้าถึงอินเด็กซ์
นอกลิสต์ และครอบคลุมทุกตำแหน่งที่มีเพื่อนบ้านครบสองด้าน

---

## การเก็บคำตอบ

โปรแกรมเริ่มจากลิสต์ว่าง `peak_indices` แล้วเพิ่ม `i` เมื่อเงื่อนไขของยอดเป็นจริง
เนื่องจากลูปตรวจอินเด็กซ์จากซ้ายไปขวา อินเด็กซ์ที่เพิ่มด้วย `append(i)` จึงเรียง
จากน้อยไปมากอยู่แล้ว

ตัวอย่างเช่น สำหรับลิสต์

```python
[1.2, 9, 1.2, 1.0, 9, 1.0, 1.0, 9]
```

-   อินเด็กซ์ `1` เป็นยอด เพราะ `9 > 1.2` ทั้งสองด้าน
-   อินเด็กซ์ `4` เป็นยอด เพราะ `9 > 1.0` ทั้งสองด้าน
-   ค่า `9` ที่อินเด็กซ์สุดท้ายไม่ถูกตรวจ เพราะไม่มีเพื่อนบ้านด้านขวา

ฟังก์ชันจึงคืน `[1, 4]` โดยคืนเป็นอินเด็กซ์แบบเริ่มนับจาก `0`

---

## กรณีที่ควรสังเกต

-   ลิสต์ที่มีสมาชิกน้อยกว่า `3` ตัวไม่มีตำแหน่งที่มีเพื่อนบ้านครบสองด้าน
    `range(1, len(numbers) - 1)` จึงว่างและฟังก์ชันคืน `[]`
-   ชุดค่าเท่ากันบนยอดไม่ถือเป็นยอด เช่น `[1, 99, 99, 1]` ไม่มีตำแหน่งใด
    ผ่านเงื่อนไข `>` ทั้งสองด้าน
-   ฟังก์ชันอ่านข้อมูลอย่างเดียวและไม่แก้ไขลิสต์ `numbers`
-   PDF ใช้ชื่อพารามิเตอร์ `x` ส่วนโค้ดเฉลยใช้ `numbers` แต่ทั้งสองชื่อแทน
    ลิสต์จำนวนที่รับเข้ามาเหมือนกัน

## การทำงานของตัวตรวจคำตอบ

ฟังก์ชัน `peaks()` คืนลิสต์ด้วย `return peak_indices` และไม่ได้พิมพ์เอง
บรรทัด `exec(input())` เปิดทางให้ระบบตรวจคำตอบส่งคำสั่งสำหรับเรียกฟังก์ชัน
เข้ามา เช่น `print(peaks([1, 3, 1]))`

> [!WARNING]
>
> `exec()` จะรันข้อความที่ได้รับในฐานะคำสั่ง Python จึงใช้ได้เฉพาะกับคำสั่ง
> จากระบบตรวจคำตอบที่เชื่อถือได้ ห้ามใช้กับข้อมูลจากผู้ใช้หรือแหล่งที่ไม่
> เชื่อถือ เพราะอาจทำให้มีการรันคำสั่งอันตรายบนเครื่องได้

# Solution

```python
# --------------------------------------------------
# File Name : 05_List_F14.py
# Problem   : Peaks (Function)
# Author    : Worralop Srichainont
# Date      : 2025-06-12
# --------------------------------------------------


# Create a function to find index of peaks in a list of numbers
def peaks(numbers):
    peak_indices = []
    for i in range(1, len(numbers) - 1):
        if numbers[i] > numbers[i - 1] and numbers[i] > numbers[i + 1]:
            peak_indices.append(i)
    return peak_indices


# Execute the input string as code
exec(input())
```
