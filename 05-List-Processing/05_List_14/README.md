## ความหมายของยอด

ให้ข้อมูลที่ตำแหน่ง `i` มีค่าเป็น $x_i$ ตำแหน่งนี้จะเป็น **ยอด** ก็ต่อเมื่อ
ค่าของมันมากกว่าค่าที่ติดกันทั้งทางซ้ายและทางขวาอย่างเคร่งครัด

$$
x_i > x_{i-1} \quad \text{และ} \quad x_i > x_{i+1}
$$

เงื่อนไขทางคณิตศาสตร์นี้เขียนเป็น Python ได้ตรง ๆ ว่า

```python
numbers[i] > numbers[i - 1] and numbers[i] > numbers[i + 1]
```

คำว่า `and` บังคับให้การเปรียบเทียบทั้งสองด้านเป็นจริงพร้อมกัน
ถ้ามากกว่าเพียงด้านเดียวก็ยังไม่นับเป็นยอด

---

## ตำแหน่งที่ต้องตรวจ

การตรวจยอดต้องอ่านสมาชิกทางซ้ายที่ index `i - 1` และสมาชิกทางขวาที่ index
`i + 1` ดังนั้นสมาชิกตัวแรกและตัวสุดท้ายไม่มีเพื่อนบ้านครบสองด้านและไม่สามารถ
เป็นยอดได้

```python
for i in range(1, len(numbers) - 1):
```

ลูปจึงเริ่มที่ index `1` และหยุดก่อน index `len(numbers) - 1`
ทำให้ตรวจเฉพาะสมาชิกด้านในของลิสต์อย่างปลอดภัย

---

## การนับยอด

โปรแกรมเริ่ม `peak_count = 0` แล้วเพิ่มค่าทีละ `1` ทุกครั้งที่พบตำแหน่งซึ่งผ่าน
เงื่อนไขยอด เมื่อจบลูปจึงแสดงจำนวนเต็ม `peak_count`

ตัวอย่างเช่น ข้อมูล `[1, 4, 2, 5, 3]`

-   index `1` มีค่า `4` ซึ่งมากกว่า `1` และ `2` จึงเป็นยอด
-   index `2` มีค่า `2` ซึ่งน้อยกว่าเพื่อนบ้าน จึงไม่เป็นยอด
-   index `3` มีค่า `5` ซึ่งมากกว่า `2` และ `3` จึงเป็นยอด

ข้อมูลชุดนี้มีทั้งหมด `2` ยอด

ข้อมูลนำเข้าถูกแปลงด้วย `float()` จึงรับได้ทั้งข้อความจำนวนเต็ม เช่น `4`
และจำนวนจริง เช่น `5.2` ส่วนผลลัพธ์เป็นจำนวนยอด จึงแสดงเป็นจำนวนเต็มโดยไม่ต้อง
ปัดเศษ

---

## กรณีที่ควรระวัง

-   เงื่อนไขใช้เครื่องหมาย `>` ไม่ใช่ `>=` ถ้าค่าเท่ากับเพื่อนบ้านด้านใดด้านหนึ่ง
    เช่นช่วง `[3, 3, 2]` จะไม่ถือว่า `3` ตัวกลางเป็นยอด
-   ถ้ามีข้อมูลน้อยกว่า `3` ตัว `range(1, len(numbers) - 1)` จะไม่มี index
    ให้ลูปตรวจ โปรแกรมจึงแสดง `0`
-   โปรแกรมเปรียบเทียบค่า `float` โดยตรงตามค่าที่ Python อ่านได้
    ไม่มีการปัดเศษก่อนเปรียบเทียบ

# Solution

```python
# --------------------------------------------------
# File Name : 05_List_14.py
# Problem   : Peaks
# Author    : Worralop Srichainont
# Date      : 2025-06-11
# --------------------------------------------------

# Input a list of numbers
numbers = [float(num) for num in input().split()]

# Count the number of peaks
peak_count = 0
for i in range(1, len(numbers) - 1):
    if numbers[i] > numbers[i - 1] and numbers[i] > numbers[i + 1]:
        peak_count += 1

# Output the number of peaks
print(peak_count)
```
