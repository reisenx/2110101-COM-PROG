## ลำดับคอลลาตซ์

โจทย์รับจำนวนเต็มบวก `n` เพียง **หนึ่งจำนวน** แล้วเปลี่ยนค่าของ `n`
ซ้ำไปเรื่อย ๆ จนกระทั่งได้ `1` โดยเลือกสูตรจากความเป็นจำนวนคู่หรือจำนวนคี่

$$
n_{\text{ถัดไป}} =
\begin{cases}
\dfrac{n}{2}, & \text{เมื่อ } n \text{ เป็นจำนวนคู่} \\
3n + 1, & \text{เมื่อ } n \text{ เป็นจำนวนคี่}
\end{cases}
$$

ในภาษา Python ตรวจว่าเป็นจำนวนคู่ได้ด้วย `num % 2 == 0` และเขียนสองสูตรเป็น

```python
if num % 2 == 0:
    num //= 2
else:
    num = 3 * num + 1
```

เครื่องหมาย `//` คือการหารจำนวนเต็ม สำหรับโจทย์นี้เราใช้กับจำนวนคู่
จึงหารด้วย `2` ได้ลงตัวพอดี

## การสร้างลำดับ

ลำดับคำตอบต้องมีทั้งค่าเริ่มต้นและค่า `1` ตัวสุดท้าย จึงเริ่มสร้างลิสต์ด้วย
ค่าแรกก่อนเข้าลูป

```python
collatz = [str(num)]
```

จากนั้นลูป `while num != 1` จะคำนวณค่าถัดไป แล้วจึงนำค่าที่เพิ่งคำนวณได้
ไปต่อท้ายลิสต์ด้วย `append()` การต่อท้ายเกิดขึ้นหลังการเปลี่ยนค่า
จึงทำให้ค่า `1` ถูกเก็บก่อนจบลูปด้วย

ค่าทุกตัวถูกแปลงเป็นสตริงตั้งแต่ตอนเก็บ เพราะขั้นตอนสุดท้ายจะใช้ `join()`
เชื่อมข้อความเข้าด้วยกัน ตัวอย่างเช่น เมื่อเริ่มจาก `10` จะได้

```text
10, 5, 16, 8, 4, 2, 1
```

แม้คอมเมนต์ `# Input numbers` ในโค้ดจะเขียนเป็นพหูพจน์
แต่คำสั่ง `num = int(input())` และข้อกำหนดของโจทย์รับจำนวนเต็มเพียงหนึ่งจำนวน

## การแสดง 15 ค่าสุดท้าย

โจทย์ต้องการเฉพาะ 15 ค่าสุดท้าย หรือทั้งหมดหากลำดับสั้นกว่านั้น
จึงใช้ negative slice `collatz[-15:]` เพื่อหยิบสมาชิกตั้งแต่ตัวที่ 15
นับย้อนจากท้ายลิสต์ไปจนถึงตัวสุดท้าย

ถ้าลิสต์มีไม่ถึง 15 ตัว Python จะคืนสมาชิกทั้งหมดโดยไม่เกิดข้อผิดพลาด
จากนั้น `"->".join(...)` จะเชื่อมสมาชิกโดยวาง `->` ไว้ระหว่างแต่ละคู่
จึงไม่มีลูกศรเกินมาที่หัวหรือท้ายคำตอบ

```python
print("->".join(collatz[-15:]))
```

กรณีเริ่มจาก `n = 1` เงื่อนไขของลูปเป็นเท็จตั้งแต่แรก ลิสต์จึงมีเพียง
`"1"` และโปรแกรมแสดงผล `1` ได้ถูกต้อง

# Solution

```python
# --------------------------------------------------
# File Name : 05_List_16.py
# Problem   : Collatz
# Author    : Worralop Srichainont
# Date      : 2025-06-11
# --------------------------------------------------

# Input numbers
num = int(input())

# Initialize the Collatz sequence list
collatz = [str(num)]

# Generate the Collatz sequence
while num != 1:
    if num % 2 == 0:
        num //= 2
    else:
        num = 3 * num + 1
    collatz.append(str(num))

# Output the Collatz sequence
print("->".join(collatz[-15:]))
```
