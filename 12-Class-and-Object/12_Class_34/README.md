## การเก็บเหรียญหลายมูลค่า

โจทย์ข้อนี้ต่อยอดจาก Piggy Bank 1 โดยให้กระปุกหนึ่งใบรับเหรียญมูลค่าใดก็ได้
จึงไม่สามารถเตรียม key ไว้เพียง `1`, `2`, `5` และ `10` บาทได้อีกต่อไป
คลาส `PiggyBank` เริ่มต้นด้วย dictionary ว่าง

```python
self.coins = {}
```

ใน dictionary นี้ key คือมูลค่าของเหรียญซึ่งเก็บเป็น `float`
และ value คือจำนวนเหรียญมูลค่านั้น เช่น `{0.25: 3, 5.0: 2}` หมายถึง
เหรียญ 0.25 บาท 3 เหรียญ และเหรียญ 5 บาท 2 เหรียญ

เมื่อพบมูลค่าใหม่ โค้ดสร้าง key ด้วย `float(value)` แล้วเก็บจำนวน `n`
แต่ถ้ามีมูลค่านั้นอยู่แล้วก็เพิ่ม `n` เข้าไปในจำนวนเดิม

> [!NOTE]
>
> ตัวเลข `5` และ `5.0` มีค่าเท่ากันและใช้เป็น key เดียวกันใน dictionary
> ของ Python ดังนั้น `add(5, 1)` ตามด้วย `add(5.0, 1)` จะรวมกันเป็น
> รายการเดียว และเนื่องจาก key ถูกเก็บเป็น `float` จึงแสดงเป็น `5.0:2`

## การเพิ่มเหรียญและความจุสูงสุด

เมธอด `add(value, n)` พยายามเพิ่มเหรียญมูลค่า `value` จำนวน `n` เหรียญ
แต่กระปุกเก็บเหรียญรวมทุกชนิดได้ไม่เกิน 100 เหรียญ ขั้นตอนสำคัญคือ

```python
if self.total_coins() + n > 100:
    return False
```

-   ถ้าจำนวนใหม่ **เกิน** 100 เมธอดคืน `False` ทันที
    และ dictionary จะไม่ถูกแก้ไขเลย
-   ถ้าจำนวนใหม่ไม่เกิน 100 เมธอดเพิ่มเหรียญแล้วคืน `True`

การตรวจสอบเกิดก่อนเปลี่ยน dictionary จึงเป็นการเพิ่มแบบสำเร็จทั้งชุดหรือไม่เพิ่มเลย
ตัวอย่างเช่น ถ้ามีอยู่ 1 เหรียญ การขอเพิ่มอีก 100 เหรียญจะคืน `False`
และยังคงมีเพียง 1 เหรียญ แต่การขอเพิ่มอีก 99 เหรียญจะสำเร็จพอดีที่ 100 เหรียญ

สังเกตว่าเงื่อนไขใช้ `> 100` ไม่ใช่ `>= 100` ดังนั้นจำนวนรวมเท่ากับ
100 เหรียญยังยอมรับได้

## การหาจำนวนเหรียญและมูลค่ารวม

เมธอด `total_coins()` รวมเฉพาะ **จำนวนเหรียญ** ด้วย
`sum(self.coins.values())` และถูกใช้ตรวจความจุของกระปุก

ส่วนมูลค่าเงินทั้งหมดคำนวณใน `__float__()` หากเหรียญแต่ละชนิดมีมูลค่า
$v$ บาทและมีจำนวน $q$ เหรียญ จะได้

$$
\text{total money} = \sum (v \times q)
$$

ซึ่งตรงกับคำสั่ง Python ในลูป

```python
total_money += value * quantity
```

เมื่อเขียน `float(p1)` Python จะเรียก `p1.__float__()` และคืนผลเป็น `float`
เช่น เหรียญ `0.25` บาท 4 เหรียญมีมูลค่ารวม `1.0`
โค้ดไม่ได้ใช้ `round()` หรือกำหนดจำนวนตำแหน่งทศนิยม จึงแสดงผลตามรูปแบบปกติ
ของ `float` ใน Python

> [!NOTE]
>
> ตัวอย่างช่วงต้นใน PDF มีบรรทัด `int(p1)` แต่ข้อกำหนดของคลาสและโค้ดเฉลย
> นิยามเฉพาะ `__float__()` ไม่มี `__int__()` การเรียกที่สอดคล้องกับคลาสจริงคือ
> `float(p1)` ส่วน `int(p1)` กับโค้ดนี้จะเกิด `TypeError`

## การเรียงและแสดงชนิดเหรียญ

เมื่อใช้ `str(p1)` หรือ `print(p1)` Python จะเรียก `__str__()`
โค้ดใช้ `sorted(self.coins.items())` เพื่อเรียงตามมูลค่าเหรียญจากน้อยไปมาก
ก่อนประกอบข้อความรูปแบบ `{มูลค่า:จำนวน, ...}`

ตัวอย่างเช่น dictionary ที่มีเหรียญ 5 บาท 2 เหรียญ และเหรียญ 0.25 บาท
3 เหรียญ จะแสดงเป็น `{0.25:3, 5.0:2}` ไม่ขึ้นกับว่าเพิ่มชนิดใดก่อน
ถ้ากระปุกยังว่าง `str(p1)` จะได้ `{}`

## การรับคำสั่งจาก grader

โปรแกรมรับข้อมูล 2 บรรทัด แยกแต่ละบรรทัดด้วย `;` แล้วใช้ `eval(c)`
ประมวลผลคำสั่งย่อยตามลำดับ ทั้งสองบรรทัดสามารถอ้างถึง `p1` หรือ `p2` ได้
โดยออบเจ็กต์ทั้งสองถูกสร้างเป็นกระปุกว่างไว้ก่อนเริ่มทำตามคำสั่ง

ตัวอย่างข้อมูลหนึ่งบรรทัด

```text
p1.add(0.25,3);p1.add(5,2);print(float(p1), p1)
```

คำสั่งนี้เพิ่มเหรียญรวม 5 เหรียญ แล้วแสดงมูลค่ารวมและรายละเอียดเหรียญ
ผลลัพธ์คือ `10.75 {0.25:3, 5.0:2}`

> [!WARNING]
>
> `eval()` สามารถประมวลผลโค้ด Python ที่อยู่ในข้อความได้
> ในข้อนี้ใช้เพื่อรับคำสั่งจาก grader ที่เชื่อถือได้เท่านั้น
> ห้ามใช้กับข้อมูลจากผู้ใช้หรือแหล่งที่ไม่น่าเชื่อถือ

## ตัวอย่างการทำงาน

เริ่มจากกระปุกที่มีเหรียญ 0.25 บาทอยู่ 1 เหรียญ

```python
p1.add(0.25, 1)
```

ขณะนี้ `total_coins()` เท่ากับ `1` หากเรียก `p1.add(0.25, 100)`
จำนวนใหม่จะเป็น `101` จึงคืน `False` และกระปุกยังไม่เปลี่ยน
จากนั้นเรียก `p1.add(0.25, 99)` จะคืน `True` เพราะจำนวนใหม่เท่ากับ `100`

มูลค่ารวมหลังเพิ่มสำเร็จคือ

$$
0.25 \times 100 = 25.0
$$

ดังนั้น `float(p1)` จึงได้ `25.0`

# Solution

```python
# --------------------------------------------------
# File Name : 12_Class_34.py
# Problem   : Piggy Bank 2
# Author    : Worralop Srichainont
# Date      : 2025-08-09
# --------------------------------------------------


class PiggyBank:
    # __init__ method
    def __init__(self):
        self.coins = {}

    # add method
    def add(self, value, n):
        # Total coins cannot exceed 100
        if self.total_coins() + n > 100:
            return False
        # Add coins to the piggy bank
        if value not in self.coins:
            self.coins[float(value)] = n
        else:
            self.coins[float(value)] += n
        return True

    # total_coins method
    # Calculate the total number of coins in the piggy bank
    def total_coins(self):
        return sum(self.coins.values())

    # __float__ method
    # Calculate the total value of coins in the piggy bank
    def __float__(self):
        total_money = 0.0
        for value, quantity in self.coins.items():
            total_money += value * quantity
        return total_money

    # __str__ method
    def __str__(self):
        ordered_coins = []
        for value, quantity in sorted(self.coins.items()):
            ordered_coins.append(f"{value}:{quantity}")
        return "{" + ", ".join(ordered_coins) + "}"


# Output
cmd1 = input().split(";")
cmd2 = input().split(";")
p1 = PiggyBank()
p2 = PiggyBank()
for c in cmd1:
    eval(c)
for c in cmd2:
    eval(c)
```
