## การเลือกเส้นทางจากเลขคี่และเลขคู่

บรรทัดแรกรับจำนวนเต็ม `n` และ `k` แล้วใช้เศษจากการหาร `n` ด้วย `2`
เพื่อเลือกว่าจะทำงานตามผังงานฝั่งใด

```python
n, k = [int(e) for e in input().split()]

if n % 2 != 0:
    # n เป็นจำนวนคี่
else:
    # n เป็นจำนวนคู่
```

ตัวแปร `n` ใช้เลือกเส้นทางเท่านั้น ส่วน `k` มีหน้าที่ต่างกันในแต่ละเส้นทาง

-   ถ้า `n` เป็นจำนวนคี่ โปรแกรมรับจำนวนเต็ม `a`, `b`, `c` เพิ่มอีก `k`
    บรรทัด แล้วแสดง `sum_a`, `sum_b`, `sum_c`
-   ถ้า `n` เป็นจำนวนคู่ โปรแกรมรับจำนวนเต็ม `s`, `t` เพิ่มอีกหนึ่งบรรทัด
    แล้วแสดง `x`, `y`

## กรณี n เป็นจำนวนคี่

โปรแกรมเริ่มตัวสะสม `sum_a`, `sum_b`, `sum_c` และตัวนับรอบ `m` ที่ `0`
จากนั้นวนลูปขณะที่ `m < k` จึงรับข้อมูลและประมวลผลทั้งหมด `k` ชุด

ในทุกรอบ `m` จะเพิ่มขึ้น `1` ไม่ว่าค่าที่รับมาจะเข้าเงื่อนไขใด
ค่าของตัวสะสมเปลี่ยนตามตารางนี้

| เงื่อนไขของ `a`, `b`, `c` | `sum_a` | `sum_b` | `sum_c` |
|---|---:|---:|---:|
| `a != b` | ไม่เปลี่ยน | ไม่เปลี่ยน | ไม่เปลี่ยน |
| `a == b` แต่ `c` ไม่เท่ากับสองค่านี้ | `+2` | `-3` | ไม่เปลี่ยน |
| `a == b == c` และ $a+b>k$ (`a + b > k`) | `+1` | `+2` | `-3` |
| `a == b == c` และ $a+b\leq k$ (`a + b <= k`) | `-3` | `-2` | `+1` |

เงื่อนไขถูกเขียนเป็น `if` ซ้อนกัน จึงตรวจ `a == b` ก่อน
หาก `a` กับ `b` ไม่เท่ากัน โปรแกรมจะไม่สนใจว่าคู่อื่นเท่ากันหรือไม่

> [!NOTE]
>
> การเปรียบเทียบใช้ `a + b > k` แบบมากกว่าอย่างเคร่งครัด
> ดังนั้นเมื่อ `a + b == k` จะเข้ากรณี `a + b <= k`

เมื่อครบ `k` รอบ โปรแกรมแสดงผลรวมสะสมทั้งสามค่าตามลำดับ
`sum_a sum_b sum_c`

## กรณี n เป็นจำนวนคู่

เมื่อ `n` เป็นจำนวนคู่ โปรแกรมรับ `s` และ `t` แล้วกำหนดค่าเริ่มต้นเป็น
`x = s` และ `y = t` ก่อนปรับค่าตามความสัมพันธ์ของ `s` กับ `t`

| เงื่อนไข | ค่า `x` | ค่า `y` |
|---|---|---|
| `s > t` | `s - t` | `t` |
| `s < t` | `s` | `2 * (t - s)` |
| `s == t` | `s` | `t` |

จากนั้นจึงตรวจ $x+y>k$ ด้วย `x + y > k`

-   ถ้าเงื่อนไขเป็นเท็จ โปรแกรมคงค่า `x`, `y` ไว้แล้วแสดงผล
-   ถ้าเงื่อนไขเป็นจริง โปรแกรมทำสองคำสั่งตามลำดับ

เนื่องจากใช้เครื่องหมาย `>` ถ้า `x + y == k` จะไม่สลับหรือคำนวณค่าใหม่

```python
x, y = y, x
x = y + (s**2)
```

คำสั่งแรกเป็นการสลับค่าพร้อมกัน โดย Python จะอ่านค่าเดิมทางขวาให้ครบ
ก่อนนำไปเก็บทางซ้าย สมมติว่าก่อนสลับมีค่า `x_old` และ `y_old`
หลังสลับจะได้ `x = y_old` และ `y = x_old`

คำสั่งถัดมาเปลี่ยน `x` อีกครั้งตามสูตร $x=y+s^2$
ซึ่งเขียนเป็น `x = y + (s**2)` ดังนั้นค่าท้ายสุดจะเป็น
`x = x_old + s**2` และ `y = x_old`

## ตัวอย่างการไล่ค่า

**ตัวอย่างฝั่งจำนวนคี่**

เมื่อบรรทัดแรกเป็น `431 4` จะได้ `n` เป็นจำนวนคี่และ `k = 4`
จึงอ่านข้อมูลอีกสี่ชุด

1. `2 2 2` มีสามค่าเท่ากันและ `2 + 2 == 4` จึงสะสมเป็น
   `(-3, -2, 1)`
2. `3 3 9` มีเพียง `a == b` จึงเพิ่ม `(2, -3, 0)`
3. `1 1 10` มีเพียง `a == b` จึงเพิ่ม `(2, -3, 0)`
4. `0 0 -9` มีเพียง `a == b` จึงเพิ่ม `(2, -3, 0)`

ผลรวมสุดท้ายคือ `3 -11 1`

**ตัวอย่างฝั่งจำนวนคู่**

เมื่อข้อมูลเป็น

```text
152 91
11 73
```

จะได้ `n` เป็นจำนวนคู่ และเพราะ `s < t` จึงมี `x = 11` กับ
`y = 2 * (73 - 11) = 124` ผลรวม `x + y = 135` มากกว่า `k = 91`
จึงสลับเป็น `x = 124`, `y = 11` แล้วคำนวณ `x` ใหม่เป็น
`11 + 11**2 = 132` ผลลัพธ์คือ `132 11`

# Solution

```python
# --------------------------------------------------
# File Name : P1_Flowchart_02.py
# Problem   : Part-I Flowchart 02
# Author    : Worralop Srichainont
# Date      : 2025-06-16
# --------------------------------------------------

n, k = [int(e) for e in input().split()]

if n % 2 != 0:
    sum_a, sum_b, sum_c, m = 0, 0, 0, 0

    while m < k:
        a, b, c = [int(e) for e in input().split()]

        if a == b:
            if a == b == c:
                if a + b > k:
                    sum_a += 1
                    sum_b += 2
                    sum_c -= 3
                else:
                    sum_a -= 3
                    sum_b -= 2
                    sum_c += 1
            else:
                sum_a += 2
                sum_b -= 3
        m += 1
    print(sum_a, sum_b, sum_c)

else:
    s, t = [int(e) for e in input().split()]

    x = s
    y = t

    if s > t:
        x = s - t
    else:
        if s < t:
            y = 2 * (t - s)

    if x + y > k:
        x, y = y, x
        x = y + (s**2)

    print(x, y)
```
