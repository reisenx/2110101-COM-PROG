## การอ่านข้อมูลและแยกเส้นทาง

โจทย์รับจำนวนเต็ม `4` จำนวนในบรรทัดเดียว แล้วเก็บไว้ในตัวแปร `a`, `b`,
`c` และ `d` ตามลำดับ

```python
x = input().split()
a, b, c, d = int(x[0]), int(x[1]), int(x[2]), int(x[3])
```

`input().split()` แยกข้อมูลด้วยช่องว่างและได้ลิสต์ของสตริง
จึงต้องใช้ `int()` แปลงสมาชิกแต่ละตัวก่อนคำนวณ จากนั้นค่าเริ่มต้นของ `a`
จะเลือกเส้นทางหลักเพียงหนึ่งเส้นทาง

-   `a == 1` ทำงานตามแขนงด้านซ้ายของผังงาน
-   `a == 2` ทำงานตามแขนงตรงกลาง
-   ค่าอื่นทำงานตามแขนงด้านขวาที่มีการวนซ้ำ

---

## กรณี `a` เท่ากับ `1`

ขั้นแรกสลับค่า `c` กับ `d` พร้อมกันด้วย

```python
c, d = d, c
```

เช่น ถ้าเดิม `c = 7` และ `d = 5` หลังสลับจะได้ `c = 5` และ `d = 7`
จากนั้นเลือกปรับ `c` เพียงกรณีเดียวตามค่า `b`

| เงื่อนไข | การเปลี่ยนค่า `c` |
| :--- | :--- |
| `b == 1` | `c = c + d` |
| `b == 2` | `c = c - d` |
| `b == 3` | `c = c / d` |
| ค่าอื่น | `c = c + (c**d)` |

กรณี `b == 3` อาจดูไม่ตรงกับลำดับในโค้ดทันที แต่เกิดจากเงื่อนไข
`elif b != 3` เป็นเท็จ จึงเข้า `else` และหารด้วย `d`

สุดท้ายคำนวณค่าใหม่ของ `a` จากสูตร

$$
a = \frac{d + \sqrt{(c / b)^3 + d}}{2 + bd}
$$

ซึ่งตรงกับ Python ดังนี้

```python
a = (d + math.sqrt((c / b) ** 3 + d)) / (2 + b * d)
```

ตัวดำเนินการ `** 3` คือยกกำลังสาม และ `math.sqrt()` คือรากที่สอง

---

## กรณี `a` เท่ากับ `2`

แขนงนี้ต้องอ่านโค้ดจากบนลงล่าง เพราะใช้ `if` แยกกันสามครั้ง ไม่ใช่
`if-elif-else` ชุดเดียว ค่า `c` ที่เปลี่ยนในขั้นก่อนหน้าจึงถูกนำไปใช้ต่อ
ในขั้นถัดไป

1. ถ้า `b > 1` ให้ทำ `c = c + d`
2. ถ้า `b > 2` ให้ทำ `c = c / d` โดยใช้ค่า `c` ล่าสุด
3. ถ้า `b > 3` ให้ทำ `c = c + (c**d)` อีกครั้ง
4. ถ้า `b > 3` เป็นเท็จ ให้ทำ `a = math.log10(c)`

> [!WARNING]
>
> `else` ในส่วนนี้จับคู่กับ `if b > 3` เท่านั้น ดังนั้นเมื่อ `b` เท่ากับ
> `2` หรือ `3` โปรแกรมจะปรับ `c` ตามเงื่อนไขก่อนหน้า แล้วจึงคำนวณ
> $a = \log_{10}(c)$ จากค่า `c` ที่ปรับแล้ว

ตัวอย่าง `2 3 2 2` ทำให้ `c` เปลี่ยนจาก `2` เป็น `4` แล้วเป็น `2.0`
ก่อนคำนวณ `a = math.log10(2.0)`

---

## กรณี `a` เป็นค่าอื่น

โปรแกรมวนซ้ำขณะที่ `a > d` ในแต่ละรอบจะลด `a` ลง `2` ก่อน

```python
a = a - 2
```

หลังจากลดแล้ว ถ้า `a < b` จะใช้ `break` จบลูปทันทีโดยไม่บวกค่า `a`
รอบนั้นเข้า `c` แต่ถ้า `a >= b` จะทำ `c = c + a` แล้วกลับไปตรวจ
`a > d` สำหรับรอบถัดไป

เพราะทุกเงื่อนไขเป็นการเปรียบเทียบแบบเคร่งครัด กรณี `a == d`
จะไม่เข้าลูป และกรณี `a == b` จะยังบวก `a` เข้า `c`

## การแสดงผลและจำนวนจริง

ทุกเส้นทางจบด้วยการแสดง `a`, `b`, `c`, `d` ในบรรทัดเดียวตามลำดับ
โดย `print()` คั่นแต่ละค่าด้วยช่องว่าง

การใช้ `/`, `math.sqrt()` หรือ `math.log10()` อาจทำให้ผลลัพธ์เป็น `float`
แม้ข้อมูลเริ่มต้นเป็นจำนวนเต็ม และโค้ดไม่ได้กำหนดจำนวนหลักทศนิยมเพิ่มเติม

> [!NOTE]
>
> ตัวอย่าง `2 2 2 2` และ `2 3 2 2` ใน PDF ลงท้ายค่า `a` ด้วย
> `...9623` และ `...98114` ตามลำดับ แต่ `math.log10()` บน Python
> ที่ใช้ตรวจสอบโค้ดนี้แสดง `...9624` และ `...9812` ความต่างอยู่ในหลักท้าย
> ของการแทนจำนวนจริงแบบ floating-point เท่านั้น โค้ดเฉลยจึงพิมพ์ค่าที่ Python
> คำนวณได้โดยตรงตามผังงาน

ข้อมูลทดสอบที่ถูกต้องจะต้องทำให้ตัวหารไม่เป็นศูนย์ ค่าภายในรากที่สองไม่ติดลบ
และค่าที่ส่งให้ `math.log10()` เป็นบวก

# Solution

```python
# --------------------------------------------------
# File Name : P1_Flowchart_03.py
# Problem   : Part-I Flowchart 03
# Author    : Worralop Srichainont
# Date      : 2025-06-16
# --------------------------------------------------

import math

x = input().split()
a, b, c, d = int(x[0]), int(x[1]), int(x[2]), int(x[3])

if a == 1:
    c, d = d, c

    if b == 1:
        c = c + d
    elif b == 2:
        c = c - d
    elif b != 3:
        c = c + (c**d)
    else:
        c = c / d

    a = (d + math.sqrt((c / b) ** 3 + d)) / (2 + b * d)

else:
    if a == 2:
        if b > 1:
            c = c + d
        if b > 2:
            c = c / d
        if b > 3:
            c = c + (c**d)
        else:
            a = math.log10(c)

    else:
        while a > d:
            a = a - 2

            if a < b:
                break
            else:
                c = c + a

print(a, b, c, d)
```
