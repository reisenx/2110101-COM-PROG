## การเลือกเส้นทางจากคำสั่ง

โปรแกรมรับคำสั่งบรรทัดแรกด้วย `input().strip()` แล้วเลือกวิธีประมาณค่า
$\pi$ ตามตัวอักษรที่ได้รับ

| คำสั่ง | ข้อมูลบรรทัดที่สอง | วิธีคำนวณ |
| :---: | :--- | :--- |
| `R` | จำนวนเต็ม `n` | ผลบวกอนุกรมตั้งแต่ `k = 0` ถึง `k = n` |
| `P` | ไม่มี | สูตรรากที่สองซ้อนกัน |
| `S` | จำนวนเต็ม `m` | สร้างเลขของ $\pi$ ทีละหลัก |
| ค่าอื่น | ไม่มี | แสดง `Invalid` |

สังเกตว่าโปรแกรมอ่านบรรทัดที่สองเฉพาะคำสั่ง `R` และ `S` เท่านั้น

---

## วิธี `R` ด้วยอนุกรม

สูตรในผังงานคือ

$$
p = \sqrt{12}\sum_{k=0}^{n}\frac{(-3)^{-k}}{2k+1}
$$

โค้ดเริ่ม `k = 0` และ `p = 0` แล้วบวกพจน์ต่อไปนี้ขณะที่ `k <= n`

```python
p = p + (((-3) ** (-1 * k)) / (2 * k + 1))
```

ดังนั้นลูปมีทั้งหมด `n + 1` พจน์ เพราะนับทั้ง `0` และ `n` นิพจน์
`(-3) ** (-1 * k)` เขียนแทน $(-3)^{-k}$ และหลังจบลูป
`p = (12**0.5) * p` คือการคูณผลรวมด้วย $\sqrt{12}$

สุดท้ายใช้ `round(p, 12)` ก่อนแสดงผล ตัวอย่างเมื่อ `n = 10` ได้
`pi = 3.141593304503`

---

## วิธี `P` ด้วยรากซ้อน

คำสั่ง `P` ใช้สูตรคงที่

$$
p = \sqrt{7 + \sqrt{6 + \sqrt{5}}}
$$

Python เขียนรากที่สองเป็นการยกกำลัง `0.5` จึงได้

```python
p = (7 + (6 + (5**0.5)) ** 0.5) ** 0.5
p = round(p, 6)
```

วิธีนี้ไม่ต้องรับจำนวนเต็มเพิ่ม และได้ผลลัพธ์ `pi = 3.141633`

---

## วิธี `S` สร้างเลขทีละหลัก

คำสั่ง `S` ใช้ขั้นตอนแบบ **spigot algorithm** ซึ่งค่อย ๆ ยืนยันเลขแต่ละหลัก
โดยเก็บสถานะทั้งหมดเป็นจำนวนเต็ม

-   `n` คือเลขหลักถัดไปที่กำลังตรวจสอบ
-   `i` คือจำนวนหลักที่ยืนยันและเก็บแล้ว
-   `p` คือสตริงสะสมหลักของ $\pi$
-   `q`, `r`, `t`, `k` และ `x` เป็นสถานะสำหรับคำนวณและปรับค่า `n`

ลูปทำงานจน `i == m` แต่หนึ่งรอบของลูปอาจยังไม่สร้างเลขใหม่

1. ถ้า `4 * q + r - t < n * t` เป็นจริง แสดงว่า `n` เป็นหลักที่ยืนยันได้
   โปรแกรมต่อ `str(n)` เข้า `p`, เพิ่ม `i` แล้วคูณสถานะบางส่วนด้วย `10`
   เพื่อเตรียมหาหลักถัดไป
2. ถ้าเงื่อนไขเป็นเท็จ โปรแกรมปรับ `q`, `r`, `t`, `k`, `x` และ `n`
   ให้ละเอียดขึ้น โดยยังไม่เพิ่ม `i`

เครื่องหมาย `//` ในสูตร เช่น
`(7 * q * k + 2 + x * r) // (x * t)` คือการหารแบบจำนวนเต็ม
จึงรักษาสถานะของวิธีนี้เป็นจำนวนเต็มตลอดการวนซ้ำ

เมื่อได้ครบ `m` หลัก โปรแกรมแทรกจุดทศนิยมหลังหลักแรก

```python
p = p[0] + "." + p[1:]
```

เช่น `m = 5` ทำให้ `p` เปลี่ยนจาก `"31415"` เป็น `"3.1415"`
ค่าของ `m` ต้องมีอย่างน้อย `1` เพราะโค้ดเข้าถึง `p[0]` หลังจบลูป

## การปัดเศษและแสดงผล

วิธี `R` และ `P` เก็บ `p` เป็น `float` แล้วใช้ `round()` ส่วนวิธี `S`
เก็บ `p` เป็นสตริงและไม่ได้ปัดเศษ ทั้งสามวิธีแสดงผลด้วย
`print("pi =", p)` จึงมีช่องว่างหนึ่งช่องหลังเครื่องหมาย `=`

> [!WARNING]
>
> `round(p, k)` ปัดค่าตัวเลข แต่ไม่ได้บังคับให้ `print()` เติมศูนย์ท้ายจนครบ
> `k` ตำแหน่ง เช่น ค่าที่ลงท้ายด้วยศูนย์อาจแสดงทศนิยมน้อยกว่า `k` หลัก
> โค้ดข้อนี้จึงไม่ใช้รูปแบบข้อความแบบกำหนดจำนวนตำแหน่งตายตัว

# Solution

```python
# --------------------------------------------------
# File Name : P1_Flowchart_05.py
# Problem   : Part-I Flowchart 05
# Author    : Worralop Srichainont
# Date      : 2025-06-16
# --------------------------------------------------

c = input().strip()

if c == "S":
    m = int(input())

    q = 1
    r = 0
    t = 1
    k = 1
    n = 3
    x = 3
    i = 0
    p = ""

    while i < m:
        if 4 * q + r - t < n * t:
            p = p + str(n)
            i = i + 1
            a = 10 * (r - n * t)
            n = 10 * (3 * q + r) // t - 10 * n
            q = 10 * q
            r = a
        else:
            a = (2 * q + r) * x
            b = (7 * q * k + 2 + x * r) // (x * t)
            q = k * q
            t = x * t
            x = x + 2
            k = k + 1
            n = b
            r = a

    p = p[0] + "." + p[1:]
    print("pi =", p)

else:
    if c == "R":
        n = int(input())

        k = 0
        p = 0
        while k <= n:
            p = p + (((-3) ** (-1 * k)) / (2 * k + 1))
            k = k + 1
        p = (12**0.5) * p

        p = round(p, 12)
        print("pi =", p)
    else:
        if c == "P":
            p = (7 + (6 + (5**0.5)) ** 0.5) ** 0.5
            p = round(p, 6)
            print("pi =", p)

        else:
            print("Invalid")
```
