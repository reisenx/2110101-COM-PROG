## การเตรียมข้อมูลสามบรรทัด

โปรแกรมรับสตริงสามบรรทัดเป็น `x1`, `x2`, `x3` โดยเรียก `strip()`
กับแต่ละบรรทัด เพื่อตัด whitespace เช่น ช่องว่างหรือแท็บที่อยู่ตรงหัวและท้าย
ของสตริง (`input()` ไม่นำอักขระขึ้นบรรทัดใหม่มาเก็บอยู่แล้ว)
จากนั้นนำทั้งสามสตริงมาต่อกันเป็น `x`

```python
x1 = input().strip()
x2 = input().strip()
x3 = input().strip()
x = x1 + x2 + x3
```

โปรแกรมทำงานต่อเมื่อ `len(x) == 9` เท่านั้น หากความยาวรวมไม่เท่ากับ `9`
จะแสดง `ERROR`

> [!WARNING]
>
> โปรแกรมตรวจเฉพาะ **ความยาวรวมหลังต่อสตริง** ไม่ได้ตรวจว่าแต่ละบรรทัด
> ยาว `3` ตัว ดังนั้นบรรทัดที่ยาวไม่เท่ากัน หรือแม้แต่บรรทัดว่าง
> ก็ยังผ่านได้ถ้าความยาวรวมเท่ากับ `9`

## การแทนกระดานด้วยสตริง

เมื่อความยาวรวมถูกต้อง โปรแกรมมองอักขระทั้งเก้าตัวใน `x`
เป็นช่องตารางขนาด $3\times3$ ตามดัชนีดังนี้

```text
0 1 2
3 4 5
6 7 8
```

ขอบเขตของบรรทัดเดิมไม่มีผลอีกต่อไป เช่น ข้อมูลสามบรรทัดนี้

```text
Ox--xO

-x-
```

จะถูกต่อเป็น `Ox--xO-x-` ซึ่งยาว `9` ตัว และถูกมองเป็น

```text
O x -
- x O
- x -
```

โปรแกรมเปรียบเทียบเพียงว่าอักขระเท่ากันหรือไม่ จึงรองรับอักขระใดก็ได้
ไม่ได้จำกัดเฉพาะ `X` และ `O`

## ลำดับการตรวจหาตัวอักษร

ตัวแปร `i` วิ่งตั้งแต่ `0` ถึง `2` ในแต่ละรอบโปรแกรมตรวจ

1. แถวที่ `i` จากดัชนี $3i, 3i+1, 3i+2$ ด้วย
   `x[3 * i] == x[3 * i + 1] == x[3 * i + 2]`
2. ถ้าแถวนั้นไม่เท่ากัน จึงตรวจคอลัมน์ที่ `i` จากดัชนี
   $i, i+3, i+6$ ด้วย `x[i] == x[i + 3] == x[i + 6]`

ถ้าพบอักขระสามตัวเท่ากัน โปรแกรมเก็บอักขระนั้นใน `win` แล้ว `break`
ออกจากลูปทันที ลำดับการค้นหาจริงจึงเป็น

```text
แถว 0 → คอลัมน์ 0 → แถว 1 → คอลัมน์ 1 → แถว 2 → คอลัมน์ 2
```

หากยังไม่พบค่า `win` โปรแกรมจึงตรวจชุดแนวทแยงตามลำดับ

1. ดัชนี `0`, `4`, `8`
2. ดัชนี `3`, `4`, `6`

> [!WARNING]
>
> ชุดที่สองในโค้ดคือ `3`, `4`, `6` ตามผังงานจริง
> ไม่ใช่แนวทแยงมาตรฐาน `2`, `4`, `6`

เพราะการตรวจชุดที่สองเขียนด้วย `elif` โปรแกรมจะตรวจชุดนี้
เฉพาะเมื่อชุด `0`, `4`, `8` ไม่เท่ากันเท่านั้น

## ค่าเริ่มต้นและผลลัพธ์พิเศษ

โปรแกรมใช้ `win = "-"` เป็นค่าเริ่มต้นเพื่อหมายถึง “ยังไม่พบคำตอบ”
หลังตรวจครบแล้วมีผลลัพธ์สามรูปแบบ

-   ความยาวรวมไม่ใช่ `9` ตัว: แสดง `ERROR`
-   ความยาวรวมเป็น `9` ตัว แต่ `win` ยังเป็น `"-"`: แสดง `???`
-   `win` เป็นอักขระอื่น: แสดงอักขระนั้นหนึ่งตัว

การใช้ `"-"` เป็นทั้งค่าเริ่มต้นและอักขระที่อาจอยู่ในข้อมูลทำให้เกิดกรณีพิเศษ
ถ้าพบ `---` โปรแกรมจะถือว่าอักขระทั้งสามเท่ากันและอาจ `break`
ออกจากลูป แต่ค่า `win` ยังคงเป็น `"-"` จึงยังเข้าสู่การตรวจแนวทแยง
และหากสุดท้ายไม่เปลี่ยนเป็นอักขระอื่นก็จะแสดง `???`

นอกจากนี้ เมื่อพบ `---` ในลูปแล้ว `break` แถวหรือคอลัมน์ลำดับถัดไป
จะไม่ถูกตรวจ แม้ตำแหน่งเหล่านั้นอาจมีอักขระอื่นเรียงกันสามตัวก็ตาม

## ตัวอย่างการทำงาน

**ตัวอย่างบรรทัดไม่เท่ากันแต่ความยาวรวมถูกต้อง**

ข้อมูล `Ox--xO`, บรรทัดว่าง และ `-x-` ถูกต่อเป็น `Ox--xO-x-`
เมื่อไล่ตรวจจะพบ `x` ที่ดัชนี `1`, `4`, `7` ในคอลัมน์ที่ `1`
จึงแสดง `x`

**ตัวอย่างที่แสดงผล `???`**

```text
--x
---
o--
```

เมื่อ `i == 1` โปรแกรมพบแถว `---` จึงเก็บ `"-"` และออกจากลูป
ชุดดัชนี `0`, `4`, `8` ก็เป็น `---` ทำให้ `win` ยังเป็น `"-"`
และไม่ตรวจชุดถัดไปเพราะใช้ `elif` สุดท้ายจึงแสดง `???`

**ตัวอย่างลำดับความสำคัญ**

ถ้าข้อมูลเป็น `###`, `---`, `$$$` โปรแกรมพบ `###` ที่แถว `0`
ก่อนตำแหน่งอื่น จึงแสดง `#` และหยุดค้นหาทันที

# Solution

```python
# --------------------------------------------------
# File Name : P1_Flowchart_04.py
# Problem   : Part-I Flowchart 04
# Author    : Worralop Srichainont
# Date      : 2025-06-16
# --------------------------------------------------

x1 = input().strip()
x2 = input().strip()
x3 = input().strip()

x = x1 + x2 + x3

if len(x) == 9:
    win = "-"
    i = 0

    while i < 3:
        if x[3 * i] == x[3 * i + 1] == x[3 * i + 2]:
            win = x[3 * i]
            break
        elif x[i] == x[i + 3] == x[i + 6]:
            win = x[i]
            break
        else:
            i += 1

    if win == "-":
        if x[0] == x[4] == x[8]:
            win = x[0]
        elif x[3] == x[4] == x[6]:
            win = x[6]

    if win == "-":
        print("???")
    else:
        print(win)

else:
    print("ERROR")
```
