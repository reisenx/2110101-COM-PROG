## แปลงผังงานเป็นคำสั่งเงื่อนไข

โปรแกรมอ่านจำนวนเต็มห้าจำนวนจากบรรทัดเดียวตามคำสั่งที่โจทย์กำหนด

```python
x1, x2, x3, x4, x5 = [int(e) for e in input().split()]
```

ในผังงาน รูปสี่เหลี่ยมข้าวหลามตัดแต่ละรูปคือคำถามที่มีทางออก `Y` (จริง)
และ `N` (เท็จ) เมื่อนำมาเขียนเป็น Python จะใช้ `if` สำหรับทางจริงและ `else`
สำหรับทางเท็จ ส่วนคำถามที่อยู่ถัดลงไปในทางใดทางหนึ่งต้องเยื้องเข้าไป
เป็นเงื่อนไขซ้อนของทางนั้น

เงื่อนไขแรกคือ `x1 - x5 > x2` ซึ่งแบ่งผังงานออกเป็นสองฝั่งหลัก
ตำแหน่งการเยื้องจึงสำคัญ เพราะ `else` แต่ละตัวจะจับคู่กับ `if`
ที่อยู่ระดับการเยื้องเดียวกัน

## เส้นทางเมื่อเงื่อนไขแรกเป็นจริง

เมื่อ `x1 - x5 > x2` เป็นจริง โปรแกรมเข้าฝั่งแรกและตรวจ
`x2 > x3 + x1` ต่อ

-   ถ้า `x2 > x3 + x1` เป็นเท็จ เส้นทางนี้ไปถึงจุดจบโดยไม่แสดงผล
-   ถ้าเป็นจริง โปรแกรมตรวจ `x3 + x5 > x4`
    -   ถ้าเป็นจริง แสดง `C5` เพียงบรรทัดเดียว
    -   ถ้าเป็นเท็จ ตรวจ `x3 < x5` อีกครั้ง ถ้าจริงแสดง `C6`
        มิฉะนั้นแสดง `C7` แล้วทั้งสองเส้นทางจึงแสดง `C8` เป็นบรรทัดถัดไป

โครงสร้างสำคัญของฝั่งนี้คือ `print("C8")` อยู่หลัง `if x3 < x5`
แต่ยังอยู่ภายใน `else` ของ `if x3 + x5 > x4`
ดังนั้น `C8` จะแสดงต่อจากทั้ง `C6` และ `C7` แต่ไม่แสดงต่อจาก `C5`

## เส้นทางเมื่อเงื่อนไขแรกเป็นเท็จ

เมื่อ `x1 - x5 > x2` เป็นเท็จ โปรแกรมตรวจ `x2 - x1 > x3`

-   ถ้า `x2 - x1 > x3` เป็นจริง ใช้ `pass` และจบโดยไม่แสดงผล
-   ถ้าเป็นเท็จ ตรวจ `x4 < x5 + x1`
    -   ถ้าเป็นเท็จ แสดง `C1` เพียงบรรทัดเดียว
    -   ถ้าเป็นจริง ตรวจ `x3 + x2 > x5` ถ้าจริงแสดง `C3`
        มิฉะนั้นแสดง `C2` แล้วทั้งสองเส้นทางจึงแสดง `C4`

ตัวอย่าง `-15 -8 19 0 17` เดินทางดังนี้

1.  `x1 - x5 > x2` คือ `-32 > -8` ซึ่งเป็นเท็จ
2.  `x2 - x1 > x3` คือ `7 > 19` ซึ่งเป็นเท็จ
3.  `x4 < x5 + x1` คือ `0 < 2` ซึ่งเป็นจริง
4.  `x3 + x2 > x5` คือ `11 > 17` ซึ่งเป็นเท็จ

จึงแสดง `C2` ก่อน แล้วแสดง `C4` ในบรรทัดถัดไป ตรงกับตัวอย่างของโจทย์

## เงื่อนไขขอบเขตและเส้นทางที่ไม่มีผลลัพธ์

ทุกเงื่อนไขในโปรแกรมใช้ `<` หรือ `>` แบบเคร่งครัด ถ้าค่าทั้งสองข้างเท่ากัน
ผลของเงื่อนไขจะเป็น `False` และต้องเดินไปทาง `else` เช่น
`x3 + x5 == x4` จะไม่ไปทางที่แสดง `C5`

ผังงานนี้มีสองเส้นทางที่จบโดยไม่เรียก `print()`

1.  เงื่อนไขแรกเป็นจริง แต่ `x2 > x3 + x1` เป็นเท็จ
2.  เงื่อนไขแรกเป็นเท็จ และ `x2 - x1 > x3` เป็นจริง

คำสั่ง `pass` ในเส้นทางที่สองหมายถึง “ไม่ทำอะไร” และช่วยให้บล็อก `if`
มีคำสั่งที่ถูกต้องตามไวยากรณ์ Python จึงไม่มีข้อความพิเศษหรือบรรทัดว่าง
ถูกพิมพ์ออกมา ตัวอย่าง `4 1 3 5 2` ก็ไม่มีผลลัพธ์จากเส้นทางแรกในรายการนี้

## ลำดับของผลลัพธ์หลายบรรทัด

ลำดับการเรียก `print()` เป็นส่วนหนึ่งของคำตอบ เพราะบางเส้นทางมีผลลัพธ์
สองบรรทัด สรุปผลลัพธ์ที่เป็นไปได้ทั้งหมดได้ดังนี้

| เงื่อนไขปลายทาง | ผลลัพธ์ตามลำดับ |
|:---|:---|
| `x3 + x5 > x4` | `C5` |
| `x3 + x5 <= x4` และ `x3 < x5` | `C6` แล้ว `C8` |
| `x3 + x5 <= x4` และ `x3 >= x5` | `C7` แล้ว `C8` |
| `x4 >= x5 + x1` | `C1` |
| `x4 < x5 + x1` และ `x3 + x2 > x5` | `C3` แล้ว `C4` |
| `x4 < x5 + x1` และ `x3 + x2 <= x5` | `C2` แล้ว `C4` |

ในตารางนี้ เงื่อนไขปลายทางต้องอ่านร่วมกับเส้นทางหลักที่อธิบายไว้ด้านบน
เส้นทางที่ไม่มีผลลัพธ์ทั้งสองกรณีไม่ปรากฏในตาราง เพราะไม่มีบรรทัดให้แสดง

# Solution

```python
# --------------------------------------------------
# File Name : P1_Flowchart_01.py
# Problem   : Part-I Flowchart 01
# Author    : Worralop Srichainont
# Date      : 2025-06-16
# --------------------------------------------------

x1, x2, x3, x4, x5 = [int(e) for e in input().split()]

if x1 - x5 > x2:
    if x2 > x3 + x1:
        if x3 + x5 > x4:
            print("C5")
        else:
            if x3 < x5:
                print("C6")
            else:
                print("C7")
            print("C8")

else:
    if x2 - x1 > x3:
        pass
    else:
        if x4 < x5 + x1:
            if x3 + x2 > x5:
                print("C3")
            else:
                print("C2")
            print("C4")
        else:
            print("C1")
```
