## กฎการเปลี่ยนคำนามเป็นพหูพจน์

โจทย์ให้คำนามภาษาอังกฤษตัวพิมพ์เล็กมา 1 คำ แล้วให้เปลี่ยนเป็นรูปพหูพจน์
โดยพิจารณาตัวอักษรท้ายคำตามลำดับดังนี้

| ลักษณะท้ายคำ | วิธีเปลี่ยน | ตัวอย่าง |
|:--|:--|:--|
| ลงท้ายด้วย `s`, `x` หรือ `ch` | เติม `es` | `bus` → `buses`, `box` → `boxes`, `witch` → `witches` |
| ลงท้ายด้วย `y` และตัวก่อนหน้า **ไม่ใช่สระ** | ตัด `y` แล้วเติม `ies` | `memory` → `memories` |
| กรณีอื่น ๆ | เติม `s` | `toy` → `toys`, `book` → `books` |

สระที่โปรแกรมใช้ตรวจสอบถูกเก็บไว้ในตัวแปร `VOWELS`

```python
VOWELS = ["a", "e", "i", "o", "u"]
```

สังเกตว่า `toy` ไม่เปลี่ยนเป็น `toies` เพราะตัวอักษรก่อน `y` คือ `o`
ซึ่งเป็นสระ จึงต้องเข้าสู่กฎสุดท้ายและเติมเพียง `s`

---

## การตรวจสอบตัวอักษรท้ายคำ

Python ใช้ดัชนีติดลบเพื่ออ่านตัวอักษรจากท้ายข้อความ และใช้การ slice
เพื่อเลือกข้อความบางช่วงได้

| นิพจน์ | ข้อความที่เลือก เมื่อ `word = "memory"` |
|:--|:--|
| `word[-1]` | ตัวสุดท้าย คือ `"y"` |
| `word[-2]` | ตัวรองสุดท้าย คือ `"r"` |
| `word[-2:]` | สองตัวสุดท้าย คือ `"ry"` |
| `word[:-1]` | ทุกตัวยกเว้นตัวสุดท้าย คือ `"memor"` |

เงื่อนไขแรกจึงตรวจคำลงท้ายด้วย `s` หรือ `x` ผ่านตัวดำเนินการ `in`
และตรวจ `ch` ด้วยการเปรียบเทียบสองตัวท้าย

```python
if word[-1] in ["s", "x"] or word[-2:] == "ch":
    word += "es"
```

ถ้าเงื่อนไขแรกไม่เป็นจริง โปรแกรมจึงตรวจต่อว่าตัวสุดท้ายเป็น `y`
และตัวก่อนหน้า `not in VOWELS` หรือไม่ ถ้าใช่จะใช้ `word[:-1]` ตัด `y`
ก่อนเชื่อม `"ies"`

```python
elif word[-1] == "y" and word[-2] not in VOWELS:
    word = word[:-1] + "ies"
```

> [!WARNING]
>
> ความเห็นในโค้ด Solution เขียนว่าอักษรก่อน `y` เป็นสระ แต่เงื่อนไขจริงคือ
> `not in VOWELS` ซึ่งหมายถึง **ไม่ใช่สระ** พฤติกรรมของโปรแกรมส่วนนี้ตรงกับกฎในโจทย์

โจทย์รับคำนามที่ถูกต้องตามรูปแบบที่กำหนด โปรแกรมจึงสามารถใช้ `word[-1]`
และ `word[-2]` ได้โดยไม่ตรวจข้อความว่างหรือคำ `y` เพียงตัวเดียวเพิ่มเติม

## ลำดับการทำงานของโปรแกรม

1. รับคำนามด้วย `input()` และใช้ `strip()` ตัดช่องว่างที่หัวและท้ายข้อความ
2. ตรวจท้ายคำตามลำดับ `s`/`x`/`ch` ก่อน แล้วจึงตรวจพยัญชนะตามด้วย `y`
3. ถ้าไม่ตรงสองกรณีแรก ให้เติม `s`
4. แสดงคำนามรูปพหูพจน์ด้วย `print(word)`

การเรียงเงื่อนไขด้วย `if`–`elif`–`else` ทำให้โปรแกรมเลือกทำเพียงกฎเดียว
และแสดงคำตอบเพียง 1 บรรทัด

---

# Solution

```python
# --------------------------------------------------
# File Name : 07_StrFile_11.py
# Problem   : Plural
# Author    : Worralop Srichainont
# Date      : 2025-06-12
# --------------------------------------------------

# List of vowels
VOWELS = ["a", "e", "i", "o", "u"]

# Input a word
word = input().strip()

# Add -es if the word ends with 's', 'x', or 'ch'
if word[-1] in ["s", "x"] or word[-2:] == "ch":
    word += "es"

# Add -ies if the word ends with 'y' and the second last character is a vowel
elif word[-1] == "y" and word[-2] not in VOWELS:
    word = word[:-1] + "ies"

# Otherwise, just add -s
else:
    word += "s"

# Output the plural form of the word
print(word)
```
