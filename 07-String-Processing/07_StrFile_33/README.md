## รูปแบบข้อมูลและลำดับที่ต้องการ

โจทย์ให้ชื่อแฟ้มข้อมูลสองชื่อในบรรทัดเดียว แต่ละบรรทัดภายในแฟ้มประกอบด้วย
เลขประจำตัวนิสิตและเกรดเฉลี่ย คั่นด้วยช่องว่าง เช่น

```text
6231111122 2.45
```

เลขสองหลักท้ายของเลขประจำตัวบอกคณะ ดังนั้นนิสิตตัวอย่างนี้อยู่คณะ `22`
ผลลัพธ์ต้องเรียงตามเงื่อนไขสองระดับ คือ

1. เรียงคณะจากน้อยไปมาก
2. ถ้าอยู่คณะเดียวกัน ให้เรียงเลขประจำตัวนิสิตจากน้อยไปมาก

โปรแกรมเก็บเลขประจำตัวและเกรดเฉลี่ยเป็นสตริงตลอดการทำงาน เนื่องจากเลขประจำตัว
มีจำนวนหลักเท่ากันตามรูปแบบของโจทย์ การเรียงสตริงจึงให้ลำดับเดียวกับการเรียง
ค่าตัวเลข และการเก็บเกรดเป็นสตริงช่วยรักษารูปแบบเดิม เช่น `2.50` ไม่กลายเป็น
`2.5`

## การอ่านและรวมข้อมูลจากแฟ้ม

คำสั่ง `input().strip().split()` แยกชื่อแฟ้มทั้งสองออกเป็นลิสต์ `filenames`
จากนั้นโปรแกรมเปิดอ่านทีละแฟ้มด้วย `with open(filename) as file:` ซึ่งจะปิดแฟ้ม
ให้อัตโนมัติเมื่ออ่านเสร็จ

สำหรับแต่ละบรรทัด คำสั่ง

```python
student_id, grade = line.split()
faculty = student_id[-2:]
students.append([faculty, student_id, grade])
```

ทำงานดังนี้

-   `line.split()` แยกข้อมูลเป็น `student_id` และ `grade`
-   `student_id[-2:]` ตัดสองอักขระท้ายมาเป็นรหัสคณะ
-   `append()` เพิ่มระเบียนรูป `[faculty, student_id, grade]` ลงใน `students`

ตัวอย่างบรรทัด `6231111122 2.45` จะถูกเก็บเป็น
`["22", "6231111122", "2.45"]` เมื่ออ่านครบทั้งสองแฟ้ม ข้อมูลทั้งหมดจึงอยู่ใน
ลิสต์เดียวกันและพร้อมนำไปเรียง

ถ้าแฟ้มใดแฟ้มหนึ่งว่าง วงวน `for line in file` ของแฟ้มนั้นจะไม่ทำงาน
แต่โปรแกรมยังสามารถนำข้อมูลจากอีกแฟ้มไปเรียงและแสดงผลได้ตามปกติ

> [!NOTE]
>
> เอกสารโจทย์แนะนำให้ลองเขียนโปรแกรมโดยไม่ใช้ลิสต์ แต่โค้ดเฉลยนี้เก็บทุกระเบียน
> ใน `students` แล้วเรียงด้วย `sort()` คำอธิบายนี้จึงอ้างอิงพฤติกรรมของโค้ดเฉลย
> ที่ให้มาเป็นหลัก

## การเรียงข้อมูลหลายเงื่อนไข

Python เปรียบเทียบลิสต์แบบเรียงจากสมาชิกตัวแรกไปยังสมาชิกตัวถัดไป
เมื่อเรียก `students.sort()` จึงเกิดการเปรียบเทียบตามลำดับดังนี้

1. เปรียบเทียบ `faculty` ก่อน ทำให้นิสิตเรียงตามคณะ
2. ถ้า `faculty` เท่ากัน จึงเปรียบเทียบ `student_id` ทำให้นิสิตในคณะเดียวกัน
   เรียงตามเลขประจำตัว
3. ถ้าสองค่าแรกเท่ากัน จึงค่อยเปรียบเทียบ `grade`

ตัวอย่างเช่น ระเบียนคณะ `21` จะอยู่ก่อนระเบียนคณะ `22` เสมอ ไม่ว่าจะอ่านมา
จากแฟ้มใด และระหว่างระเบียนต่อไปนี้

```python
["21", "6133333321", "3.20"]
["21", "6032222221", "3.12"]
```

ระเบียนของ `6032222221` จะอยู่ก่อน เพราะรหัสคณะเท่ากัน แล้ว
`"6032222221" < "6133333321"`

การเรียงหลังจากรวมข้อมูลแล้วทำให้ลำดับเดิมของแฟ้มและลำดับชื่อแฟ้มที่รับเข้ามา
ไม่กระทบต่อลำดับผลลัพธ์

## การแสดงผล

หลังเรียงเสร็จ แต่ละระเบียนยังมีรหัสคณะอยู่ที่ตำแหน่งแรก โปรแกรมแยกสมาชิกด้วย

```python
for _, student_id, grade in students:
    print(student_id, grade)
```

ชื่อ `_` สื่อว่าค่านี้มีไว้ช่วยเรียงและไม่ต้องนำไปใช้ต่อ ส่วน `print()` ที่รับ
สองค่า จะแทรกช่องว่างหนึ่งช่องระหว่างเลขประจำตัวกับเกรดโดยอัตโนมัติ
จึงได้ผลลัพธ์หนึ่งระเบียนต่อหนึ่งบรรทัด โดยไม่แสดงรหัสคณะแยกออกมา

เนื่องจาก `grade` ไม่ได้ถูกแปลงเป็น `float` โปรแกรมจึงไม่มีการคำนวณ
หรือปัดเศษ และแสดงเกรดด้วยรูปแบบเดียวกับที่อ่านจากแฟ้ม หากแฟ้มทั้งสองว่าง
ลิสต์ `students` จะว่างและโปรแกรมจะไม่แสดงบรรทัดใดเลย

# Solution

```python
# --------------------------------------------------
# File Name : 07_StrFile_33.py
# Problem   : File Merge
# Author    : Worralop Srichainont
# Date      : 2025-06-12
# --------------------------------------------------

# Input file names
filenames = input().strip().split()

# Initialize a list to store student data
students = []

# Read each file and append the data to the students list
for filename in filenames:
    with open(filename) as file:
        for line in file:
            student_id, grade = line.split()
            faculty = student_id[-2:]
            students.append([faculty, student_id, grade])

# Sort the students list by faculty and then by student ID
students.sort()

# Output the sorted student data
for _, student_id, grade in students:
    print(student_id, grade)
```
