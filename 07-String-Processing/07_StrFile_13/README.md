## หลักการเขียน camelCase

`camelCase` คือการนำคำหลายคำมาต่อกันโดยไม่เว้นวรรค คำแรกเขียนด้วยตัวพิมพ์เล็ก
ส่วนคำถัดไปเปลี่ยนตัวอักษรตัวแรกเป็นตัวพิมพ์ใหญ่ เช่น
`"computer programming"` กลายเป็น `"computerProgramming"`

โจทย์อาจคั่นแต่ละคำด้วยช่องว่างหรือสัญลักษณ์ โปรแกรมจึงต้องทำงาน 2 ส่วนใหญ่ ๆ
คือแยกข้อความออกเป็นคำก่อน แล้วค่อยปรับและเชื่อมคำเหล่านั้นกลับเข้าด้วยกัน

---

## การแยกข้อความออกเป็นคำ

เมื่อรับข้อมูล โปรแกรมใช้ `strip()` ตัดช่องว่างที่หัวและท้ายข้อความ
แล้วใช้ `lower()` เปลี่ยนตัวอักษรทั้งหมดเป็นตัวพิมพ์เล็ก

```python
text = input().strip().lower()
```

จากนั้นวนดูทีละอักขระด้วย `for char in text` หาก `char.isalnum()` เป็นจริง
แสดงว่าอักขระนั้นเป็นตัวอักษรหรือตัวเลข จึงเก็บไว้ตามเดิม แต่ถ้าเป็นช่องว่าง
หรือสัญลักษณ์ โปรแกรมจะแทนที่ด้วยช่องว่าง 1 ตัว

```python
if char.isalnum():
    new_text += char
else:
    new_text += " "
```

ดังนั้นสัญลักษณ์ทำหน้าที่เป็น **ขอบเขตระหว่างคำ** ไม่ได้ถูกลบแล้วนำข้อความ
สองฝั่งมาติดกันทันที ตัวอย่างเช่น `"a-b"` จะถูกเตรียมเป็น `"a b"`
และนำไปสร้างผลลัพธ์ `"aB"`

คำสั่ง `new_text.split()` จะแยกข้อความตามช่องว่าง และไม่สร้างคำว่างแม้มี
ช่องว่างหรือสัญลักษณ์หลายตัวติดกัน เช่น `"one---two"` ยังแยกได้เป็น
`["one", "two"]`

## การประกอบคำเป็น camelCase

คำแรกใน `words` เป็นตัวพิมพ์เล็กอยู่แล้ว โปรแกรมจึงเริ่มวนจากดัชนี `1`
เพื่อเปลี่ยนเฉพาะอักษรตัวแรกของคำที่สองเป็นต้นไป

```python
for i in range(1, len(words)):
    words[i] = words[i][0].upper() + words[i][1:]
```

ในแต่ละคำ `words[i][0]` คืออักษรตัวแรก และ `words[i][1:]` คือส่วนที่เหลือ
เมื่อปรับครบแล้ว `"".join(words)` จะเชื่อมทุกคำโดยไม่มีตัวคั่น

ลองพิจารณาข้อความ `"True" or "False"` ทีละขั้นตอน

| ขั้นตอน | ค่า |
|:--|:--|
| หลัง `lower()` | `"true" or "false"` |
| หลังแทนสัญลักษณ์ด้วยช่องว่าง | `" true  or  false "` |
| หลัง `split()` | `["true", "or", "false"]` |
| หลังปรับคำตั้งแต่ดัชนี `1` | `["true", "Or", "False"]` |
| หลัง `join()` | `"trueOrFalse"` |

ตัวเลขผ่าน `isalnum()` และถูกเก็บไว้ ส่วนการเรียก `upper()` กับตัวเลข
จะไม่เปลี่ยนค่า เช่น `"version 2 test"` ให้ผลลัพธ์เป็น `"version2Test"`

> [!NOTE]
>
> ถ้าข้อมูลมีแต่ช่องว่างและสัญลักษณ์ `split()` จะได้ลิสต์ว่าง
> และ `"".join(words)` จะเป็นข้อความว่าง โปรแกรมจึงแสดงบรรทัดว่างโดยไม่เกิด error

## ลำดับการทำงานของโปรแกรม

1. รับข้อความ ตัดช่องว่างหัว–ท้าย และเปลี่ยนเป็นตัวพิมพ์เล็ก
2. เก็บตัวอักษรกับตัวเลขไว้ และแทนอักขระอื่นทุกตัวด้วยช่องว่าง
3. ใช้ `split()` แยกข้อความที่เตรียมแล้วเป็นคำ
4. เปลี่ยนอักษรแรกของคำลำดับที่ 2 เป็นต้นไปเป็นตัวพิมพ์ใหญ่
5. ใช้ `join()` เชื่อมทุกคำโดยไม่เว้นวรรค แล้วแสดงผล 1 บรรทัด

# Solution

```python
# --------------------------------------------------
# File Name : 07_StrFile_13.py
# Problem   : Camel Case
# Author    : Worralop Srichainont
# Date      : 2025-06-12
# --------------------------------------------------

# Input a text as lowercase string
text = input().strip().lower()

# Remove all symbols and split the text into words
new_text = ""
for char in text:
    if char.isalnum():
        new_text += char
    else:
        new_text += " "

# Convert all words to camel case
words = new_text.split()
for i in range(1, len(words)):
    words[i] = words[i][0].upper() + words[i][1:]

# Output the CamelCase string
print("".join(words))
```
